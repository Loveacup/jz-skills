# WRR 事实核查集成：政策/新闻类 B站 视频

> 适用于：UP 主对公共政策、教育改革、社会新闻等「可验证声明类」内容做解读的视频。
> 不适用于：纯个人观点 / Vlog / 娱乐 / 创作类视频（这些没有"可验证事实"可查）。

## 何时触发

当视频满足以下任一条件时，在 Phase 2 分析阶段自动启用 WRR 事实核查：

- 标题含政策关键词：政策 / 改革 / 取消 / 出台 / 发布 / 新规 / 通知
- 内容涉及可验证声明：政府决定 / 官方数据 / 法律条文 / 教育部文件 / 地方试点
- UP 主以"专家/教师/内部人士"身份做断言式解读
- 弹幕或评论中出现大量质疑（"标题党""营销号""卖课"等）

## 核查流程

### Step 1: 提取可验证声明 (Claim Extraction)

从转录文本中提取所有**可被独立验证的事实声明**，忽略观点和预测。每条声明标注：
- 时间戳
- 原文措辞
- 预期权威来源类型（教育部官网 / 新华社 / 地方政府公告 / 统计数据等）

示例（本会话 BV12W7Z69EXX）：
| 声明 | 时间 | 预期来源 |
|:---|:---|:---|
| "中考取消这是大概率板上钉钉了" | 0:15 | 教育部文件 |
| "北京中考...取消生物地理历史化学四门计分科目" | 1:39 | 北京市教委 |
| "2月5日基础教育工作会议明确...每日两小时体育活动" | 1:07 | 教育部部署会 |
| "上海中学早就已经实行二加四学制" | 2:16 | 上海市教委/上中官网 |

### Step 2: WRR 多引擎交叉验证

使用 WRR `grounding` 模式（双主力 Exa + Brave），对每条声明逐一验证：

```bash
# 中文政策类推荐引擎组合
# Primary: Brave (独立索引，对中国政府网站覆盖好) + Exa (语义精准)
# 搜索词策略: 使用具体政策名称 + 年份 + "官方" 做 exact match
```

- 中文政策声明 → Brave + web_search（中国政府网站对 Brave 索引友好）
- 技术/API 声明 → Exa + Brave
- 地方试点 → Brave（覆盖地方新闻网站）
- 统计数据 → Exa + Tavily（结构化抽取）

### Step 3: 声明-来源对照表

为每条声明生成对照结果：

| 标记 | 含义 | 示例 |
|:---|:---|:---|
| ✅ 属实 | ≥2 个权威来源一致确认 | "教育部2月5日会议要求每天2小时体育" |
| 🟡 夸大 | 事实部分正确但被扭曲/灾难化解读 | "北京取消四科计分"（实为等级制改革） |
| 🔴 不实 | 无权威来源支撑或与权威来源矛盾 | "上海中学实行2+4学制"（上中官网明确三年制） |
| ⚪ 无法验证 | 无法找到任何可信来源 | "教育内部出现坏人"（阴谋论） |

### Step 4: 写入报告

- **§3 核心洞察**：至少一条洞察专门聚焦"事实偏差"（而非仅分析叙事技巧）
- **§7 批判审视**：在"局限与偏见"中评估 UP 主的信息可信度
- **§8 附录**：完整的 Source Map 表格（ID / 来源 / 核心事实 / URL），格式如下：

```markdown
| ID | 来源 | 核心事实 | URL |
|:---|:---|:---|:---|
| s1 | 新华网 | 教育部2026年2月5-6日全国基础教育部署会... | https://... |
| s2 | 新京报 | 嵊泗县教育局明确"取消中考选拔功能不是取消中考" | https://... |
```

## 注意事项

- **不要把所有 video claims 都当作"待验证声明"**——只提取有具体外延的可验证声明（政策/数据/事件），观点/预测/建议不需要验证
- **弹幕是事实核查的"众包信号"**——如果大量弹幕指向"标题党""卖课"，说明受众已识别出信息问题，这本身就是有价值的数据
- **政策类搜索优先用中文关键词**——英文搜索对中国政策文件覆盖极差（Brave 和 Exa 对 Chinese gov sites 的中文检索效果优于英文翻译）
- **标注置信度**：双源一致 = 高置信；单源 = 中；仅有自媒体转载 = 低 / 不采用
