# 反 AI 味黑名单（Khazix 验证）

> 来源：[[khazix-writer 写作风格分析]]。卡兹克在 4000-8000 字长文里实战验证过的具体词表。

## AI 标志性词汇黑名单
- 说白了 / 本质上 / 换句话说
- 意味着什么 / 这意味着
- 不可否认 / 综上所述 / 总的来说
- 值得注意的是 / 不难发现

## 教科书引导腔黑名单
- 让我们来看看 / 接下来让我们
- 下面我来介绍 / 首先需要了解
- 在当今 AI 时代 / 随着技术不断进步

## 空泛指代禁令
- 禁：AI 工具 / 某个模型 / 相关技术
- 必须：落到具体名字（Claude / GPT-5 / Cursor / Manus 等）

## 假设性例子禁令
- 禁：「比如有一次..."（编造场景）
- 必须：「我今天正在做的 xxx」或诚实说「我没试过，但想想就 xxx」

## 中文排版规则
- 冒号 ":" 在正文里换成逗号或句号
- 双引号 "" 换成「」
- 破折号 "——" 慎用

## 结构反膨胀
- 加粗 > 2 行 = 过度结构化（短文 ≤ 3 处）
- bullet > 3 条 = 改散文（短文 ≤ 2 条）
