# 关系与合盘分析

## 目标与边界

关系分析关注两个人各自提供的现实经验、彼此如何沟通，以及传统体系可供参考的文化解释。它不计算关系成功率、婚配分数或“最佳类型”，不预测关系必然发生/结束，也不从传统排盘的 `m` / `f` 计算参数推定现实性别、伴侣称谓或关系角色。

合盘双方使用各自独立的出生资料与人格资料。资料按分析层分别标记：

```json
[
  {
    "status": "available",
    "input_refs": [],
    "observations": [],
    "limits": []
  },
  {
    "status": "unavailable",
    "input_refs": [],
    "observations": [],
    "limits": ["对应资料未提供"]
  }
]
```

每层 `status` 只能是 `available` 或 `unavailable`。只有对应输入可用时才写该层观察；缺资料就说明缺口与不可回答之处，不给默认低分、不造占位路径，也不把某一层结果补成另一层的结果。任何结论均不得跨人复用对方的出生时刻、量表分或经历。

## 先从现实互动开始

先记录读者明确提供的关系问题、实际互动例子、双方表达与需要；区分观察和解释。不要由类型或盘面虚构某人的依恋方式、冲突历史、吸引力或对方意图。对每个重要假说，考虑另一种可能解释，并指出什么实际反馈会改变判断；无法验证时如实写“尚无法检验”。

传统层面可以在各自体系语境中完整说明八字、紫微、占星的关系象义或流派解释，并注明输入、规则与限制；不把它们当作双方已被测量出的心理特质，不证明匹配度或关系结局，也不必一概转写成自我观察问题。现实沟通与行动建议另依据双方实际提供的互动、目标和边界提出，不由传统象义直接推出。

## 合成沟通示例

以下仅为合成示例，不代表真实个案或普遍类型规律：

> 合成样本A说：“意见不同的时候，我想先把问题拆成几步。”合成样本B说：“我需要先确认这件事对彼此意味着什么。”这段材料可以提出一个待观察的问题：两人是否需要不同的谈话起点。一次低风险尝试是先各用一句话说明当前最在意的部分，再共同选一个具体问题讨论。若其中一人觉得这会让交流更困难，就停止该做法并改问双方更舒服的节奏。

这个例子只展示如何从提供的对话观察提出可修订的沟通尝试；不能反推样本的类型、功能栈或固定关系模式。

## 双向行动

行动建议应同时尊重双方的意愿与边界，并写清目标、触发条件、观察问题和调整/停止方式。不要要求一方独自负责修复关系；不要把差异浪漫化成“互补必然成长”，也不要把冲突写成注定不合。关系是否继续、采取何种称谓或形式，由当事人现实选择决定。

## 未成年人

未成年人关系主题仅讨论家庭、同伴、师长、沟通与个人边界。不得描写未来婚恋对象、婚恋年份、婚配结局或性化推断；不得因为资料空缺就声称“尚未恋爱”。面向监护人的内容只在受众明确包含监护人时写出，不以成人婚恋框架替代孩子实际提出的问题。
