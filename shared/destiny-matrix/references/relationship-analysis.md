# 关系/合盘分析方法论

## 三维合盘框架

关系分析需要将两人的三维数据进行交叉比对，找出互补点、冲突点和共振点。

## 维度一：荣格认知功能合盘

### 功能互补模式

| 模式 | 组合特征 | 关系动态 |
|:---|:---|:---|
| 镜像型 | 双方功能栈高度相似 | 相互理解但缺乏新鲜感 |
| 互补型 | 一方强项为另一方弱项 | 相互成长但需要包容差异 |
| 对立型 | 功能偏好完全相反 | 高张力但高成长潜力 |
| 影子型 | 一方的阴影功能是另一方的主导 | 深层吸引但容易投射 |

### 经典互补组合

| 组合 | 互补逻辑 | 关系特点 |
|:---|:---|:---|
| INFJ + ENTP | Ni-Fe vs Ne-Ti | 深度洞察与创新思维碰撞 |
| INTJ + ENFP | Ni-Te vs Ne-Fi | 战略规划与创意探索平衡 |
| INFP + ENTJ | Fi-Ne vs Te-Ni | 价值深度与执行力互补 |

### 功能冲突热点

| 冲突 | 表现 | 化解方向 |
|:---|:---|:---|
| Te vs Fi | 效率vs价值观 | 尊重对方的决策框架 |
| Fe vs Ti | 情感vs逻辑 | 先共情再分析 |
| Ne vs Si | 新可能vs旧经验 | 创新中保留有效传统 |
| Se vs Ni | 当下vs未来 | 兼顾眼前体验和长远规划 |

## 维度二：八字合盘

### 日柱关系

| 关系 | 含义 | 示例 |
|:---|:---|:---|
| 天合地合 | 最佳婚配（天干合+地支合） | 甲子+己丑 |
| 天干合 | 性格互补，有吸引力 | 甲+己，乙+庚 |
| 地支合 | 生活方式兼容 | 子丑合，寅亥合 |
| 天克地冲 | 冲突激烈，需要大量磨合 | 甲子+庚午 |

### 天干五合

甲己合化土、乙庚合化金、丙辛合化水、丁壬合化木、戊癸合化火

|:---|:---|:---|
| 缺火 | 火旺 | 温暖·表达·活力 |
| 缺水 | 水旺 | 智慧·灵活·滋养 |
| 缺木 | 木旺 | 成长·创造·仁慈 |
| 缺金 | 金旺 | 决断·逻辑·收敛 |
| 缺土 | 土旺 | 稳定·包容·落地 |

## 维度三：星座合盘

### 日月交叉相位

| 组合 | 含义 |
|:---|:---|
| A的太阳合B的月亮 | 最佳情感共鸣，A照亮B的内在 |
| A的太阳冲B的月亮 | 吸引力强但张力大 |
| A的月亮合B的月亮 | 情感需求一致，居家和谐 |
| A的太阳合B的太阳 | 生日相近，志同道合 |

### 元素匹配

优先级：同元素 > 互补元素 > 中性 > 对立元素

| 匹配类型 | 组合 | 特点 |
|:---|:---|:---|
| 和谐 | 火+风 / 土+水 | 自然流动，相互支持 |
| 互补 | 火+土 / 风+水 | 需要努力但回报高 |
| 对立 | 火+水 / 风+土 | 高张力，需要大量沟通 |

## INFJ + ENTP 特殊专题

（因命主 Alex 为 INFJ-A，此处提供 INFJ 相关合盘参考）

### INFJ-ENTP 认知互补

| INFJ 功能 | ENTP 功能 | 互动模式 |
|:---|:---|:---|
| Ni（主导） | Ne（主导） | 深度洞察 vs 广度探索——互相拓展视野 |
| Fe（辅助） | Ti（辅助） | 情感共鸣 vs 逻辑分析——互补但需磨合 |
| Ti（第三） | Fe（第三） | 双方都在发展的功能——共同成长点 |
| Se（劣势） | Si（劣势） | 共同弱点——可能一起忽略实际细节 |

### 关键互动建议

1. INFJ 需要理解 ENTP 的"跳跃思维"不是不认真，而是 Ne 在工作
2. ENTP 需要理解 INFJ 的"沉默"不是冷漠，而是 Ni 在深度处理
3. 冲突时 INFJ 倾向回避（Fe保护），ENTP 倾向辩论（Ti探索）——需要建立"安全对话"机制
4. 共同成长方向：一起发展 Se/Si——如户外活动、烹饪、手工等感官体验
