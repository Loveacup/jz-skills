# 西方占星学分析框架

> **v2 计算引擎**：本框架的核心排盘由 `scripts/astro_calc.py` 完成，基于 `pyswisseph`（瑞士星历表的 Python 绑定，业界标准）。输出 10 大行星 + 北交点 + 凯龙星 + 12 宫宫始 + 上升 / MC + 主要相位。
>
> **典型调用**：
> ```bash
> python3 scripts/astro_calc.py 1993-09-30 17:30 30.27 120.16 8
> # 参数: yyyy-mm-dd hh:mm 纬度 经度 时区
> ```
>
> 输出 JSON 包含：三轴心（太阳/月亮/上升/MC）、十二行星位置（含落宫与逆行）、十二宫宫始与宫主、主要相位列表（合冲三四六）。

## 上承《果老星宗》

本 skill 之所以将占星纳入四维框架，是因为占星与四柱合参在中国传统命理学中**有典籍依据**——上承《果老星宗》"星命合参"传统：

> 命主以四柱为体，星宗以七政为用；体用相参，方知全貌。

四柱看"命"——能量结构、格局高低；占星看"运"——星辰行度、应期窗口。两者并陈，是完整命理路径，而非现代拼接。详见 `references/classical-texts.md` 第七节。

## 三轴心：太阳·月亮·上升

占星论命的根本三角形：

| 轴心 | 意义 | 比喻 |
|:---|:---|:---|
| **太阳** | 自我意识·生命力·父亲原型·人生目的 | 你这一生要"活成谁" |
| **月亮** | 情感模式·内在安全感·母亲原型·童年印记 | 你独处时是谁 |
| **上升** | 外在形象·第一印象·身体气场·与世界相遇的方式 | 你穿在外面的"衣服" |

**三轴互动**：
- **太阳=月亮**（同星座/三合）：内外一致，安宁但缺张力
- **太阳冲月亮**（180° 对冲）：内外拉扯，存在感强，命题是"整合对立"
- **太阳=上升**：表里一致，单纯但容易被看透
- **上升与太阳冲**：你想成为的人和别人看到的你不一样

### 个人行星 vs 社会行星 vs 世代行星

- **个人行星**（太阳、月亮、水、金、火）：个人独有，决定个性
- **社会行星**（木、土）：定义生涯节奏与社会角色
- **世代行星**（天、海、冥）：同代人共有，定义时代主题

世代行星只有当它们落入"个人行星 / 角宿（1/4/7/10 宫）/ 与个人行星形成相位"时，才对个人有显著影响。

## 行运（Transits）— 时间命题

行运指**当下天空的行星**对**本命盘**的影响。各行星的行运周期不同：

| 行星 | 周期 | 触发事件类型 |
|:---|:---|:---|
| 木星 | 12 年回归一次 | 扩张·机会·乐观期 |
| 土星 | 29.5 年回归（28-30岁、56-60岁是"土星回归"）| 重大成熟考验·人生分水岭 |
| 天王星 | 84 年（中点 42 岁是"天王对冲"）| 中年危机·突破期 |
| 海王星 | 165 年（约 41-42 岁四分本命）| 边界消融·灵性觉醒 |
| 冥王星 | 248 年（约 36-40 岁四分本命）| 彻底转化·灵魂的暗夜 |

**重要节点**：

- **第一次土星回归（28-30 岁）**：被命运叩问"你成熟了吗？"
- **天王星对冲本命（42 岁）**：中年危机典型期
- **冥王星四分本命（36-40 岁）**：核心身份的死亡与重生

行运的查询方法：将"今天的天空"作为新数据传入 pyswisseph，得到当下行星位置，再与本命盘对比，找显著相位。

## 推运（Progressions）— 内在演化

不同于行运（外在事件），推运表示内在心理的展开节奏。

最常用的是"次限推运"（Secondary Progression）：**出生后 N 天的天空 = 命主 N 岁时的内在状态**。

例：1993-09-30 出生的人，2026 年（33 岁）的次限推运盘 ≈ 1993-11-02 的天空。

推运月亮约 27-28 年走完黄道一圈，每 2.3 年换一个星座——决定每两三年的"心情主调"。

`astro_calc.py` 当前不直接输出推运盘；需要时，把推运对应的"出生后 N 天"作为新输入再排一次。

## 与四柱·紫微的合参要点

四维交叉时，占星贡献以下独特视角：

1. **心理层面**（其他三系较少）：童年原型、情绪暗流、潜意识
2. **西洋时间节点**：土星回归、天王对冲、冥王转化——与八字大运、紫微大限并列
3. **关系动力**（最强）：金星 / 月亮 / 7 宫的细致触感——超越紫微夫妻宫的星象层面
4. **世代背景**：天王/海王/冥王的同代人共题——补充个人命格之外的时代脉络

**典型四维印证示例**：

> 八字"伤官见官"——克夫之象
> 紫微"夫妻宫破军化禄"——感情中的破局者
> 占星"金星四分火星"——爱与攻击的张力
> 荣格"Fi 极高"——对感情的内在标准苛刻
>
> 四道力同向 → 命运密码 = "感情中必须主导，无法被驯服"
