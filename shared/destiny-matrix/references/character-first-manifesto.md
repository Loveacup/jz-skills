# 以人为本宣言

## 立场

这本书写给一个具体的人。阅读主线是读者本人的自述、关切、选择与可以尝试的行动；人格资料、八字、紫微、占星是四个各自成立的视角，每个视角都要在自己的传统里把话说明白，再围绕读者的同一个问题放到一起看。

人格这一层的任务，是告诉读者“这组分数的人是什么样”。做法是由分数轮廓提出类型假说，讲清主导与辅助怎样搭配、哪根轴拉得最开、劣势功能落在哪里，再给备选和一个读者可以自己检验的对照。报完分数就收笔，等于什么也没说。

命书可以保留诗性与传统文化语言。“性格即命运”“命运密码”一类说法是文学表达，用作意象，不当作因果定律。

## 人格资料的构念与读法

`personality_input.construct` 按实际来源标注，读法各不相同，细则见 `character-inference-workflow.md`，知识与推读路径见 `cognitive-functions.md`。

- `functions8`：直接提供的八功能分数。由分数轮廓定类型假说、功能栈与备选。
- `subtypes16`：十六亚型分数（如 JUNGUS 第二代测验）。两亚型取均值得功能分，再定类型假说；亚型方向另读。
- `mbti_type`：自述或报告上的四字母类型。按类型展开功能栈来读，说明这是自述类型，没有分数可以对照。
- `neris5`：16Personalities 的五维结果。该测验不分配功能栈，按五个维度本身来读，不换算成八功能分。参见 [16Personalities for AI](https://www.16personalities.com/for-ai)。
- `interview`：访谈中的具体自述与例子。按情境记录，可以据此提出类型假说，说明依据是自述而不是测验。
- `none`：没有人格资料。先给一次访谈机会；人格层不由出生盘、年龄或分析师的直觉来填。

`instrument`、`version`、`test_date`、`scale_min`、`scale_max` 未知时保留 null，不猜。

## 假说的分寸

类型假说要说得明确，也要让读者能够推翻它。三件事一起出现：结论（这组分数最贴合哪一型）、依据（分数表上指得出的两三处）、对照（一个情境，两种反应，落空的一支指向备选）。当事人提供的观察和反例优先于分数推演。

倾向写成在某些场合出场的做法，不写成身份。分数说的是偏好，做得好不好要看具体的事。

## 多维分析与写作

各体系先按自己的推读路径独立读完，再做综合。综合可以写汇聚：几种读法在同一主题上落到相近的地方，就直接写出来，并说明各自看的是哪一层。各体系是相互独立的传统，相近不等于科学证明，这句话在综合章开头说一次。分析阶段各席位互不通气，不拿预设的人格结论去别的盘里找印证。

传统术语与文化意象在它自己的语境里讲完整。好的人格分析具体到情境，容得下反例，并在用得上的地方给读者可以选择、观察、调整或停止的行动。

## 发展与关系

Beebe 的原型位置与 Quenk 的压力反应（Grip）是有名有姓的理论，用时点明出处，写成“在类型理论里，这一型常被描述为……”的条件句。功能的位置说的是偏好的次序；年龄阶段表不用来推定某个人走到了哪一步。

已知的人生事件帮助理解读者在问什么，也可以用来检验描述贴不贴合；它们不用来反推出生时间，也不算预测命中。出生时间只在有新的出生记录或家人原始记忆时修订，并保留依据与前后差异。

## 红线

1. 不由分数、类型或盘面推断疾病、身体状况、寿命、生育，不作心理或医学诊断。
2. 不承诺确定事件，不给关系成功率或匹配总分。
3. 不编造分数、类型、引文、出处与当事人的经历。
4. 未成年读者：关系只谈家庭、同伴、师长与边界，事业只谈学习与兴趣；不写婚恋对象与年份，不性化；正文不出现四字母类型名，不贴能力标签，类型名只进监护人段或附录。面向家长的文字仅在受众包含监护人时提供。
5. 不向外部站点提交个案资料，不把个案写进跨会话记忆或公共参考资料。
6. 类型假说是对自评分数的读法，不写成科学定论；不由出生盘生成人格分数。
