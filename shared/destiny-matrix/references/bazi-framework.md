### 计算起运岁数

**顺行**：从出生日计算到下一个**节气**的天数 ÷ 3 = 起运虚岁
**逆行**：从出生日计算到上一个**节气**的天数 ÷ 3 = 起运虚岁

注意：这里用的是12个"节"（立春、惊蛰、清明、立夏、芒种、小暑、立秋、白露、寒露、立冬、大雪、小寒），不是"气"。

### 排大运

从月柱开始，顺行则取下一个干支，逆行则取上一个干支。每运管十年。

## sxtwl 精确排盘（Python）

**日柱必须用此方法计算，不可手算。**

```python
import sxtwl  # pip install sxtwl --break-system-packages
HS = ['甲','乙','丙','丁','戊','己','庚','辛','壬','癸']
EB = ['子','丑','寅','卯','辰','巳','午','未','申','酉','戌','亥']

d = sxtwl.fromSolar(year, month, day)
yGZ, mGZ, dGZ = d.getYearGZ(), d.getMonthGZ(), d.getDayGZ()
# 年柱: HS[yGZ.tg] + EB[yGZ.dz]
# 月柱: HS[mGZ.tg] + EB[mGZ.dz]
# 日柱: HS[dGZ.tg] + EB[dGZ.dz]
# 农历: d.getLunarMonth(), d.getLunarDay()

# 时柱天干: 甲己→甲, 乙庚→丙, 丙辛→戊, 丁壬→庚, 戊癸→壬
hour_start = {0:0,1:2,2:4,3:6,4:8,5:0,6:2,7:4,8:6,9:8}
hour_stem = (hour_start[dGZ.tg] + hour_branch_idx) % 10
```

## 穷通宝鉴·十天干调候用神速查

**调候原则**：秋冬生人寒湿，以火暖之；春夏生人燥热，以水润之。调候为急，先其所急。

### 调候用神的判定步骤（加入Phase 2分析流程）

1. 确定日主五行+出生月份
2. 查穷通宝鉴对应表，找到调候用神
3. 检查命局中是否有调候用神：
   - **有且有力** → 命局调候到位，格局加分
   - **有但弱** → 大运行至调候用神旺地时发达
   - **完全没有** → 命局偏枯，需大运补充，否则一生难展
4. 将调候用神与格局用神对比：
   - 调候=格局用神 → 最佳（一举两得）
   - 调候≠格局用神 → 需权衡，通常调候为急
