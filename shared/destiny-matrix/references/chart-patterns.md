# 图表模式库（v5）：P01–P17

本库是图表表达的索引，不是配额。规划图表前先确认它回答一个具体问题、使用了真实可追溯资料，并比正文或简单表格更易理解；不适合图示的数据直接用文字或表格。不得为满足数量、章节或“锚点”要求凑图。

## 1. 所有模式共用的发布合同

每个图表均放在语义章节内，采用以下结构；`figure`、`figcaption`、数据绑定和辅助表不能省略：

```html
<figure class="chart-container" data-chart-id="chart-<section_id>-01" data-representation="computed">
  <figcaption id="chart-example-caption">图题：说明实际表达的问题与单位</figcaption>
  <p class="chart-description" id="chart-example-description">简短文字说明主要关系；不要求读者只看颜色理解。</p>
  <div class="chart-scroll" role="region" tabindex="0" aria-labelledby="chart-example-caption" aria-describedby="chart-example-description">
    <svg role="img" aria-labelledby="chart-example-caption" aria-describedby="chart-example-description" viewBox="0 0 400 240" xmlns="http://www.w3.org/2000/svg">
      <!-- 仅放基于真实输入/计算或明确标注的定性关系图形。 -->
    </svg>
    <table class="chart-data">
      <caption>图中数据（保留原值和单位）</caption>
      <thead><tr><th scope="col">项目</th><th scope="col">值</th></tr></thead>
      <tbody><tr><th scope="row">合成项目</th><td data-value-ref="fixture#/values/item" data-value="12" data-unit="分" data-precision="0">12 分</td></tr></tbody>
    </table>
  </div>
  <p class="chart-note">来源：合成验收数据；仅演示结构。</p>
</figure>
```

- `data-chart-id` 形式为 `chart-<section_id>-<两位连续序号>`；section_id 用固定语义 ID。图表 ID 在全书唯一，并与规划表一一对应。
- `data-representation` 必须为 `measured`、`computed` 或 `qualitative`。数值必须从实际输入或计算产物绑定，`data-value-ref` 形如 `<artifact_id>#<json_pointer>`，同一值还需有 `data-value`、`data-unit`、`data-precision`，并与读者可见标签、辅助表一致。文字建议不应伪装成精确计算量。
- 定性图标注“概念示意”，只表达有依据的类别/关系，不造连续数值、运势曲线、成功概率、置信度或时间刻度。缺值采用 `omit_with_disclosure`：说明缺项、不补零、不插值、不闭合雷达。八维数据不全时改为仅列已知值的表格并明确缺项。
- 图表必须有可读表格或等效逐项文本；复杂图的 `aria-label` 不能替代数据与关系说明。键盘可聚焦的 `.chart-scroll` 只允许图表局部横向滚动，整页不得横移。
- 使用系统字体，不加载网络字体。判断字号要以变换后屏幕/PDF的实际尺寸为准，不能仅依据 SVG 源码字号。手机上保留最小可读画布和局部滚动，绝不把图压到约 4px 字号。PDF 实际高度超过 240mm 的图由作者按语义拆成并登记的子图，不由导出器缩放。
- 色彩须符合模板对比度要求并配合文本、标记或线型。`#d5d2c8` 只用于装饰线，不能用于文字、关键图形或唯一的数据区分。
- 占星轮须由真实宫始黄经与上升点生成，调用 `chart_data.py wheel --cusps <12个宫始黄经> --asc <deg>`；不使用等分假宫线。
- 五行比例只称“该规则下的元素分布”，不能称实测能量；偏好量表不解释为能力差、风险或成熟度。禁止 Grip 风险星数、关系匹配星级、实测能量/运势百分比等图例。

## 2. 模式索引

| ID | 模式 | 主要用途 | 表达边界 |
|---|---|---|---|
| P01 | 雷达图 | 完整且同量程的多维数值 | 任一维缺值时不得补零或闭合；不完整时改表格 |
| P02 | 分组条形图 | 同构类别与单个数值比较；五行原始比例 | 明示量程、单位、零点与排序规则；五行只用一组共零点横条并配数表，不解释为能量或能力 |
| P03 | 并列/堆叠条形图 | 同尺度下的分类构成或组间比较 | 仅在数据构成完整且可比时堆叠；缺项披露 |
| P04 | 定性过程示意 | 解释非量化的过程/阶段关系 | 标“概念示意”；不加虚构刻度、风险值或概率 |
| P05 | 同心层级/原型关系图 | 展示明确说明的理论分类关系 | 理论框架，不表示测得强度、诊断或时间成熟顺序 |
| P06 | 紫微十二宫格盘 | 展示完整十二宫盘面及宫位关系 | 使用固定地支位置的 4×4 外围十二格；真实宫名、主星、生年四化，命/身宫以边框文字强调，空宫明确标出 |
| P07 | 占星轮 | 展示真实行星、轴点、宫始与黄道位置 | 宫始接真实计算结果，MC 按实际黄经放置；标宫制与时刻口径 |
| P08 | 结构化数据表 | 精确多字段、相位、排盘/周期明细 | 标来源、单位、有效范围；长表允许分页 |
| P09 | 有向关系/流向图 | 少量有来源的源→目标关系 | 每条边需有实际依据；箭头不意味着因果 |
| P10 | 状态关系图 | 离散状态及允许的转移/反馈关系 | 无真实测量时标概念示意，不给频率或风险等级 |
| P11 | 多轨时间轴 | 有明确端点的周期区间与不同来源时间事件 | 仅同一时间语义且端点明确时共轴；否则用单位明确的独立面板，不伪装同时发生 |
| P12 | 多线序列图 | 有真实逐时点数据的数值趋势 | 不从本命盘补造未来曲线；数据不足改用定性说明 |
| P13 | 关系矩阵表 | 多体系围绕共同主题形成的质性关系 | 列出主题、各视角增加什么、分歧与综合含义；不用星级、总分或伪精确印证度 |
| P14 | 成对对照图 | 同一量纲下两项数值或描述对照 | 不把偏好差异解释成能力优劣；提供原始值 |
| P15 | 关系网络图 | 展示盘面/文本中有明确定义的结构连接 | 只显示已核关系；不能暗示关系强弱或因果除非有定义数据 |
| P16 | 双人双轮对照 | 同一图中分别展示双方的占星位置 | 双方数据分色/分表且来源独立；不是兼容度分数或成功率 |
| P17 | 亚型哑铃图 | subtypes16 同一功能两端的原始量表分数对照 | 同量程显示两端原值及有符号差；缺端点不连线、不解释为能力差。不是所有人格构念的通用图 |

## 3. 各模式骨架与实现指引

### P01 · 雷达图

仅当全部维度真实存在、定义相同且量程一致时使用。坐标中心 `(cx,cy)`、最大半径 `R`、值 `v`、量程 `[min,max]`：

`r = (v - min) / (max - min) × R`；第 `i` 轴角度 `θᵢ = θ₀ + i × 360°/n`；`xᵢ = cx + r sin θᵢ`，`yᵢ = cy − r cos θᵢ`。

可使用 `chart_data.py radar` 的计算输出。标签/表格逐项回链原值。存在任何未提供维度时，切换为 P08 已知值表格，并列出缺项；不闭合多边形。

### P02 · 分组条形图

只比较定义、单位与量程一致的真实数值。五行图必须以同一零点画一组横条，并与原值数表并列；标签写清“该统计口径下的元素比例/权重/统计值”，不得改称能量、能力或吉凶。五行数据引用 `/dimensions/bazi/data/五行比例`、`五行权重`、`五行统计口径` 中实际存在的字段，不从缺项补值或另造强弱分。其他分组条明确示单位、量程、零点及排序规则；同一组原值不再重复制作排名、雷达或卡片。

### P03 · 并列/堆叠条形图

并列组适合相同单位、量程的数据比较；堆叠仅适用于互斥且总量有意义的组成项。并列条各自按 P02 公式映射。堆叠段长 `wⱼ = vⱼ/总量 × W`，仅在各组成项完整、总量非零且定义明确时使用。不得把彼此不可比的体系强行归一化后并排。

### P04 · 定性过程示意

用于阐释一个理论过程或概念次序。使用节点、箭头与文字描述；图题/图注写“概念示意”。不绘制没有观测依据的连续曲线、年龄刻度、Grip 风险值、发生概率或趋势强度。若节点没有清楚规则来源，改用文字。

### P05 · 同心层级/原型关系图

表示理论角色或分类层级时，每个区域标出理论来源并提供文字表格。圆面积、半径和颜色不可暗示未经测量的强度、价值高低、风险或年龄发展顺序。若仅需列出类别，优先使用表格。

### P06 · 紫微十二宫格盘

仅在完整十二宫数据可用、且正文解释空间关系时采用。使用 4×4 外围十二格，地支位置固定如下（中心两格为简短盘面信息）：

| 巳 | 午 | 未 | 申 |
|---|---|---|---|
| 辰 | 中心 | 中心 | 酉 |
| 卯 | 中心 | 中心 | 戌 |
| 寅 | 丑 | 子 | 亥 |

各格按真实地支放入本盘宫名、主星、生年四化；命宫／身宫必须以带边框的文字标签强调，不能只靠颜色。空宫明确写“空宫”，其借对宫关系由相邻正文解释，不补星。仅当辅星参与本章判断时上图；其余辅星移至紧邻线性表。完整十二宫字段不等于十二段等长断语。图下保留可达的线性数据表；缺失字段标明未提供/不可用。字段绑定对应计算 artifact，并标注盘面历法、日期与方法。

### P07 · 占星轮

仅在十二个互异、有限且处于 `[0,360)` 的真实宫头、有效 ASC 与行星黄经均可用时，复用 `chart_data.py wheel --cusps … --asc … --planets …` 的坐标输出。MC 按实际角度绘制，不默认等于第十宫头；只突出正文讨论的主要相位，精确角度与其余相位留在结构表。图注说明宫制、时刻口径及星历；宫头、行星、轴点和相位数据回链 artifact。缺真实宫头或其余必要坐标时改用位置／相位表，不画等分假宫轮。

### P08 · 结构化数据表

用于精确值密集资料，并承担不适合图示的完整数据呈现。四柱使用可读结构表，列为年／月／日／时，按实际字段列干支、藏干与十神；用文字标出月令和日主。字段回链 `/dimensions/bazi/data/四柱` 对应路径。五行图与表共用真实的比例、权重、统计口径来源，不重复为五张单元素图。每个数值单元格包含 `data-value-ref`、`data-value`、`data-unit`、`data-precision`；单位/有效期写入表头或表注。须有标题、`thead`、正确行列标题；长表可跨页且重复表头，打印不得裁切或隐藏。

### P09 · 有向关系/流向图

节点代表有明确定义的实体/字段，边标明实际规则或关系类型。箭头只表示所定义的方向，不自动代表因果、影响大小或吉凶。图下提供边列表及来源引用；关系较多或标签拥挤时改表。

### P10 · 状态关系图

节点是明确命名的离散状态，连线表示有记录的转移或理论中明示的可能关系。若并非观测到的过程，显著标“概念示意”；不使用百分比、风险星数、粗细代表频率或确定时间顺序。

### P11 · 多轨时间轴

只有区间端点及其时间语义真实明确时才画周期轴。八字使用 `大运[].起始公历年`、`大运[].终止公历年`；紫微使用 `十二宫[].大限.范围` 与计算输出的当前大限。两者只有时间语义一致且端点明确才共用一轴；否则上下排列两个独立面板，分别标“八字：公历年范围”“紫微：原盘年龄范围”，不得以垂直连接暗示同时发生或可换算。当前标记只能来自计算输出，不从虚岁推断精确公历边界；刻度精度不得超过输入粒度。坐标刻度复用 `chart_data.py timeline --start --end --step --now --x0 --x1`；缺端点时列数据表并说明限制，不补值或新增计算 API。周期范围绑定各自原始字段，绘图坐标可另登记为坐标 artifact，但不能作为事实引用。

### P12 · 多线序列图

仅用于逐时点数值有来源的数据。每条线的点 `(t,v)` 回链源字段，显示单位、时间范围、缺失点与计算口径。没有实际未来计算数据，不画运势、人格成熟、关系质量或健康趋势。定性趋势改用 P04，且标“概念示意”。

### P13 · 关系矩阵表

只在正文已经形成真实主题综合时使用精简关系表，列为“主题／各视角增加什么／分歧与综合含义”。单元格写明不同视角各自提供的解释与综合所得的新理解，不以相似性增加事实概率；不把定性关系转成数字、星级或总分。矩阵是分析索引，不能替代正文解释；如果只是重复正文则不画。`validate_book.py` 要求 `chart_table.data_refs` 至少一项且逐项由图内数值 `data-value-ref` 覆盖，纯定性矩阵无法满足，因此 P13 不登记进 `chart_table`：在综合章内以普通语义 `<table>` 呈现，每行用 `data-claim-ids` 回链已登记的 synthesis claims。

### P14 · 成对对照图

两端数据同构、同量纲时可用平衡线/点图；坐标 `x = x₀ + (v−min)/(max−min) × W`。图下并列原始值和量表定义，不把差值命名为能力差、风险差或成熟度。定性观点对照用双栏文字，不伪造数值坐标。

### P15 · 关系网络图

每个节点/连边对应可查的盘面或文本关系，并以图例说明关系类型。避免靠节点大小、边粗细表达未经定义的强弱；不把传统关联改写成现实事件因果。提供可线性阅读的邻接/关系表。

### P16 · 双人双轮对照

以两组独立输入分别计算轮图，明确标记 A/B 只是合成样本标识而非现实身份判断。双方坐标、宫位、行星数据分别绑定各自 artifact。对照不生成合盘总分、成功概率或关系星级；图下分别列数据表并说明双方缺失项。若某一方数据不足，展示可用层并明确不对称限制。

### P17 · 亚型哑铃图

仅为完整或部分真实 `subtypes16` 原始分选择该图：同一功能左右两端使用共同量程，标原始分及完整配对的有符号差。复用 `chart_data.py dumbbell --pairs … --min 0 --max …` 坐标；缺一端时只显示已知端点与缺失标记，不补零、不连线、不计算差。完整 `functions8` 使用原分条形图；缺值只列已知项并说明缺项，不生成假八维图。NERIS、类型、访谈等不同构念各自呈现，不从缺失构念推造八维。相同原值不得再重复做排名、雷达图或卡片。图与表回链真实 artifact；只说明量表原值差异，不称能力差、偏好优劣、置信度或发展阶段。

## 4. 适配与质量检查

选模式遵循“最简单且忠实的表达”：标签比较用条形/表格，精确长列表用表格，连续真实数据才用序列图，关系分类才用矩阵/网络图。相同数据不重复制作多张图来填版面；图不能代替正文回答问题。

落图前核对来源字段、数值单位、量程、缺值策略、图表 ID 和章节归属；落图后核对 SVG/XML 有效、引用 ID 唯一、坐标有限且非退化、可访问说明及表格同步。最后在目标屏幕宽度和实际 PDF 尺寸检查文字可读、线条可辨、表格未裁切。静态图形检查通过不等于浏览器/PDF 阅读性通过。
