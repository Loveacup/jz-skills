# 性格资料识别与分析工作流

## 1. 先识别资料构念

读取 `personality_input.construct`，保留来源与原始值，不把不同工具的结果混合成一个统一人格结论。允许的构念如下：

| construct | 可做 | 不可做 |
|---|---|---|
| `functions8` | 按原量程展示八项分数；在量表和资料边界内描述作答模式 | 把分数当能力、诊断或跨情境稳定事实；按最高分自动确定唯一类型 |
| `subtypes16` | 保留 16 个原始值；按既定键对展示左右分数及有符号差 | 聚合为八功能分数；把差值说成能力、置信度、发展阶段或风险 |
| `neris5` | 描述五个 NERIS 维度的报告结果并说明来源 | 从五维或四字母类型推算 Jung 功能栈。16Personalities 明确 NERIS 不分配 cognitive-function stacks，见 [for AI](https://www.16personalities.com/for-ai) |
| `mbti_type` | 将自述类型作为类型理论的讨论入口 | 声称类型即八功能实测、诊断或已核实的个体事实 |
| `interview` | 按具体情境记录本人自述、例子与反例 | 伪装为标准化测量、由少量答案推定隐藏功能或量化置信度 |
| `none` | 说明资料缺口；提供一次访谈机会 | 从出生盘、年龄、关系经历或分析师直觉生成分数、类型或功能栈 |

工具、版本、测量日期、量程或来源未知时如实记为未知。截图转录按项目合同保留原图定位与复核状态；未能辨认的值请求澄清，不估读、不平均。

## 2. 资料不足时的唯一分支

资料不足以回应人格问题时，先向读者提供一次访谈机会，聚焦其关心的现实情境，并邀请具体例子与可能的反例。访谈须自愿，不连续追加测试来逼出完整类型。读者不接受或无法访谈时：

1. 将人格资料标为 `insufficient_data`，明确不能据此给出个体化类型结论；
2. 若任务范围允许，提供开放的自我观察问题，由读者自行判断是否有用；
3. 继续处理已有资料支持的其他请求，或明确列出尚未满足的请求；不以玄学推人格来填空。

只有类型时，最多讨论该类型理论的概念，并清楚标成类型框架，不添加未提供的功能分数或诊断语句。

## 3. 理论镜头与结果语言

Beebe 原型位置、阴影和 Grip 是有名称的理论解释镜头；必须署明所用理论，不称临床诊断、确定的“天然缺陷”、能力测试或风险等级。不得将低分解释为能力薄弱，不得仅凭偏好分数推出逻辑、共情、边界或感官能力不足。若呈现亚型成对差值，只报告原分、量程、键对及差值；差值不是功能分、置信度或成熟度。

描述应围绕明确来源：本人自述、量表报告、观察到的具体情境，或明确标识的理论假说。说明适用条件，也保留与概括不一致的例子；资料没有覆盖之处写成未知，而不是补成确定画像。

结果语言先写分数轮廓里看见的倾向，再给原分与量程。以“例如／如果／假如你……”明确标出的生活镜像，和带条件、能落空的反向情形（“如果你在〔情境〕里更常〔Y〕，这条读法就不太贴合你（此时〔另一项〕可能更重）”），是鼓励的写法，不属于补造经历；把想象写成已经发生的事，或在标注词后写具体过去事件，才越界。分值只以条件句写成行为，不写“你总是……”，也不写无条件的“有时 A、有时非 A”。倾向写成在某些场合出场的做法，不写成身份。同一构念内部的提问入口（如 Fe/Fi 的“别人表达了什么、我自己又在乎什么”）可以直接使用，见 `cognitive-functions.md`。

## 4. 事件与出生时间

已知事件用于理解问题、提供回顾背景或检查描述是否贴合，不能自动拿来反推/校正出生时间，也不计作预测命中。修订时间输入只能依据新增的出生记录、家人原始记忆等时间证据；记录来源、旧值、新值和候选差异。事件不能替代原始出生时间证据。

## 5. 未成年人适龄规则

年龄按固定的 `analysis_as_of` 与生日计算；年龄未知时按保守适龄措辞处理并追问，不猜成年。未满 18 岁必须启用 `minor_mode`：

- 关系内容聚焦家庭、同伴、师长、沟通与边界，不描写未来婚恋对象或婚恋年份；
- 事业内容改为学习、兴趣与尝试空间，不替孩子选定职业；
- 不将类型、分数或功能位置贴成能力缺陷、风险标签或人生限制；
- 健康内容只谈主动提供的作息、压力与求助，不作疾病推断或诊断；
- 写做过的事与可以尝试的事，不写“你是……的孩子”式身份标签，正面的也不写；
- 主题落在适龄边界上时，把边界内的正面内容写到位（关系就写家庭、同伴、师长与边界），不发“本章不谈婚恋”式公告；
- 行动至少配一句孩子可以直接说出口的原话（例如“也问问我想怎样，好吗？”）；
- 只有 `audience` 包含 `guardian` 时才写给家长的内容，且不能以家长版取代面向孩子的分析。家长段写可观察的情境、可能的误读、支持方式，并附一个反向情形（“如果孩子平时很快融入，只在某类场合退后，更值得留意的是那类场合本身”），不写控制方案。

未成年人截图与出生资料默认不向外提交。任何年龄都不按固定年龄阶段表断言功能成熟、可塑性比例或人格必经路径。

## 6. 分析顺序

以人为本指从读者问题和自我理解需要组织阅读，不是以某份量表结论为本，也不是要求其他体系替人格背书。人格资料的推读路径见 `cognitive-functions.md`；各体系先独立分析自己的数据与规则，再由综合分析者围绕同一读者问题说明各自增加的理解、真实张力、不可比较项及限制；不共享预设人格提示来制造一致，也不按“几维同意”判定个体事实。

资料不足时（§2）仍解释已有的真实分数轮廓与所用理论镜头，说明它能提示什么、需要什么观察来检验；不以“没有资料”替代整章，也不杜撰经历。
