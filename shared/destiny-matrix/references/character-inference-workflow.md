# 性格数据缺位时的工作流 · destiny-matrix v3

> 性格画像始终是命书第一章。即使分析师未提供荣格八维测试分数，**也不允许跳过性格画像或将其降格为附录**。本文档给出三层兜底方案。

---

## Tier 1（强烈建议）：双测试入口

若分析师可联系命主本人或自身代填，**强烈建议先做以下两个测试**：

| 测试 | 入口 | 时长 | 测什么 |
|:---|:---|:---|:---|
| 16personalities | https://www.16personalities.com/ | 12 min | MBTI 类型 + 五维分数（辅判主导功能） |
| sakinorva 认知功能测试 | https://sakinorva.net/functions | 15 min | 直接给出 Te/Ti/Fe/Fi/Ne/Ni/Se/Si 八项分数（v3 性格签名的核心输入） |

**双测试的必要性**：16personalities 易出现 J/P 误判，单测不够稳；sakinorva 出原始功能分数但缺乏类型语言。两者交叉印证可大幅降低自报误差。

**操作建议给分析师**：请命主在状态平稳时各做一次，回收 16personalities 四字母 + 五维条形图 + sakinorva 八项功能分数。获得分数后调用 `scripts/jung_calc.py` 生成功能栈 + Beebe 原型 + 性格签名。

## Tier 2（替代）：分析师访谈式反推

若无法做测试，分析师可通过 5-10 个核心问题反推。**反推结果需在命书中明确标注「访谈反推假说，非测试结果」**。

### 核心问题模板

**N vs S（抽象 vs 具体）**
1. 面对未知情况你首先关注：(X) 这件事背后的可能性、模式、含义（→ N）/ (Y) 当下的具体细节、感官事实（→ S）
2. 读小说时你更被哪个吸引：隐喻象征深层主题（→ N，尤其 Ni）/ 场景细节人物动作感官描写（→ S，尤其 Si/Se）

**T vs F（理性结构 vs 价值判断）**
3. 做决定时内部独白更接近："这样做合理 / 有效 / 一致"（→ T）/ "这样做对 / 重要 / 我能接受"（→ F）
4. 面对冲突第一反应：拆解问题结构、找出逻辑漏洞（→ T）/ 体察关系氛围、关心每个人感受（→ F）

**J vs P（结构 vs 灵活）—— 辅助辨主导/辅助方向**
5. 理想的一天：提前规划好清晰日程、按部就班（→ J，外倾判断主导）/ 保留弹性、随当下感受调整（→ P，外倾感知主导）

**E vs I（外倾 vs 内倾）—— 辨主导功能方向**
6. 充电方式：与人深度交谈后能量饱满（→ E）/ 独处或与极少数人在一起后能量饱满（→ I）

**劣势功能定位**
7. 极度疲惫或长期高压时你会变成什么样：
   - 暴饮暴食、刷剧、突然冲动消费（→ 劣势 Se，Ni 主导）
   - 灾难化想象、反复推演最坏可能性（→ 劣势 Ni，Se 主导）
   - 钻牛角尖、苛责细节（→ 劣势 Si，Ne 主导）
   - 不切实际的远期幻想或阴谋论（→ 劣势 Ne，Si 主导）
   - 突然爆发情绪、对某人怀恨（→ 劣势 Fi，Te 主导）
   - 冷漠抽离、拒绝感受任何人（→ 劣势 Fe，Ti 主导）
   - 强迫性 to-do、效率焦虑（→ 劣势 Te，Fi 主导）
   - 突然对真理 / 系统 / 知识的偏执（→ 劣势 Ti，Fe 主导）
8. 童年起就觉得自己最不擅长的领域（通常对应劣势功能或 Beebe Trickster 位）

**童年禁区 / 阴影**
9. 父母批评你最多的特质 / 你最讨厌自己的特质（→ 通常对应 Beebe Opposing 或 Senex-Witch）
10. 你最容易瞧不起的人是哪种（→ 通常照见自己未整合的阴影）

### 反推输出格式

```
访谈反推性格假说（Tier 2，待测试验证）：
- 主导功能（推测）：____ （根据 Q1, Q3, Q6 三角验证）
- 辅助功能（推测）：____
- 劣势功能（推测）：____ （来自 Q7 退行模式）
- Beebe Opposing 原型（推测）：____ （来自 Q9）
- 性格签名（假说）：____
置信度：中（仍建议补做 Tier 1）
```

## Tier 3（兜底）：玄学三维反推性格假说

若既无测试也无访谈机会，允许走 Tier 3。**输出必须明确标注**：「本性格画像由玄学三维反推生成，属假说性质。一旦命主完成 sakinorva 测试，本节需重写。」

## 通用约束（无论走哪一 Tier）

1. **性格画像始终是命书第一章**（35-45% 篇幅）
2. **性格签名是后续玄学章节的回环锚点**——八字/紫微/占星每条结论都要回到性格签名做印证
3. **置信度透明**：Tier 2/3 必须在命书中明确标注「假说」二字，不可冒充测试结果
4. **校准回路开放**：命主一旦补做测试，整份命书可基于新签名重生成
5. **玄学始终是性格的支撑**：即使在 Tier 3，也不允许把玄学放回主语位置
