# 紫微斗数分析框架

> **v2 计算引擎**：本框架的核心排盘由 `scripts/ziwei_calc.py` 完成，基于 `iztro-py`（[SylarLong/iztro](https://github.com/SylarLong/iztro) 的 Python 实现）。iztro 是目前最权威的开源紫微排盘库，支持十四主星 + 全部辅煞 + 杂耀 + 亮度（庙旺得利平不陷）+ 长生/博士/将前/岁前十二神 + 大限 / 流年 / 流月 / 流日 / 流时全套。
>
> **典型调用**：
> ```bash
> python3 scripts/ziwei_calc.py 1993-09-30 9 f   # 9 = 酉时
> ```
>
> 输出 JSON 包含：基础信息（命主、身主、五行局）、十二宫完整数据（主星+辅星+杂耀+亮度+四化+十二神）、当前大限/流年/流月/流日运限。
>
> 不再需要手排——本文件以下查表内容均为 Phase 2 紫微分析时的**判读参考**。

## 大限（紫微版大运）

紫微斗数的大限每十年换一个宫位，从命宫开始：
- **阳男阴女**：大限顺行（地支递增方向：命宫→父母→福德→...）
- **阴男阳女**：大限逆行（地支递减方向：命宫→兄弟→夫妻→...）

（注意：顺/逆指**地支方向**而非宫名序方向——十二宫宫名本身是沿地支递减排布的，故「顺行」走的是宫名序的反向。iztro-py `palace.py` 源码实证：同阴阳（阳男阴女）走地支递增。阴阳按年干或年支取均可，六十甲子干支阴阳恒一致。）

每到一个新的大限宫位：
1. 该宫位的星曜成为这十年的主题星
2. 大限四化由大限宫位的天干决定
3. 大限四化与原局四化叠加产生新的能量场

## 流年盘

### 流年命宫定位

紫微流年的命宫由"斗君"确定：
- 斗君=从生年支起正月，逆数至生月，再顺数至正月即为斗君位置
- 从斗君起子年，顺数至流年地支即为流年命宫

### 流年四化

由流年天干决定四化（使用上方四化速查表），叠加到原局命盘上。

### 流月命宫

从流年斗君（即流年命宫）起正月，逆数至流月即为流月命宫。

## 辅星计算公式（Python）

### 命宫与身宫
```python
EB = ['子','丑','寅','卯','辰','巳','午','未','申','酉','戌','亥']
def ming_gong(lunar_month, hour_idx):  # hour_idx: 0=子,1=丑,...
    return EB[((2 + lunar_month - 1) - hour_idx) % 12]
def shen_gong(lunar_month, hour_idx):
    return EB[((2 + lunar_month - 1) + hour_idx) % 12]
```

### 紫微星定位
局数×n ≥ 农历日取最小 n（借数 = 局数×n − 日）；从寅起顺数 n 位后，借数为奇**退**借数位、为偶**进**借数位：
```python
def ziwei_pos(ju, day):
    n = -(-day // ju)          # ceil(day/ju)
    borrow = ju * n - day      # 借数
    pos = 2 + n - 1            # 从寅(索引2)顺数 n 位
    pos = pos - borrow if borrow % 2 else pos + borrow  # 奇退偶进
    return EB[pos % 12]
```
验证锚点：金四局初三→丑；火六局初三→亥；水二局初二→寅；土五局十一→申。

### 一、四化表派别差异：三合派 vs 飞星派与各家版本

**结论先行**：本文件正文的「年干四化速查表」与 iztro / iztro-py 硬编码的四化表**逐行一致**（已对照 `iztro_py/data/heavenly_stems.py` 源码核实），属**通行版**（民间流传最广、多数在线排盘工具默认）。派别差异集中在**戊、庚、壬**三干的化科/化忌，其余七干各派基本无争议。

- **庚干是全部十干中争议最大的一干**，至少存在四个版本：阳武阴同（通行）/ 阳武同阴（全书系）/ 阳武府同（中州派）/ 阳武同相（古籍影印及北派）。iztro issue #212 报告者曾据《全书》影印本（识典古籍）主张「庚日武同相」（天相化忌），维护者定性为「四化版本繁多，不存在对错」。
- **三合派 vs 飞星派的差异不止在四化表**：三合派重星曜 + 宫位组合，四化居辅助地位，切忌单星单宫论断；飞星派（含钦天体系）以「四化飞宫 / 自化 / 禄忌交战」为核心技法，文昌文曲左辅右弼必入四化。两派同一张四化表也会得出不同论断路径。
- **写命书硬要求**：凡命主生年为**庚干**（或大限/流年宫干逢庚、壬），涉及天同/太阴/天相/天府的四化论断，必须显式标注「按三合派通行版四化（iztro 默认）」；若天同化忌/天相化忌的派别分歧会实质改变结论，须在文中披露该分歧。

#### iztro-py（spyfree 版）专属偏差（本地源码核实）

1. **config 是壳**：`data/types.py` 定义了 `Config`（含 `algorithm: 'default'|'zhongzhou'`、`year_divide`、`day_divide`），但**全库无任何代码消费该类型**——中州派安星、自定义四化、年分界配置实际全部不可用，只有通行版默认算法。
2. **默认值与上游相反**：`Config.day_divide` 类型默认 `'current'`（晚子时归当日），上游 iztro 默认 `'forward'`（归次日）；因 config 未被消费，实际行为以硬编码为准（`utils/calendar.py` 将 time_index 12 与 0 同按子时支处理），与 known-issues.md「lunar_python 夜子时归当日」条目属同一风险族，命书遇 23:00-01:00 出生必须显式标注归日规则。
3. **上游 bugfix 同步无对照**：iztro-py 无 CHANGELOG 对照上游版本号，上表「已修」条目在 iztro-py 中是否同样修复**逐条待定**——这正是 S2 外部验盘（7 校验点）存在的理由。
4. known-issues.md 提到的飞星派校验候选 `lzm0x219/ziwei` 已改名迁移为 [matharts/ziwei](https://github.com/matharts/ziwei)（仍活跃，2026-07 有提交）；其 README 未声明派别与飞星支持，作为校验层的可用性**待定**。

### 四、大限起算派别差异

**各派共识**（与正文一致，不变）：起限虚岁 = 五行局数（水二局 2 岁起，……火六局 6 岁起）；阳男阴女顺行、阴男阳女逆行。

**分歧点**：

1. **首限落宫**：今通行做法（iztro/iztro-py 实现，`astro/palace.py` 源码核实：`start_age = 局数 + 10*i`，i=0 即命宫）第一大限在**命宫**；但《紫微斗数全书》古籍系有「第一大限自命宫的下一宫起」的记载——iztro issue [#212](https://github.com/SylarLong/iztro/issues/212) 报告者据影印本指出「原书大限从命宫+1开始算」，[神机阁大限条目](https://www.shenjige.cn/details/0_1p3aWPN.html)亦述及此派别差异（该文细节未逐字核验，标注待定级）。两法全盘相差一宫，命书按通行「首限在命宫」并如此标注。
2. **童限**（起限前岁数）：iztro-py 实现为 1 岁命宫、2 岁财帛、3 岁疾厄、4 岁夫妻、5 岁福德、6 岁官禄（`astro/horoscope.py` childhood_order 源码核实），对应《紫微斗数全书·安童限诀》「一命二财三疾厄，四岁夫妻五福德」序（[易德轩《全书》安童限条目](https://m.yi958.com/ziwei/Article_3282.html)，原文细节待核）。
3. **虚岁分界**：上游 iztro 提供 `ageDivide: 'normal'（正月初一长一岁）| 'birthday'（生日长一岁）`（[#225](https://github.com/SylarLong/iztro/issues/225)，默认 normal）；iztro-py 无此配置。命主生日前后一两个月内的大限交接判断，必须写明按虚岁（正月初一分界）计。
4. **年分界连带影响**：立春 vs 正月初一的年分界（见第二节）改变年干 → 改变生年四化与大限宫干支，立春至正月初一之间出生者是大限论断的高危区，S2 外部验盘必须覆盖「起运岁数与大限序」校验点（7 校验点之②）。

**写命书硬要求**：双轨时间线（Ch6）中的紫微大限一律标注「三合派通行起算（首限在命宫，起限虚岁=局数）」。
