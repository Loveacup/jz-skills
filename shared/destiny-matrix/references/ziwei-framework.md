# 紫微斗数分析框架

> **v2 计算引擎**：本框架的核心排盘由 `scripts/ziwei_calc.py` 完成，基于 `iztro-py`（[SylarLong/iztro](https://github.com/SylarLong/iztro) 的 Python 实现）。iztro 是目前最权威的开源紫微排盘库，支持十四主星 + 全部辅煞 + 杂耀 + 亮度（庙旺得利平不陷）+ 长生/博士/将前/岁前十二神 + 大限 / 流年 / 流月 / 流日 / 流时全套。
>
> **典型调用**：
> ```bash
> python3 scripts/ziwei_calc.py 1993-09-30 9 f   # 9 = 酉时
> ```
>
> 输出 JSON 包含：基础信息（命主、身主、五行局）、十二宫完整数据（主星+辅星+杂耀+亮度+四化+十二神）、当前大限/流年/流月/流日运限。
>
> 不再需要手排——本文件以下查表内容均为 Phase 2 紫微分析时的**判读参考**。

紫微斗数以出生年月日时排列十二宫位，安置星曜，以命宫为核心展开人生各领域的分析。

### 三方四正

三方四正的星曜组合决定了命主的整体格局高低。

## 大限（紫微版大运）

紫微斗数的大限每十年换一个宫位，从命宫开始：
- **阳男阴女**：大限顺行（命宫→兄弟→夫妻→...）
- **阴男阳女**：大限逆行（命宫→父母→福德→...）

每到一个新的大限宫位：
1. 该宫位的星曜成为这十年的主题星
2. 大限四化由大限宫位的天干决定
3. 大限四化与原局四化叠加产生新的能量场

## 流年盘

### 流年命宫定位

紫微流年的命宫由"斗君"确定：
- 斗君=从生年支起正月，逆数至生月，再顺数至正月即为斗君位置
- 从斗君起子年，顺数至流年地支即为流年命宫

### 流年四化

由流年天干决定四化（使用上方四化速查表），叠加到原局命盘上。

### 流月命宫

从流年斗君（即流年命宫）起正月，逆数至流月即为流月命宫。

## 辅星计算公式（Python）

### 命宫与身宫
```python
EB = ['子','丑','寅','卯','辰','巳','午','未','申','酉','戌','亥']
def ming_gong(lunar_month, hour_idx):  # hour_idx: 0=子,1=丑,...
    return EB[((2 + lunar_month - 1) - hour_idx) % 12]
def shen_gong(lunar_month, hour_idx):
    return EB[((2 + lunar_month - 1) + hour_idx) % 12]
```

### 紫微星定位
局数×n ≥ 农历日，取最小n，从寅起数n位：
```python
def ziwei_pos(ju, day):
    n = -(-day // ju)
    return EB[(2 + n - 1) % 12]
```
