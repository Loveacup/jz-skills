# 紫微斗数分析框架

本框架采用三合派的传统解释框架，所有星曜、宫位与四化象义均属于文化解释，不是个人事实、能力测量、医学诊断或事件预测。排盘事实与解释必须分开，且不要求紫微结论与其他体系相互印证。

## v5 计算口径

- 计算输入来自统一 `time_context`。紫微以出生地本地视太阳日期和时辰排盘，年界按农历正月初一，不沿用八字立春年界；计算须记录日期、历法转换及时间精度。
- 农历转换先统一经 JD 适配器取得农历年月日及闰月标记，再调用 `iztro_py.by_lunar(..., is_leap_month=..., fix_leap=...)`。普通月与闰月均使用该入口，避免二次日历转换。
- 闰月主盘采用中分法；另计算 `fix_leap=False` 的对照盘。结果按算法名标识。不得将这些计算规则断言为某一历史流派的唯一或古法规则。
- 输入时刻不精确时，不选取中点作为确定出生时刻。仅报告候选结果的稳定离散字段、变化字段及各自有效区间；没有用户接受的限制不得以单盘代替候选范围。
- 流年/流月以实际计算结果为准。流年采用正月初一年界并标注有效日期区间；未计算的流年、流月、流日或流时不写入分析。
- 不得根据已知人生事件、性格吻合度或既有分析择盘、反推或校正出生时刻。

## 十二宫与传统议题

| 宫位 | 传统讨论主题（非个案结论） |
|:---|:---|
| 命宫 | 自我呈现、整体象义 |
| 兄弟宫 | 手足与同辈关系 |
| 夫妻宫 | 一对一关系与相处主题 |
| 子女宫 | 创作、照护与代际主题 |
| 财帛宫 | 资源与价值议题 |
| 疾厄宫 | 传统文本中的身体与困厄象征；不作健康判断 |
| 迁移宫 | 外出与环境互动 |
| 交友宫 | 同伴、社群与协作 |
| 官禄宫 | 工作角色与公共事务 |
| 田宅宫 | 居所、家庭与资源 |
| 福德宫 | 内在生活、休息与兴趣 |
| 父母宫 | 长辈、教育与照护关系 |

三方四正、星曜组合、亮度和四化用于组织传统解释，不构成客观“格局高低”或人生结论。不得由星曜/宫位直接推出疾病部位、病率、死亡、生育、财富结局、性别责任、伴侣身份或必然婚恋事件；不得提供投资吉日或关系成功率。健康专题只回应用户主动提供的作息、压力与求助问题。未成年关系主题仅谈家庭、同伴、师长及边界，不写红艳/桃花性化推断或婚恋年份。


## 独立解读路径与完成边界

按以下顺序推读；完整命书逐项检查，focused 只检查与请求相关的部分。检查不要求每项各写一段，未改变结论的次要细目可留在数据附录。findings 的领域解释须形成连续、可阅读的论述：讲清本盘关系结构、采用的推读依据、对读者主题的含义，以及会改变读法的反向因素；`evidence_summary` 保持简短，只记录审计所需的字段与来源。

1. 十二宫全盘定位：掌握宫位分布与盘面整体关系，不把全盘数据变成十二段等长断语。
2. 命身宫与主星状态：结合宫位、主星与实际状态解释，不孤立列星名。
3. 命宫三方四正／空宫借对宫：说明彼此牵连以及这些关系如何影响命宫读法。
4. 生年四化的落点与牵连：指出实际落宫及相关联动，不把单一化曜当作结论。
5. 请求涉及宫位及相互张力：围绕主题讲关系结构，而非星曜清单。
6. 当前大限／已计算流年：只采用实际计算的周期与数据。

主文解释结构关系，不用星名清单替代推论。空宫、庙陷、化忌不翻译成能力缺陷。疾厄、夫妻等宫名只作盘面传统议题标签；对未成年人不据此作医疗或婚恋预测。未定位到可靠来源的具体取法，列入现有来源核验任务（S4C）；无法核实时省去该条取法，继续完成其他有依据的分析。省去后正文保持沉默：不写“未核”“未采用”“不裁定”。未采用的取法及原因只在附录“本书没有采用的读法”列一次；只有当这项缺口会改变读者已读到的结论时，才作为 `changes_reading:true` 的读者层限制就近写一次。

领域论述的顺序、生活镜像与限制分层按 `agents/book-writer.md` 文风与 team-orchestration §4、§8；本体系读者可在盘上指认的依据是宫位、主星、四化落点，镜像的反向一支须明确写“这条读法就不太贴合你”。找不到可核古籍原文的通行象义，可按 team-orchestration §4 的“常见读法”写入（“在紫微的常见读法里……”，不加引号、不署名）；常见读法只替代象义的古籍原文，不替代取法与构成条件的来源核验，并同样受本页关于健康、婚恋、财富、性别与适龄的边界约束。

## 星曜与组合的阅读方式

紫微、天机、太阳、武曲、天同、廉贞、天府、太阴、贪狼、巨门、天相、天梁、七杀、破军等主星，以及辅星、煞星和四化，按采用的传统文本、算法或常见读法解释，并把本盘相关星曜在传统里怎么讲写出来，不只写星名或“话题”。诸如“杀破狼”“机月同梁”“府相朝垣”等格局名，先说明构成条件，再说明其传统象义及不同解释的边界；不可转述成职业适配、心理类型、财富/权力结果或人生必然剧情。

若引用古籍对疾病、灾祸、生育、性别或婚姻的判断，只能作为带明确出处的历史文本介绍，并说明其时代语境；不得转作当前个案建议或判断。未核实的引文不署名，不用“古书云”等模糊说法；通行象义按上文“常见读法”写，不加引号。

## 大限与流年

大限方向、起算、四化版本及流年宫位应以实际 calculator 方法元数据为准，并在重要派别分歧会改变解释时披露所用版本。大限、流年与流月只描述工具实际产出的宫位/星曜/四化及适用日期，不附加未计算事件预测或总体吉凶评级。紫微流年使用正月初一年界；有效日期区间须与八字立春年界分别标明。

## 输出边界

将排盘事实、传统象义、用户自述与行动选项明确区分。传统象义不能充当测量证据；不得从出生盘合成人格分数或替用户决定事业、关系、投资、婚育或医疗选择。行动建议应来自用户目标与现实情境，低风险、可观察、可调整，不要求等待流年窗口。
