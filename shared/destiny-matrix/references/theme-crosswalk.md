# 主题对照表：同一个主题，四个体系各看什么

综合者（S5）在选定主题后查本表：每个体系在这个主题上看盘面的哪些位置、回答的是哪一类问题、常见的汇聚与张力长什么样。流程、矩阵取值与合格标准见 [`cross-analysis-patterns.md`](cross-analysis-patterns.md)；各体系的象义细目见各自的 framework 与象义知识卡，本表只讲“跨体系时对哪里”。

## 0. 用法

1. 综合只使用各体系 analyst 已登记的主张。本表告诉你去各体系主张里找什么；找不到对应主张时，把缺口回给 Leader 定向回派，自己不从盘面另起一条读法。
2. 各体系按默认取法读：八字用子平格局法（月令取格，扶抑与调候为辅，藏干以本气为主，季月月令按土论）；紫微用三合派（空宫借对宫主星，生年四化为主）；占星用现代守护为主、传统守护为副、Placidus 宫制、先天尊贵按传统七星；人格用荣格八功能加 Beebe 八原型位置。
3. 字段写法：`结构.X` 指对应计算产物 `data.结构` 下的键。占星的 `结构.宫主落宫` 是数组，第 N 宫的下标是 N−1。人格一栏指 `jung_calc.py` 输出的 `结构`：`排序` 是按分数的名次，`类型贴合度.首选功能栈` 是首选类型八个位置上的功能（第 1–4 位为主导、辅助、第三、劣势，第 5–8 位为阴影四位），`对立轴` 四行的键是 `Te–Fi`、`Ti–Fe`、`Se–Ni`、`Si–Ne`。只有自述类型而没有分数时，`结构` 只含 `功能栈`、`主辅搭配`、`主导轴`、`辅助轴`；两样都没有时，人格一栏只用本人自述与访谈主张。
4. 占星相位的叫法分两层。字段与数据层沿用计算器标签（合相、对冲、三合、四分、六合）；写进综合主张 `statement`、核心命题与提纲的句子，一律用读者叫法：合相、对分相、三分相、四分相、六分相（见 `astrology-symbolism.md` §9.1）。八字与紫微的“三合”“六合”“冲”指地支与宫位关系，照原样用。本表示例按读者叫法写。
5. 象义细目与本表有出入时，以各体系知识卡为准：`bazi-symbolism.md`、`ziwei-symbolism.md`、`astrology-symbolism.md`、`cognitive-functions.md`。
6. 某体系在某主题上没有资料或没有主张，矩阵对应列留空。两个体系就可以综合，不为凑齐四栏硬拉。

### 四类问题

同一个主题词，四个体系往往各问各的。先分清各自答的是哪一类，才知道它们是汇聚、张力，还是各答各的。

| 类别 | 问的是 | 主要由谁回答 |
|:---|:---|:---|
| 内在取向 | 这个人习惯从哪里出发、先注意什么、靠什么下判断 | 人格的功能位置；占星的行星与星座；八字的日主与月令气质；紫微的命宫、身宫、福德宫主星 |
| 情境与角色 | 这件事发生在生活的哪个领域，当事人在其中站什么位置 | 紫微十二宫；占星十二宫与宫主去向；八字十神所代表的六亲与社会角色、四柱柱位 |
| 资源关系 | 力量从哪里来、往哪里去，谁生谁、谁制谁、谁耗谁 | 八字的生克制化与格局用神；紫微三方四正与禄权科忌的落点；占星的相位、定位星链与互容 |
| 时间结构 | 这个主题在哪一段时间被推到前台 | 八字大运、流年；紫微大限、流年；占星只在确有行运或推运计算输出时参与；人格资料没有时间结构 |

判定时的用法：

- **汇聚**通常发生在同一类问题上：两个以上体系在同一层给出相近方向。
- **张力**有两种。同层张力是两个体系在同一类问题上方向相反；跨层张力是一个体系说内在取向往东，另一个体系说所处情境或资源流向往西。跨层张力最有阅读价值，它描述的是当事人可感的拉扯。
- **各答各的**（`not_comparable`）是两个体系回答的类别不同，且没有共同落点。写出各自用途即可。

## 1. 自我与气质

| 体系 | 看什么 | 字段 |
|:---|:---|:---|
| 八字 | 日主的五行与阴阳定底色；月令是否得令、四支有无根、天干有无比劫印绶帮扶，合起来定旺衰；月令取出的格局说明这个人以什么方式立身；日支是自坐，说明贴身处的状态 | `结构.月令`、`结构.天干通根`（日柱一行）、`结构.日主十二长生`、`结构.禄刃`、`结构.十神分组固定权重合计`、`结构.藏干明细` |
| 紫微 | 命宫主星及亮度定主调；身宫落在哪一宫，说明后天着力处；福德宫看精神底色；命宫三方四正（财帛、官禄、迁移）会入什么星、什么四化，决定主调是被托起还是被牵制；命宫无主星时借对宫迁移宫主星 | `结构.命宫`、`结构.身宫`、`结构.宫位关系`（命宫、福德宫两行及其 `三方四正四化`、`借对宫主星`）、`结构.生年四化` |
| 占星 | 太阳是意志与自我认同，月亮是安全感与本能反应，上升是入世姿态；命主星的星座与落宫说明这份姿态往哪个生活领域去；合轴点的行星最显眼；终点定位星是全盘的“总调度”；元素与模式分布作补充 | `结构.命主星`、`结构.轴点合相`、`结构.盘别`、`结构.守护.现代守护.终点定位星`、`结构.先天尊贵`、`结构.元素分布`、`结构.模式分布` |
| 人格 | 主导功能及其内外倾态度；主导与辅助的搭配；类型假说与备选类型之间差在哪一个功能 | `结构.类型贴合度`（`首选`、`备选`、`首选功能栈`、`邻近型辨析`）、`结构.排序`、`结构.合计.态度` |

各自回答：人格与占星答内在取向；八字既答内在取向（日主气质）也答资源关系（身强身弱即自身与环境力量的对比）；紫微的命宫答内在取向，身宫与三方四正答情境与角色。

汇聚样式（合成示例）：

- **向内收束的底色**。八字：癸水日主生于亥月得令，年时再见壬水，比劫成势，子平读法里是身旺而内敛的水。紫微：命宫太阴在亥入庙，对宫天机化科来照。占星：太阳、水星同在天蝎十二宫，月亮摩羯。人格：分数轮廓最贴合 INTJ，Ni 主导。合读：四种读法都把重心放在“先在里面想透”上，但各说了一层：八字说的是力量充足却不外放，紫微说的是静而细密，占星说的是不愿在人前摊开，人格说的是先形成一个整体判断再开口。合起来可以给读者一句完整的话：你的主见在开口之前就已经定了，所以在需要边说边想的场合（例如头脑风暴式的会议），你显得比实际上慢。
- **以担当立身**。八字：庚金日主，月令午火正官，官星透干有财生，格局成立。紫微：命宫武曲、天府同宫，官禄宫紫微、天相。占星：太阳摩羯与天顶合相，土星在本垣。合读：三种传统读法都落在“靠承担责任确立自己”。八字补充了条件：官星要有财来生才稳，意思是这份担当需要看得见的回报支撑；没有回报的长期负责，在子平的读法里是官重身轻，读作压力。这个条件是单看紫微或占星读不到的。

张力样式（合成示例）：

- **内在要动，位置要稳（跨层）**。人格：Ne 主导，最贴合 ENFP。占星：太阳、水星双子，风象居多。八字：戊土日主生于午月，丁火正印当令，四支土多而厚，正印格。紫微：命宫天府，身宫在财帛宫。合读：人格与占星说的是注意力的走法，喜欢同时开几条线；八字与紫微说的是立身的方式，靠积累和守成。张力落在“取向”与“位置”之间：脑子想换，脚下要站稳。读者可感的情境：例如你的兴趣隔一阵就换，真正让你心安的却是手里那件做了很多年的事。
- **同层相反**。紫微：命宫七杀独坐，三方会破军、贪狼，是杀破狼的开创格局。八字：乙木日主身弱，印星为用，宜得庇护而后行。合读：两种传统读法在“该冲还是该等”上方向相反。不必裁决谁对，写出各自成立的条件：紫微说的是命宫三方的行动风格，八字说的是自身力量与环境的对比。合起来的理解是，你有冲的性子，但冲之前先要确认背后有人、有资源接得住；没有印星那一层的支撑，杀破狼的“破”容易先破到自己。

## 2. 思维与学习

| 体系 | 看什么 | 字段 |
|:---|:---|:---|
| 八字 | 印星看吸收：正印是循序、依师承、成体系地学，偏印是偏门、独解、靠悟；食伤看消化与输出：食神是从容钻研，伤官是质疑与求新；官杀看规训与考核。要看组合：伤官配印是有才而有章法；食神制杀是用专长化解压力；枭神夺食是偏印克食神，想得多而产出受阻；印重而食伤弱是学得多用得少。年柱、月柱读作成长与求学环境这一层 | `结构.藏干明细`（各支十神与是否透干）、`结构.天干通根`、`结构.十神分组固定权重合计`（印、食伤两项）、`结构.原局关系`、`结构.月令.本气十神` |
| 紫微 | 命宫与福德宫的主星定思维习惯：天机善推演，巨门善质疑与深究，太阴细密，天梁重原则；文昌偏文字与条理，文曲偏口才与才艺；化科落处是学问与名声的着力点，化忌落处是放不下、反复琢磨的地方。求学期的学业在三合派里看官禄宫，师长与文书看父母宫 | `结构.宫位关系`（命宫、福德宫、官禄宫、父母宫）、`结构.生年四化`（化科、化忌两行） |
| 占星 | 水星的星座、宫位与相位是主线；三宫是基础学习与日常交流，九宫是高等教育与信念体系，看两宫的宫主去了哪里；水星与土星成相位偏严谨而慢，与天王星偏跳跃，与海王星偏意象；水星在双子、处女有力，在射手、双鱼施展费力 | `结构.先天尊贵`（水星）、`结构.宫主落宫`（3、9 宫）、`结构.宫内行星`、`结构.相位趋势`（含水星的行）、`结构.守护.现代守护.定位星链`（水星） |
| 人格 | 知觉功能决定怎么摄入：Ne 发散联想，Ni 收敛成一个整体判断，Se 靠现场与动手，Si 靠对照已有经验；思考功能决定怎么组织：Ti 求内部自洽，Te 求可执行、可检验。看知觉轴（Si–Ne 或 Se–Ni）在主辅位还是在后两位 | `结构.类型贴合度.首选功能栈`、`结构.对立轴`（`Si–Ne`、`Se–Ni` 两行看摄入，`Te–Fi`、`Ti–Fe` 两行看组织） |

各自回答：人格答内在取向（怎么学）；占星的水星答内在取向，三宫九宫答情境（在什么场合学）；八字答资源关系（学进去的与用出来的是否相通）；紫微的星曜答内在取向，宫位答情境。

汇聚样式（合成示例）：

- **先拆后装**。八字：年干偏印透出，月支食神得令，印与食神隔位不相克。紫微：命宫天机，文昌同宫，对宫巨门。占星：水星处女在三宫，与土星成六分相。人格：Ti 主导，Ne 辅助。合读：四处都指向“把东西拆开看明白”。各自说的层次不同：人格说的是求自洽的动机，占星说的是细节上的耐心，紫微说的是推演的习惯，八字说的是偏印的独解能顺利变成食神的产出。合起来多理解的一点是，你学东西慢在开头、快在后面。前期拆解时看不到进度，一旦装回去就是自己的体系。用统一进度考核的环境（例如每周小测）容易低估你。
- **在讲给别人听的时候学会**。八字：伤官透干而有正印制，伤官配印。紫微：文曲在命宫，巨门化禄在迁移宫照命。占星：水星双子与上升点合相。合读：三种读法都把学习和表达绑在一起。八字多给了一个条件：伤官有印制，所以讲得出格但收得回来；没有印的伤官在子平读法里是锋芒外露而少章法。落到情境：你真正弄懂一件事，往往是在给别人讲第二遍的时候。

张力样式（合成示例）：

- **想得多，出得少（资源层）**。八字：偏印两见贴近日主，时干食神孤立无根，枭神夺食。人格：Ne 主导，想法多。占星：水星双鱼在十二宫，与海王星合相。合读：人格与占星说的是想法的来路很宽，八字说的是产出的通道被挡住。张力落在资源关系一层：进得来，出不去。合起来的理解比任何一方都具体：想法到成品之间缺一个强制出口。在子平的读法里，财星能制偏印、护食神，对应到生活是一个有交付期限、有人等着收货的场合。
- **信念与细节各拉一边（同层）**。占星：三宫的水星处女与九宫的木星双鱼成对分相。人格：Si 辅助，重可核对的经验。紫微：命宫天梁，重原则与大义。合读：占星在一张盘里就有细节与大图景的对分，人格站在细节一边，紫微站在原则一边。合起来说的是，你做判断时有两套标准轮流上场，一套问“对不对得上”，一套问“应不应该”。在需要快速表态的场合，这两套容易互相拖延。

## 3. 表达与创造

| 体系 | 看什么 | 字段 |
|:---|:---|:---|
| 八字 | 食伤是日主所生，是才华的出口：食神温厚持久，伤官锋利求异。身旺而食伤透出是吐秀，才气有源；身弱而食伤重是泄气，做得多而自己被掏空。食伤生财是作品能换成回报；伤官见官是表达与规范相冲；伤官配印是有锋芒也有章法 | `结构.藏干明细`（食伤所在及是否透干）、`结构.天干通根`（食伤干的根）、`结构.十神分组固定权重合计`、`结构.原局关系` |
| 紫微 | 巨门主言语，文曲主口才与才艺，文昌主文字，贪狼主才艺与多能，太阳主向外发散，天机主构思；看这些星落在命宫三方还是落在闲处；化禄、化权加在哪颗星上，那颗星的表达就被放大；福德宫看创作时的精神状态 | `结构.宫位关系`（命宫三方四正、福德宫）、`结构.生年四化` |
| 占星 | 五宫是创造与自我表现，看宫内行星与五宫主去向；太阳是想被看见的方式；水星管语言，金星管审美，海王星管想象，天王星管原创性；三宫管日常表达 | `结构.宫主落宫`（5、3 宫）、`结构.宫内行星`、`结构.相位趋势`（太阳、水星、金星相关行）、`结构.星群` |
| 人格 | 主辅功能里外倾的那一个是对外的主渠道（Fe 向人表达，Te 向事表达，Ne 抛出可能性，Se 在现场即兴）；第三功能是放松时玩出来的地方；内倾主导者的表达常经过辅助功能转译 | `结构.类型贴合度.首选功能栈`（第 1–3 位）、`结构.合计.态度` |

各自回答：人格答内在取向（走哪条渠道）；八字答资源关系（才气有没有源、有没有去处）；占星与紫微兼答取向与情境（在哪个领域、对谁表达）。

汇聚样式（合成示例）：

- **作品要落到实处**。八字：身旺，食神生财，财星有根。紫微：贪狼化禄在财帛宫。占星：五宫主金星落二宫巨蟹。合读：三种读法都把创造和回报连在一起。它们共同说的是：做出来的东西有人用、有人买，你才觉得完成；纯粹自娱的创作，你多半难以持续。
- **幕后的表达者**。人格：Ni 主导，Fe 辅助。占星：太阳十二宫，水星与海王星合相。紫微：命宫太阴，文昌同宫。合读：三处都指向经过酝酿的、书面的、一对一的表达，即兴的当众发言排在后面。合起来的理解：给你准备时间和文字载体，你的表达质量远高于现场反应。

张力样式（合成示例）：

- **锋芒与规矩（同层）**。八字：伤官透干，与月干正官相邻，伤官见官。紫微：命宫天相，重规范与分寸。合读：八字说这个人说话容易顶到规矩，紫微说这个人立身重分寸。张力落在同一层。读者可感的情境是，你在正式场合克制得很好，回头又觉得该说的没说；或者说了，事后反复想是不是过了。
- **有源而无口（跨层）**。八字：身旺印重，食伤只在时支藏干，不透。人格：Fe 主导，愿意表达。占星：太阳狮子五宫。合读：人格与占星说的是想表达、也擅长表达，八字说的是原局里出口小。合起来的理解是，你的表达更多用在照顾场面和回应别人上，自己想说的东西留得多。在子平的读法里，食伤在大运中透出时，这个出口读作打开。

## 4. 情感与亲密关系

未成年人不读本主题，改用 §11 的替换规则。

汇聚样式（合成示例）：

- **慢热而长情**。八字：日支坐正印，与月支六合。紫微：夫妻宫天府，对宫官禄宫武曲、七杀。占星：金星金牛，与土星成三分相；月亮巨蟹四宫。人格：Si 辅助，Fi 第三。合读：四种读法都指向稳定与积累。各说一层：八字说亲密关系这个位置上要的是被庇护的安稳，紫微说相处里看重的是可靠与能持家，占星说喜欢是慢慢确认的，人格说感情靠共同经历的记忆加深。合起来多理解的是，你在关系里的安全感来自可预期：约好的事照办，安排少变动。
- **关系里要有并肩做事**。紫微：夫妻宫会入官禄宫的化权。占星：七宫主落十宫。八字：日支藏官星，与月令官星同气。合读：三种传统读法都把亲密关系与事业连在一起。合起来的理解：对你来说，能一起做事的人才谈得上亲近；只在闲暇里相处的关系，你会觉得隔着一层。

张力样式（合成示例）：

- **要亲近，也要空间（跨层）**。人格：Fe 主导，关系气氛对你重要。占星：金星水瓶，与天王星成四分相；七宫无行星。紫微：夫妻宫天机，主变动与聪敏。合读：人格说你会主动照顾关系，占星与紫微说你在一对一里需要变化与留白。张力落在取向与情境之间：在人群里你是暖的，越靠近反而越要各自的时间。这一点值得你自己先说出来：你需要独处，与亲疏无关。
- **位置被牵动（资源层）**。八字：日支与月支相冲，月支又是月令。占星：四宫月亮与十宫土星成对分相。合读：八字说亲密关系的位置与月令（家庭与事业的门户）相冲，占星说安全感与社会责任相互挤压。两处都指向亲密关系与家庭或工作之间的时间争夺，这是汇聚在“张力的位置”上。合起来的理解：你在关系里的难处，多半出在两个人与各自身后的事情之间。

## 8. 人际与社群

| 体系 | 看什么 | 字段 |
|:---|:---|:---|
| 八字 | 比肩、劫财是同侪：比肩是并肩的同类，劫财是既合作又争夺；印看庇护与提携，官杀看规范与约束，食伤看自己带出来的人。看这些十神在哪一柱、与日主远近如何；天干五合与地支六合多的盘，传统读法里人缘与牵绊都多 | `结构.天干通根`（各干十神）、`结构.藏干明细`、`结构.十神分组固定权重合计`（比劫）、`结构.原局关系`（合的部分） |
| 紫微 | 交友宫（旧称仆役宫）看朋友、同事与下属，兄弟宫是其对宫，看手足与亲近的同辈；迁移宫看在外的际遇与给人的印象；左辅右弼、天魁天钺是助力之星，看它们落在哪里 | `结构.宫位关系`（交友宫、兄弟宫、迁移宫及邻宫、`三方四正四化`）、`结构.生年四化` |
| 占星 | 十一宫是社群、朋友与共同理想，三宫是手足、邻里与日常往来，七宫是一对一的合作；金星是与人相处的方式，水星是交流的方式，木星是贵人与善意所在 | `结构.宫主落宫`（11、3、7 宫）、`结构.宫内行星`、`结构.星群`、`结构.相位趋势`（金星、木星相关行） |
| 人格 | 内倾或外倾的总体态度；Fe 顾及群体气氛，Fi 重一对一的真诚；第五位（对立人格位）的功能是最容易在别人身上看不顺眼的方式 | `结构.合计.态度`、`结构.对立轴`（`Ti–Fe`、`Te–Fi`）、`结构.类型贴合度.首选功能栈`（第 5 位） |

各自回答：人格答内在取向；紫微与占星答情境与角色；八字答资源关系（人际是助力还是分耗）。

汇聚样式（合成示例）：

- **朋友少而深**。人格：Fi 主导，内倾。占星：十一宫主落八宫，月亮天蝎。紫微：交友宫太阴，兄弟宫天同。八字：比劫仅一位，在日支藏干。合读：四处都指向少数、长期、私下的交情。合起来的理解：你不缺社交能力，缺的是对泛泛之交的兴趣。需要维持大量弱联系的场合（例如行业酒会）对你是纯消耗。
- **助力来自请教**。八字：年干正印透出，生扶日主。紫微：天魁在命宫，天钺在福德宫。占星：木星与上升点合相。合读：三种传统读法都说这张盘得人提携，八字把来路指向印星一路，也就是师承与庇护。落到情境：例如遇到难处时，主动去找懂行的人请教，对你是顺水的事。

张力样式（合成示例）：

- **合作里有争夺（资源层）**。八字：时干比肩，与日主争合月干正财。占星：十一宫木星，朋友多而慷慨。合读：占星说你在群体里受欢迎，八字说同侪之间有资源上的分夺。合起来的理解：你和朋友之间情分是真的；涉及共同的钱与机会时，事先把账写清楚，情分才留得住。你这张盘上的同侪关系本来就有这两面。
- **在人群里暖，在团队里独（跨层）**。人格：Fe 辅助，善于照顾场面。紫微：交友宫七杀，对宫兄弟宫天府。合读：人格说你会主动让大家舒服，紫微说你与同事下属的关系是直来直去的、各管各的。读者可感的情境：聚会上你是照顾别人的那个，做项目时你却更愿意自己包一块，不太喜欢反复协调。

## 9. 压力与阴影

本主题谈压力从哪里来、表现为什么样的行为与感受、靠什么恢复。不从盘面或分数推断疾病、身体部位或心理障碍，见 §12。

| 体系 | 看什么 | 字段 |
|:---|:---|:---|
| 八字 | 七杀无制是压力直接攻身；官杀混杂是两套要求同时压来；枭神夺食是想法堵住出口；伤官见官是与规范的摩擦；羊刃逢冲是力量过猛而失控；地支的冲与刑是结构里长期的不安稳处。调候看全局寒暖燥湿是否偏于一端，读作处境的紧绷或沉滞 | `结构.原局关系`（冲、刑、害）、`结构.禄刃`、`结构.天干通根`（官杀干）、`结构.十神分组固定权重合计`、`结构.月令` |
| 紫微 | 生年化忌落在哪一宫，那一宫就是最放不下的领域，它还冲对宫；擎羊、陀罗、火星、铃星、地空、地劫六煞落处是用力与受挫处；福德宫看精神上的负担与恢复方式。疾厄宫只作传统宫名，不据此谈身体 | `结构.生年四化`（化忌一行）、`结构.宫位关系`（化忌所在宫及其对宫、福德宫） |
| 占星 | 土星是恐惧与自我要求，冥王星是控制与执念，十二宫是独处、隐退与不易被看见的内在生活，八宫是共享资源与心理上的转化；T 三角的顶点行星是全盘压力的出口，大十字是四面受力；失势或落陷的行星是施展费力处，读作费力，不读作能力差 | `结构.相位图形`、`结构.相位趋势`（硬相位行）、`结构.宫内行星`（12、8 宫）、`结构.先天尊贵`、`结构.宫界距离` |
| 人格 | 劣势功能在长期压力下会以粗糙的形式接管（Quenk 称为 grip）；阴影四位（第五至第八位）是平时不认同的方式，被触发时带着防御。JUNGUS 一类测验里第五、第六位的分数高过劣势位是常态，不当作异常。要与本人自述对照，不单凭分数断言 | `结构.类型贴合度.首选功能栈`（第 4 位为劣势，第 5–8 位为阴影四位）、`结构.对立轴`、`结构.分层`（阴影位功能是否进了上层） |

各自回答：人格答内在取向（压力下变成什么样）；八字答资源关系（压力从哪个关系来）；紫微与占星答情境（压力在哪个生活领域）；时间结构由大运、大限补充（哪一段被推到前台）。

汇聚样式（合成示例）：

- **压力来自自我要求**。八字：七杀透干贴身，仅有偏印化杀，无食神制。紫微：化忌在官禄宫，冲夫妻宫。占星：土星与太阳合相于十宫。人格：Te 主导，Fi 劣势。合读：四处都把压力指向事业上的自我要求。各说一层：八字说压力是靠“忍”和“学”化解的（印化杀）；紫微说最放不下的是工作，代价落在亲密关系上；占星说标准是自己给自己定的；人格说压到极限时，平时不理会的个人感受会突然涌上来。合起来可以给读者一个识别信号：当你开始对小事觉得委屈、觉得没人在乎你，那多半是负荷已经过线的信号。
- **压力来自说不出口**。八字：枭神夺食。占星：十二宫水星与土星成四分相。紫微：巨门化忌在福德宫。合读：三种传统读法都指向话在心里打转、出不来。合起来的理解：事情解决之后，你的压力多半还在，要等到把它说出来或写下来才算完。

张力样式（合成示例）：

- **恢复方式相反（同层）**。人格：内倾主导，靠独处恢复。紫微：福德宫太阳、巨门，闲不住，越说越通。合读：两种读法在“怎么恢复”上方向相反。写出各自的条件，让读者对照：如果一场长谈之后你觉得轻了，紫微这条读法更贴近你；如果觉得更累，独处那条更贴近，福德宫这条读法在你身上就不太贴合。
- **看起来稳，里面紧（跨层）**。占星：上升金牛，太阳金牛，固定星座居多。八字：日支与时支相刑，月支逢冲。合读：占星说的是你给人的样子和你的意志都稳，八字说结构内部有两处长期不安稳。合起来的理解：旁人很少察觉你在承压，因此也很少有人主动来分担。需要帮助时，你得自己开口说。

## 10. 人生节奏与时间

只使用计算器实际给出的周期与区间。谈这一段时间的主题，不谈某年会发生什么事。

| 体系 | 看什么 | 字段 |
|:---|:---|:---|
| 八字 | 大运十年一换，看当前大运的干支对原局是生扶还是克泄，是补上了用神还是加重了忌神；大运与月令相冲、与某柱伏吟或天克地冲，是结构被牵动的十年；流年看与原局、大运的同类关系。四柱配人生阶段的说法属通行框架，本表不据此写人生历程 | `结构.大运与原局`、`结构.流年与原局`，以及计算产物中的起运与大运表 |
| 紫微 | 大限十年一宫，大限命宫落在本命哪一宫，那一宫的主题就是这十年的主场；大限四化落在本命哪几宫，说明这十年顺手处、掌权处、操心处；流年同理 | `结构.当前大限四化`、`结构.当前流年四化`、`结构.宫位关系`（大限命宫所在的本命宫一行） |
| 占星 | 本命盘的计算产物不含行运与推运。只有确有这类计算输出时，占星才参与时间主题；否则本列留空，不以土星回归之类的通用年龄周期充当个人化的时间判断 | 无对应字段 |
| 人格 | 人格资料没有时间结构。类型发展的说法（主导先分化，辅助次之，劣势最晚）是理论框架，不作为年龄时间表 | 无 |

各自回答：八字与紫微答时间结构；本主题通常是两个体系的综合。人格与占星的本命主张可以作为“被推到前台的是哪一条内在主题”的说明，登记为父主张时要写清它们不提供时间依据。

汇聚样式（合成示例）：

- **同一个十年，同一个主场**。八字：当前大运走食神，原局食神本弱，此运透干得根。紫微：当前大限命宫落在本命官禄宫，大限化禄入本命命宫。合读：两种传统读法都把这十年读作专长得以施展、事业成为主场的阶段。各说一层：八字说的是原局里出口小的那部分才华，这十年有了通道；紫微说的是这十年的生活重心落在事业领域。合起来的理解：这一段适合把积累多年的东西做成可以署名的作品。
- **结构被牵动的十年**。八字：大运与月令相冲。紫微：大限命宫落在本命迁移宫，大限化忌冲本命命宫。合读：两处都说这十年是变动期，根基与环境在换。合起来多理解的是变动的性质：八字说动的是事业与家庭的门户，紫微说变动与外出、换环境相连。对读者的意思是，这十年值得花心思的是选择往哪里动。

张力样式（合成示例）：

- **一个说进，一个说守（同层）**。八字：当前大运为印，身弱得生，宜积蓄学养。紫微：当前大限命宫落在本命财帛宫，大限化权入官禄宫，主进取。合读：两种读法对这十年的基调看法不同。写出各自着眼的东西：八字看的是自身力量在恢复，紫微看的是外部领域有掌权的机会。合起来是一个可操作的理解：机会是真的，但这十年接机会的方式宜是边做边学、借助师长与资质。
- **时间说到了，取向还没到（跨层）**。八字与紫微都把当前十年读作事业主场。人格：本人自述与分数都显示此刻更想向内整理（Ni 主导，近期回避对外事务）。合读：传统读法说的是时间结构，人格说的是当下的内在取向，两者没有谁推翻谁。写给读者的是对照：如果你感到外面的事一件件找上门而自己只想躲，这正是这组张力的样子。

## 11. 未成年人的主题替换

当事人未满 18 岁或年龄未知时，按下表替换主题。替换后的主题仍可做汇聚与张力的综合，要求相同。

| 原主题 | 替换为 | 各体系改读什么 |
|:---|:---|:---|
| 情感与亲密关系 | 家庭、同伴、师长与边界 | 八字读印星（长辈）、比劫（同伴）、官杀（规矩与师长），日支只按自坐读；紫微读父母宫、兄弟宫、交友宫；占星读月亮、四宫、三宫、十一宫，七宫只读一对一的同伴与搭档，金星、火星只读喜好与行动方式；人格读 Fe 或 Fi 的方向与辅助、第三功能。配偶星、配偶宫、夫妻宫、五宫的恋爱义、八宫的亲密义一律不读 |
| 事业与社会角色 | 学习与兴趣 | 八字的格局读作“擅长以什么方式投入”，不读职业；紫微读官禄宫的学业义与命宫、福德宫；占星读水星、三宫、九宫、五宫的兴趣义；人格读知觉与判断功能的学习方式 |
| 财务与资源 | 对物与时间的使用习惯 | 只谈怎样安排零用、物品与时间，不谈财运与取财方式 |
| 压力与阴影 | 压力从哪里来、怎样恢复 | 写成观察与支持的角度；不把盘面、类型、分数或功能位置写成能力缺陷、风险标签或人生限制 |
| 人生节奏与时间 | 当前学段的主题 | 只谈当前大运或大限所对应的学段，不写成年以后的婚恋、职业年份 |

写给未成年人的综合判断，情境取自学校、家庭、同伴与兴趣活动。不写“你是……的孩子”式的身份标签。监护人读的段落只在受众包含监护人时写，内容限于观察与支持。

写给未成年读者的综合主张、核心命题与提纲里不出现四字母类型名，只写主导与辅助功能的做法（“你拿到新东西，先……”）。类型名只出现在监护人段或附录。

## 12. 红线

以下各条适用于本表全部主题与示例，也适用于据本表写出的综合主张。

1. 不从盘面或分数推断疾病、身体部位、寿命、死亡、生育结果，不作心理或医学诊断。健康或身心状态类主题（`wellbeing`）只谈作息与节奏、压力来源、恢复方式与当事人自述；八字五行偏枯、紫微疾厄宫、占星六宫与十二宫都不对应到器官或病名。
2. 不承诺确定事件，不给结婚、升职、发财的年份，不给投资时机、关系成功率或匹配分数。
3. 不编造盘面值、分数、引文、来源或当事人经历。生活情境以“例如”“如果”标明，是供读者对照的设想，不写成已经发生的事。
4. 汇聚是几种传统读法在叙事上落到一处，不构成科学验证，也不提高任何一条读法的概率；不让其他体系替类型假说作证。不由出生盘生成人格分数或类型。
5. 本表示例全部为合成，不对应任何真实个案。个案的出生资料不写进参考资料或跨会话记忆，不提交外部站点。

判断是否越线的标准：说的是“这个传统怎么读这张盘”，可以说得肯定；说的是“现实里一定会发生什么”或“身体、能力有什么毛病”，不可以。
