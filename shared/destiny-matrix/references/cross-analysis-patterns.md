# 多维交叉分析 · v3 · 性格本位重构

> 本文档是 destiny-matrix v3 的交叉分析骨架。
> **核心立场：性格决定命运，玄学辅证，命运可塑。**
> 性格画像（荣格八维）是主语；八字、紫微、占星是谓语与状语，负责印证、映照、解释——而非裁判。

---

## 顶部哲学声明：重读《果老星宗》"体用相参"

> 命主以四柱为体，星宗以七政为用；体用相参，方知全貌。
> ——《果老星宗》

v2 曾将这段引文解读为"四柱为体、占星为用"的横向并列。v3 必须翻转：

- **「体」= 性格本质**（恒量 · 可发展）。荣格八维所揭示的认知结构、Beebe 八位原型剧场、阴影与劣势功能、个体化进程——这才是真正不可让渡的"体"。
- **「用」= 玄学时机注解**（应期 · 窗口）。八字给出能量基础，紫微给出剧场舞台，占星给出宇宙节律。它们不"决定"性格，而是为性格的展开标注"在哪一段时间、以何种文化坐标登场"。

这不是横向并列的四维投票，而是纵向递进的解释链：

```
性格签名（荣格主导，恒量 · 可发展）
       │
       ├─ 八字「解构」── 性格能量的物质基础（材质）
       ├─ 紫微「对应」── 性格上演的剧场舞台（场域）
       └─ 占星「映照」── 性格共振的宇宙节律（节拍）
       │
玄学解释力评级（一致性 = 文化坐标的清晰度，而非真理的概率）
       │
终极裁判：性格自身（个体化进程 / 劣势功能整合）
```

玄学的价值不在"预言"，而在"文化坐标"。当三维玄学共同清晰地印证同一性格签名时，意味着这一签名拥有跨越体系的文化语义厚度；当三维出现张力或反向时，**终极裁判永远是性格画像本身**，玄学只标注其"解释边界"。

## 玄学三维印证工作流

**Step 1 · 完成荣格性格画像**

调用 `scripts/jung_calc.py` 输出的性格签名作为唯一主语。性格签名至少包含：

- 功能栈（主导 / 辅助 / 第三 / 劣势）
- Beebe 八位原型（Hero / Parent / Child / Anima·Animus / Opposing / Senex·Witch / Trickster / Demon）
- 主导 Grip 模式（劣势功能爆发的典型场景）
- 个体化进程当前阶段（青年立基 / 中年整合 / 老年传承）

任何后续玄学解读，**禁止脱离性格签名独立成段**。

**Step 2.1 · 八字解释力评估**

任务问题：**"为什么是这种性格？性格的能量从何处供给？"**

工具：十神配置、格局高低、喜用神调候、神煞、五行旺衰。

输出：一段说明八字如何为性格签名提供"能量基础"的注解，并填写本章末的解释力自评。

**Step 2.2 · 紫微解释力评估**

任务问题：**"性格在哪个舞台上演？"**

工具：命宫 / 身宫 / 三方四正 / 十二宫 / 十四主星 / 四化 / 大限。

输出：一段说明紫微如何为性格签名提供"剧场舞台"的注解（家庭、事业、感情、迁移……分别是什么类型的剧场），并填写解释力自评。

**Step 2.3 · 占星解释力评估**

任务问题：**"性格与什么时代节律共振？"**

工具：日月上升、内行星（水金火）、社会行星（木土）、超个人行星（天海冥）、关键相位、当前行运。

输出：一段说明占星如何为性格签名提供"宇宙节律"的注解，并填写解释力自评。

**Step 3 · 玄学三维印证强度评级**

将三维印证结果汇总成一个总评（详见后文"玄学解释力评级机制"）：

- 三维清晰一致印证 → ★★★★★（文化坐标极清晰）
- 双维印证、单维中性 → ★★★★☆
- 双维印证、单维张力 → ★★★☆☆
- 仅单维印证 → ★★☆☆☆
- 玄学与性格签名整体反向 → ★☆☆☆☆，必须明示"玄学解释边界"

**Step 4 · 玄学与性格存在张力时的裁判规则**

- **以性格画像为最终判定**。
- 标注"玄学解释边界"：说明该维度玄学体系的方法论局限、数据敏感度（如紫微闰月、占星高纬度 fallback）或文化语义错位。
- 不得用"四维投票"反推性格——玄学没有否决权。

## 玄学解释力评级机制

每一个玄学维度（八字 / 紫微 / 占星）的分析章节末尾，必须做如下自评：

```markdown
**本章对性格签名的解释力：★★★★☆**

- 强解释：[列举强印证点，如"日主庚金 + 七杀显露 → 强力印证 Se-Hero"]
- 弱解释：[列举弱印证或张力点，如"食神见伤但官星不显，对 Fi 主导仅中度印证"]
- 总评：[一句话总评，如"八字为性格签名提供了清晰的能量基础，唯独感情维度需让位给紫微夫妻宫"]
```

评级语义（注意：这是"文化坐标清晰度"，不是"真理的概率"）：

| 评级 | 语义 |
|:---|:---|
| ★★★★★ | 所有性格签名核心维度都被印证，文化坐标极清晰 |
| ★★★★☆ | 大部分印证，少数张力，文化坐标基本清晰 |
| ★★★☆☆ | 部分印证、部分中性，文化坐标局部清晰 |
| ★★☆☆☆ | 弱印证、多张力，文化坐标模糊 |
| ★☆☆☆☆ | 玄学与性格相反，**必须明示"玄学解释边界"**，并以性格画像为最终判定 |

**禁止行为**：

- 不得用玄学评级反推或修改性格签名。
- 不得在评级为 ★★☆☆☆ 或更低时，强行编造"勉强自洽"的解读。诚实标注边界比表演自洽更可信。

## 常见共振模式库（性格本位重写版）

以下模式皆遵循"性格签名居首、玄学三维印证"的写法。每一段先描述性格画像，再列出玄学三维的"通常印证特征"。

### 模式 A：头脑远超心灵

**性格画像**：T 功能（Te / Ti）位居主导或辅助，F 功能（Fe / Fi）退居第三或劣势。这类人认知极强、逻辑清晰，但情感表达受困——主导功能的高效与劣势功能的迟钝形成长期张力。Aspirational Child（第 3 位）常落在 F 上，意味着"对情感联结的隐秘渴望"是其个体化的核心课题。

**玄学三维印证特征**：

| 维度 | 通常印证特征 |
|:---|:---|
| 八字 | 金旺或水旺，火弱；正官 / 偏官透干，食伤受制 |
| 紫微 | 命宫武曲 / 紫微等理性主星，福德宫主星陷落或带煞 |
| 占星 | 风象 / 土象主导；日月对冲或紧张相位（90°、180°） |

**性格本位结论**：感情是核心课题。终极任务不是"变得感性"，而是让劣势 F 功能从"被嘲弄的位置"回到"被承认的位置"。

### 模式 B：大器晚成

**性格画像**：直觉功能（Ne / Ni）主导，需要长时间的内在整合才能输出。青年阶段常被误判为"懒散 / 不接地气"，因为辅助与第三功能（往往是 T 或 S）尚未发展成熟。中年之后劣势功能整合、阴影接纳，性格签名才真正"完整上线"。

**玄学三维印证特征**：

| 维度 | 通常印证特征 |
|:---|:---|
| 八字 | 喜用神落在后半程大运（如金神格待火运、伤官待印运） |
| 紫微 | 前几个大限星曜组合煞重，后段大限主星庙旺或四化喜聚 |
| 占星 | 土星行运多次回归后的节点（约 30、58 岁）形成绽放期 |

**性格本位结论**：前半生积蓄、后半生释放，不是命定，而是直觉型人格的天然节律。

### 模式 C：内在撕裂

**性格画像**：主导与劣势功能的能量级差极大（信息处理风格与情感判断风格相互掣肘），Opposing Personality（第 5 位）常被激活成持续的内耗。

**玄学三维印证特征**：

| 维度 | 通常印证特征 |
|:---|:---|
| 八字 | 五行极端偏枯，喜用与忌神同柱见 |
| 紫微 | 命宫与福德宫主星性质矛盾（如命宫七杀 + 福德天同） |
| 占星 | 日月对冲或日月刑相，内外行星跨象限对立 |

**性格本位结论**：深层撕裂不是缺陷，而是个体化进程的高浓度题目。终极任务是让 Opposing Personality 从"对抗者"转为"另一种声音"。

### 模式 D：孤勇者

**性格画像**：Te / Se 高，Fe 落在劣势。行动力极强、独立性极高，但群体协作中容易"自我孤立"。Demon（第 8 位）常落在 Fe 上，意味着"被群体抛弃的恐惧"在深处反复书写。

**玄学三维印证特征**：

| 维度 | 通常印证特征 |
|:---|:---|
| 八字 | 比劫旺或孤鸾煞 / 华盖 |
| 紫微 | 命宫七杀 / 破军坐守，交友宫空宫或煞星多 |
| 占星 | 火象主导，上升白羊 / 天蝎；土星合相个人行星 |

**性格本位结论**：独立性是天赋；终极任务是让 Fe 从"恐惧位"回到"可发展位"——学会接受协助而不视之为羞辱。

### 模式 E：敏感过载

**性格画像**：Ni / Fi 高、Se 落在劣势。感知力极细腻，但身体感官与外部现实接触不足，容易被情绪与象征淹没。Trickster（第 7 位）常表现为"对身体节奏的笨拙"。

**玄学三维印证特征**：

| 维度 | 通常印证特征 |
|:---|:---|
| 八字 | 水旺或印星过多，食伤不显 |
| 紫微 | 命宫太阴 / 天同 / 天梁组合，福德宫化忌 |
| 占星 | 水象主导，月亮落水象，海王显著 |

**性格本位结论**：高感知是天赋；终极任务是发展 Se——通过身体节奏、规律饮食、空间秩序，把"内在涟漪"锚回现实。

### 模式 F：内外反差

**性格画像**：外倾与内倾功能的分数差距大；Persona（社会面具）与 Hero（核心功能）有距离，容易被外人误读。

**玄学三维印证特征**：

| 维度 | 通常印证特征 |
|:---|:---|
| 八字 | 天干与地支五行矛盾，干透与藏支不一 |
| 紫微 | 命宫与迁移宫主星性质反差大 |
| 占星 | 太阳与上升所在元素对立 |

**性格本位结论**：反差不是"双面人"，而是 Persona 与 Hero 的健康分工。终极任务是让二者不要互相否认。

### 模式 G：开拓型创业者

**性格画像**：Ne / Se 高、Si 落在第三或劣势。探索性极强、安稳感弱，天生不耐重复。但若不发展 Si，会陷入"反复推倒重来"的循环。

**玄学三维印证特征**：

| 维度 | 通常印证特征 |
|:---|:---|
| 八字 | 食伤生财格、或七杀 + 食神配置 |
| 紫微 | 命宫三方会杀破狼 |
| 占星 | 火象 + 风象主导，木星 / 天王显著 |

**性格本位结论**：天生开拓者；终极任务是让 Si 成为"可调用的资源"而非"被嫌弃的劣势"——稳定的复盘、规律的运动、可继承的流程，正是其个体化进程的关键。

### 模式 H：体制稳健型

**性格画像**：Si / Te 高，重传统、重秩序、重系统。在大型组织内能稳步升迁，但 Ne 落在劣势时容易被外部变革打懵。

**玄学三维印证特征**：

**性格本位结论**：稳健是天赋；终极任务是让 Ne 不被视为威胁——为它腾出一个安全的"小实验区"，让创新不必颠覆秩序。

## 命运密码提炼公式（v3 修订版）

```
命运密码 = 性格底色（荣格主） × 玄学时机（大运 / 大限 / 行运）
```

每一条命运密码必须满足以下 6 段结构：

1. **隐喻标题**（一个意象，例如"钢琴线之喻""安静的火山""锈剑寻锋"）
2. **性格底色**（一句话总结荣格签名的核心）
3. **玄学注解**（三维各一句话）
   - 八字：能量基础是什么
   - 紫微：上演的剧场是什么
   - 占星：宇宙节律是什么
4. **时机窗口**（点出大运 / 大限 / 行运的应期）
5. **核心含义**（在性格 × 时机的交叉点上，正在发生什么）
6. **可塑路径**（**必须可操作**的具体行动建议，至少 2-3 条）

示例骨架：

```markdown
### 密码 1：锈剑寻锋

- **性格底色**：Te-Hero + Fi-Inferior，决断力极强但情感锚点稀疏。
- **八字注解**：庚金日主，七杀透干无制，能量集中于"对外征服"。
- **紫微注解**：命宫武曲坐辰，三方会七杀，是金属决断剧场。
- **占星注解**：火星合冥王在第十宫，事业是冥王式的转化场。
- **时机窗口**：33-42 岁大限走入夫妻宫，土星行运合相本命月亮（约 34 岁）。
- **核心含义**：劣势 Fi 在事业巅峰期被土星硬性拽出来训练；不是要"变温柔"，而是要让"价值锚点"从外部成就转向内在意义。
- **可塑路径**：
  1. 每周一次"非生产性"独处（写日记、长走、独自吃饭），训练 Fi 的内向通道。
  2. 在关键决策前增加一道"我重视什么"的自问，而不仅问"什么有效"。
  3. 选择一个不功利的兴趣，坚持三年，作为 Fi 的练习场。
```

## 终极课题约束

终极课题是命书的"最后一句话"，必须遵守：

1. **必出自荣格劣势功能 / 阴影整合任务**。不得从玄学单独推出。
2. 玄学只用来标注"最迫切的应期窗口"（即"什么时候、以什么样式被外界推到这个题目面前"）。
3. **必须含具体行动建议**，禁止抽象口号（如"学会爱""活出自己"）。
4. 行动建议应贴合性格签名的可操作性：Si 弱的人不要被要求每天打卡；Ne 弱的人不要被要求"多探索新事物"——要给与性格签名同频的练习方式。

终极课题示例：

> **终极课题：让 Fi 从"嘲弄位"回到"承认位"**
>
> 时机窗口：35-44 岁大限走福德宫，土星行运二次回归。
>
> 行动建议：
> 1. 建立"非工作身份"——每年一次的非功利创作，可以无人知晓。
> 2. 拒绝一次"看似正确"的事业邀约，记录拒绝时身体的反应。
> 3. 寻找一位允许你不强势的关系（友情或亲密关系皆可），每月深谈一次。

## 双轨时间线：性格发展 × 玄学应期

将荣格个体化阶段（性格本位的恒量发展轴）与八字大运 / 紫微大限 / 占星行运（玄学应期）对齐：

| 年龄段 | 性格本位发展（荣格主轴） | 八字应期注解 | 紫微应期注解 | 占星应期注解 |
|:---|:---|:---|:---|:---|
| 13-20 | 辅助功能发展 | 第 1-2 步大运 | 第 1-2 个大限 | 木星首次回归（约 12 岁） |
| 20-35 | 第三功能觉醒 | 第 2-3 步大运 | 第 2-3 个大限 | 土星首次回归（约 29-30 岁） |
| 35-50 | 劣势功能整合（"中年危机"） | 第 3-4 步大运转折 | 第 3-4 个大限 | 天王对冲（约 40-42 岁） |
| 50+ | 阴影功能接纳、整合传承 | 后段大运 | 后段大限 | 土星二次回归（约 58-60 岁） |

**使用方法**：性格本位决定"该做什么作业"，玄学决定"何时被外界推到作业面前"。当两轴交叉、应期与发展任务同频时，该阶段就是命书中应当被重点展开的"核心章节"。

## 感情专题交叉框架（性格本位重写版）

感情章节必须以荣格 Fi / Fe + 阿尼玛 / 阿尼姆斯为骨架，玄学三维只负责"应期标注"。

### 必须包含的六个部分

1. **荣格骨架**：Fi / Fe 在功能栈中的位置 + 阿尼玛 / 阿尼姆斯投射模式 + Child（第 3 位）的情感渴望。
2. **玄学应期注解**：
   - 八字：日主与官杀 / 财星 / 食伤的能量结构（说明性格的感情"能量基础"）。
   - 紫微：夫妻宫主星、三方四正、大限是否走入夫妻宫本位（说明感情剧场）。
   - 占星：金星 / 火星相位、第七宫主星、关系类行运（说明感情节律）。
3. **择偶画像**：从荣格阿尼玛 / 阿尼姆斯投射 + 玄学剧场推导"会被吸引的人"和"真正适合的人"——并明示二者的差距。
4. **"会给予的"与"需要但不会主动说出口的"**：前者来自主导 / 辅助功能，后者来自劣势 / 第 3 位 Aspirational Child。
5. **感情演化阶段**：至少分三阶段，以荣格个体化为主轴，玄学大运 / 大限 / 行运标注每阶段的"加压点"或"礼物点"。
6. **当前感情运势 + 未来感情窗口期**：明示"性格在此时段被推到的作业是什么"，而非"会不会遇到对象"。

### 感情阶段判定原则

- 紫微大限走入夫妻宫本位 = 感情剧场进入主舞台年代，往往是关键期。
- 八字大运行至食伤克官 / 财星旺 / 桃花柱 = 性格在该阶段的"感情能量"特别充沛或特别紧张。
- 占星金星行运 / 第七宫主行运 = 感情节律的具体应期。
- **以上三者皆是"应期"，不是"结果"。结果由性格在此应期中如何回应所决定。**
