# 多维分析与综合

## 综合要交出什么

综合章是全书最有分量的一章。各体系 analyst 先按自己的 framework 独立读完，综合者再围绕读者的问题，把几种读法放到同一个主题下，回答三件事：

1. 各体系在这个主题上分别看到了什么，依据是盘面或分数的哪一处；
2. 它们是落到了同一处（汇聚）、互相拉扯（张力）、可以并排读（并列），还是回答的根本不是同一个问题；
3. 合起来之后，比任何单独一种读法多理解了什么，这个理解落在读者生活里的哪种情境。

四份摘要排在一起不算综合。“各体系相互呼应”“不同视角各有侧重”这类换一张盘也成立的话不算综合判断。

各体系在每个主题上看什么、对应哪些字段、常见的汇聚与张力是什么样子，见 [`theme-crosswalk.md`](theme-crosswalk.md)。综合判断的具体程度以该表的示例为准。

## 综合顺序

1. **选主题**。从 intake 的问题和各体系已登记的主张出发，对照 `theme-crosswalk.md` 的主题清单选取。完整书通常覆盖自我与气质、思维与学习、事业与社会角色、关系、人生节奏，再按读者的问题增减。某体系在某主题没有主张，该列留空；两个体系就能综合。
2. **读清各体系回答的是哪一类问题**。内在取向、情境与角色、资源关系、时间结构四类，见对照表 §0。同一个主题词下，人格说的可能是“你习惯怎么做”，紫微说的是“这件事发生在哪个领域”，八字说的是“力量够不够、从哪来”。先分层，再比较。
3. **判定关系**。按下文“矩阵关系”的条件，在 `convergent`、`tension`、`parallel`、`not_comparable` 中选一个。
4. **写综合判断**。按下文“综合判断的合格标准”写成一条主张，登记为 `synthesis_claims`，`parent_claim_ids` 指向所依据的各体系主张。
5. **提炼核心命题并写进提纲**。从综合主张里提炼 3–5 条 `core_propositions`；在 `outline.sections[].required_content` 写明每章要解释的关系、新增的理解和回扣的命题编号。

产出须通过 `scripts/synthesis_contract.py` 的校验，见文末。

## 矩阵关系

`matrix` 是索引，说明哪些主张被放在一起读、关系是什么。每个主题一行：

```json
{
  "theme": "思维与学习",
  "personality_claim_ids": [],
  "bazi_claim_ids": [],
  "ziwei_claim_ids": [],
  "astro_claim_ids": [],
  "relationship": "convergent",
  "limits": []
}
```

各列只填该体系 analyst 已登记且有效的主张 ID，综合主张不填进矩阵列。`relationship` 取以下四值之一：

| 取值 | 判定条件 | 正文里怎么说 |
|:---|:---|:---|
| `convergent` 汇聚 | 至少两个体系各自独立得出的主张，在同一主题、同一类问题上指向相近方向；每个体系的主张都能回到盘面或分数依据；相近的是判断的方向，不只是用了同一个词 | “三种读法在这里落到同一处” |
| `tension` 张力 | 至少两个体系的主张方向相反或相互牵制，各有依据。同层张力是同一类问题上方向相反；跨层张力是内在取向与所处情境、资源流向之间不一致 | “两种读法各拉一边”“性子往这边，位置在那边” |
| `parallel` 并列 | 各体系在同一主题上各有主张，可以并排阅读，既不指向同一处也不相互牵制 | “可以并读” |
| `not_comparable` 各答各的 | 回答的问题类别不同且没有共同落点，或某一方的资料不足以比较。写出各自的用途，不以这个标签收尾 | “回答的不是同一个问题” |

判定时注意：

- **汇聚要逐条核对独立性。** 各体系的主张必须是 analyst 在不看其他体系的情况下得出的。综合者不为了凑汇聚去改写某体系的主张，也不从盘面另起一条读法。某体系的主张本身是从人格资料推出来的，不算独立。
- **汇聚说的是叙事上落到一处。** 各体系是各自独立的传统，相近不等于科学证明，也不提高任何一条读法的概率。这句话在综合章开头对读者说一次，此后各处直接写汇聚，不再逐处声明。
- **汇聚与张力可以同时存在于一个主题。** 例如三个体系汇聚、第四个体系与它们成张力。矩阵按主导关系标一个值，另一层关系写进综合主张，并在 `limits` 注明。需要分开讲时，拆成两个主题行（主题名不同）。
- **标 `convergent` 或 `tension` 的行至少引用两个体系的主张**，并且要有一条综合主张以这一行里至少两个体系的主张为父主张。
- 矩阵不设评分、百分比、一致性等级。缺某体系资料时该列为空数组，在 `limits` 写明缺口。

## 综合判断的合格标准

每条综合判断同时满足三条，并遵守一条用语约定。

0. **用读者叫法。** 占星相位在 `statement`、命题与提纲里写合相、对分相、三分相、四分相、六分相；计算器标签（对冲、三合、四分、六合）只留在字段与数据层。八字、紫微的“三合”“六合”“冲”指地支与宫位关系，照原样用。
1. **点名盘面依据，过得了换盘测试。** 写出每个体系具体依据的是哪一处：哪个十神在哪一柱、哪颗星在哪一宫带什么四化、哪颗行星在哪个星座宫位成什么相位、哪个功能在哪个位置。把这些依据换成另一张盘的，这句判断就应当不成立。
2. **说出汇聚或张力落在哪一层。** 是内在取向一致，还是取向与情境相左，还是资源流向受阻，还是时间结构与当下状态不合。各体系各说了哪一层，合起来补全了什么。
3. **落到读者可感的情境。** 给出一个读者能回答“像”或“不像”的具体场合。情境以“例如”“如果”标明，是供对照的设想，不写成已发生的经历。

判断用正面说法写：直接说“是什么”，少用“不是甲，而是乙”的句式。写倾向（“多半”“容易”），不写现实结果（“不回落”“隔几年就会”）。关系与家庭主题只写当事人自己的方式与感受，不写对方或家人是什么样的人，不写“早年”“晚年”“一生”这类人生历程断语。

写法上按“依据、层次、合读、情境”的顺序组织素材；成文由 writer 负责，综合者交的是内容齐备的判断。

### 不合格与合格的对照（全部为合成示例）

**对照一：思维与学习**

不合格：

> 四个体系都显示你有较强的学习能力，思维活跃，善于思考。学习做到哪一步，与这一步处在什么情境，是两个问题。

问题：没有一处盘面依据，换任何一张盘都成立；第二句是方法论，不是关于这位读者的判断。

合格：

> 八字里年干偏印透出、月支食神得令，两者隔位不相克；紫微命宫天机化科；占星水星处女在三宫，与土星成六分相；人格分数最贴合 INTP，Ti 主导。四种读法在“把东西拆开看明白”这一点上落到同一处，各说了一层：人格说的是求自洽的动机，占星说的是对细节的耐心，紫微说的是推演的习惯，八字说的是独到的理解能顺利变成产出。合起来可以看到你学习的节奏：慢在开头，快在后面。例如一门新课的头三周，你可能是班上看起来进度最慢的人，因为你在拆；一旦装回去，那套东西就是你自己的。按周考核进度的环境容易低估你。

**对照二：事业与社会角色**

不合格：

> 八字显示你适合稳定的工作，而人格测验显示你喜欢自由，这两者存在一定张力，需要在稳定与自由之间找到平衡。

问题：没有说依据是什么；没有说张力落在哪一层；“找到平衡”不是理解，是劝告。

合格：

> 在子平的读法里，这张盘月令正官、官星清透而有财印相随，是以规范与职守取得位置的格局；紫微官禄宫天相，同样重分寸与章法。人格分数最贴合 ENFP，Ne 主导、Fi 辅助；占星太阳水瓶在十一宫。前两者说的是你取得社会位置的方式，后两者说的是你的注意力和价值感往哪里去。张力落在取向与角色之间。合起来的理解是：你适合的位置在一个规矩清楚的体系里、带有自主裁量权的那一格。如果你做过纯自由的工作而觉得没有着落，又做过纯执行的工作而觉得闷，这组张力说的就是这件事。

**对照三：情感与亲密关系**

不合格：

> 紫微夫妻宫和占星金星都显示你重视感情，三重印证说明你会遇到稳定的伴侣。

问题：把汇聚写成证明；承诺了现实结果；没有落到相处的情境。

合格：

> 八字日支坐正印，与月支六合；紫微夫妻宫天府，对宫官禄宫武曲、七杀；占星金星金牛，与土星成三分相。三种传统读法在这里落到同一处：你在亲密关系里要的是可靠。八字说的是这个位置上需要被庇护的安稳，紫微说的是相处里看重能持家、靠得住，占星说的是喜欢要慢慢确认。合起来多理解的是，你的安全感来自对方的可预期。例如约好的安排临时改了，即使理由充分，你感到的不快多半比自己预想的大。

**对照四：人生节奏**

不合格：

> 大运和大限都显示未来十年运势上升，是事业发展的黄金期，应当把握机会。

问题：预测结果；没有说两个体系各依据什么；“把握机会”是空话。

合格：

> 在子平的读法里，当前这步大运走食神，原局食神只在时支藏干，这十年透出得根；按三合派，当前大限命宫落在本命官禄宫，大限化禄入本命命宫。两种读法都把这十年读作专长得以施展的阶段：八字说的是原局里出口小的那部分才华有了通道，紫微说的是这十年生活的主场在事业。合起来的理解是，这一段适合把积累的东西做成可以署名的作品。如果你手里有一件一直在“再准备准备”的事，两种读法指的都是它。

### 没有新增理解时

某个主题各体系的主张放在一起，说不出比单独读更多的东西，就如实标 `parallel`，在对应体系的章节里各自写足，综合章不为它另立一节。综合章宁可少而实。

## 综合主张的登记

综合判断写入 `synthesis_claims`，字段与 `schemas/case_evidence.json` 的 claim 一致（`owner`、`status` 由 Leader 登记时补齐）。

- **父主张来自至少两个体系。** `parent_claim_ids` 指向各体系已登记且有效的主张，或指向本次产出中的其他综合主张。只依据一个体系的判断是该体系自己的主张，应回到该体系章节。
- **`kind` 的取法。** 由传统读法合成的判断用 `traditional_interpretation`；涉及读者真实心理特点的判断用 `psychological_hypothesis`，它的父主张里必须有本人自述、观察或人格假说；现实尝试用 `practical_option`。
- **`statement` 写成完整的综合判断**，包含盘面依据、所在层次与合读结论。它是 writer 成文的依据，写得越具体，成书越不空。
- **子主张的确定程度不超过父主张。** 父主张的限制与反例在审计层对子主张继续有效，不抄进 `statement`，也不因继承而在正文重复。
- **体系归属**按父主张在 `case_evidence.json` 中的 `owner`（登记时的席位名）判定；`owner` 看不出体系时，按该主张被引用在矩阵的哪一列判定。

## 全书核心命题

完成各主题后，从综合主张里提炼 3–5 条 `core_propositions`，每条为 `{proposition_id, image, statement, claim_ids}`。它是全书骨架：导读预告，各章回扣，综合章对照，结尾回到读者本人。

- `proposition_id`：`CP-01` 起顺序编号。
- `statement`：一句关于这位读者的判断，带对象或条件。句式是“在〔什么场合〕，你〔怎样〕”或“你的〔某事〕是〔怎样的〕，条件是〔什么〕”。它要过得了换盘测试。
- `image`：一个帮助记忆的意象，取自盘面或读者的生活（“先拆后装”“规矩里的自由格”）。没有自然的意象时为 `null`。
- `claim_ids`：回链已登记的主张，以综合主张为主。
- **覆盖面**：全部命题所回链的主张，合起来至少覆盖三个体系；本案可用体系不足三个时，覆盖全部可用体系。
- **互不重复**：每条命题说一件不同的事。通常一条讲底色，一条讲做事或学习的方式，一条讲关系，一条讲当前阶段。
- **每条命题都有章节回扣**：`outline.sections[].required_content` 里要出现它的编号。

对照（合成示例）：

| 不合格 | 合格 |
|:---|:---|
| 做最好的自己，顺势而为。 | 先拆后装：学新东西时你慢在开头，给你完整的前三周，后面的进度会反超。 |
| 你兼具理性与感性。 | 规矩里的自由格：你在章法清楚的体系里、握有自主裁量权的位置上最能发挥。 |
| 三重印证：你注定在事业上成功。 | 这十年的主场在事业，适合把一直在准备的那件事做成能署名的作品。 |

命题不把意象升级为能力或命运结论，不把汇聚写成证明。

## 提纲

`outline.sections[]` 使用 chart_plan 的 section 字段。`required_content` 逐条写明本章要解释的内容，具体到关系与结论，例如：

- “思维与学习：四体系汇聚于‘先拆后装’（S-01），说明各体系各说的一层，给出头三周的对照情境；回扣 CP-01。”
- “事业：取向与角色之间的跨层张力（S-02），说明张力落在取向与角色之间；回扣 CP-02。”

“放综合矩阵”“综合四体系”这类写法不合格。综合章的 `claim_ids` 要包含它所解释的综合主张。`limitation_ids` 只收 `required_placement:"adjacent"` 的读者层限制，同一限制只进一个章节。有现实资料时说明它如何影响读者的选择；没有时给出以“例如”“如果”标明的对照情境。

## 限制的两层

- **审计层**：`claims[].limits`、`counterevidence`、矩阵行 `limits`、判官与 chief 的差异措辞。供评审和附录使用，writer 不原样渲染进正文。父主张的限制在这一层向子主张继承。
- **读者层**：`case_evidence.limitations[]` 中由 Leader 登记的条目。`changes_reading` 回答“删掉它，读者会不会形成一个具体误读，或者某句结论会不会因此改变”；为 `true` 时写 `reader_text`（面向读者的条件句，如“如果〔前提〕，这一节改读为〔Z〕”），按 `required_placement` 落在开篇或受影响判断旁；为 `false` 时只进附录。
- 综合者只在某条限制会改变读者对综合判断的理解时，提出读者层限制增量。出生时刻不确定而影响到紫微宫位或占星宫位时，涉及这些宫位的汇聚判断属于这种情形。

## 主张的层次

综合判断所依据的父主张分属不同层次，检验方式不同：

- **自述或测量观察**：回链本人提供的观察与量表原始数据。
- **计算事实**：回链计算产物字段；检验输入与方法。
- **传统解释**：回链计算事实与取法；以“在子平的读法里”“按三合派”这类声源标签说出，可以说得肯定。会改变读法的盘面条件（破格、借星、宫界附近）记在 `limits`。
- **心理假说**：回链自述、分数与所用理论；类型假说配可落空的对照情境。真实生活中的反例只在这一层讨论。
- **实践选项**：回链相关判断，是读者可以选择、调整或不做的尝试。

算法错误、错引来源、无依据的推断按证据纠正，不以流派差异掩盖。chief 判定的实质差异与披露要求带入综合，不隐去。

## 行动选项

`action_options` 每项的字段固定为：

```json
{
  "goal": "为什么是这位读者：回链判断的一句话，再写希望改变或理解什么",
  "claim_ids": [],
  "small_action": "本周可启动的低风险小行动，含载体与时长",
  "frequency_or_trigger": "具体触发线索或频率",
  "review_question": "读者能回答的复盘问题",
  "adapt_or_stop": "无效、不适或条件变化时如何调整或停止"
}
```

行动按“因、行、判”组织：先说为什么适合这位读者，再给触发线索、载体与时长，最后给复盘问题。触发线索写成具体情境（“下次你发现自己又替别人把事扛下来时”）。行动从综合判断里来：上文“先拆后装”的判断，对应的行动可以是“接到新课题的第一周，先画一张拆解图，不急着交初稿”。行动随时可以开始，不等传统上的时间窗口。未成年读者至少配一句可以直接说出口的原话。六个字段是数据结构，正文由 writer 写成连贯段落。

## 年龄

年龄只作语境。类型发展顺序与固定年龄发展表不作为个人的时间表。未成年人的主题替换见 `theme-crosswalk.md` §11 与 `character-inference-workflow.md` 的适龄规则。

## 红线

1. 不从盘面或分数推断疾病、身体部位、寿命、死亡、生育结果，不作心理或医学诊断。
2. 不承诺确定事件，不给年份、投资时机、关系成功率、匹配总分或一致性评分。
3. 不编造盘面值、分数、引文、来源或当事人经历；对照情境以“例如”“如果”标明。
4. 汇聚不写成科学验证或相互证明；不由出生盘生成人格分数或类型；不从传统材料推断能力缺陷。
5. 未成年人按主题替换规则处理；个案资料不外传、不写进参考资料与跨会话记忆。

判断标准：说的是“这个传统怎么读这张盘”，可以说得肯定；说的是“现实里一定会发生什么”或“身体、能力有什么毛病”，不可以。

## 产出校验

综合产出存为 `synthesis.json`（结构见 `schemas/synthesis.json`），运行：

```bash
"$DM_PY" scripts/synthesis_contract.py --synthesis "$WS/synthesis.json" --evidence "$WS/case_evidence.json" --intake "$WS/intake_brief.json" --json
```

三个参数都要传。不传 `--intake` 时未成年人检查不运行，输出里 `minor_check` 为 `"skipped"` 并带一条 `minor_check_skipped` 提示；这样的结果不能作为通过的凭据。

退出码 0 为通过，1 为有合同问题，2 为参数或文件错误。输出为 `{ok, kind, issues, warnings, minor_check, coverage}`：`issues` 阻断，`warnings` 不阻断但要逐条看过；`minor_check` 取 `applied`、`not_applicable`（intake 写明已成年）或 `skipped`。

阻断项（`issues`）：

| 代码 | 含义 |
|:---|:---|
| `schema` | 结构不符合 `schemas/synthesis.json`，且该处没有专门代码 |
| `matrix_empty` | `matrix` 为空 |
| `relationship_enum` | `relationship` 取值不在四个之内 |
| `relationship_needs_two_systems` | 标 `convergent` 或 `tension` 的行引用的体系不足两个 |
| `convergent_without_chart_basis` | 汇聚行里某个体系的主张回不到盘面或分数依据 |
| `matrix_row_without_claim` | 汇聚或张力行没有对应的综合主张 |
| `matrix_column_mismatch` | 主张填进了别的体系的列 |
| `synthesis_claim_in_matrix` | 矩阵列里填了综合主张 |
| `matrix_row_empty` | 整行没有可用主张 |
| `duplicate_theme` | 主题重复 |
| `synthesis_claim_kind` | 综合主张的 `kind` 取了观察或计算事实 |
| `single_system_synthesis` | 综合主张的有效父主张不足两个体系 |
| `dependency_cycle` | 综合主张的父主张链绕回自身；环上的边不计入体系 |
| `hypothesis_without_observation` | 心理假说类综合主张缺少自述、观察或人格假说作父主张 |
| `dangling_claim` | 引用的主张不存在 |
| `inactive_claim` | 引用的主张已失效 |
| `claim_id_collision` | 综合主张的 ID 与他人主张相同 |
| `subject_crossing` | 跨人主张未标 `joint` |
| `duplicate_id` | 综合主张、命题或章节的 ID 重复 |
| `proposition_count` | 命题数目在 3–5 条之外 |
| `proposition_statement_empty` | 命题判断为空 |
| `proposition_claims_empty` | 命题没有回链 |
| `proposition_coverage` | 全部命题合起来覆盖的体系不足 |
| `proposition_unplaced` | 命题没有章节回扣 |
| `duplicate_statement` | 两条命题判断相同 |
| `proposition_escalation` | 命题把汇聚写成证明或命运公式 |
| `escalation_wording` | 综合主张、提纲、行动选项或限制增量里出现同类措辞 |
| `required_content_empty` | 章节没有写明要解释的内容 |
| `synthesis_section_without_claims` | 综合章没有引用综合主张 |
| `minor_theme` | 未成年或年龄未知时出现婚恋类用词 |
| `minor_career_verdict` | 未成年或年龄未知时出现职业判定 |
| `minor_ability_label` | 未成年或年龄未知时出现能力缺陷标签 |
| `minor_type_name` | 未成年或年龄未知、受众不含监护人时出现四字母类型名 |
| `evidence_invalid` | `case_evidence` 不是带 `claims` 数组的对象 |
| `argument_error`、`file_error` | 参数错误、文件读不出（退出码 2） |

提示项（`warnings`）：

| 代码 | 含义 |
|:---|:---|
| `minor_check_skipped` | 没有传 intake，未成年人检查未运行 |
| `minor_theme_negated` | 婚恋类用词出现在否定语境里（如“本书不谈婚恋”），请确认句子确实是在排除该主题 |
| `minor_type_name` | 受众包含监护人时出现类型名，请确认它只落在监护人段或附录 |

校验只能查结构、引用和词表。未成年人检查是词表兜底，换一种说法就拦不住，不能代替 I3 终审。判断是否具体、是否过得了换盘测试，由综合者按上文标准自查，终审按 R1、R2 复核。
