# 八字神煞：查法与常见读法

神煞是以年支、月支、日干、日支为基准，查四柱中某干某支是否落在特定位置而立的名目。本页列出计算器输出的十七种神煞的查法、取义与常见读法，配合 [`bazi-framework.md`](bazi-framework.md) 与 [`bazi-symbolism.md`](bazi-symbolism.md) 使用。

## 神煞在子平法里的位置

神煞属辅助，不单独定论。子平法以月令格局、旺衰、用神定一张盘的成败喜忌；格局已成，满盘凶煞也不减其成；格局已破，满盘吉神也无从补救。古人自己也说神煞名目繁多、其说支离。所以用法是：

1. **先定格局喜忌，后看神煞。** 旺衰、格局、用神的结论不因神煞而改。
2. **神煞落在什么十神上，就跟着那个十神走。** 贵人落在用神上，是锦上添花；落在忌神上，吉意大减。凶煞落在喜用上，多半只是给喜用添了一点性格色彩。
3. **与格局的读法相互呼应时才写。** 例如印格又带文昌、华盖，学问一面的读法有了旁证，可以一提；孤零零一个神煞而与格局读法无涉，不写。
4. **逢合冲空亡要打折。** 神煞所在之支被冲、被合去或落空亡，其意减轻。

正文写法：“传统上把这个位置叫作某某，常见的讲法是……”，不加引号、不挂书名。神煞所在柱位的读法同十神：年柱主早年与背景，月柱主成长环境与平台，日支主自身与亲近关系，时柱主后程。

## 计算口径

- 神煞从 `/dimensions/bazi/data/神煞` 读取，按柱分列（`年柱`、`月柱`、`日柱`、`时柱`），依最终四柱计算。柱、日主或时间候选变更后随之重算。
- 时刻不确定时，只写各候选盘都有的神煞；随时辰变化的，按 `bazi-framework.md` 完成边界的条件句写法处理。
- 各家查法不尽相同。下表是计算器实际采用的查法，以此为准；与读者从别处看到的神煞表不同，属取法差异，记入附录。
- 大运流年的神煞计算器不输出，不自行推算。

## 常见读法

### 贵人与德神

| 神煞 | 取义 | 常见读法 | 读时要看 |
|:---|:---|:---|:---|
| 天乙贵人 | 传统上最尊的吉神 | 遇事有人相助，为人有气度，逢难易得转圜 | 落在喜用之支最得力；逢冲、落空亡则减；两见为佳，过多则泛 |
| 天德、月德 | 德神，主化解 | 心性仁厚，处事平和，逢难有缓冲。传统认为日柱见之最亲 | 落在用神或日干上最佳；与印同柱，读作学养与品行相辅 |
| 天德合、月德合 | 与德神相合之干 | 同德神而力稍轻 | 同上 |
| 太极贵人 | 取始终之义 | 好钻研根本之理，喜玄思，有专注力 | 与印星、华盖同见，钻研一面更显 |
| 文昌贵人 | 以日干查支，取文星之义 | 聪明好学，文思与表达好 | 落在食伤或印上呼应最强；用于学业与思维主题（知识卡 §10.2） |
| 国印 | 取印信之义 | 为人守信重诺，办事有章法，宜掌事务 | 与官印同见则应在职分上 |
| 金舆 | 禄前二位，取车乘之义 | 性情温和，得人扶助，生活有依托 | 只作陪衬 |

### 动与静

| 神煞 | 取义 | 常见读法 | 读时要看 |
|:---|:---|:---|:---|
| 驿马 | 三合局首字所冲 | 主动、走动、变迁，思路快，坐不住 | 马逢冲则动得更急，逢合则被绊住；落在财官喜用上，读作因奔走而得；落在忌神上，读作奔波多而所得少 |
| 华盖 | 三合局之墓库 | 主清高、独处、好艺术与玄思，有自己的精神世界 | 与印同见，钻研与才艺更显；华盖多而无财官，读作孤高 |

### 需按红线处理的神煞

下列神煞的传统断语集中在婚恋、孤寡、灾伤上。它们的写法受 `bazi-framework.md` 红线约束：只取性情与处事方式的一面，其余作为历史语境，不写进个案结论。未成年读者的命书不写桃花与红艳。

| 神煞 | 取义 | 可写的读法 | 只作历史语境的部分 |
|:---|:---|:---|:---|
| 桃花（咸池） | 三合局沐浴之位 | 人缘好、有魅力、重审美与情趣，才艺上有灵气 | 传统的风流、婚恋断语 |
| 红艳煞 | 以日干查支 | 气质出众、感情丰富、表现力强 | 同上 |
| 孤辰、寡宿 | 一方之前后隔角 | 性情独立、耐得住独处、与人保持距离 | 传统的孤寡、刑克六亲断语，以及按性别立论的部分 |
| 亡神 | 三合局五行临官之地，取自内而失之义 | 心思深、有城府、善谋；为喜用时读作沉稳有谋略 | 传统的破败断语 |
| 劫煞 | 三合局五行绝地，取自外夺之义 | 行事果决、反应快；为喜用时读作敢断 | 传统的灾祸、破财断语 |
| 灾煞 | 三合局中位所冲 | 性急、行事带冲劲 | 传统的灾伤断语 |
| 流霞 | 以日干查支 | 默认不写 | 传统断语全部落在灾伤与生产上 |

## 写作要点

- 一张盘通常只有两三个神煞值得写。选与格局、用神读法相呼应的。
- 神煞的读法写成性情与处事方式的补充，句子里保留声源标签。
- 不因神煞叠见而加重语气，不给神煞配强度、启动时间或应期。
- 传统歌诀与原文只用 `sources.json` 已核的 `quote_id`；其余按常见读法转述。
