# 八字神煞：传统文化解释参考

神煞是条件性传统阅读资料：只有当盘面存在对应字段、神煞会改变本案解释且具体取法来源可核时才纳入；其余情况不为求完整而罗列。它用于说明相关文化文本的分类和象义，不作为个体事实、人格测量、诊断或事件预测。无法定位取法时列入现有来源核验任务（S4C）；无法核实时省去该条，保留其他有依据的核心分析。神煞不能证明某种性格，也不为八维分数或其他体系提供印证。不得从神煞推出疾病/身体部位、灾祸、死亡、生育、财富结局、性别责任或必然关系事件。

## 计算与资料口径

神煞需依据最终确认的四柱计算。八字年/月柱与节气使用固定 UTC+8 的 `time_context.term_datetime`，日/时柱使用 `time_context.local_apparent_datetime`；子时规则按 `midnight|zi_start` 及计算器结果记录。柱、日主或时间候选变更后，所有依赖神煞必须随最终柱重新计算，不从旧盘复制。时刻不确定时，只描述候选之间稳定/变化的神煞字段及有效区间，不择一盘。

不同传统文本对查法、名称及象义可能有差异。每次使用应注明采用的规则来源；不应将表中单一版本写成普遍定论。

以上名称在传统典籍中带有吉凶、婚恋、性别及身体等历史解释。介绍这些内容时须以已核验的 `references/sources.json` 条目和 quote_id 对应的原文为准，并标明历史语境；未核实的原话应删除署名或改为不冒充原文的概述。不得用“古歌云”“古书说”等模糊归因。

## 使用边界

- 不把单一神煞、所在柱位或叠加数量写成某人必然的性格、经历或未来事件；不称“强度倍增”“启动时间”或“风险信号”。
- 桃花、红艳、流霞等不作性化判断、婚恋预测或性别区分；未成年内容尤其不得写红艳/桃花性化推断与婚恋年份。
- 孤辰、寡宿、华盖等不推断孤独、心理状态、神经类型或人际能力；驿马不推断职业或迁居；金舆、国印不预测财富、身份或权力。
- 灾煞、劫煞、流霞等不转译为医疗、身体敏感、意外或安全风险建议。健康主题仅回应用户主动提出的作息、压力与求助问题。
- 古典原文若确需介绍，作为历史文献内容说明，不转化为当前个案断语。所有署名直接引文必须回链已核 quote_id；没有可核验 quote_id 时删去引号与署名，必要时仅概述为传统观念并注明来源未核。
- 不要求神煞与人格测量、八字其他结构、紫微或占星结论相互印证；并列解释时说明其来源与限制。
