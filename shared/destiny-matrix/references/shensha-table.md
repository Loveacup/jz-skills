# 八字神煞速查表与性格映射

<!-- v3.0 -->

> **v3 立场**：神煞是性格的"修辞"，不是"主语"。本表配合 `scripts/bazi_calc.py` 输出的 `神煞` 字段使用，命书叙事时务必牢记——
> **桃花不是命定多情，而是 Fi 或 Fe 觉醒的能量入口；华盖不是孤僻定数，而是 Ni 主导者的内倾倾向。**
> 神煞只提供"印证"，不提供"判决"。

神煞共 17 种，由 19 个查表函数实现（月德/月德合、天德/天德合各占两条规则）。按四柱分列输出。
查法基础：以**日干**、**月支**、**年支**、**日支**为四类基准。

典籍参考：《三命通会》（万民英）、《神峰通考》（张神峰）、《渊海子平》（徐子平 / 徐大升）、《珞琭子三命消息赋》、《李虚中命书》。

## 一、贵人类（吉星）

### 1. 天乙贵人

**查法**：以**日干**查地支。

| 日干 | 天乙贵人位 |
|:---:|:---:|
| 甲、戊、庚 | 丑、未 |
| 乙、己 | 子、申 |
| 丙、丁 | 亥、酉 |
| 壬、癸 | 巳、卯 |
| 辛 | 午、寅 |

口诀：「甲戊兼牛羊，乙己鼠猴乡，丙丁猪鸡位，壬癸兔蛇藏，庚辛逢马虎，此是贵人方。」

**典籍意义**：《三命通会·论天乙贵人》："天乙者，乃天上之神，在己丑、未之位，其神最尊贵，所至之处一切凶煞隐藏。" 主一生多遇贵人提携、化险为夷、社会资源相对充裕。

**性格映射（v3 关键解读）**：
- 天乙贵人 ≠ "天降运气"，而是性格中"接收社会善意"的开放度
- 高位（年/月）+ 命主自信 → Fe 外倾情感发达，社交润滑
- 低位（日/时）+ 命主性格封闭 → 善意常擦肩，需 Fi 觉醒后才"看见"贵人

## 二、桃花·情感类

### 8. 桃花（咸池）

**查法**：以**年支**或**日支**的三合局首位前一位（"沐浴"之位）。

| 三合局 | 桃花位 |
|:---:|:---:|
| 申子辰（水局） | 酉 |
| 寅午戌（火局） | 卯 |
| 巳酉丑（金局） | 午 |
| 亥卯未（木局） | 子 |

**典籍意义**：《渊海子平·咸池论》："咸池者，败神也。主酒色之事。" 现代命理重新解读：桃花 = 异性缘 + 艺术审美。

**性格映射（v3 重点改写）**：
- 桃花不是"风流定数"，而是**性能量与审美能量的觉醒入口**
- 男命桃花 + Fi 整合阶段 → 善于体察他人情感，吸引力来自共情而非外貌
- 女命桃花 + Fe 主导 → 社交圈活跃，魅力来自情绪辐射
- 桃花在年柱 = 童年情感早熟；在日柱 = 婚姻宫桃花，正缘 / 烂桃花皆可能；在时柱 = 晚年情欲未消，亦可解为创作力延续

**注意**：桃花与"红艳煞"叠加，性能量倍增，但需结合是否有官 / 印制衡判断。

## 神煞使用原则（v3 命书写作总纲）

1. **神煞不预言，神煞只印证**：每条神煞的解读必须挂回性格主线（荣格八维），不可独立成命
2. **古凶 → 现代信号**：劫煞、灾煞、孤辰寡宿等"凶煞"统一转译为"性格未整合时的能量信号"，不渲染宿命色彩
3. **强度而非有无**：神煞临何柱（年/月/日/时）决定其"何时启动"，而非"是否存在"
4. **叠加放大原则**：
   - 桃花 + 红艳 → 性能量 × 2，命书需提示"边界训练"
   - 华盖 + 太极 → Ni 倍增，命书定调"修行者 / 学者命"
   - 孤辰 + 寡宿同现 → "深度独处倾向"，配合 Fi 整合阶段建议
5. **女命特殊解读**：流霞、桃花、咸池在女命中传统多渲染凶意，**v3 一律转译为"情感能量与身体感知的强度信号"，绝不写"克夫 / 风流 / 不正"**
