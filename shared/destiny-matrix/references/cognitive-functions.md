# 认知功能：理论词汇与反思问题

> 本文介绍 Jung 认知功能及后续类型理论中的概念，用作理解差异的理论镜头，不是经本技能验证的能力测验、诊断或人格预测工具。原始测量构念须见 `character-first-manifesto.md` 与 `character-inference-workflow.md`。

## 使用原则

Jung 在《心理类型》（CW 6）中以不同方向的判断与知觉过程描述心理类型；后续类型理论进一步发展了常见的八功能用语与功能位置。这里的内容是对理论概念的概述，不是 Jung 的逐字引文，也不宣称后续模型完全等同于其原著。
原始构念与分数轮廓先按其自身量程解释，不与 functions8、subtypes16、NERIS、类型或自述互相换算。理论术语用于提供一种有出处的观察镜头，不是测量结果；不自动排类型，不把分差、排序或功能位置当能力。缺少访谈时仍解释实际分数轮廓及相关理论镜头，但不补造个人经历（以“例如／如果”明确标出的假设镜像不属于补造）；有个体假说时结合真实材料、情境差异与反例。

## 独立解读路径与完成边界

按以下顺序推读；完整命书逐项检查，focused 只检查与请求相关的部分。findings 的领域解释须连续可读，说明实际构念与轮廓、采用的理论镜头、对读者主题的含义，以及情境差异或反例如何改变判断。检查不要求每项各写一段；未影响解释的细节可留在数据附录。`evidence_summary` 仅简要记录实际输入和来源，不代替领域解释。

1. 原构念与分数轮廓／自述：交代工具实际测量或记录了什么、量尺与结果分布；自述仅按其原义呈现。
2. 有材料支持的偏好张力：解释轮廓中有意义的相对差异，不把差分或排名解释为能力高低。
3. 情境差异与反例：结合可用的实际观察、自述或访谈，指出何种条件支持、限制或改变该解释；无访谈时不虚构情境，也不因此省略对真实分数轮廓的解释。
4. 可署名的理论镜头及观察用途：说明 Jung 或后续理论概念的来源与用途，将其作为理解假设；直接引文按已核来源处理。

functions8、subtypes16、NERIS、类型、自述及访谈维持各自构念，不互转、不自动推导功能栈。未定位到可核来源的理论取法列入现有来源核验任务（S4C）；无法核实时省去该条理论解释，保留数据本身及其他有依据的分析。省去后正文保持沉默，不写“未核”“未采用”；它只在附录“本书没有采用的读法”列一次。

领域论述的顺序与限制分层按 `agents/book-writer.md` 文风与 team-orchestration §4、§8；本构念读者可指认的依据是原分、量程与构念名称。

## 八种功能的工作假设

| 功能 | 理论上关注的过程 | 可用于自我观察的问题 | 什么情况下这条不太适用 |
|---|---|---|---|
| Se（外倾感觉） | 留意当下环境中的具体信息与即时变化 | 面对新环境时，哪些现场信息会先进入注意？ | 如果对现场的敏锐主要出现在训练过、角色要求或很熟悉的场合，换到陌生场合就不明显，那它更像技能或角色习惯，偏好读法要让位给情境。 |
| Si（内倾感觉） | 将当下经验与个人记忆、身体感受和既有参照联系 | 遇到熟悉任务时，过去的经验怎样影响当前判断？ | 如果看重既有做法主要是因为规范要求，离开规范后你并不常回到过去的参照，这条读法要按情境看；不爱重复的人，也可能在熟悉任务里大量调用经验。 |
| Ne（外倾直觉） | 从当前对象联想到可能性、替代路径与关联 | 遇到开放问题时，自己通常会先探索哪些不同解释？ | 如果发散主要出现在任务要求头脑风暴的时候，平时你更快收拢到一个方案，那它更多来自任务需要；收拢得快的人，同样可以在别处提出新办法。 |
| Ni（内倾直觉） | 将线索整合为模式、主题或未来方向的理解 | 事后回看时，最初的整体判断依据了哪些可说明的线索？ | 如果“早就看出来了”的感觉多出现在事后回看，事前说不出依据，那更可能是记忆的整理；确信感要和事前记下的判断对照，才能说明整合得准不准。 |
| Te（外倾思考） | 以外部标准、可观察结果和组织方式处理问题 | 决策时会怎样定义目标、约束与可检查的结果？ | 如果执行力主要来自职责、资源或经验，换到没有外部标准的事上就不明显，这条偏好读法就要让位给角色；重视流程的人也常常很在意感受。 |
| Ti（内倾思考） | 检查概念之间的一致性、定义与内部逻辑 | 遇到结论时，哪些定义或前提需要先澄清？ | 如果细致推敲只出现在熟悉的领域，或你更习惯在讨论中边说边理清，这条读法要按领域和场合看；推理能力要看具体问题上的表现。 |
| Fe（外倾情感） | 留意人际情境中的表达、共同规范与相互影响 | 讨论分歧时，自己会怎样注意双方的表达和关系影响？ | 如果顾及他人主要来自礼貌规范或职位要求，私下并不常留意气氛，那它更像情境策略；读得准不准对方的情绪，要看对方的反馈。 |
| Fi（内倾情感） | 以个人价值、感受与真实性判断经验 | 面对选择时，怎样辨认什么对自己重要、又愿意承担什么代价？ | 如果重要选择主要依据外部标准，只在少数私人事情上先问自己在乎什么，这条读法只适用于那部分事情；一时说不清感受，常见于价值还在形成的时候。 |

表中是理论导向的问题，不是功能识别量表。回答可同时支持多个解释；应保留具体语境与相反例子。右栏是写反向情形的素材：它给出一个能落空的条件，读者可以据此判断“像不像”，写进正文时用条件句，不改回否认句。

## 功能位置与 Beebe 理论

主导、辅助、第三、劣势等常见位置属于后续类型模型；Beebe 的 Hero、Parent、Child、Anima/Animus、Opposing、Senex/Witch、Trickster、Demon 等术语是其原型理论框架。使用时须明确标明理论来源，并作为一种解释视角，而不是由分数确诊的结构或临床标签。

不得把位置说成固定成熟阶段、天生缺陷、道德等级、风险星数或必然的压力行为。Grip 可作为某种理论对压力体验的描述性假说；须由本人实际叙述支持，不能因类型推定暴食、危险行为、疑病、成瘾或其他症状。若涉及显著困扰或安全风险，应依据现实描述提供适当求助信息，而不是用功能术语诊断。

## 从概念到可用反思

结合可用的实际说法、行为观察与情境写个体性格假说；条件允许时纳入合理替代解释及会改变判断的反馈。没有足够个体材料时，不补造人物经历，也不把开放问题当作对原始构念和分数轮廓的替代；仍可说明数据本身及有出处的理论解释。

生活镜像与提问入口：

- 镜像写这种倾向在教室、家里、朋友之间（成年读者写工作与生活场合）可能是什么样子，写法见 `agents/book-writer.md` 文风第 5 条；反向一支写成“如果你在〔情境〕里更常〔Y〕，这条读法就不太贴合你（此时〔另一项功能〕可能更重）”。
- 成对功能的张力本身就是人格层的提问入口，属于同一构念内部，不是跨体系互证，可以直接写给读者：Fe/Fi 问“别人表达了什么、我自己又在乎什么”；Te/Ti 问“哪个结果要先看见、哪条定义要先说清”；Se/Si 问“眼前变了什么、过去的经验提示什么”；Ne/Ni 问“还有哪些可能、它们指向哪一个方向”。

反思问题示例：

- 在最近一次重要决定中，你更先注意到哪些事实、可能性、标准或关系影响？
- 哪些例子支持这种说法？有没有相反例子？
- 这种做法在什么条件下有帮助，在哪些条件下会失效？
- 你希望尝试哪一个小变化？怎样观察它是否适合自己？
