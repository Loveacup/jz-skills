# 紫微斗数知识卡（三合派）

本卡写给执行紫微解读的模型（ziwei-analyst、judge-ziwei）。它提供可以直接用来下判断的象义与判断方法；推读顺序和必须给出的结论项见 [`ziwei-framework.md`](ziwei-framework.md)。

## 0. 怎样使用本卡

**取法。** 默认三合派：以十四主星的星性、亮度、同宫与三方四正的会照为主干，生年四化定重心，大限与流年四化叠到本命盘上读。空宫借对宫主星。宫干飞化、自化属飞星一路，计算器没有算，正文不用，只进附录。

**声源。** 本卡正文是紫微三合派的通行读法。落到个案时用“在紫微的读法里”“按三合派”这类声源标签说出，可以说得肯定：这张盘是什么格局、命宫强还是弱、重心在哪里，要给结论。通行象义对应来源 kind `common_reading`（来源目录中的 `ziwei-common-reading`），不加引号、不挂书名。只有 §10 登记的句子是逐字核过的原文，引用时用对应 `quote_id`。

**盘面依据。** 每个判断都要能回到计算器输出。本卡写到“看某字段”时，指的是 `/dimensions/ziwei/data` 下的路径：

| 字段 | 内容 |
|:---|:---|
| `基础信息` | `命宫地支`、`身宫地支`、`命主`、`身主`、`五行局` |
| `十二宫[]` | 每宫的 `宫位`、`地支`、`天干`、`是否身宫`、`主星`／`辅星`／`杂耀`（每颗星含 `名称`、`亮度`、`四化`）、`长生十二神`、`博士十二神`、`将前十二神`、`岁前十二神`、`小限年龄`、`大限.范围` |
| `运限` | `虚岁`、`当前大限`、`当前流年`（各含 `天干`、`地支`、`宫位排列`、`四化`）。`宫位排列` 从寅宫起顺数十二地支，写的是该地支在这一运限里充当什么宫 |
| `结构.命宫`、`结构.身宫`、`结构.空宫` | 命宫地支、身宫落在哪一宫、哪些宫没有主星 |
| `结构.宫位关系[]` | 每宫的 `对宫`、`三合宫`、`邻宫`、`借对宫主星`（空宫才有）、`三方四正四化` |
| `结构.生年四化` | 禄权科忌各自的星曜、亮度、落宫 |
| `结构.当前大限四化`、`结构.当前流年四化` | `命宫所在本命宫`，以及四化星曜各自的 `本命落宫` |

计算器里十二宫的名称是：命宫、兄弟宫、夫妻宫、子女宫、财帛宫、疾厄宫、迁移宫、交友宫、官禄宫、田宅宫、福德宫、父母宫。交友宫即古书的奴仆宫（仆役宫）。辅星一组含十四颗：左辅、右弼、文昌、文曲、天魁、天钺、禄存、天马、擎羊、陀罗、火星、铃星、地空、地劫。其余入 `杂耀`。

**红线（全卡只写这一次，处处适用）。**

1. 不从盘面推断疾病、身体部位、寿命、死亡、生育结果。疾厄宫不作健康判断：它在三方四正里照常参与会照（它是兄弟、田宅两宫的三方之一，又是父母宫的对宫），落在这里的星和四化只用来读这几宫的关系，不读成身体。古书里大量的夭寿、残疾、刑克断语是历史文本，不转成个案判断。
2. 不承诺确定事件。格局名里的“富”“贵”“公卿”是古人对结构好坏的分等用语，今天读作“这一组结构在传统里评价很高，主题在事业与声望一侧”，不读作必然发财升职。大限、流年只讲这一段的主题与着力处，不报事件和年份。
3. 未成年人：夫妻宫只读作一对一亲近关系里的相处方式（好友、同桌、搭档），子女宫读作照顾比自己小的人、经营自己的作品与兴趣的方式；不写婚恋对象与年份。桃花一类星曜（贪狼、廉贞、天姚、咸池、红鸾、天喜）读作人缘、审美、才艺与表现欲，不作性化解读。官禄宫读学业与兴趣，财帛宫读对资源和零用的态度。
4. 星曜陷弱、化忌、空宫、煞星，说的是传统里这一处“费力”“多转折”“要自己补”，不写成能力缺陷或身份标签。
5. 六亲宫（父母、兄弟、夫妻、子女、交友）读的是当事人在这段关系里的相处方式与感受，不描述对方是什么样的人、处境如何；不按性别指派亲属、贵人或配偶星。带“早年”“晚年”“某岁以后”的人生历程说法不用；传统对某星某格的总体评价（如先难后易），要带“传统上的讲法是”说出。
6. 不编造引文与出处；传统象义不说成科学事实或心理测量。

## 1. 盘面基础

### 1.1 十二宫各管什么

| 兄弟宫 | 手足与同辈至亲；也看合伙与身边的帮手 | 疾厄、田宅 | 交友 |
| 夫妻宫 | 一对一的亲密关系：相处模式、被什么样的人吸引、关系里的功课 | 迁移、福德 | 官禄 |

| 疾厄宫 | 古书论身体与困厄。本技能只把它当作三方四正的一员（见红线 1） | 兄弟、田宅 | 父母 |
| 迁移宫 | 出门在外、在陌生环境里的样子、外界怎样回应你；命宫的镜面 | 夫妻、福德 | 命宫 |
| 交友宫 | 朋友、同事、部属、社群；人际的广度与质量 | 子女、父母 | 兄弟 |

| 田宅宫 | 家宅、不动产、家庭气氛；也是“库”，看守成与积蓄 | 兄弟、疾厄 | 子女 |
| 福德宫 | 精神生活：想什么、享受什么、心里安不安；财帛的源头 | 夫妻、迁移 | 财帛 |
| 父母宫 | 与父母、师长、上司的关系；也看文书、仪表与受到的荫护 | 子女、交友 | 疾厄 |

十二宫因此分成四组三方，每组三宫互为三合：

- **命、财、官**（加对宫迁移）：一个人“做什么、怎么做、得什么”。论格局主要看这一组。
- **夫、迁、福**（加对宫官禄）：关系、外缘与内心。夫妻宫的对宫是官禄，感情与事业在盘上天然相冲相照。
- **兄、疾、田**（加对宫交友）：家底、身边人与根基。
- **子、友、父**（加对宫田宅）：上下辈与人群。

命、身、迁移、财帛、官禄、福德六宫最要紧，通称六强宫（《紫微斗数全书》卷三谈星要论把这六宫单独提出，§10 ziwei-quanshu-j3-q14）。解盘时这六宫先看、细看。

### 1.2 怎样读一个宫：三方四正

三方四正 = 本宫 + 对宫 + 两个三合宫，取 `结构.宫位关系[]` 中该宫的 `主星`、`对宫`、`三合宫`。读法分四层，按力量从大到小：

1. **坐守（本宫）**：同宫的星力量最直接，定这一宫的主调。先主星，再辅星，再杂曜。
2. **对照（对宫）**：对宫的星直冲本宫，力量仅次于同宫，约当七八成。对宫是“外面照进来的”，常表现为环境、对方、外界给你的东西。
3. **会照（三合宫）**：两个三合宫的星拱照本宫，各约当五六成。它们说明这一宫靠什么支撑。
4. **夹（邻宫）**：前后两宫的星把本宫夹在中间，只在成对的星曜夹宫时才论（左右夹、昌曲夹、魁钺夹、日月夹、禄存所在被羊陀夹、空劫夹、火铃夹），取 `邻宫`。

下结论的顺序：先定本宫主星是什么、亮度如何；再看三方四正里吉星（六吉、禄存、化禄权科）多还是煞忌（六煞、化忌）多；最后看有没有成对、成格。一句“命宫天机”不成结论，“命宫天机在午入庙，对宫巨门、三合太阴与天梁会照，机月同梁会齐，又得文昌同宫”才是。

**吉煞的算法。** 会齐成对的吉星比单见有力（左辅右弼一在命一在官，胜过只见其一）。煞星同宫最重，对冲次之，三合会照又次。吉多煞少，煞星化为魄力与专长；煞多吉少，吉星只能救急。《全书》的总纲是“主强宾弱”与“吉多逢凶也吉”（§10 ziwei-quanshu-j1-q06、ziwei-quanshu-j1-q04）：主星庙旺为主强，能驾驭煞星；主星陷弱而煞星庙旺，则喧宾夺主。

### 1.3 亮度：庙、旺、得、利、平、不、陷

亮度是主星在所落地支的状态，计算器已标在每颗星的 `亮度` 字段，共七级，由强到弱：**庙 > 旺 > 得（得地）> 利（利益）> 平（平和）> 不（不得地）> 陷（落陷）**。

- **庙、旺**：星性里好的一面充分发挥，短处被收住。吉星庙旺则吉力足；煞星庙旺则“刚而有用”，其破坏性转为果决与专业。
- **得、利**：中上。星性正常发挥，成色看同宫和会照的星。
- **平**：星性不显，好坏都随会照的星走。
- **不、陷**：星性里费力的一面容易出来。吉星陷弱则“有心无力”“虚而不实”；煞星陷弱则损害直接。陷地的星最需要吉化（化禄、权、科）和吉星扶持，有则“反背成格”，无则这一宫是全盘要花力气的地方。

### 1.4 空宫与借星

宫内没有十四主星叫空宫（`结构.空宫`）。默认取法：**借对宫主星来读**（`结构.宫位关系[].借对宫主星`）。

- **借什么**：只借对宫的主星及其生年四化。辅星、煞星不借，它们仍在对宫，照常以“对照”论。
- **亮度怎么论**：借来的星按它在对宫原位的亮度论（字段里给的就是原位亮度），不按本宫地支重新查表。
- **力量打几折**：借星的力量约当原星的七成。所以空宫的主调是“像对宫那组星，但淡一层，而且更受环境牵动”。
- **本宫自己的辅星煞星地位上升**：空宫里若有文昌文曲、左辅右弼、魁钺、禄存，它们就成了这一宫实际的主事者；若坐的是擎羊、陀罗、火星、铃星、地空、地劫，这一宫的性质先由煞星定调，借来的主星只作背景。
- **三合宫照常会照**，不受借星影响。注意不要重复计数：对宫的主星已经借来当本宫主星，就不再另算一次“对照”。

命宫是空宫（古称命无正曜）时的读法：这个人的底色不由一颗主星定死，可塑性大，容易随环境和身边人变样；迁移宫那组星既是他在外面的样子，也借回来成为他本人的底色，所以“在外面是什么样，就是什么样”。成败看三方：财帛、官禄两宫有庙旺的吉星拱照，古书仍许为好命（§10 ziwei-quanshu-j3-q02）；三方也弱而煞星坐命，才是真正费力的盘。特殊的空宫格局（明珠出海、日月并明等）见 §6。

其他宫位空宫同理。夫妻宫空而借官禄宫的星，常见读法是“关系里的相处方式与做事方式相似”“在工作学习的场合里认识亲近的人”。

### 1.5 身宫

身宫看 `结构.身宫.所在宫位`。命宫是先天底色，身宫是后天着力处：一个人成年以后把力气和注意力投向哪里，越往后越像身宫。传统上认为年岁渐长，身宫的分量渐重。身宫只落在六个宫位，由出生时辰决定：

| 身宫所在 | 时辰 | 读法 |
|:---|:---|:---|
| 命宫（命身同宫） | 子、午 | 先天与后天合一，个性鲜明而固定，自我主张强，少受环境改变。命宫那组星的好处与短处都加倍 |
| 福德宫 | 丑、未 | 重精神生活与内心感受，在意“心里过不过得去”。做选择时先问自己愿不愿意 |
| 官禄宫 | 寅、申 | 重事业与成就，把自我价值系在做出来的事上。对学业与工作投入深 |
| 迁移宫 | 卯、酉 | 重外界与变动，在外比在家更能施展，与环境变化、出行、迁徙的关系深 |
| 财帛宫 | 辰、戌 | 重资源与实际所得，务实，对钱与物的运用敏感 |
| 夫妻宫 | 巳、亥 | 重亲密关系，亲近的人对自己影响深，在关系里投入大（未成年人读作看重要好的朋友和亲近的人怎样回应自己） |

身宫那一宫要像命宫一样读它的三方四正。命宫强而身宫弱，是先有底气、后天着力处反而费劲；命宫弱而身宫强，是起点平常、后天在那一领域越做越顺。命身两宫的主星性质相反（例如命宫天同、身宫七杀），就写成“底色求安稳，后天被推着去闯”的张力。

### 1.6 命主、身主、五行局

- **五行局**（`基础信息.五行局`）：水二局、木三局、金四局、土五局、火六局。实际作用是定起运岁数（几局就几岁起第一个大限）与紫微星的位置。局数小起运早，局数大起运晚。不必从五行局另推性格。
- **命主**（由命宫地支定）：子—贪狼；丑、亥—巨门；寅、戌—禄存；卯、酉—文曲；辰、申—廉贞；巳、未—武曲；午—破军。
- **身主**（由生年地支定）：子、午—火星；丑、未—天相；寅、申—天梁；卯、酉—天同；辰、戌—文昌；巳、亥—天机。
- 读法：命主、身主是两颗“值班”的星。在盘上找到这两颗星落在哪一宫、亮度如何、有没有化忌或煞星同宫。它们落在命、身、财、官、迁、福六宫而且庙旺，是给全盘加分；落陷逢煞，是减分。三合派里命主身主只作辅助参考，分量远不及命宫主星与四化，一两句带过即可，不单独立论。

### 1.7 命宫强弱怎样下结论

解读必须给出“命宫强、中、弱”的结论。按下面五项逐项取证，再合起来说：

| 项目 | 取证字段 | 加分 | 减分 |
|:---|:---|:---|:---|
| 主星亮度 | `十二宫[命宫].主星[].亮度`；空宫看 `借对宫主星` | 庙、旺 | 不、陷；空宫先减一等 |
| 三方四正的吉星 | 命、迁、财、官四宫的 `辅星` | 左右、昌曲、魁钺成对会齐；禄存、天马 | 六吉一颗不见 |
| 三方四正的煞星 | 同上 | 煞星庙地且主星庙旺（刚而有用） | 煞星同宫或对冲，尤其陷地；空劫同宫 |
| 四化 | `结构.宫位关系[命宫].三方四正四化` | 化禄、化权、化科会入，尤其三者会齐 | 化忌坐命或由迁移宫对冲 |
| 夹与格局 | `邻宫`；§6 | 吉星夹；成吉格 | 羊陀夹忌、空劫夹、火铃夹；破格 |

- **强**：主星庙旺或得地，吉星成对，煞忌不在本宫与对宫。
- **中**：主星尚可而吉煞互见；或主星陷弱而得吉化、吉星扶持；或空宫而三方庙旺有吉。多数盘在这一档，要写清“强在哪、弱在哪”。
- **弱**：主星陷或空宫，煞忌同宫或对冲，三方又少吉星。

写法：“按三合派的看法，这张盘的命宫属于中上：天梁在午入庙，又有文昌同宫、禄存在官禄宫会照，是它的底气；对宫太阳落陷、擎羊由财帛宫会入，是它费力的地方。”强弱说的是这组结构在传统里的成色，不等于这个人的能力高低。

## 2. 十四主星

十四主星分两系。**紫微系**六颗：紫微、天机、太阳、武曲、天同、廉贞，逆时针排布；**天府系**八颗：天府、太阴、贪狼、巨门、天相、天梁、七杀、破军，顺时针排布。两系的相对位置固定，所以星曜组合只有固定的若干种（§3）。

按性质，三合派习惯把主星分成几组，解盘时先认出命宫三方四正属于哪一组：

- **杀破狼**（七杀、破军、贪狼）：动、变、开创。三颗永远互在三合。
- **紫府廉武相**（紫微、天府、廉贞、武曲、天相）：稳、管、掌事。常与杀破狼同盘相杂。
- **机月同梁**（天机、太阴、天同、天梁）：静、谋、辅佐、服务。
- **巨日**（巨门、太阳）：言、名、传播。常与机月同梁相会。

下面每颗星按同一体例写：星性、亮度、命宫、各宫、四化。星曜的五行阴阳各家略有出入（例如七杀有庚金、辛金两说），这里只作背景，不据以推论。四化按本技能计算器采用的四化表（§5.1）。“各宫”一栏写的是该星坐守那一宫时的常见读法，实际解读必须结合亮度和三方四正。

### 2.1 紫微

- **星性**：己土，阴。北斗主星，诸星之首，化气为尊。主尊贵、主见、统御、责任感，也主好面子、不肯屈居人下、耳根软（喜听好话）。紫微是“帝星”，它的成色全看有没有臣佐：左辅右弼、天府天相、文昌文曲、天魁天钺会齐，叫君臣庆会，有人可用、有事可成；三方四正一颗辅佐都没有，叫孤君，心气高而助力少，容易自己硬撑（§10 ziwei-quanshu-j1-q09）。紫微还有“解厄制化”之功：能压住火星铃星，能把七杀的冲劲化为权柄。
- **亮度**：午、丑、未入庙，子宫最弱（平）。紫微无陷地，弱在无辅而不在地支。
- **命宫**：气度稳重，有主见，自尊心强，愿意担事也要求被尊重；遇事先想“我该怎么定”，不喜欢被人指挥。得辅弼昌曲，是能组织人、让人服的人；无辅而见煞，则主观、孤高、多劳。紫微独坐只在子午；其余都是双星（§3）。
- **各宫**：
  - 夫妻：被有主见、稳重的人吸引；关系里看重体面，容易各持己见。
  - 财帛：求财重稳定与体面，财源与职位、名分相关；得禄或武曲、天府会照则财务有规划。
  - 官禄：最得位（紫微为官禄主）。适合独当一面、负责决策的位置；不耐久居人下。
  - 迁移：在外受人看重，有贵人；出门比在家施展得开。
  - 福德：精神上要求高、自我期许重，享受讲品质；易因自尊而操心。
  - 父母、兄弟、交友等六亲宫：在这些关系里自己多担待、多操劳。
- **四化**：乙干化科——名声、体面、得人敬重，是清贵的化法。壬干化权——主导欲与掌控力加重，利于掌事，也更固执。紫微不化禄、不化忌。

### 2.2 天机

- **星性**：乙木，阴。南斗，化气为善。主智慧、谋划、机变、思虑；是“动脑”的星，也是“动”的星（变动、迁移、转换）。长处是反应快、学得快、善分析、善筹划；短处是想得多而定不下来、心思细而易焦虑、兴趣广而不专。天机是参谋星，宜辅佐、策划、专业技术，不宜独当开创之任。
- **亮度**：子、午入庙，卯、酉旺；丑、未落陷，巳、亥平。庙旺则机敏而有条理；陷弱则多虑多变、聪明用在琐碎处。
- **命宫**：头脑灵活，好学多思，善于看出门道，口才与文笔常不错；心性善良而敏感。传统上的讲法是这颗星主变动，职业、环境、想法都容易换。会文昌文曲则长于学问文字；会天梁则善谈论、好分析事理；会巨门则长于口才与钻研；逢煞则心神不宁、计较多。
- **各宫**：
  - 夫妻：被聪明、心思细的人吸引；关系多变化，相处靠沟通与心智上的投契。
  - 财帛：靠智力、策划、专业求财；财来财去有起伏，宜动中求财。
  - 官禄：宜企划、分析、技术、教育、顾问等用脑的工作；工作内容或岗位多变。
  - 迁移：出外多变动，适应力强；在外靠机变得人赏识。
  - 福德：思虑不停，闲不下心；精神上求知欲强。
  - 兄弟（天机为兄弟主）：手足、同辈之间聪明而各有主意。
- **四化**：乙干化禄——点子能变现，机会多，善于在变动中得利；丙干化权——谋划有主导权，思路更果断；丁干化科——以才智、学识、策划得名；戊干化忌——思虑过度、钻牛角尖、计划多变而反复，落哪一宫那一宫就多费心神。

### 2.3 太阳

- **星性**：丙火，阳。中天星，化气为贵。主光明、博爱、付出、名声、公众。古法以太阳、太阴分别象父母与男女亲属，属历史语境，不用来判断当事人的亲属或关系。太阳“施而不受”：热心、好管事、乐于照顾人，重名甚于重利。短处是好面子、急躁、劳碌、付出多而自己留得少。
- **亮度**：卯入庙，寅、辰、巳、午旺（午为日丽中天）；未、申为偏西（得）；酉、子、亥落陷，戌、丑不得地。太阳最重亮度：庙旺则光明磊落、有名望、做事有回响；落陷则同样热心付出，但劳多功少、名不显，或出力不讨好。白天出生（卯至申时）加分，夜间出生减分。
- **命宫**：性格开朗直率，热情大方，有正义感，喜欢参与公共事务；庙旺者有领袖气质与公众缘。落陷者内敛一些，常是默默承担的人。会巨门主口才与传播；会天梁主清誉与原则；会太阴主日月并照、刚柔兼具。
- **各宫**：
  - 夫妻：在关系里是付出、操持的一方；庙旺则付出得明朗有回响，落陷则付出多而少被看见。
  - 财帛：钱财公开透明，重名誉所带来的收入；太阳主散，手松，宜以名求利。
  - 官禄：宜公共事务、传播、教育、政治、公益、能见度高的工作；庙旺主事业有声望。
  - 迁移：在外活跃，人面广，远方有发展；落陷则在外奔波劳碌。
  - 福德：心胸开阔，好忙碌，闲不住。
  - 父母：在与长辈、师长的关系里，自己是主动付出、愿意担事的一方。
- **四化**：庚干化禄——因名得利，付出有回报，公众缘好；辛干化权——有威望与话语权，主导公共事务；甲干化忌——付出不被看见、是非由名声而起、与长辈、上司的关系多波折，落陷更甚，庙旺则只是劳心。

### 2.4 武曲

- **星性**：辛金，阴。北斗，化气为财，为财帛主。主财、主行动、主刚毅果决。武曲是“正财星”“将星”：务实、重效率、说到做到、执行力强，对数字和实利敏感。短处是刚硬、直来直去、少情趣、偏好独来独往。
- **亮度**：辰、戌、丑、未入庙，子、午旺；巳、亥平。无陷地。庙旺则果断而能成事；平弱则劳碌、急进。
- **命宫**：性格刚直，行动派，重承诺，能吃苦，有担当；不擅表达柔情，容易显得严肃。武曲要动才有财，宜实业、财务、技术、纪律性强的领域。会贪狼主大器晚成；会天府主理财守财；会七杀、破军主冲劲大而波动大；会文曲文昌主刚柔相济。
- **各宫**：
  - 夫妻：关系里偏理性、务实，表达少；相处宜各有事业、互相尊重空间。传统认为武曲入夫妻宫，感情上偏硬、话少，需要有意识地表达。
  - 财帛：最得位。求财积极，凭实力与行动得财；庙旺会禄主财务稳健。
  - 官禄：宜财经、金融、工程、军警、实业、需要决断的管理。
  - 迁移：在外肯拼，远方求财（古书有武曲与禄马同会利于远方求财之说，§10 ziwei-quanshu-j3-q12）。
  - 福德：心里闲不下来，凡事求实效，精神上较紧。
  - 田宅：重置产与守成。
- **四化**：己干化禄——财源顺畅，行动带来实利；庚干化权——财权在握，执行与决断更强，也更刚；甲干化科——理财有方、财务上有信誉，名声来自专业；壬干化忌——财务周转、因钱起的是非、决断过刚而折，落在财帛、官禄最需留意现金流与风险（只谈做事方式，不预言破财）。

### 2.5 天同

- **星性**：壬水，阳。南斗，化气为福，为福德主。主福气、和顺、享受、童心。天同是“福星”：温和、乐天、不与人争、有人缘、懂生活情趣。短处是安于现状、少冲劲、易懒散、情绪化。传统认为天同“先难后易”，要经过激发才肯用力，所以反而喜见一点煞星或化权来“激”。
- **亮度**：巳、亥入庙，子、申旺；午落陷，丑、未不得地。庙旺则福厚心宽；陷弱则操心多、想享福而不得闲。
- **命宫**：性情温和，随和好相处，有同情心，兴趣广泛，重感受与生活品质；不喜冲突与竞争。会太阴主细腻柔美；会天梁主稳重乐于助人；会巨门则心里话多、易有闷气。
- **各宫**：
  - 夫妻：相处温和，重陪伴与情绪上的舒服；关系里像朋友。
  - 财帛：求财不急，财来平顺；重享受，花在生活情趣上。
  - 官禄：宜服务、福利、教育、设计、餐饮休闲等令人舒适的行业；不宜高压竞争。
  - 迁移：在外人缘好，得人照顾。
  - 福德：最得位。心宽、知足、会享受。
- **四化**：丙干化禄——福气与享受加厚，人缘带来机会；丁干化权——福星得权，由安逸转为肯做事，是天同最好的激发；庚干化忌——想安稳而不得，情绪起伏，劳心。传统另有一说：天同化忌在戌宫反为佳（古书称反背，见 §6.2），因为忌星激发了它的动力。

### 2.6 廉贞

- **星性**：丁火，阴（兼带木性）。北斗，化气为囚，又为次桃花，为官禄主。廉贞最复杂：一面是“囚”——原则、纪律、自我约束、是非分明，宜公职与规范性强的工作；一面是“桃花”——感情丰富、有魅力、重人际与审美。好则公私分明、精明干练、有政治头脑；差则心高气傲、好胜、情绪激烈、纠结。它的好坏极受同宫星与四化影响。
- **亮度**：寅、申入庙；巳、亥落陷；其余平、利。
- **命宫**：聪明干练，事业心强，有手腕，处事讲原则也讲策略；外冷内热，自尊心强。会天府天相主稳重掌事；会七杀破军贪狼则大起大落、敢闯；会文昌文曲则多才艺（古书对廉贞会昌曲有不利的断语，属历史文本，不用于个案）。
- **各宫**：
  - 夫妻：感情浓烈，爱憎分明，关系里有较劲的成分；需要学会不把原则带进亲密关系。
  - 财帛：求财精明，善于在规则与人脉中取利。
  - 官禄：最得位。宜公职、法务、管理、公关、电子与精密行业。
  - 迁移：在外善交际，能见度高。
  - 福德：心思重，对自己要求高，不易放松。
- **四化**：甲干化禄——桃花化为人缘与财缘，感情与事业上都得利，廉贞的锋芒变柔；丙干化忌——原则变成执念，感情纠葛或与规范、文书、是非有关的困扰（传统所谓“囚”的一面加重），落哪宫哪宫多纠结。

### 2.7 天府

- **星性**：戊土，阳。南斗主星，化气为令（贤能），为财帛、田宅主，是“库星”。主守成、包容、稳重、理财。与紫微相比，紫微主“权”而天府主“库”：天府重实际、善管理、善保存资源，从容不迫。短处是保守、好安逸、不愿冒险、爱面子。天府的成色看有没有禄：有禄存或化禄会照是“满库”；不见禄而见空劫是“空库”，见煞是“露库”，稳重之中多了不安。
- **亮度**：无陷地，子、丑、寅、辰、未、戌入庙。
- **命宫**：气度宽厚，稳重踏实，有管理才能，善于在既有基础上经营；重衣食与安全感。会紫微见 §3；会天相称府相朝垣（§6）。
- **各宫**：
  - 夫妻：在关系里求安稳，重实际的照顾与过日子的踏实。
  - 财帛：最得位。善理财、能积蓄；见禄更佳。
  - 官禄：宜管理、财务、行政、守成型事业。
  - 田宅：得位。重家宅与置产，家底稳。
  - 迁移：在外稳当，得人信任。
  - 福德：心宽，重生活品质与安全感。
- **四化**：在本技能采用的四化表里天府不参与四化。其他常见版本有壬干天府化科（《全书》安星诀即如此，见 §5.1）。

### 2.8 太阴

- **星性**：癸水，阴。中天星，化气为富，为田宅主、财帛主。主阴柔、内敛、细腻、积蓄。古法以太阳、太阴分别象父母与男女亲属，属历史语境，不用来判断当事人的亲属或关系。太阴主“藏”：与太阳的外放相对，太阴重内心、重家、重美感、重积累，财是慢慢存出来的。短处是多愁善感、优柔、洁癖、想得多说得少。
- **亮度**：亥、子、丑入庙（亥为月朗天门），寅、戌旺；卯、辰、巳落陷，午、未、酉不得地，申利。太阴同样最重亮度与日夜：夜间出生、月亮明亮则温润富足；落陷则同样细腻，但心事重、积蓄难、得不到想要的安宁。
- **命宫**：气质温和文雅，心思细腻，重感情，有审美与艺术感受力；做事有耐心、善规划。庙旺者从容，落陷者敏感多虑。会天同主温柔享福；会天机主聪明多思；会太阳主日月同辉。
- **各宫**：
  - 夫妻：在关系里重体贴与情绪上的被理解。
  - 财帛：财来自积累、不动产、稳定收入；庙旺主善储蓄。
  - 官禄：宜财务、不动产、设计、文艺、幕后企划、照护类工作。
  - 田宅：最得位。重家宅，利置产，家中安宁。
  - 迁移：在外安静低调，得人暗中相助。
  - 福德：内心世界丰富，重情调，易感伤。
  - 父母：在与长辈、师长的关系里，重体贴与情感上的亲近。
- **四化**：丁干化禄——财富缓缓积聚，得人助力，家宅有福；戊干化权——内敛中有掌控，善于掌管财务与家务；庚干、癸干化科——以文雅、才艺、细致得名，财务上有好名声；乙干化忌——心事重、情绪内耗、为家宅与家里的事操心，落陷更甚，庙旺则只是多思（传统认为太阴在亥子化忌反为“变景”，不以凶论）。

### 2.9 贪狼

- **星性**：甲木，阳（兼带癸水）。北斗，化气为桃花。主欲望、才艺、交际、探索。贪狼是“欲望之星”：什么都想要、什么都想试，多才多艺、长于应酬、反应快、有魅力，也主修行与神秘学的兴趣（欲望的另一极）。短处是贪多、不专、好投机、喜新厌旧。古书称其“善恶之星”，好坏随所会的星而变（§10 ziwei-quanshu-j1-q03）。
- **亮度**：辰、戌、丑、未入庙，子、午旺；巳、亥落陷；寅、申平。庙旺则多才而有成；陷弱则欲望多而方向乱。
- **命宫**：活泼外向，善交际，兴趣广泛，学东西快，有表现欲与企图心。传统上的讲法是贪狼的成就来得从容，不在一时。遇火星铃星成火贪、铃贪格（§6）；遇文昌文曲，见 §4.1 昌贪同宫的读法；遇空劫反而收敛欲望，转向专精或精神追求。
- **各宫**：
  - 夫妻：感情经历丰富，重吸引力与新鲜感；关系需要共同的兴趣来维系。
  - 财帛：求财手段灵活，有偏财意识，财来得快也去得快。
  - 官禄：宜公关、业务、娱乐、艺术、设计、餐饮、教学等与人和欲望打交道的行业。
  - 迁移：在外人缘广，机会多，应酬多。
  - 福德：兴趣多，好享乐，也可能好玄学、宗教。
- **四化**：戊干化禄——人缘与才艺变现，机会与偏财；己干化权——企图心与掌控力强，能把兴趣做成事业；癸干化忌——欲望受阻、求而不得、因贪多而失，或桃花与人际的困扰，反过来也主收心专一。

### 2.10 巨门

- **星性**：癸水，阴。北斗，化气为暗。主口、主是非、主疑、主钻研。巨门是“暗星”：它遮住别人的光，也能看见别人看不见的东西。长处是口才、分析、研究、怀疑精神、能深究；短处是多疑、多言招怨、心里有话不吐不快、易与人有隔阂。巨门最喜太阳来解其暗（巨日同宫），最喜化禄、化权把“是非”转成“以口生财”“言而有威”。
- **亮度**：寅、申、卯、酉入庙，子、午、巳、亥旺；辰、戌落陷，丑、未不得地。
- **命宫**：观察力强，善言善辩，做事认真、肯钻研；心思深，不轻信。传统读法里，这颗星的长处要经过磨合才显出来。会太阳主光明正大的表达；会天机主机辩与研究；会天同则心里闷；逢擎羊陀罗火星则是非加重。
- **各宫**：
  - 夫妻：关系里沟通是核心课题，话多或话不投机；宜找能谈得来的人。
  - 财帛：以口才、专业知识求财（教学、法律、销售、咨询、传媒）。
  - 官禄：宜靠嘴与专业吃饭的行业；工作中多竞争与言辞往来。
  - 迁移：在外多口舌或靠口才立足。
  - 福德：心里话多，爱琢磨，不易放下。
- **四化**：辛干化禄——口才生财，言语讨喜，是非化为名气；癸干化权——言而有威，说服力强，能在争议中胜出；丁干化忌——是非口舌、误会、有苦难言，落哪宫哪宫的沟通最费力。传统另有一说：巨门在辰宫化忌，辛年生人反为奇格（§6.2）。

### 2.11 天相

- **星性**：壬水，阳。南斗，化气为印，为官禄主。主印信、辅佐、公正、服务。天相是“宰相”“掌印官”：谨慎、守规矩、重形象、乐于助人、善协调，是可靠的副手与执行者。它没有自己强烈的立场，好坏随旁边的星走——所以天相最重“夹”：它的两邻永远是巨门和天梁。巨门化禄，叫财荫夹印，得人提携；巨门化忌，或邻宫、同宫有擎羊，叫刑忌夹印，受人牵累、夹在中间为难（§6）。
- **亮度**：子、午、丑、寅、申入庙；卯、酉落陷；其余得地。
- **命宫**：仪表端正，待人诚恳，有正义感，做事有分寸；服务精神强，适合辅佐、管理、协调。短处是缺少主见、易受环境和上司影响、顾虑多。会紫微、武曲、廉贞见 §3。
- **各宫**：
  - 夫妻：在关系里讲规矩与责任，求稳定。
  - 财帛：财务规矩、稳定，宜受薪或管理他人之财。
  - 官禄：最得位。宜行政、秘书、法务、人事、公务、服务业管理。
  - 迁移：在外得人信任，形象好。
  - 福德：重生活品质与衣食，心里讲究公平。
- **四化**：天相不参与四化。它的吉凶看两邻巨门、天梁的四化，以及对宫破军的状态（天相的对宫永远是破军）。

### 2.12 天梁

- **星性**：戊土，阳。南斗，化气为荫，为父母主，又称寿星、老人星。主荫护、原则、监察、清高。天梁是“荫星”：自己受长辈荫庇，也荫庇别人；有长者之风，正直、重原则、好打抱不平、喜欢教导与照顾人。它也是“解厄之星”：传统上的讲法是天梁长于在麻烦出现之后把它化解掉，所以这颗星的本事常在难处才显出来。短处是好说教、固执、清高、孤芳自赏；陷地则流于散漫、漂泊。
- **亮度**：子、午、寅、卯、辰、戌入庙，丑、未旺；巳、亥、申落陷。
- **命宫**：稳重老成，有正义感与责任感，思想成熟，乐于助人，有名士气；适合专业、监察、教育、医护法律一类“替人解决问题”的工作。会太阳主清誉与公共事务；会天机主善谈兵、好分析；会天同主温厚。陷地逢天马则好动不定。
- **各宫**：
  - 夫妻：被成熟稳重的人吸引，关系里有照顾与被照顾的结构。
  - 财帛：不以求财为先，财来自专业与名誉；天梁不喜化禄（见下）。
  - 官禄：宜公职、监察、教育、社会服务、保险、专业顾问。
  - 迁移：在外得长辈贵人，逢事有人相助。
  - 福德：精神上清高，好思考人生与道理。
  - 父母：最得位。受长辈荫庇。
- **四化**：乙干化权——原则有了威信，监督与专业权威，是天梁最好的化法；己干化科——清誉、学术与专业名声；壬干化禄——传统认为天梁清高而不宜亲财，化禄则“财来带着麻烦”，得利的同时多一层是非或负担，要写成“得到的好处附带责任”。天梁不化忌。

### 2.13 七杀

- **星性**：属金（庚金、辛金两说，兼带火性）。南斗，化气为杀（权），是“将星”。主肃杀、冲锋、独立、决断。七杀是冲锋陷阵的大将：刚强、果敢、不服输、独来独往、喜怒形于色，能在逆境里扛事。短处是急躁、不合群、冲动；传统上的讲法是这颗星起伏大。七杀要有“主帅”才成器：得紫微同宫或对照，叫化杀为权；得禄则刚中有柔。
- **亮度**：无陷地。寅、申、辰、戌、丑、未、酉入庙，子、午、卯旺；巳、亥平。
- **命宫**：个性强，有魄力，独立自主，不喜受约束；做事干脆，敢于承担风险。人生多变动与挑战，宜从事需要决断、竞争、开创的工作。七杀坐命，财帛宫必是贪狼、官禄宫必是破军，杀破狼格自然成立（§6）。
- **各宫**：
  - 夫妻：关系里个性碰撞强，需要空间；宜晚定或各自独立。
  - 财帛：求财敢冲，起伏大。
  - 官禄：宜军警、外科、工程、创业、竞争性强的管理。
  - 迁移：在外奔波，敢闯，宜离开出生地发展（§10 ziwei-quanshu-j1-q19）。
  - 福德：心里不得闲，好强，对自己严。传统认为七杀不宜入福德宫，主精神上辛苦。
- **四化**：七杀不参与四化。它的吉凶看同宫、对宫的紫微、廉贞、武曲的四化，以及有没有禄来会。

### 2.14 破军

- **星性**：癸水，阴。北斗，化气为耗。主破坏、消耗、变革、开创。破军是“先锋”：先破后立，除旧布新，敢于打破现状，有创意与冲劲，不按牌理出牌。短处是破坏性、冲动、反复、耗损大、与人难长久相处。破军的对宫永远是天相：它的“破”要有天相的“规矩”来收。破军喜化禄（有了资源，破而能立）、喜紫微来制。
- **亮度**：子、午入庙（古称英星入庙），辰、戌、丑、未旺；卯、酉落陷；巳、亥平。
- **命宫**：个性鲜明，求新求变，行动力强，有开创精神；传统上的讲法是这颗星主大变动，事业、居所、关系都可能有推倒重来的时候。会紫微主在变革中掌权；会武曲主在财务上大进大出；会廉贞主敢作敢为。
- **各宫**：
  - 夫妻：关系变化大，不耐平淡；需要共同成长的空间。
  - 财帛：财来财去，花费大，宜有人代为管束。
  - 官禄：宜开创、改革、创意、拆解重建型的工作；不耐例行公事。
  - 迁移：在外变动多，宜外出发展。
  - 田宅：传统有“先破后成”之说，家宅多变动而后安定。
  - 福德：心里不安分，总想改变。
- **四化**：癸干化禄——变动带来收益，破而后立有资源支持；甲干化权——变革有主导权，开创力最强。破军不化科、不化忌。

## 3. 双星组合

两颗主星同宫时，不是两段单星释义相加，而是一个新的性格。读法的通则：

1. **谁为主**：紫微、天府同别的星同宫时为主；其余以亮度高者为主，另一颗修饰它。
2. **相济还是相激**：性质互补的（紫相、武府、机梁、同阴）是相济，稳；性质都偏动偏刚的（武杀、武破、廉破、紫破）是相激，力量大而波动大。
3. **对宫是谁**：双星同宫时对宫常是空宫或固定的一颗星，下表一并列出。同宫双星之外的宫位若是空宫，就要借这组双星去读。

每组只出现在固定的两个地支。亮度以计算器 `亮度` 字段为准。

### 3.1 组合一览

| 组合 | 宫位 | 读法 |
|:---|:---|:---|
| **紫微天府**（紫府） | 寅、申 | 两颗主星同宫，对宫七杀。气度大、稳重、有领导欲与管理力，既要权又要实。好处是格局大、能守能管；难处是两个“皇帝”同宫，进取与保守互相牵制，容易高不成低不就、自视甚高。得左辅右弼与禄则成大器（§6 紫府同宫）；无辅则孤高 |
| **紫微贪狼**（紫贪） | 卯、酉 | 帝星遇桃花。有魅力、善交际、多才艺、重享受，古称“桃花犯主”。宜把欲望导向才艺与事业；得左右昌曲或化权、化禄则风雅而有成。逢火星铃星成火贪。逢空劫、华盖则转向哲学宗教（古书称脱俗）。未成年人只读才艺、人缘与审美 |
| **紫微天相**（紫相） | 辰、戌 | 对宫破军。帝星与掌印官同在“天罗地网”之地，有才干、有抱负、想突破现状而受环境约束，故多有不甘与反叛。做事有规划、重原则。得吉化则在体制内掌实权；三方见杀破狼，事业上多变革 |
| **紫微七杀**（紫杀） | 巳、亥 | 对宫天府。化杀为权：七杀的冲劲受紫微节制而成权威。果断、有魄力、事业心极强、能独当一面，自我要求高。短处是强势、劳心。得禄与辅弼则权与实兼备 |
| **紫微破军**（紫破） | 丑、未 | 对宫天相。帝星与先锋同宫：敢于破旧立新、不受拘束、有开创魄力，也主主观、反复、与上级和规范多冲突。得左右、魁钺、禄则在变革中成事；无吉而逢煞，则劳而少成。古书对紫破评价两极（富贵堪期与为臣不忠并存），关键在吉煞多少 |
| **天机太阴**（机月） | 寅、申 | 对宫空宫。聪明细腻、多思多感、善筹划、心思灵巧；重感情、易敏感、想得多。是机月同梁格的核心（§6）。宜企划、文职、财务、设计。动荡感来自天机，内敛来自太阴；两宫孰优以 `亮度` 字段和出生时辰的日夜为准 |
| **天机巨门**（机巨） | 卯、酉 | 对宫空宫。机辩之才：分析力与口才俱强，善研究、好钻研、敢质疑。卯宫两星皆庙旺，古称巨机居卯为贵格；酉宫稍次。短处是多疑、多言；传统评价是先破后成 |
| **天机天梁**（机梁） | 辰、戌 | 对宫空宫。“善谈兵”：好分析、好议论、有谋略、有见识，适合顾问、参谋、研究、教育、宗教哲学。性格清高，原则性强而思虑多。逢煞与空劫，传统上认为偏向宗教与出世之思 |
| **太阳太阴**（日月） | 丑、未 | 对宫空宫。日月同宫，刚柔并存：性格有两面，时而外放时而内敛，情绪起伏，做事容易反复。丑宫月明日暗，偏太阴的内敛；未宫日尚有光而月暗，偏太阳的外向。传统认为日月同宫坐命不如日月从三方来会照（§6） |
| **太阳巨门**（巨日） | 寅、申 | 对宫空宫。太阳解巨门之暗：口才好、有表达与传播能力、做事光明正大、先名后利。寅宫太阳旺、巨门庙，最佳，古称巨日同宫；申宫太阳偏西，虎头蛇尾、先勤后惰之象。宜教育、传播、法律、外交、涉外事务 |
| **太阳天梁**（阳梁） | 卯、酉 | 对宫空宫。正直、重名誉、有原则、乐于助人，宜公职、专业、学术、监察。卯宫日出扶桑，两星俱庙，最佳；酉宫太阳落陷，清高而劳、名大于实。会文昌与禄成阳梁昌禄格（§6） |
| **武曲天府**（武府） | 子、午 | 对宫七杀。财星入库：理财能力强、务实稳重、能赚能守，是财务与管理之才。短处是重利、保守。见禄则富足；见空劫则为空库 |
| **武曲贪狼**（武贪） | 丑、未 | 对宫空宫。财星遇欲望星，两星俱庙：企图心强、能拼、有财缘，传统评价是先难后易。遇火星铃星则暴发力强。性格刚而精明，偏重实利 |
| **武曲天相**（武相） | 寅、申 | 对宫破军。刚毅的武曲得天相调和：务实、有服务精神、办事可靠、善理财务与行政。受对宫破军影响，事业上有变动与开创的一面 |
| **武曲七杀**（武杀） | 卯、酉 | 对宫天府。两颗金星同宫，刚上加刚：性急、果决、拼劲十足、敢冒险，行动先于思考。事业起伏大，宜技术、工程、纪律部队、需要决断的实务。要禄或紫微来化其刚；逢擎羊、火星则冲动易折（古书对此断语严厉，属历史文本） |
| **武曲破军**（武破） | 巳、亥 | 对宫天相。财星遇耗星：赚钱能力与花钱能力都大，财来财去，事业多变，敢破敢立。性格直率、不守成规。宜靠技艺、专业与变动求财，不宜守成；得禄则破耗有源 |
| **天同太阴**（同阴） | 子、午 | 对宫空宫。两颗水星同宫，温柔、细腻、重感情、有艺术气质与生活情趣。子宫两星俱庙旺，古称水澄桂萼，清雅有福；午宫两星俱弱，多愁善感、想安逸而多劳，反喜煞星激发（午宫擎羊同宫，古称马头带箭） |

## 4. 辅曜、煞曜与杂曜

### 4.1 六吉星

六吉都是“助力”，自己不成主调，要附着在主星上发挥。**成对出现才算数**：同宫、对照、三合会照或夹宫，凑齐一对，力量倍增；只见一颗，助力有限。

| 星曜 | 性质 | 读法 |
|:---|:---|:---|
| **左辅**（土）、**右弼**（水） | 平辈的助力：同事、朋友、下属、帮手 | 入命主为人宽厚、有人缘、得人帮助，也善于帮人、善于协调。紫微、天府最需要它们（§10 ziwei-quanshu-j1-q02）。左辅偏正面直接的协助，右弼偏暗中的、感情上的协助。传统认为左右单独入夫妻宫不利专一，主关系里有第三方的参与感，可读作“身边人对这段关系影响大”。壬干左辅化科、戊干右弼化科，主因他人推荐而得名 |
| **文昌**（金）、**文曲**（水） | 才华与文采：文昌主正途功名、文书、典章、考试；文曲主口才、才艺、偏门学问 | 入命主聪明好学、气质文雅、有表达能力。亮度要看：巳、酉、丑入庙，寅、午、戌落陷。二星在丑未同宫或夹命最佳。**昌贪同宫**（文昌或文曲与贪狼同宫）的定稿读法：在紫微的常见读法里，文昌与贪狼同宫，是才思碰上了兴致，点子多、上手快、什么都想试一试；传统上提醒的是容易铺得太开、细处顾不周全，所以落到文书、数字和答应过别人的事情上，宜多核一遍。古书对这一组合另有严厉的断语，属历史文本，不用。文昌文曲是四化星：丙干文昌化科、辛干文曲化科，利考试、文名；辛干文昌化忌、己干文曲化忌，主文书、契约、考试、言辞上的失误与反复，读作“白纸黑字的事要多核一遍”。昌曲遇廉贞、破军，传统上提醒才思容易用得零散 |
| **天魁**、**天钺**（火） | 长辈与贵人的提携：天魁为阳贵（明处的、公开的提携），天钺为阴贵（暗处的、私下的帮助） | 入命或在三方四正，主关键时候有人提拔、有机会送上门，也主仪表端庄、有威仪。一在命一在对宫或三合，古称坐贵向贵。魁钺重在“机遇”，辅弼重在“人手” |

### 4.2 六煞星

煞星是“阻力”也是“动力”。三合派的原则不是见煞就凶：**庙地的煞星配庙旺的主星，是魄力、专业、突破；陷地的煞星配陷弱的主星，才是损害**（§10 ziwei-quanshu-j1-q07、ziwei-quanshu-j1-q08）。煞星同宫最重，对冲次之，夹宫又次（§10 ziwei-quanshu-j1-q05）。

| 星曜 | 性质 | 读法 |
|:---|:---|:---|
| **擎羊**（金，化气为刑） | 明枪：刚烈、冲动、竞争、正面的冲突 | 辰戌丑未入庙，主果决、有权威、敢竞争（古称擎羊入庙）；子午卯酉落陷，主冲动、易起争执。入命性格刚强、不服输、爱恨分明。与火星同宫，庙地主威权出众。在午宫古称马头带剑，吉凶两极 |
| **陀罗**（金，化气为忌） | 暗箭：拖延、纠缠、反复、暗中的阻碍 | 辰戌丑未入庙；寅申巳亥落陷。入命主固执、慢热、钻牛角尖，事情拖而不决；庙地则主坚持、能熬。擎羊永远在禄存的前一宫，陀罗在后一宫，二者夹着禄存（§4.3） |
| **火星**（火） | 明火：暴躁、突发、爆发力、来得快去得快 | 寅午戌入庙，申子辰落陷。入命性急、行动快、脾气来得快。与贪狼同宫为火贪格（§6），主爆发。紫微能制火星铃星（§10 ziwei-quanshu-j1-q10） |
| **铃星**（火） | 阴火：阴沉的烈性、记仇、内在的煎熬、持久的压力 | 亮度同火星。入命外表沉着而内心刚烈，有胆识与谋略。与贪狼同宫为铃贪格。传统认为铃星比火星更难化解，因为它不发作 |
| **地空**（火）、**地劫**（火） | 空亡与劫夺：地空主精神上的空、想法落空；地劫主物质上的失、钱财被劫 | 二星不论庙陷。入命主思想独特、不落俗套、有创意与哲学倾向，也主不切实际、钱财难聚、半途而废。入财帛、田宅、福德，传统认为最不利聚财（读作“财务上宜保守、少投机”）。对贪狼、廉贞等欲望重的星反而有收敛之功。空劫夹命、夹财为败局。古书称地空为天空；计算器另有杂曜“天空”，是另一颗星，力量轻得多，不要混同 |

**四煞与主星的关系**：七杀、破军、贪狼、廉贞、武曲、巨门这些本身刚烈或带暗的星，再遇煞星则烈上加烈；天同、天府、天梁、紫微这些温厚或有制化力的星，耐煞的能力强；太阳太阴庙旺时不畏煞，落陷时最畏煞；天机、天相最易受煞星影响心神与立场。

### 4.3 禄存与天马

- **禄存**（土）：由生年天干定位，是“天禄”，主财禄、稳定的收入、衣食无缺，也主保守、谨慎、独守（因为它永远被擎羊陀罗前后夹着，所以禄存坐守的宫位自带“被夹”的紧张：有财而守得辛苦）。入命、财帛、田宅、官禄最佳。禄存喜与化禄相会，叫双禄交流（同宫）或明禄暗禄（一明一暗合），主财源不止一处。禄存单守命宫而无主星吉化，传统讥为守财奴。禄存所在的宫如果同时有化忌，就是羊陀夹忌（§6）。
- **天马**（火）：由生年地支定位，只落在寅、申、巳、亥四宫。主动、迁移、奔波、远行、变动。天马本身无吉凶，看它与谁同行：与禄存或化禄同宫、对照，叫禄马交驰（§10 ziwei-quanshu-j1-q11），主动中得财、越动越有；与紫微天府同行，主出行有排场；与陀罗同宫叫折足马，主动而受阻；与火星同宫叫战马；逢地空地劫、空亡，主奔波而劳而无功（§10 ziwei-quanshu-j1-q01 所在的《太微赋》有马遇空亡之说）。天马入命或迁移，这个人坐不住，宜外出发展。

### 4.5 十二神

计算器另输出四组十二神，力量比杂曜更轻，三合派只在细节处参考：

- **长生十二神**（长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养）：标示该宫气势的盛衰阶段。命宫、财帛、官禄坐长生、冠带、临官、帝旺，气势足；坐病、死、墓、绝，气势收。古书所谓“生逢败地”“绝处逢生”指此。这里的“病”“死”是十二阶段的名称，不作健康判断。
- **博士十二神**（博士、力士、青龙、小耗、将军、奏书、飞廉、喜神、病符、大耗、伏兵、官府）：从禄存起排。博士主聪明，力士主权势，青龙主喜庆，奏书主文书之喜，将军主威猛；小耗、大耗主耗损，伏兵、官府主是非。
- **将前十二神、岁前十二神**：主要用于流年细断，本技能正文一般不用。

十二神只在它与主星格局同向时顺带一提（例如“官禄宫天梁化科，又坐奏书，文书与名誉的主题更集中”），不单独立论。

## 5. 四化

四化是化禄、化权、化科、化忌。它们不是独立的星，而是附着在某颗星上、改变其表现的四种“变化”。三合派以**生年四化**为主：出生年的天干决定哪四颗星带禄权科忌，这四颗星落在哪四宫，就是这张盘的重心所在。星曜讲“是什么性质”，四化讲“力气往哪里使、在哪里得、在哪里卡”。

### 5.2 禄权科忌各自的含义

| 四化 | 古称 | 性质 | 读法 |
|:---|:---|:---|:---|
| **化禄** | 福德之神（§10 ziwei-quanshu-j1-q12） | 得、顺、缘分、财、享受、增多 | 这颗星的好处流出来，那一宫顺遂、有缘、有进益。禄主“情”和“财”，是因，是开始。化禄喜见禄存（双禄）、喜落命财官田。禄太多（禄存、化禄、大限禄叠在一处）则流于安逸、贪多 |
| **化权** | 掌判生杀之神（§10 ziwei-quanshu-j1-q13） | 掌握、主导、争、能力、坚持、加重 | 这颗星的力量加重，那一宫有主导权、肯争取、有实际能力，也主固执、压力、争执。权主“势”，是过程中的用力 |
| **化科** | 主掌文墨（§10 ziwei-quanshu-j1-q14） | 名声、体面、文雅、贵人、条理、缓和 | 这颗星变得斯文、有名、得人好评，那一宫讲体面、有贵人、逢事能缓解。科的力量最轻，利名不利财；它的大用处是“解”——能缓和同宫或对宫的化忌与煞星 |
| **化忌** | 多管之神（§10 ziwei-quanshu-j1-q15） | 执着、亏欠、不顺、收敛、纠结、变动 | 这颗星的短处被放大，那一宫是心之所系、放不下、多费周折的地方。忌主“执”和“欠”，是果，是收束。化忌不等于坏：它是一个人最在意、投入最多的地方，因为在意所以多事。忌也主“收藏”，入田宅、财帛而星曜庙旺时，传统有“忌入库”可以守财之说 |

**四化的力量受星曜亮度制约。** 庙旺的星化禄权科，好处实在；陷弱的星化禄权科，好处虚浮、得而费力，但聊胜于无，陷地的星尤其需要吉化来救。庙旺的星化忌，只是劳心、多事，古书甚至以太阳在寅至午、太阴在酉至子化忌为福（§10 ziwei-quanshu-j2-q05）；陷弱的星化忌，才是真正的卡点。取证看 `结构.生年四化[].亮度`。

**四化改变星性的方向**，读时要把星性和四化合起来说，不说“化科只是一个标记”：

- 化禄在财星（武曲、太阴、天府系）主实财；在桃花星（贪狼、廉贞）主人缘与情缘；在智慧星（天机）主机会；在口舌星（巨门）主以口生财；在耗星（破军）主破而后有得。
- 化权在刚星（武曲、破军、贪狼）主执行与开创的实权；在柔星（天同、太阴）主由柔转刚、肯担事；在紫微、天梁主权威；在巨门主言语的分量；在天机主谋略定夺。
- 化科在紫微、天梁、太阴主清誉；在文昌、文曲主文名与考试；在武曲主财务信誉；在天机主才智之名；在左辅、右弼主得人举荐。
- 化忌的具体表现见 §2 各星条目。

### 5.4 四化之间的关系：三合派常用的看法

1. **先找禄和忌，再看权和科。** 禄是得处，忌是卡处，这两者定全盘重心。一句话概括一张盘的四化，应该是“得在某宫，执着在某宫”。
2. **三方四正会齐。** 化禄、化权、化科三者同时出现在命宫的三方四正，叫三奇加会（科权禄拱，§6），是很高的评价。取 `结构.宫位关系[命宫].三方四正四化` 直接核对。只会到两个（禄权、禄科、权科）也各有其名，力量递减。
3. **忌冲。** 化忌坐在某宫，对宫受冲，受冲的一宫往往比忌星坐守的一宫更不安：坐忌是“我执着于此”，冲忌是“被它打到”。所以化忌在迁移宫冲命宫、在官禄宫冲夫妻宫、在福德宫冲财帛宫、在财帛宫冲福德宫、在子女宫冲田宅宫，都要把对宫一并写出来。
4. **禄忌同宫与禄忌相冲。** 化禄与化忌同宫或对照，叫禄忌相缠：先得后失、得中带累、好处伴着麻烦，读作“这一处既是机会也是负担”。古书所谓禄逢冲破，即禄存或化禄被忌星、空劫冲破（§10 ziwei-quanshu-j1-q01 所在的《太微赋》开篇即论此）。
5. **禄随忌走。** 这是看因果流向的口诀：禄是缘起，忌是归宿。同一张盘里，化禄所在的宫位给出机会与资源，最终都要流向化忌所在的宫位去“交账”。读法是把两宫连起来说一条线：例如化禄在官禄宫、化忌在夫妻宫，就是“事业上得来的，最后用在、耗在或者被要求偿还在亲密关系上”；化禄在财帛、化忌在田宅，就是“赚来的钱最后落到家宅上”。这一条让四化从四个孤立的点变成一条有方向的线，解读时必须写出来。
6. **权科制忌。** 化忌所在的三方四正若有化科或化权，化科能缓、化权能扛。科忌同宫主名誉上有瑕疵、文书上有波折但可解；权忌同宫主硬碰硬、争执，但也主“有能力把难事办下来”。
7. **夹。** 化禄、化权、化科夹某宫是吉夹（§10 ziwei-quanshu-j1-q17）；化忌被擎羊陀罗所夹是羊陀夹忌（§6）。
8. **辅星的四化同样算数。** 文昌、文曲、左辅、右弼的化科、化忌与主星四化同等看待。文昌、文曲化忌常被忽略，它们落在哪一宫，那一宫的文书、考试、合约、言辞就是要小心的地方。

### 5.5 大限四化、流年四化怎样叠到本命盘上

大限与流年各有天干，各自再起一组四化（`结构.当前大限四化`、`结构.当前流年四化`）。这些四化的星曜**仍然落在本命盘的宫位上**（`本命落宫`），所以读的时候是三层叠加：

| 层 | 管多久 | 作用 |
|:---|:---|:---|
| 生年四化 | 本命盘，不随运限变 | 定底色：得处与卡处 |
| 大限四化 | 十年 | 定这十年的主题：哪一宫被点亮，哪一宫被压住 |
| 流年四化 | 一年 | 定这一年的触发点 |

读法：

1. **先看运限命宫落在本命哪一宫**（`命宫所在本命宫`）。大限命宫落在本命官禄宫，这十年的主轴就是事业；落在本命夫妻宫，主轴是关系。
2. **四化落宫有两个读法，要同时说**：一是它落在**本命**的什么宫（`本命落宫.宫位`），说的是本命格局里哪一块被触动；二是它落在**运限**的什么宫——用该地支去查 `运限.当前大限.宫位排列`（从寅宫起顺数），说的是这十年里这一块扮演什么角色。例如大限化禄落在本命财帛宫，而这个地支在大限盘里是大限官禄宫，就读作“这十年的事业机会，落在你本命求财的方式上”。
3. **叠禄、叠忌。** 大限化禄与生年化禄落同一宫（或同一颗星）叫叠禄，那一宫的顺遂在这十年加倍；大限化忌与生年化忌同宫或相冲叫叠忌、忌冲忌，那一宫的功课在这十年集中出现，是需要重点说明的地方。流年的禄忌再叠上来，就是三层重叠的触发年。
4. **运限化忌冲本命命宫、冲运限命宫**，是这一段最吃力的信号；**运限化禄、化权、化科会入运限命宫的三方四正**，是这一段最得力的信号。
5. **运限的禄存、羊陀、魁钺、昌曲、天马**（流曜）：计算器当前大限与流年的流曜字段通常为空，没有输出就不写。

大限与流年只说主题、着力点与节奏（“这十年的重心从家宅转到事业，得力处在贵人，费力处在合约文书”），不报具体事件与年份，不给择日（红线 2）。

## 6. 主要格局

格局是一组星曜在命宫三方四正形成的固定结构。三合派论命“先明格局，次看众星”。解读必须说清这张盘成了什么格、没成什么格、成格之后有没有被破。

### 6.1 判断通则

1. **格局以命宫为准。** 除特别注明外，成格条件说的都是命宫及其三方四正（`结构.宫位关系[]` 中 `宫位` 为命宫的那一行）。身宫成格算次一等。其他宫位成同样的结构，只说明那一宫的主题，不算全盘格局。
2. **成格三问**：构成的星到齐了吗（同宫、对照、三合会照都算“会”，但同宫、对照的力量大于三合）；关键的星亮度够吗（吉格要求主星庙旺或至少得地）；有没有吉星、吉化来扶（禄权科、六吉）。
3. **破格因素**：四煞（羊陀火铃）同宫或对冲、地空地劫同宫、化忌坐守或冲照、关键星曜落陷、吉星落空亡。古书的原则是陷地又逢煞忌则不以入格论（§10 ziwei-quanshu-j3-q03）。破格不是格局消失，而是“有其形而成色打折”：写作“这组结构成立，但擎羊同宫，传统上认为好处要经过一番争夺才能到手”。
4. **空宫成格**：命宫空宫借对宫主星成格，力量再减一等，并在方法说明里写明是借星成格。
5. **一张盘可以同时具备几个格局**，也可以吉格凶格并见。以会齐程度高、星曜庙旺者为主格。
6. **富、贵、公卿、乞丐这类评语是古人的分等用语**，读作评价高低与主题所在（红线 2）。

| **火贪格、铃贪格** | 贪狼与火星（或铃星）同宫坐命；对照、三合会照次之。以贪狼在辰戌丑未入庙为上（§10 ziwei-quanshu-j1-q22、ziwei-quanshu-j3-q10） | 贪狼化忌；地空地劫同宫；擎羊陀罗同会 | 爆发力：突然的机会、迅速的成就，来得快。传统评价是“横发”，同时提醒来得快的也容易去得快，要见好就收、转为守成 |

| **石中隐玉** | 巨门在子或午坐命，三方四正会化禄、化权、化科（§10 ziwei-quanshu-j1-q20、ziwei-quanshu-j2-q06） | 无吉化；羊陀火铃化忌会照 | 玉藏石中：传统上的讲法是才华内敛，经过磨砺才显出来，靠专业与口才立名。不宜锋芒早露 |

| **英星入庙** | 破军在子或午坐命，无煞 | 煞忌；文昌文曲同宫 | 开创而能成，变革中掌权 |
| **雄宿朝元** | 廉贞在寅或申独坐命宫（《全书》注作申、未宫），无煞 | 煞忌 | 廉贞入庙，干练而有声名 |
| **文星拱命、昌曲夹命** | 文昌、文曲在命宫三方四正会齐；或分居命宫两邻（看 `邻宫[].辅星`） | 昌曲落陷、化忌 | 文采、学业、才艺出众 |
| **左右同宫、左右夹命** | 左辅、右弼同坐命宫，或分居两邻 | — | 助力多、人缘好、逢事有帮手 |

**反背成格**：陷地的星得吉化，反而成格。古书举的例子有天同在戌宫、丁年生人（天同化权）；巨门在辰宫、辛年生人（巨门化禄）。读法是“这一处本来费力，但出生年给了它转机，因此先抑后扬”。这类说法各家细节不一，使用时写明是传统里的一种看法。

## 7. 大限与流年

### 7.1 大限

- **怎么排**：每个宫位管十年（`十二宫[].大限.范围`，虚岁）。第一个大限从命宫起，起运岁数等于五行局的局数；阳年生男、阴年生女顺行（命宫、父母、福德……），阴年生男、阳年生女逆行（命宫、兄弟、夫妻……）。当前所在大限看 `运限.当前大限` 与 `结构.当前大限四化`。
- **大限命宫**：当前大限所在的那个本命宫位（`结构.当前大限四化.命宫所在本命宫`），在这十年里充当“大限命宫”。以它为起点重新布十二宫，得到大限的财帛、官禄、夫妻等宫（`运限.当前大限.宫位排列`）。
- **怎么读**，按顺序：
  1. **这十年走到哪一宫**。大限命宫落在本命的什么宫，那一宫的人事就是这十年的舞台。走到本命官禄宫，事业是主轴；走到本命福德宫，是向内整理、重精神生活的十年；走到本命疾厄宫，按三方四正读，主轴是家底与身边人的调整，不写健康。
  2. **大限命宫的星曜与三方四正**。用 §1.2 的方法把大限命宫当作命宫来读：主星庙旺、吉星会齐，这十年顺；主星陷弱、煞忌交集，这十年费力。大限命宫是空宫，同样借对宫。取该宫在 `结构.宫位关系[]` 里的那一行。
  3. **本命与大限的关系**。本命命宫强而大限弱，是底子好而这一段要熬；本命弱而大限强，是这一段得时、宜把握。古书所谓“命好不如限好”即此意。大限的星曜组合与本命命宫属于同一类（例如本命机月同梁、大限也走机月同梁），这十年顺着本性走；属于相反的一类（本命机月同梁而大限走杀破狼），这十年被推着变动，要写出这种不适与它带来的开拓。
  4. **大限四化**（§5.5）。大限天干的四化落在本命哪一宫、大限哪一宫；与生年四化有没有叠禄、叠忌、忌冲。大限化忌所在与所冲，是这十年的功课；大限化禄所在，是这十年的机会。
  5. **格局在这十年有没有被引动**。本命有火贪格而大限走到贪狼所在的宫、或大限化禄化权落在贪狼上，这个格局在这十年发动；本命有羊陀夹忌而大限化忌再落到同一宫，压力在这十年集中。
- **结论要求**：用一两句话说出这十年的主题，例如“36 到 45 岁这十年走在本命田宅宫，主题是安家与守成；大限化禄落在子女宫，机会来自合作与作品；大限化忌与生年化忌同落一宫，那条线上的功课在这十年要正面处理。”

### 7.2 小限与流年

- **小限**：每宫管一年，`十二宫[].小限年龄` 列出该宫对应的虚岁。三合派传统上大限、小限、流年太岁三者同参（“二限太岁”）。本技能以大限和流年为主，小限只在与流年指向同一处时顺带提及。
- **流年**：流年地支所在的宫位是流年命宫（太岁宫），看 `结构.当前流年四化.命宫所在本命宫`。读法与大限相同而尺度缩小到一年：流年命宫落在本命与大限的什么宫，三方四正如何（§10 ziwei-quanshu-j3-q13），流年四化落在哪里、与生年和大限的四化如何叠加。
- **流年的分量受大限节制**。大限是十年的大气候，流年是其中一年的天气。大限吉而流年凶，只是小波折；大限凶而流年吉，是喘息的一年。不能脱离大限单独论流年。
- **年界**：紫微流年以农历正月初一为界，与八字的立春年界不同。计算器只算了查询日期所在的那一个流年，没有算的年份不写。
- **流月、流日**：计算器有输出，但正文一般不用；除非任务专门问到当月，且只说主题，不作择日。

## 9. 一张盘的读法示例（合成盘）

下面用一张合成的盘面演示怎样从字段走到结论。盘面是为演示拼出来的，不对应任何人。

**盘面事实**：命宫在丑，紫微（庙）破军（旺）同宫，天魁同宫；身宫在迁移宫。迁移宫在未，天相（得），文昌、文曲、天钺、陀罗（庙）同宫。财帛宫在酉，武曲（利，化权）七杀（庙），擎羊（陷）同宫。官禄宫在巳，廉贞（陷）贪狼（陷）。生年庚干四化：太阳化禄在子女宫（戌，不得地），武曲化权在财帛宫，太阴化科在田宅宫（辰，陷），天同化忌在疾厄宫（申，旺），与禄存、天马同宫。父母宫、夫妻宫为空宫。当前大限走庚辰，落在本命田宅宫。

**怎样下结论**：

1. **格局**：紫微破军在丑坐命，财帛武曲七杀、官禄廉贞贪狼，命宫三方把杀、破、狼都会齐了，是紫微领着杀破狼的盘，主调是变革与开创。天魁坐命、天钺在对宫，成坐贵向贵；文昌文曲在迁移宫对照命宫。所以结论是：杀破狼格成立，由紫微驾驭；兼有魁钺、昌曲对照之助。破格因素是财帛宫擎羊落陷、官禄宫两颗主星俱陷。
2. **命宫强弱**：主星庙旺（加分）；六吉里魁钺成对、昌曲成对由对宫照入（加分），左辅右弼不在三方四正（紫微无辅弼，减分）；擎羊在财帛宫会照、陀罗在迁移宫对冲（减分，其中陀罗入庙，减得少）；生年化权在三方（加分），没有化忌冲命（加分）。合起来是中上：命宫本身有力，外缘好，弱在做事的那一宫（官禄）主星失陷，钱财那一宫带着争夺的色彩。
3. **四化的重心**：得处在子女宫（太阳化禄，但太阳不得地，禄是辛苦换来的），实权在财帛宫（武曲化权），名声在田宅宫，执着在疾厄宫。疾厄宫不读身体：这颗化忌与禄存同宫，两邻是擎羊和陀罗，成羊陀夹忌；它对冲父母宫（空宫，借的正是这组天同天梁），又会照兄弟宫与田宅宫。所以这张盘的卡点要写成“与长辈、上司以及家底这条线上的亏欠感与牵挂”。按禄随忌走，把两头连起来：在合作、作品与晚辈身上得来的，最后要拿回去交代家里与长辈这条线。庚干化忌各家取法不同，这一条要在限制里说明。
4. **身宫**：在迁移宫，天相得地而吉星云集。后天着力处在外面，越往后越适合在外发展、靠人缘与文字口才立足。
5. **当前大限**：走在本命田宅宫，太阴落陷化科、火星同宫。十年主题是安家、置产、整理家底，过程不安静。大限天干与生年同为庚，四化完全重叠：叠禄在子女宫，叠权在财帛宫，叠忌在疾厄宫并再次对冲父母宫。这十年把本命盘的重心原样放大了一遍。

**写给读者时**，上面每一条都改成“你”做主语的判断，加声源标签，依据落到读者能在盘上指认的星与宫，并配一条可落空的对照情境。例如：“按三合派的看法，你这张盘的主调是开创。紫微和破军一起坐在命宫，管钱的一宫是武曲七杀，管做事的一宫是廉贞贪狼，七杀、破军、贪狼三颗主变动的星在你的三方会齐了。如果你回想换环境、接手烂摊子、从头搭一件事的时候，自己反而更有精神，这条读法大概贴合；如果你在稳定、按部就班的环境里更自在，这条读法就不太贴合你，那时更该看的是对宫的天相，它讲的是规矩与分寸。”
