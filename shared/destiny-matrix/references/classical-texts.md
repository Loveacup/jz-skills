## 一、《滴天髓》— 论五行旺衰、十干体象

**作者**：相传宋·京图原撰，明·刘伯温注，清·任铁樵增注

**核心命题**：脱离格局神煞的繁琐，回到阴阳五行生克制化的本理。

### 关键论命原则

#### 1. 通神论（开篇总纲）

> "欲识三元万物宗，先观帝载与神功。"

三元 = 天干、地支、人元（藏干）。命理本质是阴阳五行流转，看命须观天地人三才。

#### 2. 十干体象

每个天干都有具体意象，不可抽象论。这是 destiny-matrix「日主意象化描述」的典籍依据：

| 天干 | 体象 | 关键句 |
|:---|:---|:---|
| 甲 | 参天大树 | "甲木参天，脱胎要火" |
| 乙 | 花草藤蔓 | "乙木虽柔，刲羊解牛" |
| 丙 | 太阳 | "丙火猛烈，欺霜侮雪" |
| 丁 | 灯烛 | "丁火柔中，内性昭融" |
| 戊 | 高山大地 | "戊土固重，既中且正" |
| 己 | 田园湿土 | "己土卑湿，中正蓄藏" |
| 庚 | 刀剑铁器 | "庚金带煞，刚健为最" |
| 辛 | 珠玉首饰 | "辛金软弱，温润而清" |
| 壬 | 江河大海 | "壬水通河，能泄金气" |
| 癸 | 雨露清泉 | "癸水至弱，达于天津" |

#### 3. 旺衰判定三要素

判断日主强弱看三件事：

- **得令**：日干在月支处于旺、相状态（如甲木生于寅卯月）
- **得地**：日支为日干的禄、刃、根（如甲日生寅）
- **得势**：天干透出比劫印，或地支会合比劫局

三者全占 → 身极旺；全无 → 身极弱；占一二 → 中和身旺/身弱。

#### 4. "中和"为贵

> "能知中和之正理，而于五行之妙，有全能焉。"

不偏不枯为贵。极旺需泄克，极弱需扶印。这是用神判定的根本。

## 二、《子平真诠》— 论用神格局成败

**作者**：清·沈孝瞻

**核心命题**：以月令为重，论格局成败救应。

### 关键论命原则

#### 1. 月令为重

> "八字用神，专求月令。以日干配月令地支，而生克不同，格局分焉。"

格局的根本在月令藏干透干。这是 destiny-matrix「格局判定」的方法论起点。

#### 2. 八格速查

按月令藏干透出（或地支本气）定格局：

| 格局 | 判定 | 性情 |
|:---|:---|:---|
| **正官格** | 月令正官透干（或本气）| 端正守规，重责任，易被规矩束缚 |
| **七杀格** | 月令七杀透干 | 刚毅决断，能成大事，需印化或食制 |
| **正财格** | 月令正财透干 | 务实稳重，重物质，适合实业 |
| **偏财格** | 月令偏财透干 | 慷慨手阔，财来财去，多偏门收入 |
| **正印格** | 月令正印透干 | 重学识涵养，受长辈庇护 |
| **偏印格** | 月令偏印透干 | 偏才偏学，悟性高但孤僻 |
| **食神格** | 月令食神透干 | 才华表达，享受生活 |
| **伤官格** | 月令伤官透干 | 锋芒才华，叛逆克官 |

（建禄、阳刃为辅格，从月支本气论）

#### 3. 格局成败论

> "成中有败，皆因带忌；败中有成，全凭救应。"

- **成格**：用神有力，喜神助之 → 富贵命
- **败格**：用神受克破合 → 困顿命
- **成中带败**：原本成格，但有破坏因素
- **败中得救**：原本破格，但有救应

判定格局后，必须看用神是否有力、是否有破，破后是否有救。

#### 4. 用神四相

> 用神（命局核心需求） → 喜神（生用神或制忌神） → 忌神（克用神或助忌神） → 仇神（生忌神或克喜神）

### 在 destiny-matrix 中的引用模板

判定格局时使用：

> 月支 X 中藏 Y，透出于月干（或年干），《子平真诠》定之为「Z 格」。{格局成败判断}——你这个格局的核心特质是 {引申}。

## 三、《渊海子平》— 论十神六亲

**作者**：宋·徐升（徐子平）

#### 2. 配偶星论命法

**男命论妻**（正财为主，偏财辅看）：
- 正财清纯有力 → 妻贤淑得力
- 正财与日主相合 → 夫妻有情
- 正财被冲克 → 婚姻有变
- 正财、偏财并见 → 易有外情

**女命论夫**（正官为主，七杀辅看）：
- 正官清纯不杂 → 夫君正派得力
- 官杀混杂（正官+七杀同现）→ 感情复杂，易有多次或夹杂
- 伤官见官（伤官+正官同时透）→ 克夫之象（古义重，现代解为感情冲突频）
- 正官被合 → 夫缘易变

#### 3. 六亲位置

| 柱 | 主要六亲 |
|:---|:---|
| 年柱 | 祖上、父母（远亲） |
| 月柱 | 父母、兄弟（近亲） |
| 日柱 | **自身（日干）+ 配偶（日支）** |
| 时柱 | 子女、晚年 |

**日支即配偶宫**——这是六亲分析的核心定位。

> "调候之神，先其所急。"

| 乙 | 丙火 | 癸水 | 春需丙癸，秋需丙火 |
| 丙 | 甲木（生火）+ 壬水 | 壬水 + 庚金 | 春秋大致中和 |

## 六、《神峰通考》— 论命理辨误

**作者**：明·张楠（80 余岁集 40 年命理实践写就）

**核心命题**：辨明命理学中常见的五种错误，正本清源。

### 关键论命原则

#### 1. 辨五误（"动静说"五大谬误）

> 张楠列举命理学中常见的五种判断误区，destiny-matrix 应主动避免：

1. **虚邀禄马** — 命局没有禄马，强从远方"虚邀"——错。论命要看实有，不可凭空想象。
2. **丛辰太多** — 神煞越列越多，喧宾夺主——错。神煞为辅，主体仍是十神格局。
3. **纳音乱断** — 把纳音当作主导论命依据——错。纳音只作底色辅助。
4. **执着字句** — 死扣古书字面，不看实际命局——错。古书有时代局限，须活用。
5. **神煞繁琐** — 神煞万千，挑挑拣拣，凑论断——错。命理本理是阴阳五行，神煞不可压主。

#### 2. 看命四要

张楠明确指出看命应聚焦：

1. **日主旺衰**（《滴天髓》之核心）
2. **格局成败**（《子平真诠》之核心）
3. **用神得失**（喜忌救应）
4. **大运流年与命局之配合**

其他都是辅助。

#### 3. 病药说

> "有病方为贵，无伤不是奇。格中如去病，财禄两相宜。"

命局有"病"（即明显缺陷）反而容易出贵——只要大运能"治病"。完美无瑕的命局往往平淡。

这条对 destiny-matrix 很重要：**不可一见命局有冲克就判凶**，要看大运是否解药。

### 在 destiny-matrix 中的引用模板

避免常见误判时使用（多在分析师内部使用，不一定写入命书）：

## 七、《果老星宗》— 论星命合参 ★ 本框架核心理据

**作者**：托名唐·张果老，实为后世汇编

**核心命题**：将西方占星（七政四余）与四柱命理合参，是中国传统命理学中**唯一系统性合参**的典籍。

### 关键论命原则

#### 1. 星命合参方法论

> "命主以四柱为体，星宗以七政为用；体用相参，方知全貌。"

四柱看"命"——能量结构、格局高低；
星宗看"运"——星辰行度、应期窗口；
两者并陈，称为「**星命合参**」。

#### 2. 七政四余

- **七政**：日（太阳）、月（太阴）、五星（木火土金水）
- **四余**：罗睺、计都、紫炁、月孛（古占星中的虚拟点，类似现代北交、南交、福点等）

#### 3. 十二宫与四柱对照

《果老星宗》的十二宫与现代占星基本一致，但与紫微的十二宫**不同**。这里需注意区分：

| 类别 | 十二宫名称 |
|:---|:---|
| 紫微（中式）| 命、兄弟、夫妻、子女、财帛、疾厄、迁移、交友、官禄、田宅、福德、父母 |
| 占星（西式）| 命宫(1)、财帛(2)、兄弟(3)、田宅(4)、子女(5)、奴仆(6)、夫妻(7)、疾厄(8)、迁移(9)、官禄(10)、福德(11)、相貌(12) |

**两套十二宫名称类似但宫位顺序不同**——这是占星与紫微合参时的关键校准点。

#### 4. 星命合参实操

destiny-matrix Phase 3 多维交叉的传统理据：

- 八字日主旺衰 + 占星太阳所在宫位 → 性格主轴双印证
- 八字夫妻宫（日支）+ 占星 7 宫 + 紫微夫妻宫 → 婚恋三重印证
- 八字大运 + 占星行运（土星周期、木星周期）→ 时间节点双轨

## 八、《千里命稿》— 论命例实证

**作者**：民国·韦千里

**核心命题**：以现代命例验证传统命理。

### 关键论命价值

#### 1. 命例库

韦千里收录大量近代名人、民国政要的命例，每命都按格局、用神、运程分析。这为 destiny-matrix 提供：
- 现代生活情境下的命理应验案例参考
- 论命语言的现代化范本（韦千里以白话论命，可读性强）

#### 2. 论命语言现代化

## 跨典籍引用规范

### 引用层级

| 层级 | 使用场景 | 视觉处理 |
|:---|:---|:---|
| L1 主体引文 | 章节核心判断的"重音" | serif 字体 + 左竖线 + 灰底 blockquote |
| L2 inline 简注 | 句中专业判断的快速出处 | 斜体 + 来源括注，如 *（《子平真诠》正官格论）* |
| L3 暗用不引 | 论断显然源自典籍但不必显式引文 | 直接论述 |

### 引文密度

一份完整命书中，**主体引文 3-5 处**为佳。过多则失去"重音"效果，过少则失去专业感。

主体引文应分配于：
- Phase 2 八字（1-2 处，多为《滴天髓》或《穷通宝鉴》）
- Phase 2 紫微（0-1 处，多为《三命通会》）
- Phase 2 占星（0-1 处，多为《果老星宗》）
- Phase 3 多维交叉开篇（1 处，《果老星宗》"星命合参"）
- Phase 5 感情专题（1 处，多为《渊海子平》六亲论）

### 引文真实性原则

只引用真实存在于典籍中的句子。不可生造古文。如果记不准原文，宁可用现代语言概述：「《滴天髓》大意是说……」也不要伪造引文。

**勘误（对既有正文第二节）**：第九章原文为"**是故成中有败，必是带忌；败中有成，全凭救应。**"既有正文引作"皆因带忌"，属误引，命书引用时以"必是带忌"为准。

**可追溯引用格式范例**：

### 2. 《穷通宝鉴》版本源流与调候条目核对

- **版本源流**：原名《拦江网》（一作《栏江网》），明末无名氏作品（书中命例多为明代宰辅）；清光绪年间抄本入楚南**余春台**之手，增删编订更名《穷通宝鉴》刊行。既有正文"清·余春台编订"可细化为"明末成书、清余春台编订"。
- **徐乐吾有两套评注系统**：《穷通宝鉴评注》与《造化元钥（评注）》，后者所据抄本与余春台本文字有出入，社区有对其"混订两书"的批评（[知乎评述](https://zhuanlan.zhihu.com/p/367932942)）。引用时须区分"余春台本原文"与"徐乐吾评注"。
- **结构**：卷首「五行总论」+ 十干分论（论木：甲乙；论火：丙丁；论土：戊己；论金：庚辛；论水：壬癸），每干下按正月至十二月逐月立条（惯称三春/三夏/三秋/三冬 X 木等）。无统一的"卷 N"编号，各刊本分卷不一（有上下二卷本、五行五章本、十干十卷本），**引用定位应以"论某行 · 某月某干"为准，不写卷号**。
- **"八月甲木"条目原文核对**（既有正文"甲木酉月"段的出处）：原文为"**八月甲木，木衰金旺，丁火为先，次用丙火，庚金再次。**"既有正文的"秋金当令克木，需丁火制金、丙火调候"为释义转述，非原文，引用时不得加引号冒充原文。
- **勘误（待定）**："调候之神，先其所急"一句**未能在《穷通宝鉴》原文中核到**；"调候为急"措辞实出徐乐吾评注（如三夏甲木徐注"木性虚焦，调候为急，不能缺癸"）。既有正文第四节将该句标为《穷通宝鉴》引文，属出处存疑——命书中引用调候总纲时，建议改标"徐乐吾《穷通宝鉴》评注"，或改引具体月令条目原文，或引《子平真诠·论用神配气候得失》（第十四章）。

**可追溯引用格式范例**：

> 《穷通宝鉴·论木·八月甲木》（余春台编订本）："八月甲木，木衰金旺，丁火为先，次用丙火，庚金再次。"

来源：[维基文库《穷通宝鉴》](https://zh.wikisource.org/zh-hant/%E7%A9%B7%E9%80%9A%E5%AE%9D%E9%89%B4)、[太极书馆全文](https://www.8bei8.com/book/qiongtongbaojian.html)、[豆瓣阅读·八月甲木白话详解](https://read.douban.com/reader/column/7731974/chapter/107129901/)、[搜狐·论甲木秋冬月解析](https://www.sohu.com/a/802116474_121725443)。
