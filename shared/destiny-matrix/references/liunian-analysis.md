# 流年/流月精析方法论

## 流年分析的三轨叠加模型

流年运势不是孤立的——它是三层能量的叠加：

```
第一层：大运/大限（十年背景色）
  ↓ 叠加
第二层：流年（年度主旋律）
  ↓ 叠加
第三层：流月（月度节奏变化）
```

好比一场交响乐：大运是乐章的调性，流年是主题旋律，流月是具体的音符。分析流年时必须先明确大运的背景。

## 八字流年分析

### 步骤一：确定流年干支

查万年历或直接推算当年的天干地支。

近年干支速查：
- 2024：甲辰
- 2025：乙巳
- 2026：丙午
- 2027：丁未
- 2028：戊申
- 2029：己酉
- 2030：庚戌

### 步骤二：流年天干→十神

以日主为我，判断流年天干对日主的十神关系。

| 流年十神 | 年度主题 |
|:---|:---|
| 比肩/劫财 | 竞争年·合作或争夺·同辈关系活跃 |
| 食神 | 表达年·创造力旺盛·享受生活 |
| 伤官 | 变革年·锋芒毕露·有才华但易生是非 |
| 偏财 | 投资年·偏门收入·父亲相关事件 |
| 正财 | 稳定年·正当收入增加·务实 |
| 七杀 | 压力年·挑战与磨砺·有贵人则成大器 |
| 正官 | 权威年·升迁机会·规则与约束 |
| 偏印 | 学习年·偏门智慧·孤独感 |
| 正印 | 保护年·贵人出现·学业提升 |

### 步骤三：流年地支→与命局互动

逐一检查流年地支与命局四柱地支的关系：

| 关系 | 含义 | 影响等级 |
|:---|:---|:---:|
| 三合/六合 | 合作·顺利·新关系建立 | 吉 |
| 半合 | 趋向某种能量，但未完全成局 | 中 |
| 相冲 | 变动·冲突·搬家/换工作/分手 | 动（非必凶） |
| 相刑 | 内在矛盾·法律纠纷·健康 | 凶（需细看） |
| 相破 | 破裂·信任受损 | 小凶 |
| 相害 | 暗损·小人·阴性损耗 | 暗凶 |
| 自刑 | 自我折磨·内耗·反复犹豫 | 内凶 |

**重点关注**：
- 流年冲日支（冲夫妻宫）→ 婚姻/感情动荡
- 流年冲年支 → 家庭/祖上变故
- 流年合日干 → 新关系或事业变化
- 流年引动命局中的七杀/偏印 → 压力事件

### 步骤四：大运+流年叠加

| 组合 | 含义 |
|:---|:---|
| 大运吉+流年吉 | 全面顺利，把握机会 |
| 大运吉+流年凶 | 有惊无险，小挫折不影响大局 |
| 大运凶+流年吉 | 困境中的转机，但根基仍弱 |
| 大运凶+流年凶 | 最需谨慎的年份，守为上策 |

### 步骤五：特殊流年事件判断

| 信号 | 可能事件 |
|:---|:---|
| 流年天干合日干 | 有新的重要关系/合作出现 |
| 流年冲日支 | 婚姻变动（结婚或分居均可能） |
| 流年见桃花（子午卯酉） | 感情事件活跃 |
| 流年见驿马（寅申巳亥） | 出行·搬家·异地发展 |
| 流年引动金神格 | 金神入火乡=突破；遇水=沉寂 |
| 流年冲太岁 | 变动之年（犯太岁相关） |

## 紫微流年分析

### 步骤一：定流年命宫

通过斗君法确定流年命宫位置（见 ziwei-framework.md）。

若使用在线排盘工具，直接查看流年盘。

### 步骤二：流年十二宫星曜

流年命宫确定后，十二宫顺时针排列。每个宫位的星曜=原局星曜+流年叠加星。

### 步骤三：流年四化

由流年天干查四化速查表，确定禄权科忌分别落在原局哪个宫位。

**四化落宫解读框架**：

| 四化 | 落命宫 | 落财帛 | 落官禄 | 落夫妻 | 落疾厄 | 落福德 |
|:---|:---|:---|:---|:---|:---|:---|
| 禄 | 全年顺遂 | 财运好 | 事业旺 | 感情甜蜜 | 身体好 | 心情舒畅 |
| 权 | 掌控力强 | 赚钱主动 | 有权势 | 关系中主导 | 意志强 | 精神振奋 |
| 科 | 名声好 | 理财有方 | 受认可 | 感情文雅 | 就医顺利 | 修养提升 |
| 忌 | 多波折 | 财务压力 | 事业阻碍 | 感情纠纷 | 健康注意 | 精神紧张 |

### 步骤四：关键流年判断

| 信号 | 含义 |
|:---|:---|
| 流年化忌入命宫 | 该年多波折，需谨慎 |
| 流年化忌冲命宫（入迁移） | 外出不利或外部环境动荡 |
| 流年化禄入财帛/官禄 | 财运或事业的好年 |
| 流年化忌入夫妻 | 感情危机年 |
| 流年化禄+化权入同一宫 | 该宫代表领域大发 |
| 流年煞星聚集某宫 | 该领域需特别注意 |

## 流月分析

### 八字流月

每月的天干地支构成流月干支，与命局/大运/流年形成四层叠加。

流月主要用于：
- 定位年内的高光月和风险月
- 选择重要事件的时机（如签约、搬家、求职）

**简化判断法**：
- 流月干支与命局喜用神相同 → 该月运势好
- 流月干支与命局忌神相同 → 该月需谨慎
- 流月冲日支/冲流年 → 该月有变动

### 紫微流月

从流年命宫起正月，逆数到目标月份即为流月命宫。

流月分析重点：
- 流月命宫的星曜组合
- 流月四化（由流月天干决定）
- 流月化忌落宫 → 该月的风险领域

## 流年分析注意事项

1. **不要孤立看流年**——必须叠加大运/大限背景
2. **八字与紫微可能结论不同**——正常现象，标注差异
3. **化忌不等于凶**——化忌代表"执着、在意"，落在好宫位可能是"太在意某事而过度投入"
4. **流月分析精度有限**——用于判断大致趋势和关键月份，不要逐日推算
5. **犯太岁**：值太岁（本命年）、冲太岁、刑太岁、害太岁、破太岁——统称犯太岁，需分别判断影响程度
6. **闰月处理**：八字流月以节气为界，不受闰月影响；紫微流月需注意闰月的归属
