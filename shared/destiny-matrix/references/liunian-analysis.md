# 流年与流月：按已计算粒度解释

流年/流月分析只引用本次 chart_bundle 中实际计算的数据，不能从通则、星曜或格局补写未计算的行运、推运或具体事件。适用年份、月份及有效日期区间由 intake 的 timing_request 和计算结果确定；没有用户指定年份时只采用已记录的默认请求，不自行扩展。

## 年界与有效日期

- **八字**：年柱/流年年界按节气，立春前后按精确节气瞬间切分。年度解释须注明对应公历有效日期区间，不把立春年直接称为1月1日至12月31日。
- **紫微**：采用正月初一年界；须注明农历新年对应的有效日期区间，不与八字立春年界混为一谈。
- **占星**：本工具当前不计算行运或次限推运；未新增并实际核验相应计算前，不写行运/推运结论。
- 只写 plan/request 指定且已实际计算的年份或月份。年度结果不得冒充逐月结果；没有月度计算就不制作逐月运势表。

## 八字流年

以已确认的命盘、所用年界和该年度干支为依据，描述天干十神、地支关系及与大运的传统解释。地支的合、冲、刑、破、害等是传统关系术语，不对应可确定的生活事件、吉凶等级或健康结果。

传统层说明相应体系如何解释流年结构，可以在其自身语境中完整说明象义；它不是现实事件证据，也不必一概改写成自我观察题。现实建议另依用户明确目标与现实资料提出，标明为可调整的行动选项，不让传统象义替代现实判断。

可讨论用户明确提出的现实问题及其自述背景，区分传统象义与个人事实。不得由冲合推断结婚、分居、失业、搬迁、诉讼、疾病或其他必然事件；不得给投资吉日、投资结果或关系成功率。若给行动选项，应低风险、可尝试、可调整，不要求等待所谓吉时。

## 紫微流年

仅使用实际生成的流年盘、四化与大限/流年有效日期。紫微流年按正月初一年界，说明具体适用起止日期。宫位、星曜与四化仅作该传统框架内的象征解释，不把化禄、化忌或煞曜转成财务、健康、婚恋事件结论或概率。

## 流月

只有相应系统已经计算了用户所请求的月份及有效区间时，才可讨论月度象义。八字流月按节气月界；紫微流月按工具实际采用的历法月及闰月规则。不可由年度盘推演或填充每月结论，也不提供签约、搬家、求职、投资等事项的“吉日”。

## 报告表达与边界

- 不使用星级、总体运势分数或“高光月/风险月”配额；说明计算对象、体系、有效区间和解释限制。
- 时间章开头用一句写清本书覆盖哪些年份或月份、为什么是这些（例如“这里只算了你问到的〔年份〕”）；此后不逐年宣布“未计算”。每一年先写这一年的盘面结构对原局意味着什么，再写依据与有效日期区间。
- 各体系按各自年界与取法独立读这一年；几种读法在同一主题上落到一处或各拉一边，由综合环节按 `cross-analysis-patterns.md` 写出。
- 健康主题只回应用户主动提出的作息、压力与求助问题，不从命盘生成疾病部位、概率、诊断或死亡判断。
- 未成年关系主题聚焦家庭、同伴、师长及边界；不写性化桃花推断或婚恋年份。
- 已发生的人生事件只能作为用户提供的回顾背景，不得用于择盘、修正出生时刻或声称预测命中。
