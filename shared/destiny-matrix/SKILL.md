# 多维命运深度解析 · v3

## 核心理念（v3 哲学骨架，每次分析必先内化）

**性格决定命运，玄学辅证，命运可塑。**

1. **性格是主语**：荣格八维 / Beebe 八原型给出"性格签名"，这是恒量；八字、紫微、占星是「谓语与状语」，用来解释"为什么是这种性格 / 这种性格如何在时代节律里展开"。
2. **玄学辅证**：玄学体系不"决定"任何事，它"印证 / 映照 / 解释"性格的展开路径。一次分析的可信度由"玄学三维对性格签名的印证度"评估，而不是"四维一致性"。
3. **命运可塑**：性格可发展（Jung 个体化进程 CW 9i §490；成人大脑可塑性），因此命运不是预定剧本而是默认路径。每一份命书必须给出可塑路径与具体行动。

详见 `references/character-first-manifesto.md`（哲学锚点，每次开篇必读）。

## 使用模式

本 skill 主要服务于**「分析师代他人分析」**场景。使用者作为分析师角色，掌握命主完整信息（含已知历史事件），最终输出为给命主本人阅读的**成品命书**。

- 输入端：默认接受第三人称信息（"我朋友 1990 年生..."）
- 输出端：融合体叙事，技术内容化作叙述肌理，不分朋友友好版与专业版
- **章节顺序固定**：第一章必为性格画像；玄学三维（八字/紫微/占星）作为后续支撑

## 体系定位（v3 重新表述）

| 体系 | 在 v3 中的角色 | 擅长维度 | 时间颗粒度 |
|:---|:---|:---|:---|
| 荣格八维 | **主语**（性格签名 · 恒量可发展） | 主导功能·Beebe 原型·阴影·个体化任务 | 终身（功能发展阶段） |
| 八字命理 | **解构**（性格的能量基础） | 五行格局·十神关系·调候 | 十年大运 + 流年 |
| 紫微斗数 | **对应**（性格的剧场舞台） | 十二宫位·星曜组合·四化 | 大限 + 流年 + 流月 |
| 西方占星 | **映照**（性格与时代节律的张力） | 日月关系·行星能量·世代张力 | 行运 + 推运 |

**典籍重读**：《果老星宗》「体用相参」中的「体」在 v3 中重新解读为性格本位，「用」是玄学注解，二者合参方为完整解读（详见 manifesto）。

## 核心原则（v3 修订）

1. **性格本位**：每一条玄学论断都要回到性格签名上印证，否则不写
2. **玄学是注解，不是预言**：用"印证 / 映照 / 解释"，不用"决定 / 命中注定"
3. **可塑路径必给具体行动**：终极课题不可悬空
4. **典籍出处可追溯**：每条命理论断标注典籍依据（含卷次/页码）
5. **结构化叙事**：命运故事，不是信息堆砌
6. **感情分析必须充分**：这是命主最关注的领域，以荣格关系动力学为骨架，玄学提供应期
7. **深度优先**：少数关键点深入，优于所有维度泛谈
8. **必须使用计算脚本**：不可手算关键命理数据

## 分析工作流

### Phase 1 · 数据采集与精确排盘

使用统一调度脚本：

```bash
python3 scripts/cast_chart.py <yyyy-mm-dd> <hh:mm> <gender:m|f> <city> [出生地经纬度]
# 例：python3 scripts/cast_chart.py 1993-09-30 17:30 f 杭州
```

输出包含：八字（lunar_python）+ 紫微（iztro-py）+ 占星（pyswisseph）三体系完整 JSON。

各体系单独调用见：
- `scripts/bazi_calc.py` — 八字（lunar_python 主，sxtwl 校验）

- `scripts/astro_calc.py` — 占星（pyswisseph）
- `scripts/jung_calc.py` — 荣格功能栈 + Beebe 原型 + 性格签名（v3 新增）

详细计算方法与参考表见 `references/bazi-framework.md`、`ziwei-framework.md`、`astrology-framework.md`、`cognitive-functions.md`。

### Phase 1.5 · 时辰反查校准

如分析师在「已知背景」中提供了命主关键人生事件年份，进入校准环节：

1. 用排盘结果推演该年的大运/流年/流月应期
2. 对比分析师提供的事件性质，判断吻合度
3. **吻合**（应期与事件性质对得上）→ 排盘可信，进入 Phase 2
4. **不吻合**（应期偏差大或性质不符）→ 提示可能的时辰修正方向：
   - 早一时辰 / 晚一时辰
   - 夜子时归属（23:00 后归当日 vs 次日）
   - 真太阳时校正（出生地经度与北京时间偏差）
5. 修正后重排，再次校准。**校准点不写入最终成品命书**，仅作为分析师内部判断依据。

#### Gate 1.5 · Phase 1.5 → Phase 2.0 进入条件

完成时辰反查校准后，检查：
- [ ] 已知事件应期对照评估完成
- [ ] 评估结果：吻合 / 时辰修正 / 时辰存疑 三档明示

若评估结果是「时辰存疑」且分析师无法补充信息，**必须**在最终命书顶部标注「时辰假设」，但仍可进入 Phase 2.0。

## 计算脚本（v3）

| 脚本 | 用途 | 主要库 | 用法 |
|:---|:---|:---|:---|
| `scripts/cast_chart.py` | **统一调度** | lunar_python + iztro-py + pyswisseph + geonamescache | `python3 cast_chart.py 1993-09-30 17:30 f 杭州` |
| `scripts/bazi_calc.py` | 八字完整排盘（含神煞、调候、节气警告） | lunar_python (主) + sxtwl (校验) | `python3 bazi_calc.py 1993-09-30 17:30 f` |
| `scripts/ziwei_calc.py` | 紫微完整排盘 | iztro-py | `python3 ziwei_calc.py 1993-09-30 9 f` |
| `scripts/astro_calc.py` | 占星完整排盘（含 P0 修复 + 扩展配点） | pyswisseph | `python3 astro_calc.py 1993-09-30 17:30 30.27 120.16 +08:00` |
| `scripts/jung_calc.py` | **荣格计算引擎**（功能栈 + Beebe + Grip + 性格签名） | 内置 | `python3 jung_calc.py <test_scores.json>` |
| `scripts/_common.py` | 公共工具（真太阳时、地点解析、DST） | geonamescache + timezonefinder | 内部调用 |

```bash
pip install lunar_python iztro-py pyswisseph geonamescache timezonefinder kerykeion --break-system-packages
# v2 兼容（八字交叉校验用）
pip install sxtwl --break-system-packages
```

脚本输出 JSON 格式，包含：四柱/星盘/行星表、十神/十二宫/相位、五行统计、大运/大限/行运、特殊格局、调候用神、神煞、荣格功能栈+Beebe 原型等全部信息。
