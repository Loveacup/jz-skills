# 双轴分析框架（hv-analysis 范式吸收）

> 来源：[[Khazix Skills 深度分析]] § hv-analysis。理论根：Saussure 历时-共时语言学 + 商学院案例研究法。

## 纵轴（历时 / time-depth）
对象从诞生到当下的完整生命历程，**叙事故事体**，不是参数对照表：
- 起源追溯（为什么会出现？前置条件是什么？）
- 诞生节点（关键人物 / 关键时刻 / 关键决策）
- 演进历程（阶段划分 + 每阶段的转折点）
- 决策逻辑（每个分叉点为什么这么选？）
- 当下状态

字数权重：6,000-15,000 字（重历史对象贴上限，新生事物贴下限）。

## 横轴（共时 / breadth comparison）
当下时间截面与竞品 / 同类系统对比：
- A 场景：无明确竞品 → 与"如果没有它"的反事实对比
- B 场景：1-2 个竞品 → 逐项硬对比
- C 场景：3+ 个竞品 → 矩阵化 + 生态位划分

对比维度：核心差异 / 用户视角 / 生态位 / 趋势走向。**不要写成参数对照表的文字版，要讲清楚每个对手"活成了什么样"。**

字数权重：3,000-10,000 字。

## 交叉点（横纵交汇洞察）
两轴交叉处产出**独到洞察**，是这套方法的真正价值所在：
1. 五个核心问题：
   - 为什么是它而不是别人？（历史 × 横向对比）
   - 它最大的劫数是什么？（演进逻辑 × 当下生态位）
   - 谁是最大的隐性受益者 / 受损者？
   - 哪个分叉点改一下，今天会完全不同？
   - 三年后回看，哪件事会被证明是关键？
2. 三剧本未来推演：最可能 / 最危险 / 最乐观

字数权重：1,500-3,000 字。

---

## 适用边界
- 单纯名词解释 / 短摘要：**不要用**（过度工程化）
- 季度 / 年度赛道复盘：**首选**
- 竞品分析报告：横轴主导，纵轴轻量
- 单一产品深度解读：纵轴主导，横轴轻量

## 与短文形态的关系
**长文是母矿，短文是切片**。一份双轴研报可切出 10-20 篇小红书：纵轴某个转折点 = 1 篇钩子文；横轴某个对比维度 = 1 篇对比图；交汇某个洞察 = 1 篇观点文。
