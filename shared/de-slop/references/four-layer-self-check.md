# 四层自检体系 (Khazix-writer 范式吸收)

> 来源：[[khazix-writer 写作风格分析]]。把"反 AI 味"从平铺禁用词清单升级为金字塔层级化框架。

写作完成后按顺序自检 4 层，**任何一层不过关 → 回到对应层修改，不要跳到下一层**。

## L1 硬性规则（机器可扫描）
- 禁用词黑名单命中？（"说白了 / 本质上 / 综上所述 / 让我们来看看"等，详见 anti-ai 清单）
- 禁用标点命中？（"——" 破折号、技术内容里的 ":"、"" 英文双引号）
- 句子长度方差是否 ≥ 2σ？（全是 20+ 字长句 = AI 味）
- 加粗/bullet 是否超阈值？（短文加粗 ≤ 3 处，bullet ≤ 2 条）

## L2 风格一致性（人工对照画像）
- 调性是否符合既定 persona？（如卡兹克 lite = 真诚 + 兴奋 + 轻度自嘲）
- 转场词是否落在 persona 词表内？
- 视角是否统一？（全程 "我"/"你"，禁用 "我们" 做泛指）
- 节奏是否波动？（不是全段等长，要有"句式断裂"独立成段）

## L3 内容质量（信息密度审查）
- 有没有第一手叙事？（"我用了" vs "据说有人用了"）
- 有没有具体名字？（Claude / GPT-5 / Cursor，禁用"某个 AI 工具"）
- 有没有数据点 / 细节锚？（"十几平米出租屋" vs "他的房子"）
- 是否被打动？（敢承认情绪，而非居高临下点评）

## L4 活人感终审（朗读测试）
- 念出来不别扭？（书面腔 = AI 味）
- 有没有不完美瞬间？（自嘲、"我也不知道行不行"的谦逊铺垫）
- 读者能感到"作者就在屏幕对面打字"？
- 是否避免了"完美收尾"？（哲思余韵 / 信念宣言 / 行动呼吁三选一即可）

---

**适用边界**：
- 长文（>2000 字）：L1-L4 完整执行
- 短文（<800 字）：L1 + L4 必做，L2/L3 抽查
- 纯技术文档：L1 + L3，L2/L4 可跳
