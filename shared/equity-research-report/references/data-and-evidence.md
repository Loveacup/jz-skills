# 数据与证据

适用于阶段 2，以及之后所有引用数字的环节。

## 证据表字段

|字段|要求|
|---|---|
|编号|证据 ID，如 `E01`；正文关键数字用它回溯|
|指标|名称写明口径，如「归母净利润（TTM）」「总股本（发行后）」|
|值|原始数值，不预先四舍五入|
|单位/币种|亿元、港元、股、倍等；同一张表不混用单位|
|期间/行情时间|财报期间，或行情对应的交易日与时点（收盘/盘中）|
|发布日期|公告或数据的公开日期，用于判断截至时点是否可得|
|来源|URL、公告编号或本地文件路径；用户提供的写「用户输入」|
|抓取时间|实际获取时间，写到分钟并带时区，如 `2026-09-27 14:05 +08:00`|
|核验状态|已核验 / 单一来源 / 冲突未决 / 不可得|

来源优先级：交易所公告与公司定期报告（A 股以巨潮资讯或交易所网站的原文为准）→ 交易所行情 → 可靠数据服务（交叉验证用）→ 媒体报道（只作线索）。数据服务整理的公告索引和财务字段不替代原文。两个来源不一致时，同时列出两者和差异。官方完整报表与二手来源不一致时，采用官方值，并在证据表记下被舍弃的值和理由；两个官方来源互相矛盾，或者只有二手来源而且互相冲突时，该值标为「冲突未决」，不进入计算。

**A 股行情类数据服务（仅作交叉验证）：** 东方财富行情接口、腾讯行情与日 K 接口可以快速取数。这些是非官方接口，可能改版或限流；要按请求频率节制访问，单个主机失败时换备用主机，不能因为取不到数就改用别的口径。字段含义与缩放倍数（例如价格是否乘了 100）要先用一个已知值核对，再批量使用；按字段名取值，不按列号或位置猜测。

## 时点纪律

- **「截至」拆成三个日期：** 用户说「截至最近一期财报」时，分别写报告期末（数据覆盖到哪天）、公告日（数据哪天公开）、资料检索截止日（这次查到哪天）。公告日以交易所公告档案为准，不用文件路径或 URL 里的日期。
- **截至时点：** 回溯研究和回测，每个历史时点只使用当时已经发布的信息。财务数据按公告日生效，不按报告期末生效。数据服务返回的往往是更正或追溯调整后的最新值，不一定是当时公布的数字；做历史时点分析时，用当时的原始公告，或写明所用数据可能含后来的修订。新闻以实际发布时间为准，不用抓取时间或报道所述事件日期代替。
- **预测的三个日期分开写：** 最后观测日（最后一个已知收盘）、模拟起日（第一个预测交易日）、目标日（窗口最后一个交易日）。最后观测日是行情数据的日期，可以早于资料检索截止日（如周末或盘中检索），两者分别标注。窗口交易日数按交易所公布的真实日历计算，不按「一个季度约 63 天」之类的假设。
- **概率要指明窗口：** 「期末价格高于 X 的概率」和「窗口内曾触及 X 的概率」是两个不同的量，报告中要写明是哪一个，以及对应的起止日期。

## 价格处理

- 收益率序列用经拆分、送转、分红调整后的价格；报告中的价位用原始报价，或明确标为复权价。原始价和复权价分别打标签，不在同一张图或表中混用。记录复权方式（前复权/后复权）、数据服务和取数时间：前复权序列在每次分红后都会整体改变，历史上的前复权价并不是当时的实际价格。
- 涨跌幅、YTD 等区间收益要写明计算基准（如「以去年最后一个交易日收盘价为基准」、次新股以上市首日为基准）。跨越除权日的区间必须用复权价；拿不到复权价时标「未取到」，不用未复权价顶替。
- 多市场上市（如 A/H）：各市场使用各自币种与交易日历；比较溢价时使用同一日的行情和同一时点的汇率。日期不同的收盘价不能当作同日横截面。溢价不必然收敛。
- 股本变动（增发、回购、超额配售）会改变每股指标的分母，EPS 与市值采用对应时点的股本。

## 数据不足

- 某项分析的数据缺失或冲突未决 → 停止依赖该数据的定量结论，写明缺口，其余分析照常进行。
- 空结果、全 0、缺字段先当作取数或解析失败排查（接口状态、字段位置、单位、网络），确认数据确实为空后才能写成事实结论。
- 不用行业均值、往年同期、其他股票的数据或「典型值」填补缺失值，除非用户明确要求并在报告中注明是假设。
- 合成或演示数据：报告标题与数据表都要标注「合成数据」；不虚构来源 URL、一致预期或市场数据。
