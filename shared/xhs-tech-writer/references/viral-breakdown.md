# 六维爆款拆解 Reference

## 拆解的目的

爆款拆解的目的**不是分析为什么这篇火了**（那是事后归因），而是**提取可复用的模式**，让用户能在自己的选题上套用相同的结构和手法。

拆解原则：
- **先还原，再评价**：客观呈现笔记的结构和手法，避免主观好坏判断
- **具体到可操作**：不说"标题写得好"，而是说"标题用了数字+悬念结构"
- **关注可复制性**：重点是提取可复用的模式，不是分析为什么这篇火了

## 六维拆解框架

每篇爆款都按以下六个维度结构化拆解。AI/科技领域示例贯穿说明。

### 维度 1：封面分析

**截图输入时：**
- **视觉风格**：真人出镜 / 插画 / 纯文字图 / 拼图对比 / 信息图 — 选 1
- **色彩调性**：主色调（如蓝白冷调 / 黑黄高对比） / 明暗 / 暖冷 / 是否用对比色
- **文字排版**：封面文字大小、位置（居中 / 左上 / 底部） / 字体风格（衬线 / 黑体 / 手写）
- **视觉焦点**：第一眼被什么吸引（人脸 / 大字 / 色块 / 产品截图）
- **信息层次**：封面传递了几个层次的信息（主标题 + 副标题 + 元素？）

**纯文字输入时：**
- 根据正文内容推断封面可能的风格建议

*AI/科技示例*：一张爆款 Claude 实测笔记封面：纯文字图、黑底黄字高对比、主标题"我把 Claude 用废了"居中大字、视觉焦点是"用废了"三个超大字、信息层次为主标题+小字副标题"7 天实测"。

### 维度 2：标题分析

- **标题原文**：逐字记录（不要意译）
- **句式模式**：列表型 / 对比型 / 疑问型 / 陈述型 / 感叹型 / 故事型 — 选 1-2
- **关键词位置**：核心关键词在标题的什么位置（开头 / 中间 / 结尾）
- **技巧识别** — yes/no 清单：
  - □ 使用数字
  - □ 使用情绪词（绝了 / 救命 / 后悔 / 震惊）
  - □ 使用符号（｜ / ！ / ？）
  - □ 制造好奇心缺口（"第 3 个太绝了"）
- **搜索意图**：用户搜什么词会找到这篇笔记

*AI/科技示例*：标题"用了 3 个月 Cursor，我后悔没早点知道这 5 个技巧"— 列表+故事型双结构、关键词"Cursor"在中段、☑数字 ☑情绪词（后悔） ☐符号 ☑好奇心缺口、搜索意图"Cursor 技巧"。

### 维度 3：关键词与标签

- **核心关键词**：正文中反复出现的关键词（列 3-5 个）
- **Tag 词**：笔记末尾的 #标签 列表
- **SEO 关键词**：哪些词可能在站内搜索中排名
- **长尾词机会**：基于这个话题还能覆盖哪些长尾搜索词
- **搜索意图匹配**：信息型（学习） / 导航型（找工具） / 交易型（想买）

*AI/科技示例*：核心关键词「Cursor / AI 编程 / 提示词 / 上下文」、Tag 含 #AI编程 #Cursor使用技巧、长尾词机会包括"Cursor 跑不动大项目怎么办"。

### 维度 4：内容逻辑与结构

用流程图方式还原笔记骨架：

```
[开头钩子] → [展开1] → [展开2] → ... → [结尾CTA]
```

具体分析：
- **钩子类型**：痛点 / 反常识 / 故事 / 数据 / 好奇 — 选 1
- **展开结构**：并列式 / 递进式 / 总分式 / 问题-解决式 — 选 1
- **信息密度**：每段传达多少实质信息（高 / 中 / 低）
- **段落节奏**：长短交替规律、换行频率（如"3 短句段 + 1 长段交替"）
- **视觉节奏**：是否用 emoji / 分隔符 / 编号创造视觉节奏
- **结尾类型**：总结 / 互动引导 / 悬念 / 行动号召

*AI/科技示例*：骨架 [反常识钩子"AI Agent 瓶颈不是模型"] → [展开1：上下文工程] → [展开2：工具调用] → [展开3：评测] → [留悬念结尾]，并列式展开，每段配 1 个 emoji 起头。

### 维度 5：语言风格

- **人称视角**：第一人称 / 第二人称 / 第三人称
- **口语化程度**：1-5 分（1=书面语，5=纯口语）
- **情绪倾向**：中性 / 积极 / 共情 / 激励 / 吐槽
- **专业度**：1-5 分（1=通俗，5=专业术语密集）
- **emoji 使用**：频率、类型、位置规律
- **特征表达**：独特的句式、口头禅、表达习惯（列出 3-5 个）

*AI/科技示例*：第一人称、口语化 4/5、吐槽+共情、专业度 3/5（术语会带白话解释）、emoji 每段开头 1 个共 4-5 个、特征表达「说实话」「我个人觉得」「真的会谢」。

### 维度 6：互动设计

- **互动引导**：是否在正文中引导评论 / 收藏 / 点赞 / 分享
- **引导话术**：具体用了什么话术
- **评论区预判**：是否预设了读者会问的问题并在正文中回答
- **共鸣触发**：是否植入了让读者想转发或收藏的触发点

*AI/科技示例*：结尾抛"你们用 Cursor 遇到上下文丢失怎么解决"引发评论；正文中预判"是不是只对前端有用"并主动回答；共鸣触发为"和我一样踩过坑的扣 1"。

## 横向对比（≥2 篇爆款时）

逐篇拆解后做横向对比：
- 找**共同特征**：所有爆款都使用的元素 → 强信号
- 找**差异化策略**：每篇的独特点 → 灵活借鉴
- 提取 2-3 个最值得借鉴的核心模式作为生成依据

对比表格示例（AI/科技领域三篇爆款）：

| 维度 | 爆款 A（Claude 实测） | 爆款 B（Cursor 技巧） | 爆款 C（AI Agent 拆解） | 共同点 |
|---|---|---|---|---|
| 钩子类型 | 反常识 | 反常识 | 数据 | 强信息差 |
| 段落节奏 | 短句独立成行 | 短句独立成行 | 短句独立成行 | 视觉碎片化 |
| 结尾 | 留悬念 | 抛真实困惑 | 留悬念 | 不催互动 |
| emoji 数 | 4 | 3 | 5 | 3-5 个区间 |

从对比中提取的核心模式：
1. **反常识/数据钩子开场**：三篇都在前两行制造认知冲突
2. **短句独立成行 + 段间空行**：视觉碎片化是 AI/科技垂类共性
3. **结尾留白不催互动**：靠真实困惑驱动评论，不用"双击屏幕"硬引导

## 风格融合

完成爆款拆解后，与 `style-extraction.md` 提取出的账号风格档案做融合：

**融合规则**：
- 结构层：用爆款拆解出的句式、节奏、钩子类型
- 语言层：保持账号自己的人称、emoji、口头禅、调性

**融合方案展示格式**：

```markdown
## 融合方案

**从爆款提取（结构）**：
- 钩子类型：反常识开场
- 段落节奏：短句独立成行 + 段间空行
- 结尾：留悬念

**从账号风格保留（语言）**：
- 人称：第一人称"我"
- emoji 用法：每段开头 1 个，全文 4-5 个
- 调性：专业但带轻吐槽
- 口头禅：「说实话」「我个人觉得」

**预计生成示例**（一段示意）：
"昨天看到一个数据，让我整个人愣住了。说实话我一直以为 AI Agent 的瓶颈是模型，结果不是。…"
```

用户确认后进入生成。

## 跳过拆解的条件

如果用户没提供爆款参考：
- 跳过 Step 4（爆款拆解）
- 基于选题评估的切入点 + 账号风格档案直接生成
- 在生成时提示："本次无爆款参考，结构由 skill 默认模板提供。如要更精准，可在下次提供 1-3 篇同话题爆款。"
