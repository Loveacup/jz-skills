# 触发测试用例 Reference

## Section 1: 触发词清单

本 skill 应在用户消息中包含以下关键词或场景时触发：

**中文触发词：**
- 写小红书 / 小红书文案 / 红书文案
- 小红书选题 / 小红书帖子 / 小红书爆款
- XHS 文案 / XHS 选题
- 写一篇小红书 / 帮我写小红书 / 出几篇小红书
- AI 技术内容（小红书语境下）
- 科技小红书 / 技术科普（短图文场景）
- 技术选题评估 / 爆款拆解 / 账号风格提取

**英文触发词：**
- write XHS post / write RedNote post / RedBook post
- XHS content / XHS topic / XHS viral breakdown
- AI tech XHS / tech RedNote

**场景触发**（即使无显式关键词）：
- 用户说"我想把这个 AI 工具/项目/新闻发到社交平台" + 后续讨论方向倾向短图文
- 用户说"帮我从这份 AI 日报里挑几个选题写帖子" → 选题+图文场景
- 用户粘贴一份 AI/科技领域的爆款笔记问"怎么写出类似的"

### 测试用例 4

理由：账号风格提取 + AI/科技领域

## Section 3: 不应触发 ❌

### 测试用例 8
用户输入：`帮我写一篇公众号长文讲 RAG 架构`
判断：❌ 不触发
理由：公众号长文（4000-8000字）不是本 skill 范围，应由长文创作类 skill 处理

### 测试用例 9
用户输入：`写一篇小红书穿搭笔记`
判断：❌ 不触发
理由：非 AI/科技领域。本 skill 专注于科技内容，穿搭/美妆/美食应由通用小红书 skill 或时尚类 skill 处理

### 测试用例 10
用户输入：`帮我爬一下小红书 AI 类 topic 排行榜`
判断：❌ 不触发
理由：爬取小红书有封号风险；本 skill 明确不做数据抓取

### 测试用例 11
用户输入：`帮我把这个小红书文章翻译成英文`
判断：❌ 不触发
理由：纯翻译任务，不是内容创作。应由翻译类 skill 处理

### 测试用例 12
用户输入：`小红书的算法是怎么工作的？`
判断：❌ 不触发
理由：平台机制咨询，不是内容创作。应由用户自己研究或问通用对话

### 测试用例 13
用户输入：`写一篇知乎回答关于 Claude 用法`
判断：❌ 不触发
理由：平台是知乎，不是小红书。结构和语气差异较大，本 skill 不适用

### 测试用例 14
用户输入：`帮我写一封讲 AI 的邮件给老板`
判断：❌ 不触发
理由：邮件场景，不是社交平台短图文

## Section 4: 边界情况 ⚠️

### 边界 1: 跨平台内容
用户输入：`这篇我想同步发小红书+公众号`
判断：⚠️ 部分触发
处理：先用本 skill 出小红书版本（300-800 字），同时提醒用户公众号长文版本需切换到长文 skill。说明两个版本的差异是必要的。

### 边界 2: 选题来源不是 AI 日报
用户输入：`从我这份 AI 论文笔记里挑选题写小红书`
判断：✅ 触发
处理：信源筛选标准灵活适用——论文笔记 ≈ 原创/资源型 KOL 类信源（命中率高），按本 skill 的选题优先级走

### 边界 3: 用户只想要标题
用户输入：`给我 10 个 GPT-5 主题的小红书标题`
判断：✅ 触发，但走简化流程
处理：跳过其他步骤，只调用 `references/hook-library.md` 的标题公式，输出 10 个候选

### 边界 4: 用户提了 Claude/Cursor 但场景是博客
用户输入：`帮我写博客介绍 Cursor`
判断：❌ 不触发
理由：博客 ≠ 小红书。即使是 AI/技术内容，平台不对。

### 边界 5: 用户问"我应该写什么"
用户输入：`我今天写什么 AI 类小红书好？`
判断：✅ 触发
处理：触发后立即追问"有 AI 日报/资讯源吗？没有的话告诉我最近你看到的 1-2 条 AI 新闻"，然后走选题评估流程。

## Section 5: 触发时的首次响应模板

触发后，第一次响应应包含 3 个动作：

1. **确认理解**：用一句话复述用户的需求
2. **列出本次会用到的步骤**（根据用户提供的信息决定，参考 SKILL.md 的决策树）
3. **追问缺失信息**（按优先级：主题 > 参考笔记 > 背景受众 > 爆款）

示例：

```
✅ 收到。理解为：把 Cursor 的新功能写成 1-2 篇小红书短图文。

本次会走：
- Step 1 信息收集（确认目标受众和参考笔记）
- Step 3 选题评估（五维 + 用户场景过滤）
- Step 5 生成笔记

请先告诉我：
1. 你的账号有没有 1-3 篇代表作可以作为参考（用于风格提取）？
2. 目标受众是开发者还是非技术用户？
```
