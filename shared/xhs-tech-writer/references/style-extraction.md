# 账号风格提取方法论 Reference

## Section 1: 为什么要做风格提取

生成内容如果不像用户的账号风格，发出去会让粉丝感到突兀，互动率立刻下滑。风格提取的目标是把用户已有的笔记拆解成 7 个维度的特征，让生成内容能够"用你的风格说爆款的话"。

风格融合原则（详见 viral-breakdown.md）：
- 从**爆款**中提取的是"结构模式"（句式、节奏、钩子类型）
- 从**参考笔记**提取的是"语言风格"（调性、人称、emoji 习惯）
- 融合：结构学爆款，语气做自己

## Section 2: 输入要求

**强烈建议**用户提供 1-3 篇代表作作为参考。可接受形式：
- **截图**：读取图片，视觉分析（封面/排版）+ 文字识别（标题/正文/标签）
- **文字粘贴**：直接分析
- **链接**：先尝试抓取，失败则降级为请求截图

**当用户不提供参考时**：
- 告知无法提取风格，生成内容将使用通用小红书风格
- 建议用户后续补充参考笔记以获得更精准的输出
- 不要硬编造一个"假设的"账号风格

## Section 3: 7 维风格档案模板

输出格式（每次提取都按此结构）：

```markdown
## 账号风格档案

**人称视角**：[第一人称/第二人称/混合]
**调性**：[专业/随意/吐槽/共情/激励/种草/分享 — 选 1-2 个主基调]
**emoji 风格**：
  - 频率：[高/中/低，平均每段 X 个]
  - 类型：[可爱/职场/生活/技术/通用]
  - 位置：[标记要点开头 / 分隔段落 / 句尾装饰]
**段落节奏**：
  - 平均每段 X 行
  - 长短交替规律或均匀
  - 是否有单句独立成行
**句式特征**（列出 3-5 条，要具体）：
  - 例：「喜欢用反问句开头」
  - 例：「经常用'姐妹们/家人们'称呼读者」
  - 例：「数据用得很具体，会写到小数点后两位」
  - 例：「段尾爱抛真实困惑」
**专业度**：[1-5 分，1=纯口语，5=学术化]
**口头禅 / 标志性表达**：[列出该作者的 mannerism——3-5 个独特表达]
**整体印象**：[一句话概括这个账号给人的感觉]
```

## Section 4: 提取步骤

### 4.1 通读所有参考笔记
不要边读边总结，先全读一遍建立整体感受。

### 4.2 量化采样
对每篇笔记：
- 统计段落数和每段行数（取平均）
- 数 emoji 总数除以段落数（emoji/段比率）
- 标记所有人称代词，看主导人称
- 标记所有标点符号偏好

### 4.3 句式特征识别
浏览所有笔记找重复模式：
- 开头句式重复模式（如"昨天/前天/最近…"开头）
- 段落结尾习惯（"…说不定就是答案" / "…但说实话…"）
- 称呼读者的固定表达
- 数据呈现方式（精确数字 vs 区间 vs "好多"等模糊量词）

### 4.4 调性判定
通读后总结：是种草还是吐槽？是教学还是分享？是共情还是激励？
通常账号有 1-2 个主基调，不要超过 2 个。

### 4.5 输出并请用户确认
展示完整档案后问："这就是你的风格吗？" 用户反馈后微调。

## Section 5: 常见提取误区

### 误区 1：只看 1 篇就下结论
单篇可能是临时风格调整。至少看 2-3 篇才能找到稳定模式。

### 误区 2：把内容主题当成风格
"她写 AI" 不是风格，"她写 AI 时常用对比表格、爱用感叹号开头" 才是风格。

### 误区 3：风格描述过于抽象
"专业、有亲和力" → 无法操作。应该改成："专业度 4/5，但常用'其实'等口语词缓冲，避免学术腔"。

### 误区 4：忽略反风格特征
有时"她从不用 emoji" 这种缺席特征比出现特征更有标识性。

## Section 6: 风格应用规则（生成时）

如果用户提供了参考笔记，生成时必须严格应用以下风格特征：

1. **人称视角**：与参考笔记保持一致
2. **emoji 风格**：模仿类型和使用频率（不要超出参考范围）
3. **段落长度**：参考笔记平均每段几行，生成时保持类似节奏
4. **句式特征**：参考笔记中的特征表达要在生成内容中体现至少 1-2 个
5. **专业度**：参考笔记的专业/通俗程度
6. **情绪调性**：保持一致（参考是激励/共情/吐槽/种草哪种就保持哪种）
7. **口头禅**：在合适位置自然嵌入 1-2 个

**优先级冲突时的处理**：
如果"最优写法"和"账号风格"冲突，**优先保风格一致性**。
理由：账号长期价值 > 单篇爆款。粉丝期待的是"你写的"，不是"任何人都能写的最优解"。

## Section 7: 多账号场景

如果用户管理多个账号（例如：个人号 + 工作号），每个账号单独建一份档案，不要混用。可以保存为：
- `~/.hermes/xhs/style-profiles/<account-name>.md`

每次写作前问用户："这次给哪个账号写？" 然后加载对应档案。
