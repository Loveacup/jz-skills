# 3d-print-modeling

理解人的诉求并推进完整3D打印项目：研究设计、建模、草图与产品表达、制造优化、装配验收和问题迭代。公开版 **1.3.0**，从[SKILL.md](SKILL.md)开始，按当前问题读取references；每轮调整先读当前项目自己的核心需求。

- 亲自承担设计与问题解决，连接专业技能，不只是派任务或设置切片参数。
- 以目标、关键未知和已有成果选择工作深度，需求、表达、建模与制造可以交叉回退；不强制六阶段、固定候选数或重复审核。
- 建模与视觉表达并列为核心：原创/逆向、接口/装配、草图、爆炸图、分析图、尺寸图与产品图按问题选取，真实来源和几何依据清楚。
- 接续适用的项目管理软件和skill（如Linear与`linear-flow`）；没有可用接入就在项目内管理成果、责任、依赖、阻塞、决定与验收，断联不静默更换正本。
- 联动摆向、摆盘、分色、Z缝、支撑、层高、速度/流量/温度/冷却与后处理，必要时返回结构设计，不以单项省料或免支撑代替整体取舍。
- 每次有明确范围的工作完成、暂停或交接后，将问题查重归集至已授权GitHub仓库，有依据的经验合并到相关知识与读取入口；下次应用、验证并用反例纠错。无新增就简记，不造issue或堆规则。
- 当前已提供Jev时，可按需用于有限候选的语义第二意见；不是每轮审批、工程验证或用户决定的替代品。
- 保留原件与确认范围，现场照片/尺寸归档；几何、有效设置、实际刀路、实物成形/配合/耐久分别验收。
- 拓竹相关兼容、切片功能和质量问题按需查[官方Wiki](references/reference-research.md#按问题查拓竹官方wiki)，核当前机料、软件和证据边界，不套固定配方。
- 大件、多喷头、多盘和拆分工程继续核实际包络、每头可达域、真实路径足迹及源件数量，并对最终交付工程保存、重开、复切。

## 使用与项目入口

将本技能放在当前客户端可发现的项目技能目录，或明确要求读取其SKILL.md；沿用该客户端实际安装方式。本次GitHub发布不执行全局安装、runtime重指向或自动同步。仓库现有部署脚本未给本技能新增映射；需要部署到某个客户端时另按指定目标处理。

项目使用自己的README、核心需求、现场资料、参考清单与版本/交付目录。可采用[核心需求模板](templates/核心需求.md)，但不为小项目创建空目录或额外台账。工具按[能力入口](references/tool-routing.md)发现与选择；本包不携带所提专业技能、CAD引擎、切片器、Linear连接器或Jev服务，也不自动安装它们。

正文、报告和附件维护在所属项目，知识库不留正文副本或跳转占位。问题归集、经验写回、代码发布、客户端加载与实际打印分别核对授权及结果；公开反馈仅传必要安全摘要。

来源、通用机制、证据与许可边界见[公开发布说明](references/publication-notes.md)。私人项目文件、原模型、图片、会话日志、现场资料与运行环境留在本地项目，公开版不覆盖原维护源。
