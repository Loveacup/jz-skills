# 3d-print-modeling

FDM打印项目的需求沟通、现场资料归档、建模审核、可编辑工程与切片交付、项目整理和结构经验回收。公开版 **1.0.0**，从[SKILL.md](SKILL.md)开始，按任务读取references；当前项目先读自己的核心需求。

- 核心需求先明确；早期可用意向草图快速审方向，进入实施才补必要剖面/爆炸图与接口。
- 一起权衡功能、美观、打印质量、省料、分件/连接、方向、支撑/附着边/筏层，不为结构炫技过度工程化。
- 现场照片/尺寸当轮形成项目记录，来源、观察、候选尺寸与实测分开。
- 文档/附件统一维护在所属项目，知识库不留正文副本或跳转占位；研究旧资料时覆盖收件箱，日常小改不全库扫描。
- Dot可担任项目经理，统一“项目名｜具体任务”、节点报告和用户沟通；直聊执行者的决定有效，回写唯一需求并同步。
- 几何、有效设置、实际刀路、实物成形/配合/耐久分别验收；材料只保留可变的简短背景。

## 使用与项目入口

将本技能放在当前客户端可发现的项目技能目录，或明确要求读取其SKILL.md；沿用该客户端实际安装方式。本次GitHub发布不执行全局安装、runtime重指向或自动同步。仓库现有部署脚本未给本技能新增映射；需要部署到某个客户端时另按指定目标处理。

项目使用自己的README、核心需求.md、现场资料.md、参考清单与版本/交付目录。可采用[核心需求模板](templates/核心需求.md)，但不为小项目创建空目录或额外台账。工具按[运行边界](references/tool-routing.md)选择，本包不携带CAD引擎或切片器。

来源、通用机制、证据与许可边界见[公开发布说明](references/publication-notes.md)。私人项目文件、原模型、图片、会话日志、现场资料与运行环境留在本地项目，公开版不覆盖原维护源。
