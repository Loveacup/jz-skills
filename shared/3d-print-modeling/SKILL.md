# 3D打印建模与项目协作

将明确需求落实为好用、好看、好打印且成本合理的零件。优先采用满足需求的简单结构；按任务读取相关参考，主流程不要求一次加载全部资料。

## 工作流程

1. **每次调整先读核心需求。** 接续时从当前项目README或项目状态文档定位任务，再实际读取其独立`核心需求.md`。每轮方案、图、模型、装配、切片或项目范围调整前重读最新文件；不存在则先依据已确认信息建立，关键未知项问清。按[需求确认与维护](references/requirements-and-review.md#核心需求文档每次调整前必读)分轮沟通，可请求实拍、简单草图或让用户标注。收到现场照片/尺寸时按[现场资料落盘](references/requirements-and-review.md#现场资料收到即整理)归档原件并更新独立现场资料文档。理解一致后更新核心需求，已明确的确认沿用，核心歧义未解决不推进依赖它的出图/建模。
2. **先权衡，再选结构。** 按[方案取舍](references/design-tradeoffs.md)一起判断功能质量、美观、可打印性、打印质量、省料、分件/组合和支撑/筏层。额外零件、加厚或工序须有具体收益；少件、免支撑或省料都不是绝对目标。对真正影响用户需求的冲突确认取舍，已授权细节自行处理。新方案或关键结构/外形变更时，主动按[参考研究](references/reference-research.md)复用已有资料，缺口由本地Codex向Dot请求搜索并取回实际模型；依当前场景按[形体与外观方法](references/design-tradeoffs.md#把简洁好看落实到形体)做具体取舍。资料已足够的小改不重搜、不重复审核。
3. **按阶段出图，先快审方向。** 需求确认后按[草图详略与可读性](references/requirements-and-review.md#方案草图与爆炸图的完整性)选择图的深度：早期默认意向草图，讲清整体、关键结构和装配思路；接口/实施审核再补必要尺寸、剖面和爆炸细节，不变部分复用。实际打开导出图检查本轮问题是否表达清楚。具体几何方案确认后再改CAD；意向认可只覆盖所审方向，已有同一明确方案确认沿用。用户明确跳过审核或试片时按其范围执行，保留未知项。
4. **保留基线，实施并独立复核。** 原件、批准方案和工作版本关联；建模前读[参数源与功能基准](references/geometry-validation.md#参数源与功能基准)，实际看图、量原件并建立方向/基准，按确认范围修改。按[几何与装配检查](references/geometry-validation.md)独立读取最终实体/网格，核拓扑、修改域、完整边缘/余厚、关键接口和全装拆路径。核心需求或保留范围变化先更新确认，不能擅自加厚、改接口或用被否决方案实施。
5. **一致交付，说明验证边界。** 渲染由核查后的最终网格生成。交付3MF或调整切片时读[切片与交付](references/slicing-and-delivery.md)，核实际设备与有效设置，保存重开再切片，检查真实支撑和关键路径。以版本、路径及必要哈希关联源模型、网格、图和工程；几何/切片通过不等于实物配合、质量或耐久通过。
6. **整理文档，回收结构经验。** 按[文档与参考模型](references/project-organization.md)将正文、报告和配套附件统一维护在所属项目目录；跨项目参考和技能维护资料留本工作区对应目录。**Obsidian知识库不留正文副本或跳转占位。** 整理项目或发现外部副本时，按该参考检查收件箱等旧位置的遗留资料，核对迁入原文和附件后完成收敛。维护核心需求、README、全部参考来源、当前成果与历史，交接项目内准确入口。项目或阶段收尾按[复盘](references/closeout.md)检查可复用结构的收益、代价和证据，优先修正已有条目；没有新增价值就记“无需修改”。只更新相关项目状态与记录，保留并行成果。

## 按需资料

- **Dot协调、本地Codex执行**：共用本项目技能主源，按[自动组织、版本核对与轻量协作](references/dot-local-collaboration.md)由Dot担任项目经理，下发时统一会话名，收阶段报告并统一沟通；用户也可直聊执行者，关键决定及时同步。本地核心需求保持唯一，项目查找、派活、MakerWorld参考模型取得与报告衔接由Dot组织。
- **需要HTML审阅、CAD、打印性分析、尺寸图纸或实际切片**：按[工具选择与运行边界](references/tool-routing.md)查当前实际可用能力，任务需要且已安装时才读对应技能。未安装不自动部署；本包不包含兄弟工具或固定运行环境。
- **设备与材料背景**：[简短设备/材料背景](references/user-printing-profile.md)。材料可随时替换；概念先按功能讨论，只在影响尺寸、弹性或界面时核当次用料，见[材料与几何](references/geometry-validation.md#材料只提供建模条件)。实际切片再核工程与设备。
- **连接、支承或活动结构**：[常用结构卡](references/common-structures.md)按标题取用；借鉴已做项目读[项目结构库](references/project-patterns.md)，沿用机制与取舍，尺寸和批准不移植。
- **Gridfinity、SKÅDIS、蜂窝墙或B-RAIL接口**：按[模块体系索引](references/modular-systems.md)只读目标系统，保留接口核心并独立设计功能体；引用中的数字几何不作实物兼容或承载保证。
- **网片、镂空和沥水**：先评估切片器填充、顶底层、墙与对象设置能否形成所需结构，再决定显式CAD网格；检查实际路径，见[可编辑工程](references/slicing-and-delivery.md#可编辑工程与一致性)。
- **历史来源核实**：[会话来源](references/session-sources.md)、[B-RAIL案例](references/b-rail-case.md)或收尾记录只在追溯相关问题时读取；旧摘要不代替最新需求、文件身份和实测。

## 范围与权限

仅整理文件或修改已批准工程的切片设置时，仍读核心需求，但不新增无关的图纸/改模关卡。检查和记录随本次改动范围执行，不为小改重做整套工作。

技能不授予打印提交、设备控制、发布或全局安装权限。只承诺实际执行并留证的检查，未验证项明确保留；概念图、最终网格图与实物照片按真实来源区分。项目数值和材料参数不是通用默认。

本地技能须被当前会话发现或读取才生效，不保证后台监听、自动同步云端或所有会话自动加载。共享文件写入前重读，实质进度后只合并本次负责段落。

公开版1.0.0的内容边界与来源见[发布说明](references/publication-notes.md)。具体项目资料和验证证据保留在项目目录。
