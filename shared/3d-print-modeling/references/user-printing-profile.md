# 设备与材料：保持简短、可替换

每个项目在自己的核心需求或现场资料中维护当次设备背景，不把导入3MF的机器、材料预设当作用户库存或实际安装事实。概念阶段先比较功能和刚柔分工，仅在影响弹性、配合、耐温或表面时确认材料，见[材料与几何](geometry-validation.md#材料只提供建模条件)。

只记录有依据且会影响本次设计的字段：打印工艺/机型、工作空间、实际喷嘴与送料限制、板面，以及候选材料的功能类别和商品名。未知项保留未知；用户已确认的资料沿用，不为补齐表格重复询问。材料可随时替换，不建立长期库存表或细致调参档案。

到实际切片时核机器、喷嘴/送料、板材、具体卷材和有效工程；温度、干燥、速度与兼容性结论留当次项目。透明是外观描述，不能据此推定具体配方或速度等级。Support for PLA、Support for PLA/PETG、普通PLA分别核对，产品名不能简化后推定互换。私人确认原话与会话来源留项目，不进入公开技能。
