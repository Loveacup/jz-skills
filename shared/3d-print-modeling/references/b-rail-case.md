# 导轨附件减薄：保护功能面的检查方法

导轨附件减薄时，批准区域、局部凹井/沉孔和最终余厚需从当前真实剖面核查。以下只提供检查方法，不包含具体项目参数或验证结论。

- 把未改基线、各候选改法和实际批准区域分开；从实际批准图确定总切深、过渡和边界，不从一个局部薄区外推整块板厚。
- 保留导轨、卡扣、孔座和工具可达区；用新增/切除差集核批准域，不能偷偷补厚或改接口。
- 实体完成后独立读回，全域余厚和全边缘接缝/过渡分别检查，再导最终网格；静态间隙不能代替全装入/退出行程。
- 渲染来自最终网格，3MF反查对象与变换并实际保存重开复切；摘要中的墙数、填充或支撑与当前工程冲突时，以实际文件核实差异，不按“最终版”命名覆盖。
- 支撑核真实路径，解析E.03等数值格式；夹层上下接触间隙及侧向拆除通道分别看。数字或摘要成功不证明安装、承载和耐久。

需要复用接口时，另取得目标接口变体的真实文件/实物和来源许可，见[B-RAIL模块研究](modular-systems/b-rail.md)；已打印、用户称测试过、具体测试通过和正式安装完成是不同状态。
