# 方案取舍：够用、好看、好打印

需求已明确、选结构或准备因成本/质量调整方案时读取。先重读该项目的核心需求，再比较能满足它的简单方案。复杂度应服务于具体用途，而不是为了展示更多结构。

## 先守住需求，再比较代价

区分不可牺牲的要求与可以权衡的偏好。功能质量包括实际配合、承载/保持、操作、稳定、清洁等本项目要求；打印质量包括关键尺寸、层间结合、成形完整、表面与支撑接触痕。按用途标明关键配合面和主要可见面，不要求所有表面同等精细。外观好、切片成功或省料都不能单独代表满足需求。用户未明确的核心取舍先问清。

先提出最简单、能覆盖当前需求的基线。只有存在真实取舍才增加少量备选，不为凑方案数量展开复杂架构。每个新增零件、连接、加厚或工序都应能说明解决哪个问题，以及移除后的实际影响；已有结构能兼任时先比较是否更简单。保留必要的安全余量和载荷路径，不用无依据的极限减薄换取省料。

| 维度 | 比较什么 |
| --- | --- |
| 功能与使用 | 接口、操作空间、装拆/清理、使用姿态及故障方式是否满足核心需求 |
| 美观 | 整体比例、轮廓/过渡一致性、接缝与紧固件位置、主要可见面、握持触感；装饰应有明确目的，不遮挡功能 |
| 可打印与打印质量 | 方向与层间受力、贴床稳定、细节/孔形、桥接与悬垂、关键接触面和可见面的支撑痕、失败风险 |
| 分件与组合 | 一体或拆分后的方向收益、装配件数、公差链、工具可达、维修/更换与实际连接载荷；拆件是否解决具体问题 |
| 总成本 | 整套模型、支撑、筏层/附着边、冲刷耗料和打印时间，加上必要后处理、装配/清理与失败重打的代价；修整、涂层、粘接或嵌件还要比较可操作性、对配合尺寸的影响和维修条件。净模型重量不等于总耗材 |

比较只保留会改变选择的项目；可用一张短表或几句理由。缺实测时注明估算和未知，只有实切片后才报告相应耗材/时间数字。不设统一零件数、壁厚、填充率、重量或工时上限。

## 把“简洁好看”落实到形体

按本轮变化选用，不要求每次填表或逐项出图。美观是场景与偏好的判断，没有通用黄金比例或客观美观分数。

1. **先定场景与意图。** 从已有需求/现场图判断使用姿态、通常从哪里看到、手从哪进入、周边物体的形体与颜色。用一句话说明本轮方向，如“低矮、安静、容易拿取”；方向不明确且会改变方案时才问用户，不重新做一轮品牌问卷。
2. **先调轮廓和比例。** 在同尺度的简图里看长宽高、主体与支承的关系、开口与留白、直线/曲线和视觉重心；先消除无功能的大凸包、碎小台阶和突然的厚薄变化，再细化圆角。功能分区先定主次，再以非等分但对齐的边线组织留白和分割节奏；让必要隔墙或开孔参与构图，统一边缘过渡后再选颜色。分区数量随用途，不为整齐削弱接口、承载或清洁空间，也不把过渡一致理解为壁厚处处相同；按需看[托盘分区案例](aesthetic-cases.md#mondrian-tray)。不能为了显薄切掉载荷路径、保留接口或必要操作空间。
3. **建立少量一致的形体规则。** 同类边缘沿用同类过渡、圆角/倒角与曲率变化；大轮廓、操作部位、装饰细节有主次。触摸边、承力根部、配合口和贴床边分别按功能处理，不统一半径。操作区用握持凹位、方向形状、必要标记或触感表达，不只靠颜色，也不要求机构全部外露。重复孔/筋/纹理沿同一方向与节奏组织，端部收口和边界留白有交代；纹理只放在有握持、导流或视觉目的的表面，避开配合与密封面。粗糙外观不等于实测防滑，湿态触感与清洁性另核。
4. **接缝和紧固件与使用一起安排。** 区分实际分件缝、挤出起止形成的打印接缝和仅作视觉组织的装饰线，分别处理装拆、公差/清洁、路径痕迹和外观目的。分件缝尽量服从已有轮廓；可弱化或有序呈现五金，但必须保留工具可达、装拆提示、清洁和排水路径。清洁场景避免只为隐藏连接而增加藏污盲缝；不能为整齐搬动原孔位、削弱余厚或封死退出路径。
5. **让材料与打印方向参与外观。** 以实际材料、层纹、可见面及触摸面判断表面，而非依靠亮面渲染掩盖。细筋与浅纹理同时核截面／宽深、根部、余厚及当前设置下的真实轮廓；用实打反馈分别判断成形、可见性与手握变形，不由渲染可见或路径存在推定触感和刚度。贴床边的圆角、倒角和摆放一起比较：向床圆角可能带来较陡悬垂，局部倒角或改向可能更合适，最终看本机实际路径。配色先用足够表达层次/操作的简单方案；遮盖、装饰或一体化选择沿前表比较打印、废料、清理/装配、维修和失败重打成本，说明新增多色、嵌件或装饰盖的具体收益，不默认用多色补救形体。
6. **用真实视图检验。** 先按现有意向快审看方向；进入CAD后，从当前实际几何生成同版本、同尺度、相近视角/光照的整体和必要局部图，观察轮廓、过渡、接缝以及手的插入/拿取空间。比较前后不靠裁图、透视或色彩掩盖差别。实际使用的清洁、装拆和结构判断仍按原几何/路径检查，不因看起来顺滑就判通过。

本轮说明三件事即可：改了哪处、为什么更适合场景、为此付出什么代价。小改只核受影响的功能、表面和打印项，可一张前后对照；只有实质取舍才增加另一方向。简单、少件、免支撑、省材料/时间是优先比较的收益，不能单项压倒功能、耐久和可维护性。

### 灵感图、几何图、实物照片分开

AI生成图可帮助比较色彩、轮廓或场景意向，必须标“概念/灵感图，非实际几何”，不能用于读尺寸、判断接口、验证装拆、强度或打印性。涉及私有照片/模型上传仍按当前授权处理。结构审核和最终几何预览来自相应版本真实CAD/网格，保留文件对应；原始现场照片保留来源，合成场景标示意，不把效果图叫实物、不把生成的接口当可制造结构。只需真实几何图时不额外生成AI图。

制造依据（仅支持打印取舍，不证明审美结论）：Prusa官方 [Modeling with 3D printing in mind](https://help.prusa3d.com/article/modeling-with-3d-printing-in-mind_164135)。材料、姿态、悬垂和细节需结合实际设置判断，不移植其设备数值为通用阈值。

纹理边界依据：Prusa官方[Fuzzy skin](https://help.prusa3d.com/article/fuzzy-skin_246186)；轮廓点法向内外偏移提示纹理会影响配合边界，不证明防滑或清洁效果。

## 一体、分件与连接一起决定

一体件通常减少配合与装配，但可能牺牲方向、支撑清理或维修；分件可改善关键面的打印与受力方向，却增加连接、缝隙和公差。按功能划分而非任意切碎：明确每件做什么、接口如何定位/承载/锁止、怎样装回和更换。

用户要求简洁、一体时，先用最少必要结构实现已经确认的功能；模块本体一体不等于取消模块之间的拼接。止退舌、弹性锁扣等仅在保持需求确有必要且收益明确时加入；简化后说明保持、防脱、拆洗及相关水路的实际取舍，不把少一个零件当作功能自动通过。

将连接方式与打印摆放一起比较。螺纹、卡扣、磁吸或嵌件按拆卸频率、空间、载荷和维护选择，具体检查读[结构卡](common-structures.md)。从[项目结构库](project-patterns.md)借机制与代价，不能因为已有案例就强用相同结构。

## 支撑、附着边与筏层各按作用选择

先比较摆放方向、局部倒角/过渡、桥接、合理分件；仍需要承接时使用可拆且不会损伤功能面的支撑。免支撑是候选收益，不是绝对要求：如果为此增加大量零件、差接口或牺牲质量，应保留必要支撑。支撑须能放进去也能取出来，实际路径检查见[切片与交付](slicing-and-delivery.md#支撑查实际路径)。

- **支撑**承接悬垂/桥接风险区：比较接触面质量、拆除空间、薄件损伤和额外消耗；自动开关不能代替路径核查。
- **附着边（brim）**增加首层附着范围：比较贴床稳定与去边、尺寸和活动缝影响，见[脱板与活动间隙](slicing-and-delivery.md#脱板与活动间隙)。
- **筏层（raft）**在零件下增加打印基底：只有当它对当前附着或成形问题有明确收益时采用，并权衡底面质量、尺寸、分离和耗时耗料；既不默认加，也不一概禁止。裙边只作预挤出/观察，不能当连接到零件的附着边。

任何一种都不能补救不明的装配关系或不可清理的盲腔。材料只作为当前几何决策的条件，按[简短建模提示](geometry-validation.md#材料只提供建模条件)处理，不另展开耗材配方。

## 形成可审核的选择

给出推荐结构、关键代价与仍待验证项，说明它如何满足核心需求及为何值得采用这些部件/工序。用户需决定的实质取舍进入需求沟通；已授权的小实现选择自行处理并留依据。把选定方向写入核心需求的当前取舍，具体尺寸和工艺放设计/验证文档，按当前阶段准备[意向快审或结构审核图](requirements-and-review.md#方案草图与爆炸图的完整性)。
