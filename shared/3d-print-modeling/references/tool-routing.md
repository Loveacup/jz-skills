# 按任务选工具，不继承某台机器的安装结论

先读当前项目核心需求。已批准模型的小改沿用合适的原工具，不因本技能发布而迁移模型、安装运行环境或部署其他技能。工具名称是可选能力入口，只有当前会话确已发现且任务需要时才读其SKILL.md；本包不包含下列兄弟技能或软件。

| 需求 | 可选能力 | 实际验收 |
| --- | --- | --- |
| 可参数化实体、STEP/STL/3MF/GLB | 已安装的cad技能或当前CAD工具 | 保存后的实体/网格独立读回，单位/变换、保护域、余厚和装拆；STEP通常不保留原生特征历史 |
| 网格打印性筛查 | dfam-check | 逐body看样本数、覆盖和未测区域，退出0不能证明全模型通过 |
| 非FDM制造评审 | dfm；仅在明确钣金/CNC/注塑任务时使用 | 工艺、刀具/模具条件与几何精度另核，不把FDM规则移植过去 |
| 尺寸PDF或二维轮廓 | engineering-drawing、dxf | 图来自当前实际几何，单位/视图/尺寸和各格式生成结果分别核 |
| 实际切片 | gcode或可用切片器 | 当前机器/喷嘴/卷材与有效继承设置，保存重开复切，真实路径/耗料/限制 |
| 外购标准件 | step-parts等可信零件来源 | 零件号、实际规格、单位、许可和装配空间；未知不造精确CAD |
| 外协下单准备 | sendcutsend等对应服务能力 | 当前材料/厚度/服务与实际上传规格，报价/下单另按授权 |
| 用户明确需要机器人描述 | urdf、srdf、sdf | 对应结构、语义、仿真静态检查分开；不由文件可解析推成运动/仿真通过 |
| 打印提交 | 当前可用设备工具 | 用户对该设备/文件的明确授权；本技能不自动获得控机权限 |

执行前分别核工具可读、接口可用、运行环境可执行与本轮操作授权；没有就报告缺口并继续独立可做的工作。版本、安装路径、白名单、隔离环境和外部检查取当前机器的真实配置，不复制另一端的本机测试结论。不自动安装、启服务、开viewer或在审批拒绝后换执行器绕过。

已知方法性反例：DfAM可能有body返回空样本/厚度null而整命令退出0；离散几何的零spread不等于误差为零；综合图纸命令可能PDF已生成但因DXF失败整体退出非零；切片preset兼容字段被改写不证明机器兼容。按实际产物/返回/未测范围分别报告，不把历史案例写成当前环境已测试。

工具接口与具体软件以当前安装文档为准。几何、切片与实物验收仍回到[几何复核](geometry-validation.md)和[切片交付](slicing-and-delivery.md)。
