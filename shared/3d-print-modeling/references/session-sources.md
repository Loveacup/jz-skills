# 来源记录与证据分层

公开版只提供方法、通用机制与公开来源。用户会话、现场照片、原模型、运行日志和项目验证记录由项目目录管理，不随本技能发布；本页不提供可读私人历史的权限或入口。

项目需要追溯时，记录实际可核查的来源类型、取得日期、适用版本和项目内路径。用户明确确认、文档转录、第三方说法、亲自查看的图像、数字量测与实物测试分开。只拿到文件名/ID/链接不能写成已收到原件或已看图；执行状态不能替代结果。

依赖具体尺寸、接口、内部几何或有效配置时，读取当前真实文件；摘要只能定位问题，不能恢复未公开证据。记录缺项与影响，不猜造文件名、图片地址或审批结论。后续反馈推翻旧解释时保留旧记录并标明替代关系，按[项目文档](project-organization.md)及[收尾](closeout.md)更新。
