# 渲染、Bambu 3MF 与支撑交付

在生成效果图、交付切片工程或检查打印质量时按相关章节读取。每次调整先读项目核心需求，参数遵从本项目确认与实际验证，不从案例复制默认值。摆放、分件、支撑、附着边和筏层的取舍统一见[方案取舍](design-tradeoffs.md#支撑附着边与筏层各按作用选择)。

当次设备、材料与板材按 [设备背景维护方法](user-printing-profile.md)记录；导入工程的配置仅代表文件，不代表实际设备或库存。

## 渲染来源与镜头

直接使用经几何复核的最终网格，关联版本和网格哈希；不要为效果图另造近似几何。按用户需求选择无文字写实图或带尺寸/说明工程图。镜头要真正能看到修改面，必要时补背面、侧面或剖视；不能用正面漂亮图掩盖背面未显示的修改。

审核草图/概念图明确标用途；即使是写实渲染，也不能称为实物照片或试装结果。

## 设置建议与打印质量诊断

准备切片、比较工艺或排查质量问题时读本节；仅建模或问单项原理不增加整套切片前问卷。方法吸收自[print-prep来源与取舍](publication-notes.md#print-prep方法吸收)，具体配方不移植。

### 先核当前条件，再给差量

先从核心需求、实际工程、用户已有确认与失败记录取得信息，只询问会改变本次结论的缺项：

- **机料条件**：当次材料产品/类型与卷材、干燥及暴露情况；机器、实际安装喷嘴侧/口径/材质、热端和送料兼容性、板面与环境。磨蚀性及堵塞风险按具体材料和实际硬件核，不按机型名称或“金属色”推定。
- **形状与目标**：薄壁、小截面/高细件、悬垂/桥接、圆弧/尖角，以及外观、功能强度、尺寸或速度的优先级；同一材料在不同几何上不沿用整套最优参数。
- **变化与基线**：最近成功件与本件的卷材、模型、设置、喷嘴、环境差异。先按下节核当前有效值及覆盖，不凭预设名判断；无成功基线就明确标缺，不能补成已验证配方。

建议以当前有效值→拟改值列差量，附理由、联动影响、适用条件与证据：官方文档标版本/来源，项目实测标机料/几何和结果，作者或社区经验注明转述来源，未试的推断标“待验证”。读到作者自称“实测/共识”不等于本机实测或已核研究共识；同一条件可合并说明，简短问答不堆整套表格。操作菜单和内部设置键以当前软件/资源为准，未核路径就描述设置含义及待核位置，不沿用旧版本菜单存在/不存在清单。

### 速度、热量与冷却一起判断

涉及挤出速度、层高、线宽或最大体积流量时，先算体积约束，单位统一为mm、s：

```text
Q_request = v_request * h * w          # mm3/s，矩形截面近似
v_Q = Q_max / (h * w)                  # mm/s，体积流量限速估算
v_bound = min(v_request, v_Q)
```

使用目标路径的有效层高/线宽与对应耗材槽的体积流量；首层、变层高、可变线宽和不同路径类别分别核。以上是筛查估算，不是精确挤出截面或实际走速：还受加速度、短线段、悬垂/桥接限速、最小层时间、机器限制及切片器算法影响。用速度/体积流量预览和实际G-code核切片后的限速，机端实际速度仍需运行证据。不能为追标称速度直接抬高未验证的Q_max；VFA敏感速度依机况和测试确认，固定速度区间不作通用禁区。

| 改动/现象 | 同时检查与取舍 |
| --- | --- |
| 提速、加层高或加线宽 | 体积需求上升，重核热端熔融能力、温度、欠挤与层间结合；喷嘴材质导热率不能直接换算固定温差，也不自动要求升温 |
| 小截面、尖顶或层间光泽带 | 核每层时间、冷却降速、风扇/辅助风与路径走速变化；风量加大不等于每层已经冷却，关闭降速可能导致软化/塌陷，强冷却也可能损失结合或引起翘曲 |
| 外墙透出填充或周期纹 | 同看填充/墙重叠、墙厚/墙数、压力/流量、速度与路径周期；重叠减小可能改善外观却削弱内填充与壳体结合，功能件不因“丝绸料”就设为零 |
| 外墙顺序、接缝或斜接缝 | 按实际悬垂承接、拐角、尺寸与可见面选，圆筒和多棱件分别查看；外墙先印不保证所有表面更好，固定角度或接缝长度不跨模型套用 |

排障先用现象与成功基线缩小候选，再做有依据的单因素对照；必须联动的改动作为一组说明，保留其他条件。耗时/耗料按既有同条件整套实切方法比较，并标为切片估算；不能拿公式、未执行的工具调用或作者案例声称实际打印结果。

### 校准值与可用起点分开

压力提前/流量动态K值、挤出流量比、最大体积流量分别解决动态压力、挤出量与可持续熔融供料问题，不能互相替代。官方或已验证预设可作有来源的起点；精确校准值只沿用与当前卷材、喷嘴/热端及温度条件相符的记录，不从材料大类、品牌或另一台机器猜数。

换卷、换喷嘴/热端、明显变温或已知好配置质量变差时，复核旧校准的适用性；先排查含水、堵塞/磨损及送料等条件，再按症状选流量动态、流量比或最大流量校准。相同品牌/颜色不保证相同表现，但不把每次换卷变成无条件全套校准关卡。确需校准时记录软件方法、卷材/喷嘴/温度、样件判据和结果；最大流量上限留有依据的余量，固定百分比不作通用值。测试未授权或未执行时保留待验证起点，不冒称校准通过或擅自提交打印。

### 已授权设置修改的边界

已有明确改设置授权时，沿[整理与交接的保全规则](project-organization.md#整理与交接)在副本上做最小差量，不用整套预设覆盖无关局部工艺。核耗材槽、对象/part/modifier及高度区间的作用域和继承；普通材料/工艺调整保留机器起止、换层、换料等自定义G-code，不把脚本改动混入参数优化。只使用本机实际可用且已核接口的工具，不假设存在外部MCP、自动备份或G-code保护。完成后按下节保存、重开、核有效值和复切；只问建议不等于授权写工程，备份也不替代验证。

## 可编辑工程与一致性

保留可编辑零件、正确零件关系与实例变换，记录 CAD→网格→3MF 对应关系。反查 3MF 内嵌网格、对象/零件数、单位、平移/旋转/缩放与有效坐标；比较应用变换后的几何、孔距和尺寸，必要时比较容差内几何差，不仅比较文件名或顶点字节顺序。

说明可编辑的层次：参数源/原生CAD保留尺寸关系，STEP通常用于交换实体而不保留原生成历史，3MF保留其实际包含的零件与切片设置；不把后两者冒称完整参数化源。后续需改尺寸时，连同[已检查的权威源](geometry-validation.md#参数源与功能基准)交接。

交“完整套件”时按当前源文件列部件、数量、盘、非打印修改器及有依据的外购硬件；已一体化的旧零件不再另计，另存的耗材件注明入口。缺失的现场配件或阀芯保留为范围边界，不能从历史目录凑齐一套并宣称完整。

在实际切片器中核对机器、喷嘴侧/口径/类型、材料、板材、摆放方向和参数后切片；保存工程，重新打开这个已保存的工程并再次切片验证。记录软件版本、实际打开文件、结果和警告。仅修改文件名、压缩包元数据或设置不算完成切片验证。

生成/修改3MF出现导入、摆放或设置继承异常时，用当前版本Bambu Studio保存的、具有对应相关设置的最小正常工程作对照，比较对象关系、变换和设置字段，再修生成源并重走保存/重开/复切。外部仓库的UUID、坐标原点或隐藏字段经验只能作为排查线索，不能直接当本机格式规范；正常对照工程必须来自当前目标软件。

手工生成Bambu高度区间时，按当前版本检查每段的边界及必需选项。针对Bambu Studio 02.08.04.57的格式诊断：`layer_config_ranges.xml`即使只覆盖速度，也须显式包含`layer_height`；缺项会使区间与自身比较仍不相等，重新应用设置时作废切片。取值按该区间实际层高确定，有变层高曲线时保留曲线并核最终各层Z/层厚，不把固定层高套给所有工程。生成后的每个区间均核完整性，保存重开后复核。

自定义工艺的实际值、内嵌预设及差异/继承声明须一致；重点核`different_settings_to_system`、工艺父预设与导入后的有效值，避免打开工程时把真实覆盖静默换回默认。参数值存在于JSON不等于界面会保留它。

出现“切片末尾刀路消失、又要求重切、打印按钮禁用”时，分开核完整G-code是否生成及GUI是否保留有效结果；已生成路径时优先检查加载后设置和再次应用时的变化，按当前版本建立能复现失效的最小对照。每次明确所测文件/哈希，做单因素修复并保几何、局部工艺和原证据，再验原症状。离线比较探针、CLI保存重开复切、用户GUI成功、实体打印分别记；后台成功或预切片包可用均不能替代可编辑工程GUI验收。具体读取链与修复证据保留当前项目，不从后台成功外推GUI行为。

最后核对 CAD、最终网格、渲染、3MF 中的几何与参数一致，旧版清楚标识；不能同名混入旧网格。没有切片器或重开失败时，报告工程及未验证项，不伪称重开/再切片成功。打印提交另需当前用户授权。

网/筛孔方案须区分 CAD 明确孔网与切片器填充形成的网；填充率不能直接替代正投影开孔率。即使细筋存在于 STL，也要确认切片中形成连续实际挤出路径；省料、过滤和排水分别核查，简化面积估算不作水流实测结论。

采用切片器纹路时，核对工程→对象→part/modifier 的设置继承与覆盖，以最终有效的填充、顶底层和墙设置为准。对应原件实例须记录盘、对象/零件 ID 与完整实例变换；同源网格经缩放可得到不同厚度，厚度按该实例变换后的几何及实际层数核对，不能由新件外径反推原件。用户另选的参数标为实验条件，不冒认原件。

检查真实逐层挤出的网丝交点、边界连接、层数与成层厚度，以及孤岛和悬空起笔。薄壳裁切原生填充时，按实际挤出顺序判断起笔处是否已有材料承接，缺承接长度按完整折线累计；首层连通、层间投影重叠或单个G1很短都不能代替此检查。优先修正边界承接与接缝位置，不能只增加填充率。零悬空起笔仍可能有跨空网丝；曲线跨空与直线桥接分别判断。路径连通不证明层间结合或耐拆强度，打印和从热床取件后的强度必须实测。

细小独立立体从首层生长时，另核贴床足迹、长细段刚度、短路径起停与冷却条件。逐层搭接不证明稳定成形；成形失败时分查底部附着、运动扰动、短路径热积累与细长段刚度，不先指定单一原因。

交付保留纹路有效设置和 part/modifier 的完整可编辑 3MF，并执行前述保存、重开及复切；STL 不保留切片设置，不能等价复现纹路。任何来源的填充类型和百分比都不是通用默认参数或强度保证。

## 薄壁、底边与填充选择

来源事实：[Arachne](https://help.prusa3d.com/article/arachne-perimeter-generator_352769) 会改变线宽，低于最小特征阈值的几何可能被省略，保留的细特征也可能被加宽。旧建模页的固定线宽表不能外推到所有墙生成器；对应软件另核对 [Bambu 墙生成器说明](https://wiki.bambulab.com/en/software/bambu-studio/wall-generator)。

实践检查：薄壁、小销与细筋逐层查真实路径、尺寸变化、断续和根部连接；不以“小于喷嘴就必然不可打印”或“切片显示了就尺寸准确”下结论。

减薄、省料或提速方案用同条件实际切片比较整套时间和总耗料，包含支撑、界面及必要冲刷，另说明拆撑/装配代价。CAD切除体积不直接等于省料，局部收益可能很小；接口与外观质量仍须保留。按本项目目标判断收益，不设统一节省阈值。

来源事实：[Prusa 建模指南的 Fillet vs chamfer](https://help.prusa3d.com/article/modeling-with-3d-printing-in-mind_164135) 指出朝向热床的圆角可能形成陡悬垂。实践选择：需减少该处支撑或改善底边时考虑可打印倒角；功能根部的应力圆角另评估，不能为少支撑全部删掉。

按承载方向、顶面支撑、速度、用料或所需纹路选填充；见 [Prusa 填充说明](https://help.prusa3d.com/article/infill-patterns_177130)。实践边界：Gyroid 不是所有目标下最强的默认选择，填充结构的方向表现不能证明整件含层间、外壳和连接处的各向同性；整件结论仍需相应证据。

## 脱板与活动间隙

发生整件脱板时，核对实际机器、材料、板面、清洁情况和首层表现，再检查工程中的温度、首层速度/冷却及附着边；旧工程的设定不能证明故障时的实际温度。只改切片配置的任务保持获批几何，用保存后的有效配置与真实路径验证修改。

给弹舌、卡扣或窄槽增加 brim 后，检查自由缝隙内是否生成附着边、是否跨接活动件，以及冷却后的拆边路径。对照首层象脚补偿解释轮廓变化；加宽附着边或减小分离间隙未必改善可用性。数值由本件路径与试打决定，其他工程的温度/brim间隙不作通用预设。

## 湿区、密封与接触用途

来源事实：Prusa 的 [开放容器实验](https://blog.prusa3d.com/watertight-3d-printing-pt1-vases-cups-and-other-open-models_48949/) 中单壁花瓶模式也有不漏的结果，说明路径与实际打印条件重要，不能当作所有单壁件水密保证；[密封实验](https://blog.prusa3d.com/watertight-3d-printing-part-2_53638/) 另涉及装配接缝。

实践检查：湿区尽量简洁、均匀并便于排空和清洁；按使用条件检查底壁、接缝、密封界面及持续存水，不只增加墙数。水密、可清洁与食品接触适用性分别判断，不由“不漏”推出其余两项；接触食品时按具体材料和过程查 [Prusa 食品接触指南](https://help.prusa3d.com/article/food-safe-fdm-printing_112313)，缺证据保留未知。

模块化水路把承托、机械互锁与湿接缝分别核查；搭边和互锁不自动形成密封。沿真实装配剖面追踪入口、跨段落差、出口及拆洗路径，确认新开孔没有被保留的旧底面遮住。重复同一坡底段可能产生台阶/积水；加长组合需重排坡底或出口，再检接缝、残水与拆洗，不能由有限三段方案推断无限延长排净。

排水优化先追踪完整水路、滤网、阀芯、空气通道与旁路；最小几何截面和单处流速只帮助定位候选限制，不独立证明整套瓶颈。功能对比按同水位流量、固定进水下水位或排空时间等一致条件实测；单一节流敏感性算例不冒充整机流量预测。

发生浮起时，先分开记录成品净重、内部进水/保气、外部兜气、流动压差与活动零件接触传力。净重排除已拆的支撑、附着边和冲刷，保留设计留在成品上的实体；换材料按其实际挤出量和有效密度重新核重，不能用整盘耗材代替。排水体积依实际浸没和进水条件取值，包围盒、净塑料体积或贯通孔内空间不能直接互换。静水浮力已包含静水压力差，只把相对该基准的非静水压差列为额外项；滤片能活动不等于它已向上顶盖。

可用同朝向、底侧可进水的单件静水观察与排外部气泡前后对照，再与同底座/滤片/阀芯的组合动水观察区分机制；保留未做的试验与未知原因。静水算例或下沉不替代大水验证，保持路径沿[真实固定基准](geometry-validation.md#动态装配与可拆卸性)另查。诊断与试验结果留在所属项目，未完成的试验不能记为通过。

## 支撑查实际路径

先分开记录支撑证据，逐层标明来源与已核/未核；前一层不能代替后一层：

| 证据 | 能说明什么 |
| --- | --- |
| 作者页面、说明或演示 | 原作者的主张及所述条件；不能证明当前工程或本机打印结果 |
| 实际保存配置 | 核全局、对象覆盖、强制支撑和屏蔽体后的有效设置；开关或配置仍不证明已生成刀路 |
| 实际切片刀路 | 当前版本/盘/方向下生成的支撑位置、接触面、耗料与拆除通道；不证明实体能顺利取撑 |
| 实物拆除结果 | 对应文件、材料和实际打印条件下的拆撑、残留及功能面损伤；未报告时保留未知 |

另列**网格中的打印辅助实体**，明确哪些是须拆除的牺牲支撑（薄桥、临时连接、支撑壳等），哪些是设计为成品保留的起印小边。牺牲支撑记录位置、拆除方向及取出空间；保留的小边随成品核装配、拿取、套叠/收纳和水路，缩小贴床面积带来的附着代价另验。软件support off只表示对应软件支撑设置关闭，实际辅助实体仍须核刀路及相应的实物拆除或保留状态。使用说明按版本明确“拆/保留”，并同步装配与收纳说明；不能把旧版剥边步骤套用到永久小边。

核对实际生成 G-code 中的支撑挤出路径、层高、位置及接触面，结合切片预览定位；设置为“开启”不证明存在支撑。解析数字支持无前导零小数（如 `E.03`）、正负号和科学计数法，并处理绝对/相对挤出模式、回抽、挤出归零和注释/特征标记。不能把坐标轴的 `E` 与数字指数 `e/E` 混淆；须按实际语法解析，避免误报“无支撑”。

如临时编写或复用解析脚本，运行覆盖这些数值格式和挤出模式的测试，再使用它下结论；仅凭正则匹配行数不能证明支撑位置正确。保留支撑路径所在层/区域和可核对证据。

支撑夹在底座与弹片之间时，上下接触间隙都要查，还要查 XY 间隙及侧面拆除通道。同料支撑保持适当非零接触间隙，数值依当前材料/结构与测试确定；不能为省支撑随意开启“仅热床支撑”，须确认是否因此漏掉夹层区域。评估拆除对薄卡扣的影响，路径未知则列为未验证。

长杆下缘、凹底或内部顶面同时检查桥接路径和“桥接免支撑”等实际生效选项；自动支撑已开启也可能让长跨距被当作桥接而漏撑。按具体盘/对象纠正后复切；封闭腔还要证明支撑能取出，否则在审核阶段比较改向、贯通或分件方案。

## 材料名称与证据分层

逐字核对商品与材料类型。旧 `Support for PLA` 与 `Support for PLA/PETG` 是不同产品，二者也不等同普通 PLA；不要简称后推定互换。

说明判断属于官方明确支持、个人/本项目实测还是推测；记录具体产品、来源/日期和实验条件。没有依据就保留未知。多材料支撑先验证实际材料组合、界面粘结/脱离与相关打印过程，再用于薄卡扣；不能用推测的可剥离性冒充实测。

同料或异料支撑按当次结构与材料组合选择。本技能不内置长期不变的兼容表。
