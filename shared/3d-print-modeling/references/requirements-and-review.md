# 需求、测量与审核草图

首次建立需求文档、收到现场照片/尺寸/标注、需求变化、出方案图或图文冲突时按对应章节读取。每次项目调整都先读项目自己的核心需求文件。

## 核心需求文档：每次调整前必读

每个项目独立维护`核心需求.md`，即使小项目也单独成文；已有同用途独立文件可沿用，由README指明唯一现行入口。首次不存在时，用[简短模板](../templates/核心需求.md)根据可访问的用户确认建立，将未知项列为待确认，不从旧图或工程参数倒推需求。

每轮方案、草图、模型、装配、切片或项目范围调整前，实际重读最新文件，将本轮请求与目标、硬约束和待定项对照；不凭旧聊天摘要代替。文件无法读取时说明缺口并恢复入口，先解决关键需求再做依赖它的改动。

只写当前有效的目标/使用方式、必须满足项及验收含义、可权衡偏好、保留/可改/排除范围、关键待确认项和简短确认依据。尽量一屏到一页，复杂尺寸表、照片、方案比较和过程用链接；不复制长聊天、详细切片参数或所有历史。

开发中可随用户的新确认增删改：先核本轮新增/冲突信息，不明确的核心问题向用户提问；确认后同步更新当前要求、日期/版本和依据，再改相应方案。旧要求与否决原因放项目历史，已解决问题从待确认中移除。自主决定已授权的细节可以记录依据，但不能悄悄删除硬要求或把待定项写成已确认；纯实现细节变动不强改核心需求。

每次实质调整结束，核对结果是否仍满足这份文档，并把用户已确认的核心变化反映进去。若需求文件与当前成果不一致，明确差异及处理状态，不用更新文档来掩盖未满足项。文档位置和其他资料分工见[项目文档体系](project-organization.md)。

## 先把需求确认清楚

按当前问题组织需求澄清、视觉表达、建模与验证，可往返推进，不要求所有任务经过相同阶段。核心歧义只暂停依赖它的工作，实施遵循明确确认范围。需求沟通可以多轮进行，每轮只问当前影响判断的少量问题；收到回答后更新理解，再追问剩余关键缺口。用户已经明确的信息直接沿用，不重复盘问，也不以材料库存或切片参数代替功能需求。

按项目需要确认：要解决的问题和使用场景；与什么配合、如何装入/取出/操作；哪些必须保留、哪些可以改；会改变结构路线的空间、关键尺寸、受力或环境约束；怎样判断好用。先读已有文件和量测可得的信息；关键未知项向用户核实，不靠猜测填满。

沟通方式按缺口选择，可以组合使用：

- **实拍照片**：请用户拍实际安装位置、接触面、遮挡处或使用姿态，并说明需要的视角；尺寸关键时请在同一平面放尺或给量测值，避免只从透视照片猜配合。
- **用户简单草图**：让用户用线条和箭头说明零件关系、运动/水流方向、保留范围或想法，无需画工或完整尺寸。
- **标注已有草图**：给清楚的基准和版本，邀请用户直接圈出、划掉或标箭头；收到后实际查看，复述标注含义。没有可用底图时，仅画解决当前歧义所需的沟通示意，交代它在整体中的位置、方向和未知项。

需求阶段的沟通示意服务于澄清，不代表方案已经确定，也应让用户看懂整体关联。图可以帮助探索取舍；依赖尚未明确核心条件的方案细化与改模待确认后推进，已明确部分可继续。简短说明已确认需求、硬约束和仍待定项，确保理解一致；既有明确确认直接作为依据，不另加重复许可。细节留到适当阶段，用户明确委托自行决定的事项说明采用的假设和范围。

用户的新回答或标注改变核心需求时，先更新这份简短理解，再改受影响的图；不靠连续出新图试探需求。歧义只暂停依赖它的方案，可继续读源文件、量测和整理依据。

## 现场资料：收到即整理

收到现场照片、带尺寸照片、用户量测或现场标注后，实际查看并在本轮更新项目独立的`现场资料.md`；已有同用途文档沿用，由README和核心需求指向唯一入口。先把本轮资料整理好，再基于它推进方案/改模，不能只在聊天里说“记住了”，也不等项目结束才补。纯灵感图归参考资料，不冒充现场实测。

一份短文档维护以下内容，资料少时用照片索引和一张尺寸表即可；不要求额外测绘报告：

| 内容 | 最小记录 |
| --- | --- |
| 现场与原件 | 对象/位置、实物或模型版本、收到日期及来源消息；旧实物照片和新模型分别标明 |
| 原图与标注 | 图片编号、原图路径/可访问附件、视角/朝向及简短观察；尺寸图和用户标注关联其原图，保留原件，后加标注另存 |
| 尺寸与依据 | 特征、数值/单位、量测两端或基准/方向、来源图编号；区分用户报量、照片标注、尺具读数、模型量测、图像估计，并注明已确认/待确认及实际可知误差 |
| 对设计的影响 | 安装/装拆关系、遮挡和必须保留空间；只把明确证据支持的条件写入核心需求，不把观察或估计升级为确认 |
| 缺口与变更 | 当前需补的视角/关键量测、矛盾尺寸和影响；新资料纠正了什么、哪些旧尺寸失效及相关模型/图是否需要复核 |

带尺寸的照片也要核箭头端点、量测基准和单位；比例尺与目标不共面、透视/遮挡或刻度不清时，保留估计范围或未知，不能推出精确配合尺寸。看不清的标注问清，优先补决定当前方案的一两项，不索要无关全套照片。安装朝向不清时先记录和澄清，不为了填表强行建立完整CAD坐标系。

每张收到的相关图都登记；分别记录哪一端何时实际查看像素、是否仅取得文件名/ID/尺寸/指针等元数据，以及原件是否已本地归档。另一端的读图摘要标为转述，不冒充本地实看；原件未落地仍记待归档。失败照录本次实际返回，没有状态码证据就不把`download failed`改称HTTP403或推断权限原因。原图能保存时归入现有项目资料目录，不为统一目录搬动历史。更新后检查图片入口可用、尺寸能回溯到图/量测、核心需求中的相关约束已同步；回报文档准确路径及剩余关键缺口。

后续涉及现场接口的调整，先从核心需求链接重读相关现场记录和原图；接续旧项目发现相关资料仍散落时，先回收本轮要用的证据，不要求全库重整。新照片/新量测纠正旧依据时更新文档并留简短旧值/原因；尚未解释的实物/模型冲突保留，不因模型更新就覆盖现场事实。Dot收到资料时负责转交可访问原件并核本地落盘回报，执行者负责写文档；使用同一份资料，用户无需搬运或重复讲解。

## 图像与坐标依据

先明确使用对象、装配方式与功能验收：例如颗粒尺寸/释放速度，或滤片/排水表现。双层颗粒容器先说明各层负责释放完整颗粒、释放浸出物还是保粒通风；用途改变时重新核孔的功能和遮挡。沿用小孔不等于新颗粒已适配，孔中心畅通也不代表最大颗粒或湿后结团能通过；关键净通路按[功能边界](geometry-validation.md#全部功能边界)量测。孔宽、开孔面积和双层错孔只是设计指标，不能直接当缓释时长或排水改善的实测结论。方案优先针对实际问题，避免增加没有必要的部件。

需求明确后，按[方案取舍](design-tradeoffs.md)比较美观、功能与打印质量、分件、支撑和整套成本。长杆、多件或大面积方案尤其应提前估算握持重量、全部实例耗材与工时，标清估算限度，避免细化完成后才发现整体过重或难打印。

实际打开用户标注图；记录图片路径/来源和标注版本。图片缺失、遮挡或无法判断朝向时，先取得缺失图像或确认，不能声称已看图。文字摘要、旧渲染和概念图不能替代用户实际标注。

明确照片对应哪个实物/版本、模型对应哪个尺寸版本；实物尺寸与模型尺寸分别按对应对象、版本和基准记录，用于当前设计的取值须有明确依据，模型更新不覆盖现场事实。不同模型的孔数、内部结构或尺寸不能移植到当前实物；来源冲突先标明并解决。

在实际图片上标正面/背面、厚度方向和固定几何基准；定义坐标、原点、单位及 CAD 到图片的映射。可选 X=纵向、Y=宽度、Z=厚度，但必须根据原件建立映射，不能直接套用。换视角后的屏幕左右不等于几何左右。

用图示与尺寸表一起表达：

| 字段 | 必须表达的含义 |
| --- | --- |
| 面和方向 | 哪一面、向材料内切除还是向外增加；剖面箭头标下凹/凸起 |
| 横向范围 | 单侧带的两个边界、双侧各自边界，或两外缘之间整宽；不能用“中间”“两边”替代 |
| 纵向范围 | 起点、终点及相对基准的定位；过渡段是否包含在所标总长内 |
| 深度层次 | 每层起止面、浅层/深层、深度基准、总深度与分层增量；明确是再降还是总降 |
| 保留区域 | 孔座、导轨、卡扣、外轮廓及不能改变的装配面 |

横向边界的符号示例（不是项目尺寸或待审核方案）：

```text
俯视：X 从 x0 到 x1；Y 从原件左外缘 0 到右外缘 W
单侧带：       0 |####|................| W    修改域 Y=[0,b]
双侧带：       0 |####|............|####| W    Y=[0,bL] ∪ [W-bR,W]
整宽：         0 |#####################| W    Y=[0,W]
剖面：原表面 z0 ──────────────   以 z0 为切削深度基准
                  ↓ d_total
      最终面      ──────────────   分层时写明 d_total=d1+d2；若给的是绝对总深度，不再相加
```

把符号换成用户实际图示与测量边界才形成可审核方案；曲面原件不能被矩形示意取代。歧义只暂停依赖它的改模，可继续测量、保存基线和整理证据。

## 方案草图与爆炸图的完整性

按本轮要确认的问题选择深度，默认先快审意向，再逐步细化；不为每次讨论重做全套精细图。完整性指用户能理解当前要判断的整体关系与关键结构，精细度则可以分阶段。无需每轮另问画简图还是详图；根据风险和用户要求自行选择并说明用途。

| 阶段 | 图画到哪里就够 | 何时继续细化 |
| --- | --- | --- |
| 需求澄清 | 实拍/已有图标注，或有整体位置与方向的沟通示意，只解决当前歧义 | 核心用途、装配或约束明确后进入方案 |
| 意向快审（早期默认） | 简洁整体轮廓、主要零件/结构关系、关键动作箭头与短注；需要时加局部或简化爆炸示意，候选尺寸和未知项标清 | 用户能判断方向、使用方式和主要取舍后停笔交审，不等细节完善 |
| 结构/实施审核 | 围绕受影响接口补关键尺寸、剖面、定位/保持、装拆路径与打印方向；多件结构用可对应的装配/爆炸图说明 | 准备改模、尺寸冲突、隐藏干涉或用户看不懂时达到可核查程度 |

意向快审可用粗线框、简化形体和少量视图，五金细节、纹理、配色精修、全尺寸标注和多张写实效果图按需后置。优先复用已有合适底图或视图，只补本轮变化；不要为了出第一张意向图先完成整套CAD。局部图仍需标在整体的位置，爆炸示意仍需让人看懂各件归属和装回方向。标“意向快审/结构审核”、版本、本轮审什么及未展开处。

以下为结构审核的表达检查，按当前问题取用；可多分区一页或分图，不要求每轮逐项新画。整体、局部结构和装配各有作用，单张无对应关系的零件散开图不能代替解释。

| 视图 | 应让用户看懂什么 |
| --- | --- |
| 整体与使用状态 | 完整装配外形、比例、总尺寸/包络、安装环境和使用方向；需要操作或收纳时给相应状态，局部修改也要标在整体的位置 |
| 局部结构与剖面 | 关键接口怎样定位、承托、锁止、活动或导流；配对面、配合尺寸/间隙、厚度、修改与保留范围；隐藏结构通过剖面或放大显示，并能对应整体 |
| 多件装配与爆炸图 | 每件的编号、名称、数量及对应位置；分离方向、对齐轴/引线、装配顺序和装入/退出路径；必要的螺丝、磁铁、软垫、绳等同样交代，现场既有件另标 |
| 打印方向 | 各打印件的贴床面与层向，和使用姿态区分；关键桥接、悬空与支撑拆除区域可在相关结构图中标出 |

图的用途不限于上表。分析图可解释载荷、运动、水路、几何量测或工艺判断，区分示意、计算和仿真，标清影响结论的输入与假设；产品图表达外观、使用状态和场景。由主技能按问题选择并核查表达，不只转交绘图任务，也不要求所有图种齐备；最终几何图与生成表现各守下文的来源边界。

各视图沿用同一零件编号/名称、版本、颜色含义和尺寸基准；用简短说明解释关键动作。爆炸距离以看清连接关系为准，避免随意旋转、过远散开、遮挡接口或无标识漂浮；必要时加装回后的对应小图、连接剖面或分步图。一个零件无需硬做爆炸图，复杂多件也不强塞一张图。

减薄/切削审核应包含定位用俯视或背视与穿过修改区的厚度剖面，标外缘、深浅层和两端过渡。多件方案检查挂扣/小件松脱后是否会落入主体，锁止与收纳关系应在审核阶段说明。沿打印顺序查首层独立区、后续承接、盲腔封顶与支撑可达；需要改向、贯通或分件时画明取舍与新增件。

出图后实际打开导出图检查文字可读、箭头正确、关键关系无遮挡且视图一致。意向图能回答“方向是什么、如何用、关键结构怎样配合、要我决定什么”即可快审；结构审核再检查零件归属、装拆及关键尺寸。只补影响本轮判断的缺口，不以美化延后反馈。认可意向不等于批准尚未呈现的精确几何，已明确确认的部分也不重复索要许可。示意、实际网格图与实物照片按真实来源标记。具体边界见[灵感图、几何图、实物照片分开](design-tradeoffs.md#灵感图几何图实物照片分开)。

## 测量真实原件

读取原 CAD/STEP 或实际网格/量测，在避开螺孔、局部让位、局部螺帽座和倒角的完整截面测原主板；同时取孔区、边缘和修改区截面对照。记录位置、局部特征、工具和容差，不从局部薄区外推全板厚。

分清构成凹井的侧墙/围墙、井底面、下层板和真正沉孔，逐层画实体剖面；导轨围墙形成的空井不等于在下层板切了沉孔。螺帽座高度和主板厚度分别量测。

若沉孔、减薄、孔座同高或保留结构彼此冲突，给出带尺寸的选择：修改范围/深度、调整座高或其他具体结构取舍。未获得选择前不能偷偷补厚、抬高座面或改动保留结构。

## 确认与版本

关联核心需求版本、草图版本、原件/基线、批准的空间修改域和用户确认依据。明确批准哪张图；“你看着办”可授权范围内的细节选择，核心需求或接口边界仍有矛盾时先澄清。已有同一明确方案的确认无需重复索要。

新方案或关键结构/外形变化，默认用足够表达当前决定的图沟通并确认具体范围后改模；已有明确方案或批准范围内的局部任务直接沿用，不重走全套图审。用户明确要求跳过某轮审核或小试片、直接实施时，记录其授权范围，继续仍可完成的数字检查与交付，实物配合和强度保留待测；不再次把被跳过的步骤设为关卡。跳过出图/审核不等于关键需求已清楚，仍有影响结构路线的歧义时先澄清。最新约束优先；用户否决单侧而要求整宽时，作废旧范围，重新画整宽及厚度剖面。保留旧版用于追溯，不将旧版当成获批方案。
