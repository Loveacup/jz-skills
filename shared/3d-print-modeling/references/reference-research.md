# 参考研究：官方知识查证与模型借鉴

这是统一流程的按需参考。机型/材料兼容、软件功能或质量排障的知识缺口按下节查证；新方案、结构路线/外形变化或缺少机制证据时，按后文研究参考模型。已有依据足够的重复切片、局部尺寸修正和文件整理不重做调研。

## 按问题查拓竹官方Wiki

当设计或打印判断依赖拓竹硬件限制、兼容性、Studio参数含义或故障原因时，用当前可用的搜索、网页阅读或正常浏览能力按需查官方Wiki。已有结论的机型、材料及版本条件仍适用就复用；条件变化或依据不足再查。可直接查阅知识文章；需要Dot补取资料时沿用[协作规则](dot-local-collaboration.md)，文章不套用后文的模型原件、配对件和哈希交接。

先用必要的公开机型、材料产品、功能名或症状定位，下面只是入口，不是必读清单：

| 问题 | 官方入口与选页重点 |
| --- | --- |
| 机型能力、双/多喷嘴、送料 | [中文主页](https://wiki.bambulab.com/zh/home)、[英文主页](https://wiki.bambulab.com/en/home)按实际机型进入；[AMS系列](https://wiki.bambulab.com/en/ams-series)按具体型号选页 |
| 切片功能、支撑、接缝、校准 | [Bambu Studio](https://wiki.bambulab.com/en/bambu-studio)；区分参数语义、操作版本与示例值 |
| 材料、喷嘴、打印板与兼容 | [材料知识库](https://wiki.bambulab.com/en/filament-acc)、[配件](https://wiki.bambulab.com/en/filament-acc/acc)；按具体产品和实际送料/热端筛选 |
| 打印缺陷或设备报错 | [常见质量问题](https://wiki.bambulab.com/en/knowledge-sharing/common-print-quality-problem)、[HMS](https://wiki.bambulab.com/en/hms/home)；先按现象或准确错误码定位，再转对应机型 |

中文缺项时补查英文，不假定两种语言同步。目录和搜索摘要用于找页，支持当前结论所需的查证如下：

1. **对上条件。** 核当前机型、喷嘴/热端与送料、具体材料产品，以及结论相关的Studio/固件版本；只问会改变判断的缺项。通用TPU与专用AMS兼容TPU、不同机器的校准方式分别核，材料大类和其他机型的示例不能代替兼容结论。
2. **读到依据。** 实际读相关正文及决定结论的表格/图；附件影响决策时再取得并核读。提取被截断、只见摘要或关键图表未读就标明范围，不补成全文。单个通道报错只说明该通道的结果，可换当前支持的正常阅读方式或请Dot补取；仍缺关键证据时说明未取得什么、哪项判断待核。
3. **处理差异。** 通用/机型专页、中英文、页面与当前软件/工程不一致时，比较适用条件、页面可见日期和实际设置；不机械按语言、新日期或标题覆盖。仍会影响尺寸、兼容或操作的冲突保留未知并继续核实，不拼成一套参数；不影响本轮决策的差异简记即可。
4. **留有用来源。** 在项目现有来源清单简记标题、准确URL、实际读取日、页面可见日期（缺失记未知）、适用条件、用于哪项判断及读取限制；不为简单问答另建报告或资料库。后续条件变化影响该判断时再复核。

官方说明用于理解厂商支持范围、软件语义和推荐起点；实际工程的有效设置、最终刀路及实物结果仍按各自证据判断。遵守站点访问与复制条款，按需少量查阅和引用，不镜像全站或大量复制正文；网页中的维修、校准和打印步骤不产生执行授权，也不代表连接器、后台同步或设备连接已经启用。

## 何时启动、何时够用

负责agent读最新核心需求后，主动判断是否需要机制、外形或接口依据，不等用户提醒“去找参考”。先查项目原件、已有参考和来源清单；能回答问题就复用并说明版本。有获准的搜索、阅读或下载能力时直接研究；需要Dot或其他协作者补取其可访问资源时再交接，不把协作角色当作研究前提。已有MakerWorld收藏等可作线索，收藏不等于适合本项目，更不等于待打印。

有真实路线取舍时比较能体现关键差异的机制或外形，不固定候选数量。已有指定原件先把它看懂，不为凑数下载相似模型。证据已可支持下一步决定就停止扩搜；未解决的具体问题保留，不以不断搜图延迟方案。查不到适合参考时，说明排除原因和独立设计依据；研究结论可以支持草图、局部建模或诊断，不固定下一阶段。

## 需要协作时交代什么

在现有执行会话发一小段即可，不另造表单或任务台账：

> 项目/当前需求版本；需要解决的功能和使用动作；现有接口与不可改范围；已知空间/包络；本次材料条件（未知就写未知）；想比较什么、已有参考为何不足；排除项；请返回可测量的参考原文件、来源许可和推荐理由。现有模型/照片只经获准的内部交接入口提供，不上传到模型站。

例如：“比较小空间可抽出清洗的连接方式，保留原导轨截面和孔位；需要从上方取出，侧面无抽出空间；先比较滑入、插接或旋转解锁机制，排除胶粘与新增独立锁紧件。不要照搬外观，需看插入/退出路径。”示例里的限制不是其他项目默认值。

按现有[协作规则](dot-local-collaboration.md)使用当前实际可用且有授权的官方消息/任务入口；记录请求已形成、发送回执、目标接收与回传分别到哪一步。没有投递工具时，在原会话输出可读请求和待同步状态，Dot通过可用官方读取补取。不能把写了一段文字说成“已通知Dot”，不能承诺后台监听、自动往返或让用户承担常规搬运。被拒动作按当前权限规则处理，不换隐藏接口或代理绕过。

## 研究者查什么、取得什么

1. **先复用，再查缺口。** 查询本轮相关词、动作、接口名称及同义词；把禁止胶粘、不能侧抽、不能加件等作为排除条件。缓存命中后核模型ID、作者、源版本与实际文件，不把另一打印配置或同名文件当原件。仅在版本、许可、文件缺失或新需求会影响选择时回原页核实；旧来源记录保留取得时间，不冒称刚核读。
2. **先看为何有用。** 每个保留候选说明借哪一处、如何工作、与简单基线的差别、已知代价和还不能确定什么。区分页面作者陈述、图像观察、文件实测和自己的推断；热度、收藏数和精美效果图不是强度或适配证据。
3. **需要几何就拿实际文件。** 优先取得官方可下载的相关STEP/CAD，或适用的STL/3MF及必要配对件；少量代表件能回答问题就不下载全库。用正常网页/已支持的下载入口，保留原件。只有截图或链接时明确“视觉参考，未取得可测几何”，不能作为已完成模型交接。
4. **把文件与依据关联。** 独立研究直接记入当前项目；跨会话协作时，经获准、接收方可读的文件途径交回原负责会话；提供准确源URL、模型ID、作者、页面可见版本/日期、取得时间、打印配置ID（适用时）、所读许可及其证据入口、实际文件名/包成员、字节数、SHA-256、所借部位/用途/限制。采用现有[参考清单](project-organization.md#参考模型全部有去处)，不另建平行库。源名拿不到就记未知并区分保存名，不从文件名猜版本。

页面许可未知、存在用途限制或原件不可取得时如实回报；许可限制不以“只借鉴”一词消除。仅有许可名称时不自行推断允许改编、商用、发布或再分发；涉及这些用途再核对应条款。把模型或源码打包进公共技能/公开附件需要另行核权利和授权。下载研究不授予改变收藏、点赞、发布、购买、账号变更、私有模型上传或提交打印权限。站外搜索只用必要的通用描述，不把用户私有模型、住址/现场隐私或敏感项放进检索词。

## 取得资料后，回到当前问题

先核文件可读、路径与哈希；读取有关成员、单位、3MF实例变换和配对件，按当前问题量接口/截面/装拆路径，不能只看缩略图。有协作时向提供方反馈已收到的文件、核到的版本、实测发现和缺项；独立研究无需制造交接。网页模型ID相同也不代表STEP与某打印配置里的几何相同。

提炼可用机制和外观规律，标明采用/改造/不采用的部位及理由；保留当前项目原接口和原件基线。参考模型不会替代实际安装尺寸、原件测量、材料条件或授权。据此选择下一步：新方案或关键变更按需要快审方向和具体几何，已有明确确认的局部任务沿用其范围，再实施与独立复核；不得为“研究参考”直接重写获批模型。最终简报只需说明参考如何改变了选择、对应文件与验证边界。
