## 核心主题

### 一、经济补偿金计算(N/N+1/2N)

#### 基础公式解析

**N - 标准经济补偿**
```
公式: S × N

S(月工资) = 离职前12个月平均应发工资
           包括:基本工资+奖金+津贴+补贴等货币性收入
           
N(工作年限) = 每满1年支付1个月
              满6个月不满1年 = 按1年计算
              不满6个月 = 支付0.5个月

特别限制(仅适用高收入者):
若 S > 当地社平工资×3,则:
  - 计算基数封顶为社平工资×3
  - 年限封顶为12年
```

**N+1 - 代通知金**
```
公式: S × N + S(上月) × 1

适用情形(劳动合同法第40条):
- 医疗期满不能工作
- 不胜任工作
- 客观情况重大变化

代通知金计算:
S(上月) = 劳动者上一个月工资(不是12个月平均)

说明:用人单位可选择"提前30日书面通知"或"支付代通知金"
```

**2N - 违法解雇赔偿**
```
公式: 2 × (S × N)

适用情形(劳动合同法第87条):
用人单位违法解除或终止劳动合同

注意:支付2N后,不再支付经济补偿金(二者不并存)
```

#### 计算实例

**案例1:标准经济补偿(N)**
```
张三情况:
- 入职时间:2015年3月1日
- 离职时间:2024年12月31日
- 工作年限:9年10个月 → 按10年计算
- 离职前12月平均工资:15000元/月
- 当地社平工资(2023):8000元/月,3倍=24000元

计算:
15000 < 24000,不受封顶限制
经济补偿 = 15000 × 10 = 150,000元
```

**案例2:高收入者封顶(N)**
```
李四情况:
- 工作年限:15年
- 离职前12月平均工资:50000元/月
- 当地社平工资3倍:24000元/月

计算:
50000 > 24000,受双重封顶
经济补偿 = 24000 × 12 = 288,000元
(而非 50000 × 15 = 750,000元)
```

**案例3:分段计算(跨2008年)**
```
王五情况:
- 入职:1998年1月1日
- 离职:2024年12月31日
- 共27年
- 月工资:40000元(超社平3倍)
- 社平3倍:24000元

2008年前:10年,不受封顶限制
  补偿 = 40000 × 10 = 400,000元

2008年后:17年,受双重封顶(基数+年限)
  补偿 = 24000 × 12 = 288,000元

总计 = 400,000 + 288,000 = 688,000元
```

**案例4:代通知金(N+1)**
```
赵六情况:
- 工作5年8个月 → 按6年计算
- 12月平均工资:10000元
- 上月工资:12000元(含绩效奖金)
- 解雇原因:不胜任工作

计算:
经济补偿 = 10000 × 6 = 60,000元
代通知金 = 12000 × 1 = 12,000元
合计 = 72,000元
```

#### 月工资计算特殊情况

**1. 加班费是否计入?**

各地规定不一:
- 北京、深圳、江苏:明确计入
- 上海、四川、南京:明确不计入

**建议:** 咨询当地人社部门或参照当地司法实践

**2. 年终奖如何计算?**

**主流做法:** 分摊到12个月
```
例:年终奖36000元,离职前12月内发放
   则每月分摊 36000÷12 = 3000元
   
计入平均工资:
(月基本工资 + 月分摊年终奖 + 其他) ÷ 12
```

**3. 病假/事假期间工资?**

**北京、东莞:** 剔除非正常出勤月份

**上海、江苏:** 不剔除,按实际计算

**4. 低于最低工资?**

按当地最低工资标准计算

**5. 工作不满12个月?**

按实际月数计算平均值

### 二、用人单位解除劳动合同情形

#### 可以不支付经济补偿(劳动合同法第39条)

**过错性解除:**
- [ ] 试用期不符合录用条件
- [ ] 严重违反规章制度
- [ ] 严重失职,营私舞弊,造成重大损害
- [ ] 同时与他人建立劳动关系且严重影响工作或拒不改正
- [ ] 欺诈、胁迫手段订立合同
- [ ] 被追究刑事责任

**注意:**
- 需有充分证据证明
- 规章制度需合法且经民主程序制定并公示
- "严重""重大"需有明确标准

#### 需支付经济补偿N(劳动合同法第40条)

**无过失性解除:**
- [ ] 医疗期满不能从事原工作也不能从事另行安排工作
- [ ] 不能胜任工作,经培训或调岗后仍不胜任
- [ ] 客观情况重大变化,无法履行合同且协商不成

**程序要求:**
提前30日书面通知 OR 支付代通知金(N+1)

#### 需支付经济补偿N(劳动合同法第41条)

**经济性裁员:**
- [ ] 破产重整
- [ ] 生产经营严重困难
- [ ] 转产、重大技术革新、经营方式调整
- [ ] 客观经济情况重大变化

**裁员限制(不得裁减):**
- 职业病/工伤且丧失/部分丧失劳动能力
- 患病/负伤,在规定医疗期内
- 女职工孕期、产期、哺乳期
- 本单位连续工作满15年且距退休不足5年
- 法律、法规规定的其他情形

### 三、劳动者解除劳动合同情形

#### 随时解除,有经济补偿N(劳动合同法第38条)

**被迫辞职情形:**
- [ ] 未按约定提供劳动保护或条件
- [ ] 未及时足额支付劳动报酬
- [ ] 未依法缴纳社会保险
- [ ] 规章制度违法,损害劳动者权益
- [ ] 欺诈、胁迫、乘人之危订立合同
- [ ] 以暴力、威胁或限制人身自由强迫劳动
- [ ] 违章指挥、强令冒险作业危及人身安全

**实务要点:**
- 需保留证据(欠薪记录、社保缴费记录等)
- 建议书面通知并说明理由
- 30日内申请劳动仲裁

#### 提前通知,无经济补偿(劳动合同法第37条)

**辞职:**
- 提前30日书面通知(正式员工)
- 试用期提前3日通知

**后果:**
- 用人单位无需支付经济补偿
- 但可主张未休年假工资、加班费等

### 四、劳动合同终止

#### 需支付经济补偿N(劳动合同法第46条)

**终止情形:**
- [ ] 合同期满,单位不续订(或降低条件续订但劳动者不同意)
- [ ] 单位破产、解散
- [ ] 营业执照被吊销、责令关闭

**无需补偿:**
- 劳动者不同意续订(单位维持或提高条件续订)
- 劳动者达到退休年龄

### 五、工伤认定与待遇

#### 工伤认定情形(工伤保险条例第14、15条)

**应当认定为工伤:**
1. 工作时间和场所内,因工作原因受伤害
2. 工作时间前后在场所内,从事预备性/收尾性工作受伤
3. 履行工作职责受暴力伤害
4. 患职业病
5. 外出工作期间,因工作原因受伤或事故下落不明
6. 上下班途中,受非本人主要责任交通事故伤害
7. 法律、行政法规规定的其他情形

**视同工伤:**
1. 工作时间和岗位,突发疾病死亡或48小时内抢救无效死亡
2. 抢险救灾等维护国家、公共利益活动中受伤
3. 军人在战时负伤,到单位后旧伤复发

#### 工伤待遇主要项目

**医疗费用:**
- 治疗工伤的医疗费
- 住院伙食补助费
- 交通食宿费

**停工留薪期工资:**
- 原工资福利待遇不变
- 一般不超过12个月

**伤残津贴(1-4级):**
- 一级:本人工资90%
- 二级:本人工资85%
- 三级:本人工资80%
- 四级:本人工资75%

**一次性伤残补助金:**
- 一级:27个月工资
- 二级:25个月工资
- ...
- 十级:7个月工资

### 六、劳动仲裁与诉讼

#### 仲裁时效

**一般时效:** 1年
- 从知道或应当知道权利被侵害之日起算

**特殊时效:**
- 拖欠劳动报酬:劳动关系存续期间不受时效限制,终止后1年内

#### 举证责任分配

**用人单位承担举证:**
- 解除/终止理由
- 支付工资、缴纳社保证明
- 考勤记录
- 规章制度制定、公示程序

**劳动者承担举证:**
- 劳动关系存在(无书面合同时)
- 加班事实(初步证据)

#### 仲裁程序

**流程:**
```
1. 提交仲裁申请(向用人单位所在地或合同履行地仲裁委)
   ↓
2. 受理审查(5日内决定是否受理)
   ↓
3. 开庭审理(受理之日起45日内结案,可延长15日)
   ↓
4. 裁决送达
   ↓
5. 不服可在15日内向法院起诉
```

**所需材料:**
- 仲裁申请书
- 身份证复印件
- 劳动合同/工资条/社保记录等证据
- 用人单位工商登记信息

### 七、常见问题快速解答

**Q1: 试用期可以随时辞退吗?**
A: 不可以。需证明不符合录用条件,且应有明确的录用条件和考核标准。

**Q2: 怀孕女职工可以解雇吗?**
A: 不可以。"三期"(孕期、产期、哺乳期)内不得解除,除非严重违纪等过错性情形。

**Q3: 不签劳动合同有什么后果?**
A: 
- 用工1个月内未签:无罚则
- 超1个月不满1年:支付双倍工资
- 超1年未签:视为无固定期限劳动合同

**Q4: 竞业限制如何约定?**
A:
- 仅限高管、高级技术人员、负有保密义务的人员
- 最长2年
- 需支付竞业限制补偿(月工资30%以上)
- 未支付补偿,劳动者可解除竞业限制

**Q5: 能否约定违约金?**
A: 仅两种情形可约定:
- 违反服务期约定(单位提供专项培训费用)
- 违反竞业限制约定

其他情形约定违约金无效。

**Q6: 调岗需要员工同意吗?**
A: 原则上需要。但以下情形可单方调岗:
- 客观情况重大变化
- 医疗期满不能从事原工作
- 不能胜任工作
- 劳动合同明确约定

**Q7: 社保缴纳基数如何确定?**
A: 以上年度月平均工资为基数,不得低于当地最低缴费基数。

**Q8: 年假怎么休?**
A: 
- 工作满1年不满10年:5天
- 工作满10年不满20年:10天
- 工作满20年:15天

未休年假应支付3倍日工资(其中1倍正常工资,2倍补偿)

## 计算器工具

### 经济补偿金计算步骤

**第一步:确定工作年限N**
```
入职日期:YYYY-MM-DD
离职日期:YYYY-MM-DD

总月数 = (离职年-入职年)×12 + (离职月-入职月) + 日期差异
年限N = 
  若总月数 ≥ 6个月,按1年计算
  若总月数 < 6个月,按0.5年计算
  
注意:跨2008年的分段计算
```

**第二步:计算月工资S**
```
离职前12个月工资总和 ÷ 12 = 月平均工资S

包括:
□ 基本工资
□ 绩效奖金
□ 各项津贴补贴
□ 年终奖(分摊)
□ 加班费(视地区规定)

对比当地社平工资×3:
若S ≤ 社平×3 → 无封顶
若S > 社平×3 → 基数封顶为社平×3,年限封顶12年
```

**第三步:计算经济补偿**
```
标准公式: S × N

如有代通知金: S × N + 上月工资 × 1

如系违法解雇: 2 × (S × N)
```
