## 一、起诉与受理

### 1.1 起诉条件

**法定条件(第122条):**
1. **原告适格** - 与本案有直接利害关系的公民、法人和其他组织
2. **有明确的被告**
3. **有具体的诉讼请求和事实、理由**
4. **属于法院受理民事诉讼范围和受诉法院管辖**

**实务要点:**
- 利害关系:合同当事人、侵权受害人、继承人、债权人等
- 明确被告:有被告姓名(名称)、住所或联系方式
- 具体请求:明确诉讼标的和数额
- 事实理由:基本法律关系和争议焦点

### 1.2 立案审查

**审查期限:** 7日内(第123条)

**审查结果:**
- **符合条件** → 登记立案
- **不符合条件** → 裁定不予受理(可上诉)
- **材料不齐** → 一次性告知补正

**立案登记制:**
2015年起实行"有案必立、有诉必理",除法定不予受理情形外,应当登记立案

**不予受理的情形:**
- 已有生效裁判
- 仲裁裁决已生效
- 调解协议已司法确认
- 不属于民事诉讼范围(刑事、行政案件)

### 1.3 起诉材料

**必备材料:**
- [ ] 起诉状(正本+被告人数份副本)
- [ ] 原告身份证明(个人/营业执照/组织代码证)
- [ ] 被告身份信息(个人/企业)
- [ ] 证据材料(正本+被告人数份副本)
- [ ] 授权委托书(如有代理人)

**起诉状内容:**
1. 当事人基本信息
2. 诉讼请求
3. 事实与理由
4. 证据和证据来源
5. 法院名称、起诉时间、原告签名

## 二、管辖规则

### 2.1 级别管辖

| 法院级别 | 管辖范围 |
|----------|----------|
| **基层法院** | 一般民事案件 |
| **中级法院** | ①重大涉外案件 ②在本辖区有重大影响的案件 ③最高法院确定由中级法院管辖的案件 |
| **高级法院** | 在本辖区有重大影响的第一审民事案件 |
| **最高法院** | 在全国有重大影响的案件 |

**诉讼标的额标准(各地不同):**
- 北京中院:标的额超过5000万元
- 上海中院:标的额超过1亿元
- 广州中院:标的额超过1亿元

### 2.2 地域管辖

**一般管辖(第22条):**
```
被告住所地法院 或 经常居住地法院(连续居住1年以上)
```

**特殊管辖(第23-35条):**

| 案件类型 | 管辖法院 |
|----------|----------|
| **合同纠纷** | 被告住所地 **或** 合同履行地 |
| **保险合同** | 被告住所地 **或** 保险标的物所在地 |
| **票据纠纷** | 票据支付地 **或** 被告住所地 |
| **公司纠纷** | 公司住所地 |
| **侵权纠纷** | 侵权行为地 **或** 被告住所地 |
| **产品责任** | 产品制造地/销售地/侵权行为地/被告住所地 |
| **交通事故** | 事故发生地 **或** 车辆最先到达地/被告住所地 |
| **海上事故** | 事故发生地/船舶最先到达地/加害船舶扣押地/被告住所地 |
| **不动产** | 不动产所在地(**专属管辖**) |
| **港口作业** | 港口所在地 **或** 被告住所地 |
| **继承** | 被继承人死亡时住所地 **或** 主要遗产所在地(**专属管辖**) |
| **遗嘱继承/受遗赠** | 遗赠人/被继承人住所地/主要遗产所在地 |

**关键概念:**

**合同履行地:**
- 约定履行地:从约定
- 未约定或约定不明:
  - 给付货币:接受货币一方所在地
  - 交付不动产:不动产所在地
  - 其他标的:履行义务一方所在地

**侵权行为地:**
- 侵权行为实施地
- 侵权结果发生地

**住所:**
- 公民:户籍所在地
- 法人:主要办事机构所在地

**经常居住地:**
- 连续居住满1年以上的地方
- 住院就医除外

### 2.3 协议管辖

**适用范围:** 合同纠纷(非专属管辖)

**可选法院(第35条,五选一):**
1. 原告住所地
2. 被告住所地
3. 合同履行地
4. 合同签订地
5. 标的物所在地

**有效要件:**
- 书面协议
- 明确具体
- 有实际联系
- 不违反级别管辖和专属管辖

**无效约定:**
- "任何法院"
- 无实际联系的法院
- 违反专属管辖(如不动产案件)

### 2.4 专属管辖

**三类案件,不得协议管辖:**
1. 不动产纠纷 → 不动产所在地
2. 港口作业纠纷 → 港口所在地
3. 继承纠纷 → 被继承人死亡时住所地或主要遗产所在地

## 三、诉讼流程与期限

### 3.1 第一审程序

**简易程序(第157-165条):**

**适用条件:**
- 基层法院及其派出法庭
- 事实清楚、权利义务明确、争议不大
- 标的额≤各省、自治区、直辖市上年度就业人员年平均工资30%

**审理期限:** 3个月

**特点:**
- 可口头起诉
- 当事人可口头答辩
- 经双方同意可由审判员一人独任审理
- 简化送达程序

**普通程序(第138-156条):**

**审理期限:** 6个月(特殊情况可延长6个月,再需延长报上级法院批准)

**流程:**
```
立案 → 组成合议庭 → 送达起诉状副本(15日)
  ↓
被告答辩(15日)
  ↓
证据交换(开庭15日前)
  ↓
开庭审理(提前3日通知)
  ↓
法庭调查 → 法庭辩论 → 最后陈述
  ↓
合议庭评议
  ↓
宣判(定期宣判:10日内送达;当庭宣判:立即送达)
```

### 3.2 第二审程序

**上诉期限:**
- 判决:送达之日起**15日内**
- 裁定:送达之日起**10日内**

**审理方式:**
- 合议庭审理
- 开庭审理(可不开庭)

**审理期限:** 3个月(特殊情况可延长)

**二审判决类型:**
1. **维持原判** - 原判正确
2. **改判** - 原判错误(事实认定/法律适用错误)
3. **发回重审** - 原审程序违法/遗漏当事人/遗漏诉讼请求

**二审特点:**
- 不得加重上诉人诉讼负担(上诉不加刑原则)
- 终审判决,立即生效

### 3.3 审判监督程序(再审)

**再审事由(第207条,13种):**
1. 新证据足以推翻原判决裁定
2. 原判决裁定认定基本事实缺乏证据证明
3. 原判决裁定认定事实主要证据系伪造
4. 原判决裁定认定事实主要证据未经质证
5. 对审理案件需要的主要证据,当事人未能提供,人民法院应当调查收集但未调查收集
6. 原判决裁定适用法律确有错误
7. 审判组织组成不合法或应当回避而未回避
8. 无诉讼行为能力人未经法定代理人代为诉讼或应当参加诉讼的当事人未参加
9. 违反法律规定剥夺当事人辩论权利
10. 未经传票传唤缺席判决
11. 原判决裁定遗漏或超出诉讼请求
12. 据以作出原判决裁定的法律文书被撤销或变更
13. 审判人员审理该案时有贪污受贿、徇私舞弊、枉法裁判行为

**申请期限:**
- 判决/裁定生效后**6个月内**(但有新证据等情形的,自知道或应当知道之日起6个月)

**再审申请人:**
- 原审当事人
- 检察院抗诉
- 法院依职权再审

## 四、证据规则

### 4.1 举证责任

**基本原则:**
```
谁主张,谁举证
```

**举证责任倒置(特殊情况):**

**侵权案件:**
- 环境污染:排污者证明无因果关系
- 高度危险作业:经营者证明受害人故意/不可抗力
- 饲养动物致害:饲养人证明受害人故意/重大过失
- 建筑物/悬挂物坠落:所有人/管理人证明无过错
- 产品责任:生产者证明无缺陷/受害人故意
- 医疗损害:医疗机构证明无过错(部分情形)

**其他:**
- 劳动争议:用人单位对解除/开除决定负举证责任
- 共同危险行为:行为人证明非自己造成
- 专利侵权(新产品方法):被告证明非该方法制造

### 4.2 证据类型(第66条)

1. **书证** - 合同、收据、信函、证书等
2. **物证** - 实物、样品
3. **视听资料** - 录音、录像
4. **电子数据** - 微信聊天记录、邮件、网页、支付宝记录等
5. **证人证言**
6. **当事人陈述**
7. **鉴定意见**
8. **勘验笔录**

### 4.3 证据要求(三性)

**真实性:**
- 未伪造、变造
- 能反映客观事实

**合法性:**
- 取证手段合法
- 形式合法
- 程序合法

**关联性:**
- 与待证事实有关联
- 能证明待证事实

### 4.4 证据提交

**举证期限:**
- 法院指定期限(不少于15日)
- 当事人协商一致期限

**逾期举证后果:**
- 视为放弃举证权利
- 但有正当理由的除外

**证据交换:**
- 开庭审理前
- 组织当事人交换证据
- 确定无争议事实

**新证据:**
- 一审:举证期限届满前未发现的
- 二审:一审庭审结束后新发现的
- 再审:原审庭审结束后新发现的

### 4.5 电子数据证据(重要!)

**常见类型:**
- 微信/QQ聊天记录
- 电子邮件
- 支付宝/微信支付记录
- 网页、博客、微博
- 手机短信
- 电子合同

**证明力提升要点:**
1. 完整性(不要截图片段)
2. 来源可靠(公证/第三方存证)
3. 与其他证据印证
4. 原始载体(手机、电脑)
5. 经过公证

**微信证据要点:**
- 截屏不如录屏
- 显示聊天全貌(时间线连续)
- 保留微信号、头像、昵称
- 证明对方身份(结合其他证据)
- 关键内容可公证

## 五、诉讼时效

### 5.1 普通诉讼时效

**期间:** 3年(《民法典》第188条)

**起算:**
```
权利人知道或应当知道权利受到损害以及义务人之日起
```

**最长保护期:** 20年
```
自权利受到损害之日起超过20年,法院不予保护
(有特殊情况可申请延长)
```

### 5.2 特殊诉讼时效

| 类型 | 期间 | 法律依据 |
|------|------|----------|
| 国际货物买卖合同 | 4年 | 《民法典》第594条 |
| 技术进出口合同 | 4年 | 《民法典》第594条 |
| 人身损害赔偿(旧法) | ~~1年~~ | 已废除 |
| 出售不合格商品(旧法) | ~~2年~~ | 已废除 |

**提示:** 2021年1月1日《民法典》生效后,除上述4年特殊规定外,其他均为3年普通时效!

### 5.3 诉讼时效起算

**不同情形的起算时间:**

**1. 约定履行期限的债权:**
```
履行期限届满之日起算
```

**2. 未约定履行期限的债权:**
```
债权人首次要求履行之日起算
(给予宽限期的,宽限期届满之日起算)
```

**3. 侵权之债:**
```
知道或应当知道权利被侵害及义务人之日起算
```

**4. 附条件的债权:**
```
条件成就之日起算
```

**5. 附期限的债权:**
```
期限到达之日起算
```

**6. 人身损害赔偿:**
```
知道或应当知道权利被侵害及义务人之日起算
(伤情稳定后,损失确定时)
```

### 5.4 诉讼时效中止

**中止事由(最后6个月内发生):**
1. 不可抗力
2. 无民事行为能力人或限制民事行为能力人无法定代理人,或法定代理人死亡、丧失民事行为能力、丧失代理权
3. 继承开始后未确定继承人或遗产管理人
4. 权利人被义务人或其他人控制
5. 其他导致权利人不能行使请求权的障碍

**效果:**
```
中止事由消除后,诉讼时效继续计算(剩余时间继续)
```

### 5.5 诉讼时效中断

**中断事由:**
1. **权利人向义务人提出履行请求**
   - 直接送达主张权利文书
   - 信件或数据电文到达
   - 公开媒体上刊登催告公告
   - 金融机构依约扣款

2. **义务人同意履行义务**
   - 承认债务
   - 部分履行
   - 请求延期履行
   - 提供担保

3. **权利人提起诉讼或申请仲裁**

4. **与提起诉讼或申请仲裁具有同等效力的其他情形**

**效果:**
```
诉讼时效中断,从中断事由消除时起重新计算(重新3年)
```

**实务技巧:**
- 定期(每2年左右)发催款函并保留证据
- 要求对方书面确认债务
- 微信/邮件催款保留证据

### 5.6 不适用诉讼时效的请求权

**永久权利(第196条):**
1. 请求停止侵害、排除妨碍、消除危险
2. 不动产物权和登记的动产物权的权利人请求返还财产
3. 请求支付抚养费、赡养费或扶养费
4. 依法不适用诉讼时效的其他请求权

## 六、保全与先予执行

### 6.1 财产保全

**申请时点:**

**诉前保全(第101条):**
```
情况紧急 → 诉前向财产所在地、被告住所地或管辖法院申请
  ↓
法院裁定(48小时内)
  ↓
申请人15日内起诉(否则解除保全)
```

**诉中保全(第100条):**
```
诉讼过程中 → 向受理案件法院申请
  ↓
法院裁定(48小时内)
```

**保全条件:**
- 情况紧急
- 不保全将使申请人合法权益受到难以弥补的损害
- 提供担保(或情况紧急可先保全)

**保全措施:**
- 查封
- 扣押
- 冻结(银行存款、股权等)

**保全期限:**
- 冻结银行存款:6个月
- 查封、扣押动产:1年
- 查封不动产:2年
- 可申请延期

**错误保全责任:**
申请人申请错误的,应赔偿被申请人损失

### 6.2 行为保全(第104条,2023新增强化)

**适用:**
- 禁止被申请人作出一定行为
- 责令被申请人作出一定行为

**常见场景:**
- 禁止被告转移、处分财产
- 禁止被告继续侵犯知识产权
- 责令被告停止侵权行为
- 责令被告提供担保

### 6.3 先予执行(第106-109条)

**适用条件:**
1. 当事人之间权利义务关系明确
2. 不先予执行将严重影响申请人生活或生产经营
3. 被申请人有履行能力

**适用案件:**
- 追索赡养费、扶养费、抚养费、抚恤金、医疗费用
- 追索劳动报酬
- 因情况紧急需要先予执行的

**程序:**
```
申请 → 法院裁定(可要求担保) → 立即执行
  ↓
判决撤销先予执行裁定的 → 申请人返还+赔偿损失
```

## 七、执行程序

### 7.1 申请执行

**申请期限(第239条):**
```
生效法律文书确定的履行期届满之日起2年内
```

**申请执行人:**
- 权利人
- 继承人或权利承受人

**申请法院:**
- 一审法院
- 被执行财产所在地法院

**申请材料:**
- 申请执行书
- 生效法律文书
- 身份证明
- 申请人无法提供被执行人财产线索的,应说明

### 7.2 执行措施

**查控措施:**
- 查询存款、股票、车辆、房产等
- 冻结、划拨银行存款
- 扣留、提取收入

**处置措施:**
- 查封、扣押、拍卖、变卖财产
- 搜查隐匿财产
- 强制被执行人交付财物或票证

**强制措施:**
- 罚款、拘留(妨碍执行行为)
- 限制高消费
- 纳入失信被执行人名单
- 限制出境
- 拒不执行判决裁定罪(刑事责任)

### 7.3 失信被执行人

**纳入条件(最高法司法解释):**
1. 有履行能力而拒不履行
2. 以伪造证据、暴力、威胁等方法妨碍、抗拒执行
3. 以虚假诉讼、虚假仲裁或隐匿、转移财产等方法规避执行
4. 违反财产报告制度
5. 违反限制消费令
6. 无正当理由拒不履行和解协议

**后果:**
- 限制乘坐飞机、高铁
- 限制高消费(五星级酒店、高尔夫、旅游度假等)
- 限制子女就读高收费私立学校
- 限制担任企业高管
- 纳入征信系统
- 公开曝光

**删除:**
全部履行完毕后,申请删除

### 7.4 执行期限

**一般案件:** 6个月
**特殊情况:** 可延长,报上级法院批准

**中止执行:**
- 申请人撤销申请
- 据以执行的法律文书被撤销
- 作为被执行人的公民死亡,无遗产或继承人放弃继承
- 追索赡养费等案件权利人死亡
- 作为一方当事人的法人或组织终止,尚无权利义务承受人
- 法院认为应当中止的其他情形

**终结执行:**
- 申请人撤销申请
- 据以执行的法律文书被撤销
- 被执行人无财产可供执行且无法定义务人
- 其他法定情形

## 八、特别程序

### 8.1 调解(鼓励)

**调解原则:**
- 自愿
- 合法
- 不损害国家、社会、他人利益

**调解时机:**
- 立案后、判决前任何阶段

**调解书:**
- 经双方签收后生效
- 与判决书具有同等法律效力
- 可申请执行

**不调解案件:**
- 适用特别程序、督促程序、公示催告程序、破产程序的案件
- 婚姻等身份关系确认案件
- 其他法律规定不得调解的案件

### 8.2 小额诉讼(第165条)

**条件:**
- 事实清楚、权利义务明确、争议不大
- 标的额≤各省、自治区、直辖市上年度就业人员年平均工资30%

**特点:**
- 一审终审(不得上诉)
- 当庭宣判
- 简化程序

### 8.3 公益诉讼(第55-58条)

**适用:**
- 污染环境
- 侵害众多消费者合法权益
- 损害社会公共利益的行为

**起诉主体:**
- 法律规定的机关
- 有关组织(消协、环保组织等)
- 人民检察院(特定情形)

## 九、诉讼费用

### 9.1 案件受理费

**财产案件(按标的额比例):**

| 标的额 | 收费标准 |
|--------|----------|
| ≤1万元 | 50元 |
| 1万-10万元 | 标的额×2.5% |
| 10万-20万元 | 标的额×2% + 200元 |
| 20万-50万元 | 标的额×1.5% + 1200元 |
| 50万-100万元 | 标的额×1% + 3700元 |
| 100万-200万元 | 标的额×0.9% + 4700元 |
| 200万-500万元 | 标的额×0.8% + 6700元 |
| 500万-1000万元 | 标的额×0.7% + 11700元 |
| 1000万-2000万元 | 标的额×0.6% + 21700元 |
| >2000万元 | 标的额×0.5% + 41700元 |

**非财产案件:**
- 离婚: 50-300元(涉及财产分割的,按财产额另计)
- 侵犯姓名权、名称权、肖像权、荣誉权、名誉权: 100-500元(涉及赔偿的,按财产额另计)
- 其他非财产案件: 50-100元

**特殊案件:**
- 知识产权民事案件: 无争议金额的500-1000元;有争议金额按财产案件标准
- 劳动争议案件: 10元
- 破产案件: 依破产财产总额计算(略)

### 9.2 其他诉讼费用

**申请费:**
- 申请执行: 执行金额或价额的1‰(不满1万的50元)
- 申请保全: 财产额的0.5‰-1‰(不超过5000元)
- 申请支付令: 比照财产案件受理费标准1/3交纳
- 申请公示催告: 100元

**证人、鉴定、勘验费:**
- 按实际发生额计

### 9.3 缓交、减交、免交

**缓交:** 确有困难的,可申请缓交

**减交:** 
- 残疾人无固定生活来源
- 追索赡养费、抚养费、扶养费、抚恤金
- 遭受自然灾害生活困难

**免交:**
- 救济金案件
- 工伤保险待遇案件

### 9.4 诉讼费负担

**基本原则:**
```
败诉方负担
```

**部分胜诉:**
```
法院根据案件具体情况决定各方负担比例
```

**调解结案:**
```
双方协商负担,协商不成由法院决定
```

## 十、常见问题与实务建议

### Q&A

**Q1: 诉讼时效过了还能起诉吗?**
A: 可以起诉,法院会受理。但如果对方提出诉讼时效抗辩,法院会驳回诉讼请求。诉讼时效不是起诉期限,而是胜诉权保护期。

**Q2: 微信聊天记录能作为证据吗?**
A: 可以,但要注意:
- 保持完整性(完整聊天记录,不要只截取部分)
- 证明对方身份(微信号、头像、昵称结合其他证据)
- 最好公证或第三方存证
- 与其他证据相互印证

**Q3: 对方拖欠货款,不知道他有什么财产,怎么办?**
A: 
- 起诉时申请财产保全
- 申请法院调查对方财产(银行存款、房产、车辆、股权等)
- 胜诉后申请执行,法院会查控其财产

**Q4: 对方在外地,必须去外地起诉吗?**
A: 不一定:
- 合同纠纷可选择合同履行地或协议管辖
- 侵权纠纷可选择侵权行为地
- 建议尽量选择原告所在地有管辖权的法院

**Q5: 判决生效后多久必须申请执行?**
A: 2年。从生效法律文书确定的履行期届满之日起算。超过2年未申请的,法院不再受理。

**Q6: 可以不请律师自己打官司吗?**
A: 可以,但建议:
- 简单案件(事实清楚、证据充分)可自行
- 复杂案件(法律关系复杂、标的额大)建议委托律师
- 至少咨询律师评估案件

**Q7: 起诉后多久开庭?**
A: 不一定:
- 立案后法院会安排时间
- 简单案件可能1-2个月
- 复杂案件可能3-6个月
- 受法院案件量影响

**Q8: 一审输了还能上诉吗?**
A: 可以:
- 判决书送达后15日内
- 裁定书送达后10日内
- 向原审法院或上一级法院递交上诉状

## 实务建议

### 诉前准备

**证据收集:**
- ✅ 梳理全部证据材料
- ✅ 制作证据清单
- ✅ 证据分类编号
- ✅ 重要证据公证
- ✅ 电子证据固定(公证/存证)

**诉讼策略:**
- ✅ 确定管辖法院(选择对己有利)
- ✅ 确定被告(个人/公司/连带责任人)
- ✅ 明确诉讼请求(金额、违约金、利息等)
- ✅ 评估胜诉可能性
- ✅ 考虑诉讼成本(律师费、诉讼费、时间成本)

**风险评估:**
- ✅ 诉讼时效是否届满
- ✅ 对方财产状况(是否能执行到)
- ✅ 证据充分性
- ✅ 是否需要保全

### 诉讼技巧

**管辖技巧:**
- 合同中约定有利管辖法院
- 选择原告所在地有管辖权的法院
- 避免专属管辖限制

**证据技巧:**
- 关键证据办理公证
- 证据链完整(每个事实都有证据支撑)
- 原件优于复印件
- 书面优于口头

**时效技巧:**
- 定期发催告函
- 保留催告证据
- 及时起诉

**保全技巧:**
- 起诉时同时申请保全
- 尽早查明对方财产线索
- 必要时申请诉前保全

### 高频风险点

**时效风险:**
- ❌ 权利不主张,超过3年
- ❌ 催款无证据,无法证明中断
- ❌ 债务人失联,未采取措施

**证据风险:**
- ❌ 只有口头约定,无书面证据
- ❌ 微信聊天记录不完整
- ❌ 证据灭失(未及时固定)
- ❌ 对方身份不明确

**管辖风险:**
- ❌ 协议管辖无效
- ❌ 选择不利管辖法院
- ❌ 专属管辖限制

**执行风险:**
- ❌ 对方名下无财产
- ❌ 财产已转移
- ❌ 判决前未保全

### 核心提示

**诉前准备:**
1. 证据为王,收集完整证据
2. 查清对方身份和财产
3. 选择有利管辖法院
4. 考虑财产保全

**诉讼过程:**
1. 按时提交证据
2. 积极参加庭审
3. 陈述清晰有力
4. 尊重法官和对方

**诉后执行:**
1. 判决生效后及时申请执行
2. 积极提供财产线索
3. 配合法院执行工作
4. 必要时申请追加被执行人

**和解调解:**
- 考虑诉讼成本和执行风险
- 能调则调,但要保护核心利益
- 调解协议要明确具体可执行
