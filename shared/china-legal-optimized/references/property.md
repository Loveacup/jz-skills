## 一、业主权利与义务

### 1.1 业主认定

**业主定义(《民法典》第271条):**
```
建筑物及其附属设施的所有权人为业主
```

**取得时间:**
- 不动产权证书登记之日
- 房屋交付使用(未办证但已实际占有)

**共同业主:**
- 夫妻共有
- 共同购买人
- 继承人(遗产未分割)

### 1.2 业主权利

**《物业管理条例》第6条规定的10项权利:**

1. **服务接受权** - 按物业服务合同接受服务
2. **建议权** - 提议召开业主大会,就物业管理提建议
3. **制规权** - 提出制定/修改管理规约、议事规则建议
4. **表决权** - 参加业主大会,行使投票权
5. **选举权** - 选举业委会成员,享有被选举权
6. **监督权** - 监督业委会工作
7. **合同监督权** - 监督物业服务企业履行合同
8. **知情权** - 对共用部位、设施设备使用情况知情和监督
9. **维修资金监督权** - 监督专项维修资金管理和使用
10. **其他法定权利**

**《民法典》新增权利:**

**解聘物业权(第939条):**
```
业主可以依法共同决定解聘物业服务人
```

**查阅权(第943条):**
```
物业服务人应当定期将服务的事项、负责人员、质量要求、收费项目、
收费标准、履行情况,以及维修资金使用情况、业主共有部分的经营
与收益情况等以合理方式向业主公开并向业主大会、业主委员会报告
```

### 1.3 业主义务

**基本义务(《物业管理条例》第7条):**

1. **遵守规约** - 遵守管理规约、业主大会议事规则
2. **遵守制度** - 遵守共用部位使用、公共秩序、环境卫生等规章制度
3. **执行决定** - 执行业主大会和业委会决定
4. **交纳维修资金** - 按规定交纳专项维修资金
5. **交纳物业费** - 按时交纳物业服务费
6. **其他法定义务**

**特别提示:**
- ❗ 即使未入住,也需按时交纳物业费(除合同另有约定)
- ❗ 房屋出租的,可约定由承租人交费,但业主负连带责任

## 二、业主大会与业主委员会

### 2.1 业主大会

**成立条件(浙江省条例第8条):**

符合以下条件之一,应成立业主大会:
1. 房屋交付面积达总面积**60%以上**
2. 首套房屋交付满**2年**,且交付面积达总面积**30%以上**

**不成立业主大会的情形:**
- 只有一个业主
- 业主人数较少且全体业主一致同意不成立

**物业管理区域划分原则:**
- 一个物业管理区域成立一个业主大会
- 根据共用设施设备、建筑规模、社区建设等划分
- 分期开发的住宅区,有共同配套设施的,应划为一个区域

### 2.2 首次业主大会筹备

**筹备组组成:**
- 业主推举的代表
- 建设单位代表
- 居民委员会代表

**筹备流程:**
```
符合条件 → 物业主管部门/街道指导成立筹备组 → 
筹备组成立(3日内公告) → 会议召开前15日通知全体业主 →
告知物业主管部门、街道、居委会 → 召开首次业主大会
```

**筹备经费:** 由建设单位承担

### 2.3 业主大会会议

**会议形式:**
- 集体讨论
- 书面征求意见

**召开要求:**
- 提前15日书面通知全体业主
- 会议参加:专有面积过半数+人数过半数

**会议类型:**
1. **定期会议** - 按议事规则规定召开
2. **临时会议** - 20%以上业主提议,业委会应组织召开

**表决规则(《民法典》第278条,核心!):**

| 决定事项 | 表决要求 |
|----------|----------|
| **特别重大事项(双2/3)** | 专有面积2/3以上 **且** 人数2/3以上 |
| **一般重大事项(双过半)** | 专有面积过半 **且** 人数过半 |

**特别重大事项(双2/3):**
1. 制定和修改业主大会议事规则
2. 制定和修改管理规约
3. 选举业委会或更换业委会成员
4. 选聘和解聘物业服务企业
5. 使用建筑物及其附属设施的维修资金
6. 筹集建筑物及其附属设施的维修资金
7. 改建、重建建筑物及其附属设施
8. 改变共有部分的用途或利用共有部分从事经营活动
9. 有关共有和共同管理权利的其他重大事项

**一般重大事项(双过半):**
- 其他需业主共同决定的事项

### 2.4 业主委员会

**性质:** 业主大会的执行机构

**产生:** 业主大会选举

**委员资格:**
- 热心公益事业
- 责任心强
- 具有一定组织能力
- 不得有违法违规行为

**任期:** 3-5年(浙江省规定)

**主要职责(《物业管理条例》第15条):**
1. 召集业主大会,报告物业管理实施情况
2. 代表业主与物业服务企业签订合同
3. 了解业主意见,监督协助物业服务企业履约
4. 监督管理规约实施
5. 业主大会赋予的其他职责

**备案要求:**
选举产生后30日内向物业主管部门和街道备案,提交:
- 业主大会会议记录和决定
- 业主大会议事规则
- 管理规约
- 业委会委员名单

**会议制度:**
- 会议需半数以上委员出席
- 决定须全体委员半数以上同意
- 讨论事项应提前3日公告

**换届:**
- 任期届满2个月前召开业主大会换届
- 逾期未换届的,物业主管部门、街道、居委会应指导换届
- 新一届业委会产生后10日内,原业委会应移交资料、印章

### 2.5 物业管理委员会(临时机构)

**设立情形:**
- 业委会未产生
- 由街道办事处、乡镇政府组建
- 代为履行业委会职责

**职责:**
- 推动产生业委会
- 临时履行业委会职责

**终止:**
- 业委会产生并备案之日起停止履职

## 三、物业服务

### 3.1 物业服务人选聘

**前期物业服务:**
```
建设单位选聘 → 签订前期物业服务合同 → 
业主大会成立后可重新选聘 → 新合同生效,前期合同终止
```

**选聘方式:**
1. **招标**(住宅物业应当招标)
   - 投标人少于3个,可协议方式
   - 物业管理区域建筑面积较小,可协议方式

2. **协议**(需物业主管部门批准)

**提倡:** 通过公开、公平、公正的市场竞争机制选择

### 3.2 物业服务合同

**签订主体:**
- 业主委员会 与 物业服务企业

**必备条款(《物业管理条例》第34条):**
1. 物业管理事项
2. 服务质量
3. 服务费用
4. 双方权利义务
5. 专项维修资金管理使用
6. 物业管理用房
7. 合同期限
8. 违约责任

**《民法典》新增要求(第938条):**
应载明:
- 服务事项
- 服务质量
- 服务费用的标准和收取办法
- 维修资金的使用
- 服务用房的管理和使用
- 服务期限
- 服务交接等条款

**备案:** 签订或变更后15日内报物业主管部门备案

### 3.3 物业服务费

**收费方式:**
1. **包干制** - 物业服务费固定,盈亏自负
2. **酬金制** - 预收服务费,据实结算,结余归业主

**交纳义务人:**
- 业主
- 业主与使用人约定由使用人交纳的,从其约定,但业主负连带责任
- 未售出或未交付的物业,由建设单位全额交纳

**拖欠后果:**
- 业委会督促交纳
- 物业服务人可申请仲裁或起诉

**调整物业费:**
- 需业主大会决定(双过半或双2/3,视合同约定)

### 3.4 物业服务人义务

**基本义务(《民法典》第942条):**
1. 按约定和性质提供服务
2. 维护物业管理区域秩序
3. 采取合理措施保护业主人身财产安全
4. 定期公开服务信息
5. 及时答复业主对物业服务的询问
6. 及时回应物业使用人的投诉
7. 物业服务合同约定的其他义务

**禁止行为:**
- 采取停止供电、供水、供热、供燃气等方式催交物业费
- 擅自改变物业服务用房用途
- 擅自占用、挖掘物业管理区域内道路、场地
- 擅自利用共有部分进行经营

**服务交接(《民法典》第950条):**
合同终止后,应在约定期限或合理期限内退出并移交:
- 物业服务用房
- 相关设施
- 物业服务所必需的相关资料

### 3.5 专业服务费用

**原则(浙江省条例第35条):**
```
供水、供电、供气、供热、通信、有线电视等专业单位
应当向最终用户直接收取费用
```

**不得强制代收:**
- 专业单位不得强制要求物业服务人代收
- 确需委托代收,应签订委托代收协议并支付手续费

## 四、物业使用与维护

### 4.1 禁止行为(浙江省条例第44条)

业主和使用人**禁止**下列行为:
1. ❌ 违法改变房屋承重结构
2. ❌ 违法搭建建筑物、构筑物
3. ❌ 擅自改建、占用物业共用部位
4. ❌ 损坏或擅自占用、移装共用设施设备
5. ❌ 存放不符合安全标准的易燃、易爆、剧毒、放射性等危险物品
6. ❌ 超标排放有毒、有害物质
7. ❌ 排放超标准噪声
8. ❌ 其他法律法规禁止的行为

**特别提示:**
- 改建房屋需符合《民法典》第279条(应当经专有面积2/3以上+人数2/3以上业主同意)
- 装修前应告知物业服务人
- 物业服务人应告知禁止行为和注意事项

### 4.2 共用部位和设施设备

**共用部位包括:**
- 公共门厅、楼梯间、电梯间
- 管道井、设备间、过道
- 值班保安室、公共停车位
- 房屋承重结构
- 户外墙面、屋面
- 道路、场地、绿地等

**共用设施设备包括:**
- 供水箱、水泵、排水管道
- 窨井、化粪池、垃圾箱(房)
- 电梯、照明设施
- 安全防范智能系统
- 避雷装置、单元防盗门
- 文化体育设施、围护设施等

**使用原则:**
- 不得擅自占用、挖掘
- 确需临时占用,须经业委会、物业服务人和直接利害关系人同意
- 应及时恢复原状

### 4.3 停车管理

**停车位权属:**
- 规划内的车位、车库,归业主共有(除建设单位依法出售或附赠的)
- 占用业主共有道路或其他场地设置的车位,属业主共有

**临时停车位设置要求:**
- 经业主大会同意
- 不得影响其他车辆和行人正常通行
- 不得损坏绿地等共用部位、设施设备
- 不得阻碍消防通道

**收益归属:**
- 利用共有部分设置的停车位收益归业主共有
- 可用于补充维修资金或物业管理其他需要

### 4.4 经营性使用共有部分

**利用共用部位、设施设备经营(浙江省条例第47条):**
```
征得相关业主、业主大会、物业服务人同意
  ↓
向有关部门申请办理审批手续
  ↓
业主所得收益按业主大会决定使用
  (补充维修资金/物业管理其他需要)
```

**常见经营形式:**
- 外墙、电梯广告
- 公共区域摊位、停车位
- 会所、活动室出租
- 基站、充电桩等设施

**收益分配:**
- 归业主共有
- 应定期公布收支情况

## 五、专项维修资金

### 5.1 基本原则

**管理原则(浙江省条例第49条):**
```
业主交纳、统一存储、按幢核算、建账到户
业主决策、专款专用、政府监管
```

**归属:** 专项维修资金属于业主所有

**用途:** 专项用于物业保修期满后物业共用部位、共用设施设备的维修、更新和改造

### 5.2 交纳标准

**应交纳物业类型:**
- 住宅物业
- 住宅小区内的非住宅物业
- 与单幢住宅楼结构相连的非住宅物业

**首期交纳标准(各地不同,以当地规定为准):**
- 一般按购房款的2%-3%
- 或按建筑面积一次性交纳(如杭州市:多层60元/㎡,高层90元/㎡)

**续交:** 余额不足30%时,应续交

### 5.3 使用程序

**一般情况(《民法典》第281条):**
```
业主大会决定(专有面积2/3以上+人数2/3以上)
  ↓
向专户管理银行申请
  ↓
审核通过
  ↓
拨付使用
```

**紧急情况(简易程序):**
发生危及房屋安全等紧急情况,需要立即维修的:
- 业委会或物业服务人可先使用
- 费用按专有面积比例分摊
- 事后补办手续

**应急使用情形:**
- 屋面、外墙防水严重损坏
- 电梯故障
- 消防设施故障
- 公共护(围)栏破损严重
- 楼体外立面有脱落危险
- 其他危及房屋使用和人身财产安全的紧急情况

### 5.4 使用监督

**公示要求:**
- 使用方案应公示
- 使用情况应定期公告
- 接受业主监督

**审计监督:**
- 业委会可委托审计
- 物业主管部门监督

## 六、物业保修

### 6.1 建设单位保修责任

**保修范围和期限(《建设工程质量管理条例》):**

| 项目 | 最低保修期限 |
|------|--------------|
| 地基基础和主体结构 | 合理使用年限 |
| 屋面防水 | 5年 |
| 卫生间、房间、外墙面防渗漏 | 5年 |
| 供热与供冷系统 | 2个采暖期、供冷期 |
| 电气管线、给排水管道、设备安装 | 2年 |
| 装修工程 | 2年 |

**起算时间:** 自竣工验收合格之日起

**保修义务(浙江省条例第51条):**
- 住宅物业质量保证书应载入物业买卖合同
- 建设单位解散时,应对尚在保修期内的物业保修责任作出安排
- 未按规定清算造成损害的,业主可向相关主体主张赔偿

### 6.2 维修养护责任

**专有部分:** 业主自行维修

**共有部分:**
- 保修期内:建设单位负责
- 保修期外:使用专项维修资金或业主分摊

**责任人不明确:**
```
存在安全隐患 → 责任人应及时维修 → 
责任人不履行 → 经业主大会或业委会同意 → 
物业服务人代为维修 → 费用由责任人承担
```

## 七、常见纠纷处理

### 7.1 物业费纠纷

**Q1: 房屋未入住,是否需要交物业费?**
A: 
- 原则:需要交纳
- 理由:物业服务已提供,公共服务已发生成本
- 例外:合同明确约定未入住可减免的除外
- 实务:部分地区规定未入住可打折(如70%-90%)

**Q2: 对物业服务不满意,能否拒交物业费?**
A:
- 不能直接拒交
- 正确做法:
  1. 向业委会反映
  2. 通过业主大会更换物业公司
  3. 向物业主管部门投诉
  4. 服务确有问题可要求减免,但需证据

**Q3: 物业费能否涨价?**
A:
- 需经业主大会决定
- 政府指导价的,应符合定价程序
- 市场调节价的,应与业主协商一致

### 7.2 维修资金纠纷

**Q1: 专项维修资金使用慢怎么办?**
A:
- 查看是否符合使用条件
- 确属紧急情况可走简易程序
- 可向物业主管部门投诉

**Q2: 维修资金被挪用怎么办?**
A:
- 向物业主管部门举报
- 业主大会可更换业委会
- 可以要求审计
- 涉嫌犯罪的报警

### 7.3 业委会纠纷

**Q1: 业委会不作为怎么办?**
A:
- 20%以上业主提议召开临时业主大会
- 业委会不召集的,物业主管部门、街道、居委会应指导召开
- 可质询、撤销决定或改选业委会

**Q2: 业委会成员利益输送怎么办?**
A:
- 向物业主管部门举报
- 业主大会罢免
- 涉嫌犯罪的报警
- 可以起诉要求赔偿

### 7.4 邻里纠纷

**Q1: 楼上漏水怎么办?**
A:
- 先确定责任:
  - 专有部分问题:楼上业主负责
  - 共有部分问题:动用维修资金或相关业主分摊
- 协商不成可起诉
- 保留证据(照片、鉴定报告等)

**Q2: 邻居噪音扰民怎么办?**
A:
- 向物业服务人反映,由其劝阻
- 向业委会投诉
- 向环保部门、公安机关投诉
- 协商不成可起诉要求停止侵害、赔偿损失

**Q3: 违建怎么办?**
A:
- 向物业服务人、业委会反映
- 向城管部门、规划部门举报
- 物业服务人有义务劝阻、制止并报告

## 八、实务操作指南

### 8.1 成立业主大会操作指南

**第一步:确认条件**
- [ ] 交付面积达60%以上,或
- [ ] 首套交付满2年且达30%以上

**第二步:申请筹备**
- [ ] 向物业主管部门或街道提交申请
- [ ] 提交:房屋交付证明、业主名册等

**第三步:成立筹备组**
- [ ] 业主推举代表(一般5-11人)
- [ ] 建设单位指派代表
- [ ] 居委会指派代表
- [ ] 3日内公告筹备组名单

**第四步:筹备工作**
- [ ] 核实业主身份、人数、面积
- [ ] 起草《业主大会议事规则》
- [ ] 起草《管理规约》
- [ ] 确定首次会议时间、地点、议题

**第五步:召开首次业主大会**
- [ ] 会议前15日通知全体业主
- [ ] 告知物业主管部门、街道、居委会
- [ ] 审议通过议事规则、管理规约
- [ ] 选举产生业主委员会
- [ ] 做好会议记录

**第六步:业委会备案**
- [ ] 选举产生后30日内备案
- [ ] 提交:会议记录、决定、议事规则、管理规约、委员名单
- [ ] 取得备案证明
- [ ] 刻制印章

### 8.2 选聘物业服务企业操作指南

**第一步:启动程序**
- [ ] 业委会提出选聘方案
- [ ] 业主大会审议通过

**第二步:招标准备(住宅物业应招标)**
- [ ] 编制招标文件
- [ ] 明确服务内容、质量要求
- [ ] 确定评分标准
- [ ] 发布招标公告

**第三步:评标**
- [ ] 组建评标小组(业主代表为主)
- [ ] 听取投标单位介绍
- [ ] 评分
- [ ] 确定中标单位

**第四步:公示与签约**
- [ ] 中标结果公示(不少于3天)
- [ ] 业委会与中标单位签订物业服务合同
- [ ] 合同报物业主管部门备案

**第五步:交接**
- [ ] 原物业移交资料、用房
- [ ] 新物业承接验收
- [ ] 做好移交记录

### 8.3 更换物业服务企业操作指南

**第一步:提出更换提议**
- [ ] 20%以上业主提议,或
- [ ] 业委会提出

**第二步:召开业主大会**
- [ ] 提前15日通知
- [ ] 表决是否解聘现物业
- [ ] 需双2/3通过

**第三步:通知现物业**
- [ ] 提前通知(一般提前3个月,看合同约定)
- [ ] 原物业应配合做好移交准备

**第四步:选聘新物业**
- [ ] 按选聘流程进行
- [ ] 新旧物业交接时间衔接

**第五步:办理交接**
- [ ] 原物业移交:
  - 物业服务用房
  - 竣工资料
  - 共用部位、设施设备清单
  - 业主名册
  - 财务账册(酬金制)
- [ ] 新物业承接验收
- [ ] 签署交接记录

### 8.4 使用维修资金操作指南

**第一步:确定维修项目**
- [ ] 物业服务人或业委会组织勘查
- [ ] 确定维修方案
- [ ] 编制费用预算

**第二步:公示方案**
- [ ] 在显著位置公示(不少于7天)
- [ ] 公示内容:维修范围、内容、预算、费用分摊

**第三步:业主表决**
- [ ] 一般情况:双2/3表决
- [ ] 紧急情况:可先使用,事后补办

**第四步:申请拨付**
- [ ] 向专户管理银行提交:
  - 业主大会决议(或紧急情况说明)
  - 维修方案
  - 费用预算
  - 施工合同

**第五步:实施维修**
- [ ] 组织施工
- [ ] 监督施工质量
- [ ] 验收

**第六步:费用结算**
- [ ] 凭发票结算
- [ ] 公示使用情况
- [ ] 建立使用档案

## 九、维权指南

### 9.1 投诉渠道

**物业服务问题:**
1. 物业服务人 → 客服投诉
2. 业委会 → 监督协调
3. 物业主管部门 → 12345热线
4. 街道办、居委会 → 调解协调

**违法违规行为:**
- 违建:城管、规划部门
- 噪音:环保、公安
- 消防隐患:消防部门
- 违反治安:公安机关

### 9.2 诉讼指南

**物业费纠纷诉讼:**
- 原告:物业服务人
- 被告:业主
- 管辖:物业所在地法院
- 诉讼时效:3年
- 证据:物业服务合同、催款通知、服务证据

**要求业委会履职诉讼:**
- 原告:业主
- 被告:业委会
- 诉求:要求履行职责、撤销不当决定

**相邻关系纠纷诉讼:**
- 原告:受侵害业主
- 被告:侵权业主
- 诉求:停止侵害、排除妨碍、赔偿损失

### 9.3 证据收集

**物业服务纠纷:**
- 物业服务合同
- 缴费凭证/催款通知
- 服务质量证据(照片、视频、投诉记录)
- 业主大会决议

**维修资金纠纷:**
- 交纳凭证
- 使用申请
- 公示材料
- 银行流水

**侵权纠纷:**
- 现场照片、视频
- 鉴定报告(如房屋鉴定、噪音检测)
- 证人证言
- 报警记录、投诉记录

## 十、重点提示

### 业主应知应会

**作为业主,你应该知道:**
1. ✅ 你有权参加业主大会,行使表决权
2. ✅ 你有权查阅物业服务信息和财务账目
3. ✅ 你有权对物业服务提出意见和建议
4. ✅ 你有义务按时交纳物业费和维修资金
5. ✅ 你有义务遵守管理规约
6. ✅ 改变房屋用途、外观需依法经其他业主同意
7. ✅ 利用共有部分需经业主大会同意
8. ✅ 未入住也需交物业费(除非合同另有约定)

**重要表决事项记住两个数字:**
- **双过半**:面积过半+人数过半(一般事项)
- **双2/3**:面积2/3以上+人数2/3以上(重大事项)

### 业委会应知应会

**作为业委会成员,你应该做到:**
1. ✅ 定期召开业主大会
2. ✅ 监督物业服务企业履约
3. ✅ 及时向业主公开物业服务和经营信息
4. ✅ 维护全体业主合法权益,不谋私利
5. ✅ 按时换届,做好移交
6. ✅ 妥善保管业主大会印章、资料
7. ✅ 接受物业主管部门监督指导
8. ✅ 配合居委会工作

**禁止行为:**
- ❌ 利用职务便利谋取私利
- ❌ 挪用、侵占业主共有财产
- ❌ 与物业服务企业串通损害业主利益
- ❌ 拒不召开业主大会
- ❌ 拒不移交资料

### 物业服务人应知应会

**作为物业服务企业,你应该做到:**
1. ✅ 按合同约定提供服务
2. ✅ 定期公开服务信息和收费情况
3. ✅ 及时答复业主询问和投诉
4. ✅ 对违法违规行为及时劝阻、制止、报告
5. ✅ 做好承接查验和退出移交
6. ✅ 不得以停水停电等方式催缴物业费
7. ✅ 共有部分经营收益归业主所有
8. ✅ 物业服务用房不得挪作他用
