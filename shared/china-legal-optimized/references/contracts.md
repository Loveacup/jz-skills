## 核心法律要点

### 一、合同效力判断(重大更新)

#### 强制性规定的新标准

《合同编通则司法解释》第16条改变了以往"效力性/管理性"的区分方法,采用"规范目的"标准:

**违反强制性规定但合同仍有效的情形:**
1. 强制性规定旨在促进交易而非限制交易
2. 规定针对合同订立后的履行行为
3. 履行行为违法但合同内容不违法
4. 行政处罚已足以实现规范目的

**合同无效的情形(民法典153条):**
1. 影响国家安全(政治/经济/军事)
2. 损害社会公共利益
3. 严重违背公序良俗
4. 规避法律强制性规定

**实务要点:**
- 不再机械区分效力性/管理性强制规定
- 重点审查规范目的和社会影响
- 轻微违法不导致合同无效

### 二、合同订立关键规则

#### 1. 招投标合同成立时间(司法解释第4条)

**成立时点:** 中标通知书到达中标人时

**合同内容确定:**
- 优先按书面合同
- 拒签时:依招标文件+投标文件+中标通知书确定

#### 2. 预约合同 vs 意向书(司法解释第6条)

**预约合同成立条件:**
- 约定将来一定期限内订立合同
- 能确定将来合同的主体、标的

**不构成预约:**
- 仅表达交易意向
- 无明确期限约定
- 无法确定未来合同要素

#### 3. 无权处分不影响合同效力(司法解释第10条)

**核心变化:**
- 无处分权不导致合同无效
- 但影响合同履行和物权变动
- 权利人追认后有效

### 三、合同履行核心规则

#### 1. 法定代表人越权(司法解释第20条)

**越权情形分类:**

**情形一:超越法律规定的代表权限**
- 未经权力机构/决策机构决议
- 相对人未尽合理审查义务 → 合同不生效
- 相对人已尽审查义务 → 表见代表有效

**情形二:超越章程限制但未超法律权限**
- 原则上对公司有效
- 除非证明相对人知道或应知道该限制

**追责规则:**
- 公司承担责任后可向越权代表人追偿

#### 2. 第三人利益合同(民法典522条)

**两种类型:**
- 向第三人履行的合同
- 第三人可直接请求履行的合同

**法律效果:**
- 第三人未明确拒绝前,有权直接请求履行
- 债务人可向第三人主张对债权人的抗辩

### 四、合同审核八大要素详解

#### 1. 主体资格审查

**必查事项:**
- [ ] 营业执照/身份证明
- [ ] 经营范围是否包含合同事项
- [ ] 特殊资质(许可证、备案等)
- [ ] 法定代表人身份证明
- [ ] 授权委托书(若代理人签署)

**风险点:**
- 超经营范围签约(一般不影响效力,但特殊行业除外)
- 授权不清晰或无权代理
- 分支机构签约主体错误

#### 2. 标的条款审查

**必备要素:**
- 名称和规格明确
- 数量和计量单位清晰
- 质量标准(国标/行标/约定标准)
- 验收方法和标准

**常见问题:**
- 标的描述模糊("若干""适当""合理")
- 质量标准援引过时版本
- 验收标准缺失或单方决定

**修改建议模板:**
```
🔴 高风险:标的描述不明确
【原文】"乙方提供优质的服务"
【问题】"优质"标准主观,易生争议
【法律依据】民法典512条要求标的确定
【建议】修改为:"乙方提供符合ISO9001标准的XX服务,
具体包括:(1)...(2)...(3)...验收标准为..."
```

#### 3. 价款条款审查

**必审要素:**
- [ ] 总价和单价
- [ ] 付款方式(现金/转账/承兑)
- [ ] 付款时间和条件
- [ ] 发票类型和开具时间
- [ ] 税费承担约定

**典型风险:**
```
🟡 中风险:付款时间不明确
"验收合格后付款" → 应明确"验收合格后X个工作日内"

🔴 高风险:价格调整机制缺失
大宗商品、长期合同未约定价格调整条款

🟡 中风险:税费承担不清
应明确:"本合同价款为含税价/不含税价,增值税发票由X方开具"
```

#### 4. 履行条款审查

**时间要素:**
- 具体日期 or 明确的时间计算方式
- 逾期后的宽限期约定
- 延期条件和程序

**地点要素:**
- 交付地点明确(具体地址)
- 运输方式和费用承担
- 风险转移时点

**方式要素:**
- 交付方式(一次性/分批)
- 验收程序(时限、标准、异议期)
- 留置和拒收条件

#### 5. 权利义务平衡审查

**单方权利条款警示:**
- 单方解除权(是否对等)
- 单方变更权(是否合理)
- 单方价格调整权(是否有限制)

**义务免除条款警示:**
```
🔴 禁止条款:
"甲方对产品质量不承担任何责任"
"甲方有权单方面解释本合同"
→ 违反民法典496条,属于无效格式条款
```

#### 6. 违约责任审查

**必备要素:**
- [ ] 违约情形明确列举
- [ ] 违约金计算方法
- [ ] 损失赔偿范围
- [ ] 救济措施(继续履行/解除/替代方案)

**违约金条款设计:**
```
合理设置:
"逾期交付的,每逾期一日,支付合同总价0.5‰的违约金,
累计不超过合同总价10%"

过高风险:
"逾期交付的,违约金为合同总价100%" 
→ 可能被调整(民法典585条)

过低风险:
"违约方支付1元违约金"
→ 可能因显失公平被调整
```

#### 7. 争议解决条款

**管辖约定:**
```
✓ 有效约定:
"因本合同引起的争议,由被告住所地/合同履行地/
合同签订地/原告住所地/标的物所在地人民法院管辖"

✗ 无效约定:
"由甲方所在地法院管辖"(未明确具体联系点)
```

**仲裁约定:**
```
✓ 有效约定:
"提交北京仲裁委员会按其仲裁规则仲裁"

✗ 无效约定:
"可以诉讼也可以仲裁"(或裁或审,不明确)
"提交仲裁机构仲裁"(未明确仲裁委)
```

#### 8. 其他条款

**保密条款要点:**
- 保密信息范围
- 保密期限(通常2-5年)
- 泄密责任和违约金

**知识产权条款:**
- 权利归属(甲方/乙方/共有)
- 使用许可范围
- 侵权责任承担

**不可抗力条款:**
- 定义范围(自然灾害/政府行为/战争)
- 通知义务(时限和方式)
- 法律后果(免责/延期/解除)

### 五、常见合同类型特殊要点

#### 商业租赁合同

**必审要点:**
- 租赁物权属证明
- 出租人是否为产权人(若否,需权利人同意)
- 租期(超20年部分无效)
- 租金调整机制
- 装修归属和补偿
- 优先承租权/购买权
- 提前解约条件

**高频风险:**
```
🔴 转租未经同意
🔴 租期超过出租人剩余租期
🟡 装修费用承担不明
```

#### 服务合同

**必审要点:**
- 服务内容具体化(避免"等""相关"等模糊词)
- 服务标准(行业标准/约定标准)
- 成果交付标准和时间
- 知识产权归属
- 保密义务

#### 采购/销售合同

**必审要点:**
- 货物所有权转移时点
- 风险转移时点
- 包装和运输标准
- 检验时限和异议期
- 质保期和质保内容

## 快速检索:常见问题

**Q: 对方要求签"阴阳合同"怎么办?**
A: 明确拒绝。根据民法典146条,虚假意思表示部分无效,且可能涉嫌偷税等违法行为。

**Q: 格式合同什么条款无效?**  
A: 民法典496-498条规定,免除己方责任、加重对方责任、排除对方主要权利的格式条款无效。

**Q: 合同没盖章有效吗?**
A: 未盖章不必然无效。民法典490条规定,实际履行主要义务并被接受的,合同成立。

**Q: 口头合同有效吗?**
A: 一般有效,但法律要求书面形式的除外(如房地产转让、融资租赁等)。

**Q: 违约金过高怎么办?**
A: 可申请调整。司法实践一般认为超过损失30%为过高,法院可调整至损失的130%左右。
