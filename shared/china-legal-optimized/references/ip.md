## 一、专利保护

### 1.1 专利类型与保护期限

| 专利类型 | 保护对象 | 保护期限 | 特点 |
|----------|----------|----------|------|
| 发明专利 | 产品、方法、用途 | 20年 | 技术含量高,审查严格 |
| 实用新型 | 产品的形状、构造 | 10年 | "小发明",审查较简单 |
| 外观设计 | 产品外观 | 15年 | 2021年从10年延长至15年 |

**起算点:** 均自申请日起计算

### 1.2 专利申请流程

#### 发明专利流程
```
提交申请 → 初步审查(3-6个月) → 公开 → 实质审查(18-24个月) → 授权
总周期: 2-3年
```

**关键时间节点:**
- 申请日:确定优先权
- 公开日:申请后18个月自动公开(可提前公开)
- 实审请求:申请日起3年内必须提出

#### 实用新型/外观设计流程
```
提交申请 → 初步审查 → 授权
实用新型周期: 6-12个月
外观设计周期: 4-6个月
```

**2024年新规(专利法实施细则):**
- 实用新型审查范围扩大至创造性
- 外观设计需满足"明显区别"要求
- 审查标准提高,专利质量提升

### 1.3 专利申请材料

**发明/实用新型:**
- [ ] 请求书
- [ ] 说明书(含技术领域、背景技术、发明内容、附图说明、具体实施方式)
- [ ] 权利要求书(核心!)
- [ ] 说明书附图
- [ ] 摘要及摘要附图

**外观设计:**
- [ ] 请求书
- [ ] 图片或照片(六视图+立体图)
- [ ] 简要说明

**重点提示:**
- 权利要求书决定保护范围,需精心撰写
- 说明书要充分公开,能使本领域技术人员实现
- 外观设计以图片为准,简要说明为辅

### 1.4 专利权期限补偿制度(2021新增)

**两种补偿:**

**1. 审查延迟补偿**
- 条件:申请日起4年+实审请求日起3年后才授权
- 补偿:不合理延迟的天数
- 排除:申请人自身原因导致的延迟

**2. 新药上市补偿**
- 适用:在中国获批上市的新药专利
- 补偿期限:最多5年
- 总保护期限:批准上市后不超过14年

### 1.5 专利侵权判定

**判定标准:**

**全面覆盖原则:**
被控侵权产品/方法的技术特征与专利权利要求的**全部**技术特征相同或等同

**等同原则:**
- 手段基本相同
- 功能基本相同
- 效果基本相同
- 本领域普通技术人员无需创造性劳动即可联想到

**不视为侵权的情形:**
- 专利权用尽(合法购买后使用、销售)
- 先用权(在申请日前已制造相同产品或作好准备)
- 临时过境
- 科研实验目的
- 行政审批需要(如药品注册)

### 1.6 专利侵权救济

**民事救济:**
- 停止侵权
- 赔偿损失
- 消除影响、赔礼道歉

**赔偿计算顺序:**
1. 权利人损失
2. 侵权人获利
3. 许可费的合理倍数(通常1-3倍)
4. 法定赔偿:3万-500万元(惩罚性赔偿可达5倍)

**行政救济:**
- 责令停止侵权
- 没收、销毁侵权产品
- 罚款

**刑事救济:**
假冒专利罪

## 二、商标保护

### 2.1 商标注册流程

```
商标查询 → 提交申请 → 形式审查(1个月) → 实质审查(6-9个月) → 
初审公告(3个月) → 注册公告 → 领证

总周期: 12-18个月
```

### 2.2 商标分类

**国际分类:** 45个类别
- 第1-34类:商品
- 第35-45类:服务

**重要原则:**
- 一标一类:一个商标在一个类别内申请
- 类似商品/服务:需查询《类似商品和服务区分表》

**常见类别:**
```
第9类:  计算机软件、APP
第25类: 服装鞋帽
第30类: 方便食品、调味品
第35类: 广告、商业管理(必选!)
第42类: 软件开发、云服务
```

### 2.3 商标注册要求

**不得作为商标的标志:**
- 国旗、国徽、国歌等
- 红十字、红新月
- 带有民族歧视性
- 夸大宣传并带有欺骗性
- 有害于社会主义道德风尚
- 县级以上行政区划地名(地理标志除外)

**不得注册为商标:**
- 仅有商品通用名称、图形、型号
- 仅表示商品质量、主要原料、功能等
- 缺乏显著特征(但使用取得显著特征的可注册)

**驳回情形:**
- 与在先商标相同或近似
- 抢注他人已使用并有一定影响的商标
- 损害他人在先权利(姓名权、著作权等)

### 2.4 商标使用与维护

**使用要求:**
- 注册后连续3年不使用,可被撤销
- 使用时不得改变注册商标
- 商标许可他人使用需备案

**续展:**
- 有效期:10年(自核准注册之日起)
- 续展期:期满前12个月内
- 宽展期:期满后6个月内(需加收费用)
- 每次续展10年,可无限续展

**商标变更:**
- 商标注册人名义、地址变更需及时办理
- 未及时办理可能导致商标被撤销

### 2.5 商标侵权行为

**典型侵权:**
1. 未经许可在同一商品使用相同商标
2. 在同一商品使用近似商标,易混淆
3. 在类似商品使用相同/近似商标,易混淆
4. 伪造、擅自制造商标标识或销售该标识
5. 更换商标并再次销售(反向假冒)
6. 为侵权提供便利条件

**判定要点:**
- 商标近似:视觉、听觉、含义上易混淆
- 商品类似:功能、用途、销售渠道等相近
- 混淆可能性:普通消费者标准

### 2.6 驰名商标特殊保护

**认定条件:**
- 相关公众知晓程度
- 使用持续时间
- 宣传工作的持续时间、程度和地域范围
- 作为驰名商标受保护的记录
- 其他因素

**特殊保护:**
- 跨类别保护
- 禁止作为企业名称使用
- 域名保护

## 三、著作权保护

### 3.1 作品类型

**受保护的作品:**
- 文字作品
- 口述作品
- 音乐、戏剧、曲艺、舞蹈作品
- 美术、建筑作品
- 摄影作品
- 视听作品(原"电影作品")
- 工程设计图、产品设计图、地图、示意图
- 计算机软件
- 符合作品特征的其他智力成果

**不受保护:**
- 法律、法规、决议、决定、命令
- 时事新闻
- 历法、通用数表、公式

### 3.2 著作权内容

**人身权(不可转让):**
- 发表权
- 署名权
- 修改权
- 保护作品完整权

**财产权(可转让):**
- 复制权
- 发行权
- 出租权
- 展览权
- 表演权
- 放映权
- 广播权
- 信息网络传播权
- 摄制权
- 改编权
- 翻译权
- 汇编权

### 3.3 著作权保护期

| 权利类型 | 保护期限 | 起算点 |
|----------|----------|--------|
| 署名权等人身权 | 不受限制 | - |
| 自然人财产权 | 作者终生+50年 | 作者死亡后第50年12月31日 |
| 法人/组织财产权 | 50年 | 首次发表后第50年12月31日 |
| 电影作品 | 50年 | 首次发表后第50年12月31日 |

### 3.4 合理使用(不需许可不付费)

**法定情形:**
1. 个人学习、研究、欣赏
2. 介绍、评论某作品或说明某问题时适当引用
3. 新闻报道中不可避免地再现或引用
4. 报刊、电台、电视台刊登/播放其他媒体已发表的时事性文章
5. 免费表演(非营利,未向公众收费,未支付报酬)
6. 陈列、展示作品
7. 国家机关为执行公务使用
8. 图书馆、档案馆、博物馆等为保存版本需要复制
9. 免费向公众提供的作品
10. 把汉字翻译成少数民族文字或盲文
11. 法律、行政法规规定的其他情形

**要求:**
- 指明作者姓名、作品名称
- 不得侵犯著作权人的其他权利

### 3.5 软件著作权登记

**登记材料:**
- 软件著作权登记申请表
- 软件鉴别材料(源代码+文档)
- 相关证明文件

**登记周期:** 30-60个工作日(可加急)

**作用:**
- 确权证据
- 融资、交易必备
- 享受税收优惠
- 高企认定材料

### 3.6 著作权侵权救济

**侵权行为:**
- 未经许可复制、发行、表演、放映、广播、汇编、网络传播
- 剽窃他人作品
- 歪曲、篡改他人作品

**法定赔偿:** 500元-500万元

## 四、商业秘密保护

### 4.1 构成要件

**必备条件(缺一不可):**
1. **不为公众所知悉**
   - 非公开信息
   - 不能从公开渠道直接获得

2. **具有商业价值**
   - 能带来经济利益
   - 具有实用性

3. **采取相应保密措施**
   - 签订保密协议
   - 限定知悉范围
   - 标注密级
   - 技术措施(加密、权限控制等)

### 4.2 常见类型

**技术信息:**
- 设计、程序、产品配方、工艺流程
- 改进技术、设计方案、实验数据
- 制作方法、技术秘诀

**经营信息:**
- 客户名单、供应商信息
- 产销策略、采购资料
- 招投标标底、标书内容
- 经营计划、财务数据

### 4.3 侵权行为

**违法获取:**
- 盗窃、利诱、胁迫
- 电子侵入
- 其他不正当手段

**违法披露/使用:**
- 员工违反保密义务
- 第三方违反保密协议
- 明知是侵权获得仍使用

### 4.4 竞业限制

**适用对象:**
- 高级管理人员
- 高级技术人员
- 其他负有保密义务的人员

**期限:** 最长2年(自解除或终止劳动合同之日起)

**补偿金:**
- 需支付竞业限制补偿
- 一般为月工资的30%以上
- 未按约定支付的,员工可解除竞业限制

**违约金:**
- 可约定违约金
- 但需合理,过高可调整

## 五、知识产权综合

### 5.1 侵权赔偿计算

**统一规则(专利/商标/著作权):**

**第一顺位:权利人实际损失**
```
销量减少 × 单位利润 + 调查费用
```

**第二顺位:侵权人违法所得**
```
侵权产品销量 × 单位利润
```

**第三顺位:许可费合理倍数**
```
正常许可使用费 × (1-3倍)
```

**第四顺位:法定赔偿**
- 专利:3万-500万元
- 商标:3万-500万元
- 著作权:500元-500万元

**惩罚性赔偿(2019年后):**
- 故意侵权+情节严重
- 赔偿数额:上述计算结果的1-5倍

### 5.2 知识产权海关保护

**备案:**
- 向海关总署备案
- 有效期:10年

**边境措施:**
- 海关依职权扣留
- 权利人申请扣留

**程序:**
```
发现侵权嫌疑货物 → 海关通知权利人 → 权利人提供担保 → 
海关扣留(20天) → 海关调查或当事人起诉 → 处置
```

### 5.3 电商平台知识产权保护

**"通知-删除"规则:**

**权利人通知:**
- 权利证明
- 侵权初步证据
- 侵权链接

**平台处理:**
- 收到通知后及时删除/屏蔽
- 转送通知给经营者

**经营者反通知:**
- 不侵权声明
- 身份证明
- 联系方式

**平台恢复:**
- 收到反通知后15日内恢复
- 除非权利人起诉

### 5.4 知识产权海外保护

**PCT国际专利申请:**
- 一次申请,多国生效
- 优先权期限:12个月(发明/实用新型)

**马德里商标国际注册:**
- 一次注册,多国保护
- 基于国内注册或申请

**伯尔尼公约(著作权):**
- 自动保护,无需注册
- 国民待遇原则

## 快速检索

### Q&A

**Q1: 如何判断是申请发明还是实用新型?**
A: 
- 方法、用途 → 只能申请发明
- 产品 → 可申请发明(保护期长,审查严)或实用新型(授权快)
- 可同时申请,获发明专利后放弃实用新型

**Q2: 商标被抢注怎么办?**
A:
- 公告期内(3个月):提异议
- 已注册未满5年:提无效宣告
- 连续3年未使用:申请撤销

**Q3: 软件源代码是否受著作权保护?**
A: 是。软件属于文字作品,源代码自完成之日自动受保护,登记非必须但建议。

**Q4: 员工离职带走客户名单算侵权吗?**
A: 若客户名单构成商业秘密(不公开+有价值+有保密措施),则构成侵犯商业秘密。

**Q5: 如何证明自己是作品的作者?**
A:
- 作品上的署名
- 创作底稿、原件
- 著作权登记证书
- 发表记录、合同

**Q6: 专利申请后能否修改?**
A:
- 发明:可在实审阶段主动修改2次
- 所有专利:答复审查意见时被动修改
- 不得超出原说明书和权利要求书范围

**Q7: 外观设计专利和著作权冲突怎么办?**
A: 可同时保护,不冲突。但侵权救济选其一。

**Q8: 网络图片可以随便用吗?**
A: 不可以。需获得著作权人许可,或符合合理使用情形。

## 实务建议

### 知识产权战略

**初创企业:**
1. 商标先行(核心类别+35类)
2. 软件及时登记
3. 核心技术申请专利
4. 建立商业秘密保护制度

**成长期企业:**
1. 商标全类保护
2. 专利组合布局
3. PCT/马德里国际申请
4. 知识产权尽调(投融资前)

**成熟企业:**
1. 知识产权运营(许可、转让)
2. 专利池、标准必要专利
3. 海外维权
4. 知识产权诉讼

### 常见风险

**高频风险点:**
- ❌ 商标使用与注册不一致
- ❌ 专利申请前公开技术方案
- ❌ 忽视员工职务发明
- ❌ 保密措施不到位
- ❌ 跨境电商侵权

**风险防控:**
- ✅ 申请前保密
- ✅ 明确职务发明归属
- ✅ 完善保密制度
- ✅ 使用前FTO检索(Freedom to Operate)
- ✅ 定期监测侵权
