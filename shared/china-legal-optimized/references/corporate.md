# 公司治理参考文档

## 法律版本信息

| 法律/法规 | 版本 | 生效日期 | 重大变化 |
|-----------|------|----------|----------|
| 《公司法》 | 2023年修订 | 2024-07-01 | 注册资本5年实缴、董事会强制等 |
| 《注册资本登记管理规定》 | 国务院令 | 2024-07-01 | 存量公司过渡期至2027-06-30 |
| 《公司登记管理条例》 | 修订版 | 2024-07-01 | 配套新公司法 |

## 一、注册资本制度(2024核心变化)

### 1.1 新设公司规则

**基本要求:**
```
有限责任公司: 自成立之日起5年内缴足注册资本
股份有限公司: 发起人应在公司成立前按认购股份全额缴纳股款
```

**无最低限额:** 取消了注册资本最低限额要求(除法律、行政法规另有规定)

**特殊规定行业:**
- 银行业金融机构
- 证券公司
- 期货公司
- 保险公司
- 等其他法律法规有规定的行业

### 1.2 存量公司过渡期(重点!)

**适用范围:** 2024年6月30日前登记设立的公司

**调整要求:**

**有限责任公司:**
```
2027年7月1日起剩余出资期限超过5年的
  ↓
必须在2027年6月30日前调整至5年内
  ↓
股东在调整后的期限内足额缴纳
```

**股份有限公司:**
```
发起人应在2027年6月30日前按认购股份全额缴纳股款
```

**关键时间点:**
- 2024年7月1日: 新公司法施行
- 2027年6月30日: 过渡期截止
- 2027年7月1日: 所有公司必须符合新规

**豁免情形:**
生产经营涉及国家利益或重大公共利益的公司,经国务院有关部门或省级政府提出意见,市场监管总局同意,可按原期限出资。

### 1.3 五种应对方案

**方案一: 减少注册资本**
- 适用: 认缴过高,实际无需这么多
- 流程: 股东会决议 → 编制资产负债表和财产清单 → 通知债权人 → 公示45天 → 登记变更
- 成本: 公示费+登记费
- 风险: 债权人可能要求提前清偿或提供担保

**方案二: 按期实缴**
- 适用: 有能力在5年内实缴
- 操作: 按计划分期缴纳
- 优势: 保持公司规模,有利于招投标、融资
- 注意: 需真实出资,不得虚假出资

**方案三: 股权转让**
- 适用: 部分股东无力实缴
- 操作: 转让给有实缴能力的受让方
- 风险: 原股东对受让人未按期缴纳的出资承担补充责任(新公司法第88条)

**方案四: 引入新股东增资**
- 适用: 需要资金且愿意稀释股权
- 操作: 新股东实缴出资 → 增加注册资本
- 优势: 引入资金和资源
- 风险: 股权稀释,控制权变化

**方案五: 注销公司**
- 适用: 公司无继续经营必要
- 操作: 清算 → 注销登记
- 成本: 清算费用,需处理债权债务
- 风险: 清算责任

### 1.4 出资方式

**法定出资方式:**
1. **货币** (最直接)
2. **实物** (房产、设备等)
3. **知识产权** (专利、商标、著作权)
4. **土地使用权**
5. **股权** (其他公司的股权)
6. **债权** (对公司的债权转为出资)
7. **其他可以用货币估价并依法转让的非货币财产**

**禁止出资:**
- 劳务
- 信用
- 自然人姓名
- 商誉
- 特许经营权
- 设定担保的财产

**非货币出资要求:**
- 需评估作价
- 办理财产权转移手续
- 出资后不得抽逃

**出资比例限制(已取消):**
2024年新公司法取消了"非货币出资不得超过70%"的限制

### 1.5 股东出资责任

**未按期出资的后果:**

**1. 向公司补缴(第51条)**
```
公司或已按期足额缴纳出资的股东
  ↓
书面催缴,宽限期不少于60日
  ↓
宽限期届满仍未缴纳
  ↓
股东失权或减资
```

**2. 对其他股东承担违约责任**

**3. 加速到期(第54条,重大变化!)**
```
公司不能清偿到期债务
  ↓
公司或到期债权人
  ↓
可要求未届出资期限的股东提前缴纳
```

**4. 对债权人承担补充赔偿责任**
```
公司财产不足以清偿债务
  ↓
未缴/未足额缴纳出资的股东
  ↓
在未出资本息范围内对债务承担补充赔偿责任
```

**5. 股权转让后的责任(第88条,新增!)**
```
转让时未届出资期限 → 受让人未按期缴纳
  ↓
受让人承担缴纳责任
  ↓
受让人未按期缴纳
  ↓
转让人对受让人未按期缴纳的出资承担补充责任
```

**提示:** 转让未实缴股权时,务必约定明确由受让人缴纳,并保留证据!

### 1.6 虚假出资/抽逃出资

**虚假出资:**
- 虚报注册资本
- 提交虚假材料
- 虚假出资(未交付货币/未转移财产权)

**抽逃出资:**
- 制作虚假财务报表虚增利润分配
- 通过虚构债权债务关系转移资金
- 利用关联交易转移资金
- 其他未经法定程序抽回出资的行为

**法律后果:**
- 补缴出资
- 返还抽逃出资
- 对其他股东/债权人承担责任
- 罚款(公司登记机关)
- 刑事责任(虚报注册资本罪、虚假出资抽逃出资罪)

## 二、公司治理结构

### 2.1 有限责任公司组织机构

#### 股东会

**职权(第61条):**
1. 决定公司经营方针和投资计划
2. 选举和更换董事、监事
3. 审议批准董事会、监事会报告
4. 审议批准年度财务预算方案、决算方案
5. 审议批准利润分配方案、弥补亏损方案
6. 对公司增减注册资本作出决议
7. 对发行公司债券作出决议
8. 对公司合并、分立、解散、清算或变更公司形式作出决议
9. 修改公司章程
10. 公司章程规定的其他职权

**决议方式:**
- 普通决议: 代表1/2以上表决权通过
- 特别决议: 代表2/3以上表决权通过(修改章程、增减资本、合并分立解散、变更公司形式)

**会议要求:**
- 每年至少召开一次定期会议
- 代表1/10以上表决权股东可提议召开临时会议
- 提前15日通知全体股东(章程另有规定或全体股东另有约定除外)

#### 董事会

**新规: 强制设立董事会(重大变化!)**
```
旧规: 股东人数较少或规模较小的,可不设董事会,设1名董事
新规: 所有有限公司必须设董事会,成员3-13人(第67条)
      但有限制性规定: 公司章程可规定不设董事会,仅设1名董事
```

**实际影响:**
- 规范型公司: 必须设董事会
- 小微公司: 可在章程中规定设1名董事

**职权(第68条):**
1. 召集股东会,并向股东会报告工作
2. 执行股东会决议
3. 决定公司经营计划和投资方案
4. 制订年度财务预算、决算方案
5. 制订利润分配方案、弥补亏损方案
6. 制订增减注册资本、发行债券方案
7. 制订合并、分立、解散、变更公司形式方案
8. 决定公司内部管理机构设置
9. 决定聘任/解聘经理及报酬,根据经理提名决定副经理、财务负责人及报酬
10. 制定公司基本管理制度
11. 公司章程规定的其他职权

**董事任期:**
- 每届任期不超过3年,可连选连任
- 任期届满未及时改选,在改选出的董事就任前,原董事仍应履职

#### 监事会

**设置要求:**
- 规模较大的公司: 设监事会,成员不少于3人(职工代表不少于1/3)
- 规模较小的公司: 可设1-2名监事,不设监事会

**职权:**
- 检查公司财务
- 监督董事、高管履职,提出罢免建议
- 要求董事、高管纠正损害公司利益的行为
- 提议召开临时股东会
- 向股东会提出提案
- 对董事、高管提起诉讼
- 公司章程规定的其他职权

### 2.2 股份有限公司组织机构

**三会:**
- 股东大会
- 董事会(成员5-19人)
- 监事会(成员不少于3人,职工代表不少于1/3)

**特别要求:**
- 必须设董事会秘书
- 上市公司必须设独立董事
- 董事会下可设审计委员会等专门委员会

**决议比例:**
- 普通决议: 出席会议股东所持表决权过半数
- 特别决议: 出席会议股东所持表决权2/3以上(修改章程、增减资本、合并分立解散、变更公司形式)

### 2.3 董监高的义务与责任

**忠实义务:**
- 不得利用职权收受贿赂或其他非法收入
- 不得侵占公司财产
- 不得挪用公司资金
- 不得将公司资金以个人名义开户存储
- 不得违反规定借贷公司资金给他人
- 不得自营或为他人经营与所任职公司同类的业务
- 不得利用职务便利为自己或他人谋取本应属于公司的商业机会
- 不得同本公司订立合同或进行交易
- 未经股东会同意不得接受他人给予的财物

**勤勉义务:**
- 谨慎、认真、勤勉地履行职责
- 保证信息披露的真实、准确、完整、及时

**责任追究:**
```
董监高执行职务违法/违章程/过失
  ↓
给公司造成损失
  ↓
应当承担赔偿责任
```

**股东代表诉讼(第189-191条):**
```
董监高损害公司利益
  ↓
监事会/监事或股东书面请求提起诉讼
  ↓
30日内未提起或情况紧急
  ↓
连续180日以上单独或合计持有1%以上股份的股东
  ↓
可以自己名义直接向法院提起诉讼
```

## 三、股权与股东

### 3.1 股东权利

**核心权利:**
1. **参与决策权** - 出席股东会、行使表决权
2. **选举权** - 选举董事、监事
3. **知情权** - 查阅公司章程、会议记录、财务报告等
4. **分红权** - 按出资比例分配利润(章程另有规定除外)
5. **优先购买权** - 股权转让时的优先购买权
6. **剩余财产分配权** - 公司清算后分配剩余财产

**知情权(第57条,扩大!)**

**可查阅、复制:**
- 公司章程
- 股东会会议记录
- 董事会会议决议
- 监事会会议决议
- 财务会计报告
- **会计账簿**(新增,旧法仅可查阅)
- **会计凭证**(新增!)

**行使方式:**
- 书面请求 → 说明目的
- 公司15日内答复
- 拒绝提供 → 股东可请求法院要求提供

**目的限制:**
- 正当目的
- 非为了向他人通报有关信息损害公司合法利益

### 3.2 股权转让

#### 有限公司股权转让

**内部转让:** 自由转让

**对外转让(第84条):**
```
股东拟对外转让股权
  ↓
书面通知其他股东征求同意 + 告知同等条件
  ↓
其他股东自接到书面通知之日起30日内未答复
  ↓
视为同意转让
  ↓
半数以上其他股东不同意
  ↓
应当购买该转让的股权
  ↓
不购买的,视为同意转让
```

**优先购买权:**
- 经股东同意转让的股权,其他股东有优先购买权
- 两个以上股东主张优先购买 → 协商确定购买比例
- 协商不成 → 按转让时各自出资比例购买

**例外情形:**
- 章程另有规定的从其规定
- 股东之间转让不受限制

#### 股份公司股权转让

**上市公司:** 依照证券法规定
**非上市公司:** 
- 发起人股份: 公司成立1年内不得转让
- 公司公开发行前的股份: 公开发行起1年内不得转让
- 其他: 自由转让,在依法设立的证券交易场所或国务院规定的其他方式转让

### 3.3 股东退出机制

**异议股东回购请求权(第89条):**

**适用情形:**
1. 公司连续5年盈利且符合分配条件,但不分配利润
2. 公司合并、分立、转让主要财产
3. 公司章程规定的营业期限届满/出现其他解散事由,股东会通过决议修改章程使公司存续

**行使:**
```
对股东会决议投反对票
  ↓
股东会决议通过之日起60日内
  ↓
与公司协商回购
  ↓
自股东会决议通过之日起90日内协商不成
  ↓
可在协议期限届满后90日内向法院提起诉讼
```

**退股(公司法未规定,实务争议大):**
- 有限公司可在章程中约定退股条件和程序
- 无约定的,一般需其他股东或公司同意

### 3.4 股东滥用权利

**股东滥用权利的责任(第23条):**
```
股东滥用股东权利
  ↓
给公司或其他股东造成损失
  ↓
应当承担赔偿责任
```

**股东滥用公司法人独立地位(人格否认,第24条):**
```
股东滥用法人独立地位和股东有限责任
  ↓
逃避债务、严重损害债权人利益
  ↓
对公司债务承担连带责任
```

**典型情形:**
- 一人公司财产与股东财产混同
- 关联公司人格混同
- 过度控制、资产转移
- 资本显著不足

## 四、公司变更与终止

### 4.1 公司增资

**决议要求:** 股东会特别决议(2/3以上表决权)

**增资方式:**
1. **现有股东认缴** - 按出资比例或约定比例
2. **引入新股东** - 新股东出资
3. **资本公积转增** - 留存收益、资本公积转为注册资本
4. **债转股** - 债权人债权转为股权

**程序:**
```
股东会决议 → 修改章程 → 缴纳出资 → 变更登记
```

### 4.2 公司减资

**决议要求:** 股东会特别决议

**程序(第224条):**
```
编制资产负债表及财产清单
  ↓
股东会作出减资决议
  ↓
10日内通知债权人
  ↓
30日内在报纸或国家企业信用信息公示系统公告
  ↓
债权人自接到通知书之日起30日内/未接到通知的自公告之日起45日内
  ↓
有权要求公司清偿债务或提供相应担保
  ↓
办理变更登记
```

**特别规定:**
- 减资后注册资本不得低于法定最低限额(如有)
- 不得损害债权人利益

### 4.3 公司合并

**类型:**
1. **吸收合并** - A公司 + B公司 → A公司(B公司解散)
2. **新设合并** - A公司 + B公司 → C公司(AB公司解散)

**程序:**
```
各方股东会特别决议
  ↓
签订合并协议
  ↓
编制资产负债表及财产清单
  ↓
10日内通知债权人
  ↓
30日内公告
  ↓
债权人30日/45日内要求清偿或提供担保
  ↓
办理变更/注销登记
```

**债务承继:**
- 吸收合并: 存续公司承继
- 新设合并: 新设公司承继

### 4.4 公司分立

**类型:**
1. **派生分立** - A公司 → A公司 + B公司(A继续存在)
2. **新设分立** - A公司 → B公司 + C公司(A解散)

**程序:** 与合并类似

**债务分配:**
- 分立前的债务由分立后的公司承担连带责任
- 但分立前与债权人另有约定的除外

### 4.5 公司解散

**解散事由(第230条):**
1. 公司章程规定的营业期限届满或出现其他解散事由
2. 股东会决议解散(特别决议)
3. 因合并或分立需要解散
4. 依法被吊销营业执照、责令关闭或被撤销
5. 公司经营管理发生严重困难,继续存续会使股东利益受到重大损失,通过其他途径不能解决,持有公司全部股东表决权10%以上的股东请求法院解散

**司法解散(第233条,重要救济!):**

**适用条件:**
- 经营管理发生严重困难
- 继续存续会使股东利益受到重大损失
- 通过其他途径不能解决

**"严重困难"认定:**
- 股东会机制失灵(长期无法召开或形成有效决议)
- 董事会、监事会无法正常履职
- 公司僵局,无法运营

**原告资格:** 持有公司全部股东表决权10%以上的股东

### 4.6 公司清算

**清算组组成:**
- 有限公司: 股东组成
- 股份公司: 董事或股东大会确定的人员组成
- 逾期不成立清算组: 债权人可申请法院指定组成

**清算程序:**
```
解散之日起15日内成立清算组
  ↓
清算组接管公司
  ↓
10日内通知债权人,60日内公告
  ↓
清理资产、编制清册
  ↓
制定清算方案,报股东会/股东大会确认
  ↓
清偿债务
  ↓
分配剩余财产
  ↓
制作清算报告
  ↓
申请注销登记
```

**债务清偿顺序:**
1. 清算费用
2. 职工工资、社保、补偿金
3. 税款
4. 公司债务
5. 剩余财产按出资比例分配

**清算责任:**
- 未及时清算 → 股东承担责任
- 恶意处置财产 → 股东承担赔偿责任
- 未清算即注销 → 股东对债务承担连带责任

## 五、关联交易与利益冲突

### 5.1 关联关系

**关联方包括:**
1. 控股股东、实际控制人
2. 董事、监事、高管
3. 上述人员关系密切的家庭成员
4. 上述人员直接或间接控制的企业
5. 其他可能导致公司利益转移的关系

### 5.2 关联交易规范

**程序要求:**
1. 提前披露关联关系
2. 关联股东/董事应当回避表决
3. 重大关联交易需股东会批准

**禁止行为:**
- 损害公司利益的关联交易
- 利用关联关系侵占公司商业机会
- 关联方资金占用

## 六、一人公司特别规定

### 6.1 设立要求

**投资主体:**
- 一个自然人或一个法人
- 一个自然人只能投资设立一个一人有限公司
- 该一人公司不能再投资设立新的一人公司

**特别标注:**
- 营业执照注明"自然人独资"或"法人独资"
- 公司章程需载明公司财产独立于股东个人财产

### 6.2 特别义务

**财务独立证明责任(第63条,举证责任倒置!):**
```
一人公司不能证明公司财产独立于股东自己的财产
  ↓
应当对公司债务承担连带责任
```

**实务风险:**
- 公司账户与个人账户混同
- 公司资产与个人资产混同
- 无规范的财务制度

**防范措施:**
- ✅ 建立规范的财务制度
- ✅ 每年编制财务报告并审计
- ✅ 严格区分公司财产与个人财产
- ✅ 公司资金往来必须有合法依据
- ✅ 保留完整的财务凭证

## 七、公司信息公示

### 7.1 强制公示信息(第40条)

**通过国家企业信用信息公示系统公示:**
1. 有限公司: 股东认缴和实缴的出资额、出资方式和出资日期
2. 股份公司: 发起人认购的股份数
3. 有限公司股东转让股权的情况
4. 简易注销公告
5. 其他依法应公示的信息

**未公示/不实公示的后果(第251条):**
- 公司: 1万-5万元罚款(情节严重5万-20万元)
- 直接责任人员: 1万-10万元罚款

### 7.2 年度报告

**报送期限:** 每年1月1日至6月30日

**内容:**
- 股东出资缴纳情况
- 资产状况
- 股权变更情况
- 对外投资情况
- 其他

**未按时报送:**
- 列入经营异常名录
- 影响信用记录

## 八、常见问题与实务建议

### Q&A

**Q1: 新设公司注册资本写多少合适?**
A: 
- 考虑5年内实缴能力
- 参考行业惯例
- 满足资质要求即可
- 不宜虚高(增加缴资压力、股权转让成本)
- 建议: 10-100万元(小微企业)

**Q2: 存量公司剩余出资期限不足5年,需要调整吗?**
A: 不需要。只有2027年7月1日起剩余期限**超过**5年的才需要调整。

**Q3: 如何判断是否需要减资?**
A: 评估以下因素:
- 5年内是否有能力实缴?
- 公司实际经营是否需要这么多资本?
- 股东是否愿意实缴?
- 减资成本(公示45天、债权人异议等)vs实缴成本

**Q4: 股东会和董事会的权限如何划分?**
A: 
- 股东会: 决定公司重大事项(增减资、合并分立、修改章程等)
- 董事会: 执行股东会决议,决定日常经营管理事项
- 界限: 公司章程可明确具体权限范围

**Q5: 公司僵局如何破解?**
A: 
1. 股东协商(股权回购、部分退出)
2. 引入第三方调解
3. 申请司法解散(持有10%以上表决权股东)
4. 修改公司章程(表决机制、决策机制)

**Q6: 一人公司如何避免连带责任?**
A:
- 建立规范财务制度
- 每年财务审计
- 公私账户严格分离
- 每笔资金往来有依据
- 保留完整财务凭证

**Q7: 股权代持有哪些风险?**
A:
- 名义股东擅自处分股权
- 名义股东的债权人查封股权
- 显名化困难(需其他股东过半数同意)
- 协议效力争议
- 建议: 尽量避免,或签署完善的代持协议+公证

**Q8: 董事会多少人合适?**
A:
- 法定: 3-13人(有限公司)
- 建议: 
  - 小型公司: 3-5人
  - 中型公司: 5-7人
  - 大型公司: 7-13人
- 奇数为宜(便于表决)

## 实务建议

### 新设公司必做清单

**设立阶段:**
- [ ] 注册资本考虑5年实缴能力
- [ ] 章程明确出资期限(≤5年)
- [ ] 股权比例设计(考虑控制权、决策机制)
- [ ] 董事会/监事会设置(小公司可章程约定设1名董事)
- [ ] 明确公司治理规则(股东会召集、董事会决策等)

**运营阶段:**
- [ ] 按期缴纳出资
- [ ] 规范三会运作(保留会议记录、决议)
- [ ] 建立财务制度(一人公司尤其重要)
- [ ] 每年报送年度报告
- [ ] 及时公示信息变更

### 存量公司应对清单

**评估阶段(2024-2025):**
- [ ] 核查当前出资情况(认缴vs实缴)
- [ ] 计算2027年7月1日剩余出资期限
- [ ] 评估5年内实缴能力
- [ ] 分析是否需要调整(减资/转让/引资/注销)

**决策阶段(2025-2026):**
- [ ] 股东会讨论应对方案
- [ ] 形成决议
- [ ] 修改章程(调整出资期限)

**执行阶段(2026-2027.6.30前):**
- [ ] 实施选定方案
- [ ] 办理变更登记
- [ ] 公示调整后的出资信息

**风险提示:**
- ⚠️ 不要拖到最后时刻
- ⚠️ 减资需公示45天,预留足够时间
- ⚠️ 未按期调整可能被列入经营异常/吊销执照

### 高频风险点

**资本风险:**
- ❌ 认缴过高无力实缴
- ❌ 虚假出资、抽逃出资
- ❌ 未按期调整出资期限

**治理风险:**
- ❌ 公司章程与法律冲突
- ❌ 三会不规范(无会议记录、决议瑕疵)
- ❌ 越权决策(股东会事项董事会决定)
- ❌ 一人公司财产混同

**股东风险:**
- ❌ 股权代持协议不规范
- ❌ 对外转让未履行内部程序
- ❌ 滥用股东权利损害公司/其他股东

**信息公示风险:**
- ❌ 未按时年报
- ❌ 未公示或虚假公示出资信息
- ❌ 被列入经营异常名录

### 核心建议

**资本建议:**
1. 新公司注册资本量力而行
2. 存量公司提前规划调整
3. 股东按期实缴,不要拖延
4. 非货币出资评估作价要合理

**治理建议:**
1. 章程是公司宪法,务必认真起草
2. 三会要规范运作,保留书面记录
3. 重大事项按法定程序决策
4. 董监高履职尽责,避免利益冲突

**风险建议:**
1. 一人公司务必公私分明
2. 关联交易履行程序、公允定价
3. 股权转让履行法定程序
4. 发生僵局及时寻求法律救济

2024年新公司法是30年来最大的一次修订,影响深远。所有存量公司都应重视过渡期安排,及时调整。建议咨询专业律师或会计师!
