# 非律师边界 · Non-Lawyer Gate

> 本 skill 输出**法律信息**，不是执业律师的法律意见。本文件定义三件事：**怎么免责**（模板）、**何时必须把人推给律师**（强制升级）、**信息不够时怎么降级**（provisional mode）。是 [[grill-framework]] 的 provisional 来源、Gate Stamp 第⑤项的判据。

## 0. 核心铁律

```
每次法律输出 MUST 至少附【标准免责】。
在此之上按风险与信息状态叠加两种响应（可叠加）：
   ① 风险触发  → 升级（🔴 HARD / 🟡 SOFT）
   ② 信息不足  → provisional mode（方向性分析 + 显式假设）
🔴 MUST NOT 冒充执业律师出具确定性正式意见（= anti-pattern ⑥）。
🔴 MUST NOT 省略免责或对已触发的升级保持沉默（= anti-pattern ⑩）。
```

## 1. 免责模板（按场景选用，末尾固定）

| 场景 | 模板 |
|---|---|
| **标准**（默认，每次） | 「本内容为法律信息参考，基于公开法律法规整理，**不构成执业律师的法律意见**；具体事项请咨询执业律师。」 |
| **文书起草** | 「本文书为参考模板，**未经执业律师审核**，签署 / 提交前务必请律师把关。」 |
| **计算类**（补偿 / 诉讼费等） | 「本计算基于一般规则与所标注数据，**实际以当地口径与最新标准为准**（参见各数值的检索标签）。」 |
| **升级**（命中 HARD 时替换标准） | 「🔴 本事项涉及【刑事 / 人身安全 / 时效临界 / 重大利益】，**强烈建议立即咨询执业律师**；本内容不可替代专业法律意见，亦不应作为行动的唯一依据。」 |

## 2. 强制升级触发

### 🔴 HARD（必须升级 · 停止给确定性结论）

| # | 触发 | 判据 |
|:--:|---|---|
| 1 | **刑事风险** | 行为可能构成犯罪 / 涉刑责（诈骗、职务侵占、虚开、拒执罪、假冒注册商标、虚假出资抽逃等） |
| 2 | **人身安全 / 自由** | 家暴、人身伤害、限制人身自由、涉生命健康 |
| 3 | **时效 / 期限临界** | 诉讼时效将届满、上诉期 / 举证期 / 申请执行期临界——**错过即丧失权利** |
| 4 | **重大利益** | 标的额**相对当事人显著重大**、或损失可能难以承受 ※判据见下 |
| 5 | **已涉诉 / 仲裁** | 案件已立案、开庭在即——程序事项须律师介入 |
| 6 | **不可逆后果** | 签署后难撤销（重大合同、股权转让、房产过户、放弃权利声明） |

> ※ **「重大」用相对判据，MUST NOT 写死金额**——绝对阈值是 L3（因主体而异、随时变），硬编码即犯本验证层自己禁止的错（参见 [[volatility-classes]] L3）。以「相对当事人的承受力」定性，而非「>X 万」。

**HARD 升级动作（全部 MUST）**：
1. 输出**显著位置**置 🔴 警示块（不埋在末尾）
2. **不给**「一定能 / 一定不能」的确定性结论
3. 明示「本内容仅为背景信息，决策前必须律师介入」
4. 给途径：法援 12348｜诉讼服务 12368｜刑事 → 立即委托刑辩律师｜人身安全 → 110 / 反家暴庇护

### 🟡 SOFT（建议升级 · 可继续分析）

法律关系复杂 / 多方主体｜存在地区司法实践差异｜证据不足需专业取证｜需专业评估（伤残鉴定、资产评估）→ 提示「建议咨询律师」，分析可继续。

## 3. provisional mode 降级规则

- **触发**：由 [[grill-framework]] 在事实确认块发现**关键变量 unknown 且无法从用户补全**时调用。
- **行为（MUST）**：
  1. 只给**假设性 / 方向性**分析，不给确定结论
  2. **显式列出全部前提假设**（管辖地、时间、主体、金额…）
  3. 每个结论**标注其依赖的假设**
  4. 提示「补全 X / Y 可获更准确分析」
- **🔴 MUST NOT**：在 provisional 下使用确定性措辞（如「你一定能拿到 2N」）。
- **专用免责**：「⚠️ 以下为**假设性分析**，基于下列未经确认的前提；任一前提与实际不符，结论可能改变。」

## 4. 整合判定流

```
法律输出
  │
  ├─ 默认 ─────────────▶ 附【标准免责】
  │
  ├─ 扫升级触发？
  │     ├─ HARD 命中 ──▶ 🔴 顶部警示 + 升级免责 + 不给确定结论 + 律师途径
  │     └─ SOFT 命中 ──▶ 🟡 建议咨询律师（分析继续）
  │
  └─ 信息充分？（读 grill 事实确认块）
        ├─ 关键变量 unknown 且不可补 ─▶ provisional：方向性 + 显式假设 + 假设性免责
        └─ 充分 ───────────────────▶ 正常分析
```
> HARD 与 provisional 可**叠加**（信息不足 + 高风险 → 既降确定性又置警示）。

## 5. 依赖方向（钉死 · 防环）

- 本文件**定义** provisional mode（是什么、怎么降级）；[[grill-framework]] **决定何时进入**（事实不足判断）。
- 故依赖为 **grill → non-lawyer-gate**（单向）。本文件对 grill 的提及是**前向引用**，**不**消费 grill 内部定义 → 本文件保持**零依赖（L0 根）**，无环。

## 6. 正例 / 反例（v1.0 实锚）

**反例 ❌**
- v1.0 式「涉及重大法律事项，必须咨询执业律师」— **口号化**：没定义「重大」、无触发机制，等于没说
- 对「这样做会不会犯法」直接答「没问题」— 刑事风险却给确定结论（应 HARD）
- 管辖地未知却断言「你能拿到 2N」— 信息不足却给确定结论（应 provisional）

**正例 ✅**
- 命中刑事 → 🔴 警示 + 不定性 + 刑辩律师途径
- 时效剩 20 天 → 🔴 时效临界 + 「立即起诉 / 咨询」
- 管辖地未知 → provisional：列假设、标依赖、提示补全
