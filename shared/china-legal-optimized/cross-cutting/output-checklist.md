# 表达质量自检 · Output Checklist

> 成稿后的**软自检**——只管「表达好不好、专不专业」，**不管事实对不对**（事实归 [[output-gate]] 硬闸门）。v1.0 的「质量控制要点」是 3 条散文，本文件把它变成 **6 项可勾选清单**。软自检：**不阻断输出，但任一项未达标 MUST 修正或显式说明**。

## 0. 核心铁律

```
成稿后逐项过 6 项表达自检（默认静默）
   → 任一项未达标 → MUST 修正，或显式说明为何不适用
   → 与 output-gate 的关系：output-gate 先（事实/阻断），本检后（表达/不阻断）
本检不产 Gate Stamp（那是 output-gate 的）；可选附一行紧凑标记。
```

## 1. 六项自检

| # | 项 | 判据（达标 = ?） | v1.0 反例 |
|:--:|---|---|---|
| ① | **结构完整** | 必要段齐全（咨询：分析/路径/风险；审查：摘要/逐条/重点） | 只给结论不给分析与救济路径 |
| ② | **结论有据** | 每个结论有支撑链（法条 / 事实 / 推理），不悬空 | 断言「合同无效」却不说为何、依据哪条 |
| ③ | **有利+不利同时提示** | 双向呈现，不报喜不报忧（客观性） | 只说「你能拿 2N」，藏起「需举证违法解除」的难点 |
| ④ | **可操作** | 建议含**步骤 / 材料 / 时限**，非空话 | 「建议保留证据」— 没说留什么、怎么留、何时限 |
| ⑤ | **溯源齐全（表达层）** | 来源对读者清晰可追；标签呈现得当不堆砌 | 关键数字来源不透明 / 标签乱堆影响阅读 |
| ⑥ | **无绝对化** | 用「通常 / 一般 / 在 X 情形下 / 存在 X 风险」等审慎措辞 | 「一定胜诉」「绝对无效」「100% 能调」 |

**展开两项**：
- **③ 客观性**是法律分析的命脉——对己不利的因素 **MUST** 主动提示，呼应 v1.0「分析客观性」。
- **⑥ 无绝对化**与 [[non-lawyer-gate]] 呼应：HARD 升级时尤其禁确定性措辞（法律充满不确定性）。

## 2. 与 output-gate 的分工（钉死边界）

| | `output-gate`（闸门③） | `output-checklist`（本文件） |
|---|---|---|
| 管什么 | **事实对不对 / 合不合规** | **表达好不好 / 专不专业** |
| 强度 | 硬闸门，**可阻断**输出 | 软自检，**不阻断** |
| 产物 | **Gate Stamp**（必打印） | 默认静默，可选紧凑行 |
| 检查例 | 法条溯源在场、L3 已检索、版本现行 | 结构、客观性、可操作、措辞 |

> ⚠️ **第⑤项「溯源齐全」≠ output-gate 第③项**：output-gate 管「标签**在且合规**」（缺即阻断）；本项管「标签**清晰可读、呈现得当**」（提醒级）。一个硬合规、一个软可读，**MUST NOT** 退化为重复检查。

## 3. 自检的呈现

- **默认静默**：agent 内部过一遍，**不打印**完整清单（避免冗长）。
- **未达标必修**：任一项不达标 → 成稿时修正；确实不适用 → 一句话说明。
- **可选紧凑行**（便于审计，附在 Gate Stamp 之后）：
  ```
  ✍️ 表达自检 6/6 ✅       （或： ✍️ 表达自检 5/6 — ④可操作已补步骤）
  ```

## 4. HARD 升级时的协调（解 open-issue #2）

当 [[non-lawyer-gate]] 触发 **HARD 升级**（要求「不给确定性结论」）时，与第④项「可操作」冲突——**定优先级**：

```
HARD 升级  >  可操作性
```

即升级状态下，**第④项达标标准放宽**为：给出**方向性步骤 + 明确律师介入点**即可，**不强求**确定性方案。绝对化（⑥）与确定性结论一律让位于升级警示。

## 5. 依赖方向（钉死）

- **上游依赖**：[[source-tags]]（第⑤项的标签格式规范）。
- **运行时位置**：由 `gates` 编排在 [[output-gate]] **之后**调用（先过事实闸门，再表达自检）。本文件与 output-gate **平行、不互相依赖**。

## 6. 正例 / 反例（v1.0 实锚）

**反例 ❌**：v1.0「质量控制要点」是 3 条原则散文，无清单、无强制 → 实际输出仍出现只给结论、报喜不报忧、空泛建议、绝对化。
**正例 ✅**：6 项逐条过 → 结论带依据链、有利不利并陈、建议带步骤时限材料、措辞审慎、来源透明。
