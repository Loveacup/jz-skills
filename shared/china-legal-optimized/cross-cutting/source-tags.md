# 溯源标签 + 引用规范 · Source Tags & Citation

> 防幻觉的核心**可视化**机制。**每一个法律事实断言 MUST 带且仅带一个溯源标签**，让「这句话的来源可靠度」在输出里一眼可见、可审计。本文件定义标签的**语义 / 格式 / 引用规范**；挥发级别定义以 [[volatility-classes]] 为准（本文件依赖之）。
> 📌 **本表 §3 是「标签 × 级别映射」的唯一数据源**（裁定 #1）。

## 0. 核心铁律

```
每个法律断言（法条 / 数字 / 期限 / 结论性判断）
        → 句末 MUST 紧跟一个溯源标签
        → 带且仅带一个：不重复、不遗漏
无标签的法律断言 = output-gate 第③项判定失败，MUST NOT 输出
```

## 1. 三个主标签

### `[法条原文：《法名》第X条]`
- **含义**：直接引自**现行有效**的法律 / 法规正文。
- **用于**：L0 原则、L1 结构（须现行）。
- **格式**：`[法条原文：《民法典》第87条]`、`[法条原文：《劳动合同法》第40条]`
- **MUST**：能定位到现行有效的具体条款，且条号确定。不满足 → 降级 [条号待核] 或触发检索。

### `[检索·YYYY-MM-DD·来源]`
- **含义**：来自本次实时检索（闸门② web-research-gate 的产物）。
- **用于**：L1(stale)、L2、L3。
- **格式**：`[检索·2026-06-01·国家税务总局]`
- **MUST**：带检索**日期** + **来源机构**。日期即「该事实的核验时点」。

### `[模型知识·需验证]`
- **含义**：来自模型训练知识，**未经本次核验，使用者需自行确认**。
- **用于**：L0、L1 的低风险背景陈述。
- **🔴 MUST NOT** 用于 **L2、L3**——模型知识有训练截止日，对修法 / 数值等于盲区。
- 这是**诚实标记**：把「我不确定」显式化，而非伪装成事实。

## 2. 两个降级标签

### `[条号待核]`
- **用于**：L1 规则内容确定、但具体条号不确定时。
- **用法**：描述规则 + 标记，**禁止编造条号**。
  > `标的应当确定，否则合同内容欠缺《民法典》合同编 [条号待核]`
- ⚠️ 不替代核验，只是诚实降级；有条件应补检索定位。

### `[未核验·需查证：官方入口]`
- **用于**：L2/L3 应检索但**检索失败**时的**唯一**合法降级。
- **用法**：给官方查询入口，**绝不用记忆数值兜底**。
  > `首套契税以当地税务机关口径为准 [未核验·需查证：12366/当地税务局]`
- **🔴 MUST NOT**：在「本可检索却跳过」时用此标签偷懒。

## 3. 标签 × 挥发级 映射（唯一数据源 · 裁定 #1）

| source-tag | 可用级别 | 禁用级别 |
|---|---|---|
| `[法条原文]` | L0、L1（现行） | — |
| `[检索·日期·来源]` | L1(stale)、L2、L3 | — |
| `[模型知识·需验证]` | L0、L1（低风险背景） | **L2、L3** |
| `[条号待核]` | L1（条号不定） | 不替代核验 |
| `[未核验·需查证]` | L2/L3 检索失败 | 本可检索却偷懒 |

> **依赖方向钉死（防环）**：**级别**定义以 [[volatility-classes]] 为准（本文件 depends_on）；**标签 × 级别映射以本表为唯一数据源**（裁定 #1——volatility §3 已改为只判触发、引用本表，不再自带映射表）。

## 4. 法条引用规范（防 512 错引）

**引用四要素**：法名 +（编 / 章）+ 条号 + 现行版本确认。

**引用阶梯**（自优至降级）：
```
① 条号确定 + 现行       →  《民法典》第470条 [法条原文]
② 规则确定 + 条号不定   →  《民法典》合同编关于合同内容的规定 [条号待核]
③ 现行性存疑 (L2)       →  触发闸门② → [检索·日期·来源]
④ 仅凭印象             →  描述规则 + [模型知识·需验证] + 提示需专业核实
```

**🔴 三禁**：
1. 禁**编造**精确条号 — *512 教训：512 实为电子合同交付时间，非「标的确定」*
2. 禁把**记忆条号当确定**（「我记得是 X 条」→ 必核或降级）
3. 禁**张冠李戴**（条号 ↔ 内容错配）

## 5. 标签放置规则

- **行内**，紧跟被修饰的断言（句末 / 分句末），**MUST NOT** 集中堆到段尾。
- 一个断言一个标签；复合句的多个断言**各自**带标签（呼应 volatility §5 复合拆级）。
- L3 数值类断言的标签 **MUST** 含检索日期。

## 6. 正例 / 反例（v1.0 实锚）

**反例 ❌**
- `依《民法典》512条，标的应当确定` — 张冠李戴 + 无视现行性
- `首套契税 1–1.5%` — L3 无标签 + 凭记忆 + 已过期
- `彩礼应当返还` — L2 未核 2024 新规

**正例 ✅**
- `标的应当确定，否则合同内容欠缺《民法典》合同编 [条号待核]`
- `首套住房（≤140㎡）契税 1% [检索·2026-06-01·国家税务总局]`
- `彩礼返还适用 2024《涉彩礼纠纷规定》，限三种情形 [检索·2026-06-01·court.gov.cn]`

## 7. 下游接口约定

| 下游 | 取用本文件的什么 |
|---|---|
| `web-research-gate` | 检索成功 → 回填 [检索·日期·来源]；失败 → 回填 [未核验·需查证] |
| `output-gate` | Gate Stamp 第③项：逐断言核「有且仅有一个标签 + L2/L3 非 [模型知识]」 |
| `output-checklist` | 表达自检「溯源标签齐全」项（呈现质量，不重复 output-gate 的合规检查） |
| `anti-patterns` | 红线 ①（编条号）、⑧（无标签断言）直接引用本文件 |
