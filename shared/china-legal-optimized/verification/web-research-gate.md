# 检索闸门 · Web-Research Gate（闸门②）

> v1.0 的契税过期、彩礼漏新规、512 误引，**根因都是没有实时核验**。本闸门是补丁：任何 [[volatility-classes]] 判为 **L2 / L3** 的事实，**MUST 先检索再落笔**；成功回填 [检索·日期·来源]，失败降级 [未核验·需查证]——**绝不用模型记忆的数字兜底**。

## 0. 核心铁律

```
命中 L2 / L3（或 L1 stale）
   → MUST 先检索，后落笔
   → 成功：[检索·YYYY-MM-DD·来源]
   → 失败：[未核验·需查证：官方入口]   （🔴 禁止记忆数字兜底 = anti-pattern ②）
这是 L2/L3 进入正文的【唯一】合法路径。
```

## 1. 触发条件

**① 级别触发**（以 [[volatility-classes]] 判级为准）：L2 / L3 → **必触发**；L1 标 stale → 触发。

**② 触发词预筛**（快速识别信号，最终仍以判级为准）：

| 类 | 信号词 |
|---|---|
| **L3 数值** | 税率 / 契税 / 增值税 / 个税 / 社平工资 / 最低工资 / 维修资金 / 诉讼费 / 标的额门槛 / LPR / 利率 / 补偿基数 / 单价 / 「多少元」「百分之」 |
| **L2 修法** | 最新 / 最近 / 今年 / 现行 / 是否有效 / 新规 / 修订 / 修正 / 司法解释 / 施行 / 是否废止 / 是否被取代 |
| **地方** | 具体省 / 市名 + 标准类问题 → 触发**地方 L3** 检索 |

## 2. query 构造

**四要素**：主题 + 地区（L3 地方时）+ 时间限定 + 官方倾向。

| 类型 | 模板 |
|---|---|
| L2 修法 | `<法律名> <主题> 现行有效 最新 <当前年>` |
| L3 全国数值 | `<主题> 标准 现行 <当前年> 官方` |
| L3 地方数值 | `<城市> <主题> 标准 <当前年>` |

**示例**：
- 契税 → `首套住房 契税 税率 <当前年> 国家税务总局`
- 杭州维修资金 → `杭州 住宅专项维修资金 首期交存标准 <当前年>`
- 彩礼 → `彩礼返还 司法解释 现行 最高人民法院`

> 🔴 **`<当前年>` 用实际当前年份，MUST NOT 硬编码**（写死「2026」明年即过期——本闸门自己不能犯 L3 时效错）。
> 🔴 **L3 地方查询 MUST 带 [[grill-framework]] 确认的城市**；管辖地 unknown → **回 grill 追问**，不得用默认城市瞎查。

## 3. 调用接口（跨平台抽象）

抽象为 `SEARCH(query) → results`，平台各自绑定——**MUST NOT 写死单一工具名**（吸取 v1.0 `read_file` 跨平台失效教训）：

| 平台 | 绑定 |
|---|---|
| **Hermes** | `web-research-router` skill |
| **Claude Code** | `WebSearch` + `WebFetch` |
| **pi / Windows** | 待部署确认（见 open-issue #4） |

**来源可信度优先级**：
官方（flk.npc.gov.cn / court.gov.cn / 税务总局 / 地方政府官网）＞ 权威（北大法宝、最高法公报）＞ 一般。
⚠️ 警惕自媒体、过期转载、AI 生成内容。

## 4. 回填规则（检索成功）

- **成功** = 事实值 + 可信来源 + 时点 三者齐备。
- **格式**：`<事实值> [检索·YYYY-MM-DD·来源机构]`（对接 [[source-tags]]）。
- **日期** = 检索当日（即该事实的核验时点）。
- **多源冲突**：取官方 / 最新；分歧显著 → 显式标注分歧，不强行择一。

> 例：`首套住房（≤140㎡）契税 1% [检索·2026-06-01·国家税务总局]`

## 5. 降级规则（检索失败）

**失败情形**：无结果 / 仅不可信来源 / 结果互相矛盾无法判定 / 平台无检索能力。

**降级动作（全部 MUST）**：
1. 标 [未核验·需查证：官方入口]（对接 source-tags）
2. 给**具体**官方入口（按主题）：税费 12366｜诉讼费·管辖 12368｜社平·最低工资·维修资金 → 当地统计局 / 人社局 / 住建局｜法规原文 flk.npc.gov.cn｜司法解释 court.gov.cn
3. 🔴 **绝不**用模型记忆的数字 / 结论兜底
4. 若该事实涉 HARD 升级（重大利益等）→ **叠加** [[non-lawyer-gate]] 升级

> 例：`首套契税以当地税务机关口径为准 [未核验·需查证：12366 / 当地税务局]`

## 6. 全流程

```
事实断言 X（volatility 判 L2/L3）
   │
   ├─ L3 地方？──▶ 管辖地已确认？
   │                 ├─ 否 ─▶ 回 grill 追问城市（不瞎查）
   │                 └─ 是 ─▶ 构造带城市的 query
   │
   ├─ 构造 query（主题 + 地区 + <当前年> + 官方倾向）
   ├─ SEARCH(query)  ← 平台绑定
   │
   └─ 有可信结果？
         ├─ 是 ─▶ 提取(值 + 来源 + 日期) ─▶ 回填 [检索·日期·来源]
         └─ 否 ─▶ [未核验·需查证：官方入口]（禁记忆兜底；涉 HARD → 叠加升级）
```

## 7. 依赖方向（钉死）

- **上游依赖**：[[volatility-classes]]（判 L2/L3）+ [[source-tags]]（回填 / 降级标签）。
- **运行时输入**：从 [[grill-framework]] 取确认的**管辖地 / 时间线**构造 query——**数据流，非概念依赖**（由 gates 编排传递，装配图无新增边）。

## 8. 正例 / 反例（v1.0 实锚）

**反例 ❌**：契税「1–1.5%」凭内置库（应 L3 检索）｜彩礼漏 2024 新规（应 L2 检索现行性）— 二者皆因 **v1.0 无本闸门**。
**正例 ✅**：契税 → 检索 → `1% [检索·…·税务总局]`｜杭州维修资金 → 确认城市 → 检索 → `60 元/㎡ [检索·…·杭州住建局]`｜查不到 → `[未核验·需查证：12366]`。
