# 挥发性分级 · Volatility Classes

> **本文件是 china-legal 验证层的地基。** 任何法律**事实性断言**（法条、数字、期限、是否现行有效）在写入正文前，**MUST** 先用本表判定挥发等级 L0–L3；等级决定核验强度。判级歧义时 **就高不就低**。
> 📌 **标签规则不在本表**：每级应标哪个 source-tag，以 [[source-tags]] §3 为**唯一数据源**（裁定 #1——本表只判级、不复制标签映射）。

## 0. 一句话规则

```
事实断言  →  判级(L0–L3)  →  按级核验  →  标 source-tag（见 source-tags §3）  →  写入正文
                  │
                  └─ 拿不准 → 升一级处理（宁可多检索一次）
```

## 1. 四级速查表

| 级别 | 名称 | 一句判据 | 闸门② | 典型 |
|:---:|---|---|:---:|---|
| **L0** | 静态原则 | 法理 / 原则 / 术语定义，几乎不随时间变 | 不触发 | 过错责任、思想表达二分 |
| **L1** | 慢变结构 | 写入正文的条号 / 期限 / 比例 / 流程 | 默认否 * | 时效 3 年、专利 20 年、上诉 15 日 |
| **L2** | 修法 / 解释 | 现行有效性本身存疑、最新变动 | **必触发** | 新司法解释、修正案、过渡期 |
| **L3** | 高挥发数值 | 数字 / 费率 / 地方标准，按年按市浮动 | **必触发** | 契税率、社平基数、维修资金单价 |

\* L1 在「VERSION.yaml 标记 stale」或「条款近期被修法波及」时升级触发闸门②。

## 2. 逐级详述

### L0 — 静态原则（Static）
- **判据**：法律基本原则、法理逻辑、术语定义、权利的性质。修宪 / 立法理念级别才会动。
- **例子**：过错责任 / 无过错责任 / 公平责任；合同自由、意思自治；物权法定；思想表达二分；善意取得的构成逻辑；「谁主张谁举证」基本原则。
- **核验**：无需实时核验。
- **MUST NOT**：不得把「原则」与挂靠它的「具体数值 / 最新解释」混为一谈——后者各自按 L1–L3 判（见 §5 复合拆级）。

### L1 — 慢变结构（Slow / Structural）
- **判据**：已写入法律 / 法规正文的、具体但稳定的结构性规则——条文编号、期限、比例、流程步骤。修法才变，周期以年计。
- **例子**：法条编号（民法典 1079 离婚、87 违法解雇 2N）；保护期（发明 20 / 实用新型 10 / 外观 15 年、著作权终生 +50）；时效（普通 3 年、最长 20 年、涉外货物 4 年）；程序时限（上诉 15 日 / 裁定 10 日、举证期 ≥15 日、立案审查 7 日）；表决比例（双过半 / 双 2/3）；经济补偿公式**结构** S×N / 2N / N+1。
- **核验**：标注法律版本号 + 周期核验（季 / 半年）；引用须定位**现行有效**条款。
- **🔴 防 512 铁律**：条号不确定时，**MUST** 描述规则内容 + 标 [条号待核]，**MUST NOT** 编造精确条号。
  > v1.0 反例：「《民法典》512 条要求标的确定」← 512 实为电子合同交付时间，张冠李戴。
- **升级触发闸门②**：(a) VERSION.yaml 标 stale；(b) 该条款可能被近期修法 / 新解释波及。

### L2 — 修法与解释（Volatile / Legal-change）
- **判据**：法律体系**正在变动**的部分——「现行有效性」本身存疑。新司法解释、修正案、新法、指导性案例、被废止 / 取代的旧规，以及一切「最新 / 最近 / 今年新规」类问题。
- **例子**：彩礼规定（2024-02）、合同编通则解释（2023-12）、侵权责任编解释一（2024-09）；公司法 2023 修订（2024-07 施行）、民诉法 2023 修正、专利法实施细则 2023 修订；公司法注册资本 5 年**过渡期至 2027-06-30**；「某条是否已被取代 / 废止」。
- **核验**：**每次涉及必触发闸门②**，确认 ①现行有效 ②有无更新的解释 / 修正 ③施行日期与适用范围。
- **🔴 MUST NOT**：禁止凭模型知识直接下「这是最新规定」的断言——模型知识有截止日，对 L2 等于**盲区**。
  > v1.0 反例：personal.md 彩礼沿用旧《婚姻法解释二》、离婚漏 1079 条第 5 款——都是 L2 未核。

### L3 — 高挥发数值（Hyper-volatile · Numeric & Local）
- **判据**：具体**数字** + 因**地区 / 年度**浮动的标准。周期以月 / 年计，常因省市而异。**幻觉与过期最高发区**。
- **例子**（逐条对应 v1.0 踩坑）：
  - 税率：契税（首套 ≤140㎡ 现 **1%**；v1.0 写「1–1.5%」已过期）、增值税满 2 年免、个税满 5 唯一免
  - 经济补偿基数：当地**社平工资 ×3 封顶线**（每年每市不同）、最低工资标准
  - 诉讼成本：财产案件分段费率、**管辖标的额门槛**（京 5000 万 / 沪穗 1 亿，会调）
  - 地方标准：**专项维修资金单价**（杭州多层 60 / 高层 90 元/㎡）、首期交纳比例
  - 利率：LPR、逾期利率上限（4×LPR）
  - 裁量尺度：彩礼返还的地方比例、竞业补偿下限（月工资 30%，地方有别）
- **核验**：**每次必触发闸门②实时检索**。
- **🔴🔴 红线中的红线**：**绝对禁止**凭模型记忆给 L3 数字进结论（= anti-pattern ②）。检索失败时只能标 [未核验·需查证] + 官方入口，**不得**用记忆数值兜底。
  - 官方入口：法规原文 flk.npc.gov.cn｜税费 12366 / 当地税务局｜诉讼费·管辖 12368 / 当地法院｜社平·最低工资·维修资金 当地统计局 / 人社局 / 住建局｜司法解释 court.gov.cn

## 3. 触发矩阵（与闸门② web-research-gate 的接口）

| 级别 | 闸门② 是否触发 |
|:---:|:---:|
| L0 | 不触发 |
| L1 | 默认否（stale / 被修法波及 → 是） |
| L2 | **必触发** |
| L3 | **必触发** |

> 📌 **标签归属（裁定 #1）**：检索成功 / 失败各标什么 source-tag、各级允许 / 禁用哪些标签，**全部以 [[source-tags]] §3 为唯一数据源**——本表只负责「是否触发、触发强度」，不复制标签映射。

## 4. 判级决策树

```
事实断言 X
  │
  ├─ Q1. X 含数字/费率/比例/金额门槛/地方标准？
  │        (税率、社平基数、诉讼费率、维修资金单价、利率、最低工资…)
  │        └─ 是 ──────────────────────────────▶ 【L3】必检索
  │
  ├─ Q2. X 涉「最新/修法/新司法解释/是否仍现行有效/施行日期」？
  │        └─ 是 ──────────────────────────────▶ 【L2】必检索
  │
  ├─ Q3. X 是写入法律正文的具体条号/期限/比例/流程步骤？
  │        └─ 是 ─▶ 条号确定且现行？
  │                   ├─ 是 ─────────────────────▶ 【L1】标版本 [法条原文]
  │                   └─ 否/不确定 ──────────────▶ 【L1】降级表述 [条号待核]
  │
  ├─ Q4. X 是法律原则/法理/术语定义/权利性质？
  │        └─ 是 ──────────────────────────────▶ 【L0】无需核验
  │
  └─ 都不明确？ ─────────────────────────────────▶ 就高不就低：按 L2/L3 处理
```

**就高不就低**：判级歧义、或一句话跨多级时，**MUST** 取其中最高级别的核验强度。多检索一次的成本，远低于输出一个过期 / 杜撰事实。

## 5. 边界案例（高频误判，MUST 按此处理）

1. **复合断言要逐元素拆级，整句就高标注。**
   > 「经济补偿 = 社平 ×3 × 12 个月」→ 公式结构 L1 + 社平数值 L3 ⟹ **整句按 L3**，社平数必检索。只当 L1 是 v1.0 式陷阱——数值才是会过期的部分。

2. **条号 ≠ 现行性，是两个独立判定。**
   > 引用「民法典 1087 条」：编号在场 = L1；但「此条有无被新解释改写」= L2。引用具体条款时 **MUST** 顺带一次 L2 现行性确认。

3. **全国框架 vs 地方数值：同主题可能跨级。**
   > 物业维修资金：使用程序（双 2/3 表决）是全国 L1；首期单价（60 元/㎡）是地方 L3。property.md「浙江法规当全国用」即栽在没拆这一层。

4. **「历史上的法律」一律 L2。**
   > 涉及已废止的《合同法》/《婚姻法》等 → 现行性存疑 → L2 检索是否已被民法典取代。
