# 中国法务技能 (China Legal Skill)

## 技能定位

本技能为中国法务场景提供AI辅助分析，将法律知识和实务经验封装成可复用模块。

**核心价值：**
- 将复杂的法律判断逻辑显性化
- 提供结构化的法律分析框架
- 基于最新法律法规提供咨询

**重要声明：**
本技能提供法律信息参考，不构成法律意见。涉及重大法律事项，必须咨询执业律师。

## 使用流程

### 第一步：识别法务类型

根据用户描述判断属于以下哪个领域，并加载对应参考文档：

| 领域 | 典型场景 | 参考文档 |

| 合同法务 | 审核商业合同、租赁协议、服务协议 | `references/contracts.md` |

**使用 `read_file` 工具读取相关参考文档**

### 第二步：确定服务类型

**文档审核类**（合同审核、文书审查）：
1. 要求用户上传或粘贴文档内容
2. 按照对应领域的审核框架逐条分析
3. 提供风险评级和修改建议

**咨询指引类**（流程咨询、维权建议）：
1. 了解用户具体情况
2. 基于法律依据提供分析
3. 给出操作流程和注意事项

### 第三步：执行分析

#### 合同审核标准流程

使用三层分析法：

**第一层：八大核心要素检查**
1. 主体资格 - 签约方资质和授权
2. 标的条款 - 权利义务是否明确
3. 价款条款 - 金额、支付、税务
4. 履行条款 - 时间、地点、验收
5. 权利义务 - 是否对等平衡
6. 违约责任 - 情形、计算、救济
7. 争议解决 - 管辖、仲裁、法律适用
8. 其他条款 - 保密、知识产权、不可抗力

**第二层：风险评级**

| 等级 | 标识 | 定义 | 处理建议 |
|-----|------|------|---------|
| 高风险 | 🔴 | 可能导致合同无效或重大损失 | 必须修改 |
| 中风险 | 🟡 | 存在履行障碍或权益减损 | 建议修改 |
| 低风险 | 🟢 | 表述不够完善但影响有限 | 可选优化 |

**第三层：输出结构**

```
## 审核摘要
- 合同类型：[识别]
- 主要风险：[3-5个关键点]
- 总体建议：[签署/修改后签署/不建议签署]

## 逐条分析
### 第X条 [条款名称]
**原文：** [引用原文]
**问题：** [存在的法律问题]
**风险等级：** [🔴/🟡/🟢]
**法律依据：** [引用具体法条]
**修改建议：** [具体改写建议]

## 重点提示
[关键注意事项]
```

#### 法律咨询标准流程

**第一步：事实确认**
- 询问关键事实要素
- 确认时间线和证据情况
- 了解用户诉求

**第二步：法律分析**
- 引用相关法律条文
- 分析权利义务关系
- 评估法律风险

**第三步：操作指引**
- 提供具体流程步骤
- 列出所需材料清单
- 标注时限要求和注意事项

**输出格式：**
```

[基于法律条文的权利义务分析]

## 维权路径
1. [步骤一：具体操作]

   - 时限要求：[天数]
   - 注意事项：[要点]

2. [步骤二：具体操作]
   ...

## 风险提示
[关键风险点]
```

### 常用计算公式

**经济补偿金(N)**
```
基本公式： S × N
- S = 离职前12个月平均工资
- N = 工作年限（满6个月按1年，不满6个月按0.5年）
- 封顶：月工资超过社平3倍时，按3倍计算且年限最高12年
```

**违法解雇赔偿金(2N)**
```
2 × (S × N)
```

**代通知金(N+1)**
```
S × N + S(上月) × 1
```

## 特殊情况处理

### 当法律存在争议时
- 标注不同观点
- 说明主流司法实践
- 提供最保守建议

### 当信息不足时
- 明确告知需要补充的信息
- 不得进行猜测性分析
- 可提供假设情景分析

### 当超出能力范围时
- 坦诚说明skill边界
- 建议咨询专业律师
- 可提供初步方向指引

## 质量控制要点

1. **法律依据准确性**
   - 每个结论必须有明确法条支持
   - 引用法条时注明条款编号
   - 区分法律、司法解释、部门规章

2. **分析客观性**
   - 不偏向任何一方
   - 同时提示有利和不利因素
   - 避免绝对化表述

3. **建议可操作性**
   - 提供具体步骤
   - 标注时间节点
   - 列出所需材料
