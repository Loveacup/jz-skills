# Writing Spec — 质量红线、触发表、四要素

Load in Phase 3 (enricher) and Phase 7 (writer). This is the vault minutes SOP distilled; the vault copy (`周例会纪要写作规范.md`) stays authoritative for 周例会 specifics.

## 1. 质量红线（任一条不满足 = 未完成）

| 红线 | 含义 | 门 |
|---|---|---|
| 决策完整性 | 机器小结遗漏率高；必须通读转写全文提取决策，不靠摘要 | G4, G9 |
| 责任人 + 节点 | 每个行动项有人、有日期或明确触发条件；硬节点进 P0 | G5 |
| 原话保留 | 定调性表述用 `[!quote]` 原样保留，不转译 | G6 |
| 不臆测 | 转写不清的词保留原文并括注"转写不清"，宁缺勿造 | G10 |
| 诚实标注搜索范围 | 纪要说明里写清库内/库外各查了什么、没查到什么 | G7 |
| 证据随文 | 决策、行动项、引用都带 `[hh:mm:ss]` | G4, G5, G6 |

## 2. 决策四要素（ADR 最小结构）+ DACI

每条决策一行，全局编号 `YYWnn-Dxx`（nn = ISO 周），编号永不复用：

| 编号 | 决策内容 | 背景与理由 | 预期后果（让什么变容易/变难） | 拍板人 (A) | Driver / Contributors | 证据 |
|---|---|---|---|---|---|---|
| 26W37-D01 | … | … | … | 邵总 | D: 陈总；C: 季总 | [01:36:07] |

- 拍板人单一；未拍板的不是决策，进"待确认事项"。
- 客户表述前后矛盾时，以最后一次且被对方复述确认的为准，并在"背景与理由"注明被推翻的版本与时间戳。

## 3. 外部搜索触发表（命中即联网，产出"外部情报与决策依据"表）

| 触发类型 | 例 | 检索目标 |
|---|---|---|
| 合规 / 政策 | 数据共享、个人信息、电子签、支付、广告 | 法规原文条款、监管细则；定位到条款号 |
| 第三方产品对接 | 微信支付、企业微信、订阅消息、电子签服务商 | 官方接入文档、限制清单 |
| 技术卡点 | 域名、审核类目、等保 | 官方规则、公开解决方案 |
| 商务筹码 | 定制收费口径、行业定价、竞品机制 | 行业惯例、同类项目公开信息 |
| 市场拓展 | 目标客户、区域竞品 | 公开招标记录、竞品动态 |

表格式：`证据（标题 + URL + 日期）→ 支撑的决策/行动 ID → 结论是否与内部判断一致`。矛盾处用 `[!warning]` 标出供复议。检索不到写"未检索到"。

## 4. 订正表（累积资产）

| 转写 | 正确 | 依据 | 首次出现 |
|---|---|---|---|
| 会灯 / 汇登 | 惠登 | 客户公司名，用户确认 | [00:00:22] |

- 本期新发现的误听词必须进表；同时写入 `memory/corrections.json`（Phase 8）。
- 拿不准的保留原文并括注"转写不清"。

## 5. 叙事纪律

- 每个议题先叙事：背景 → 讨论（谁提出、谁反对、为什么）→ 结论；再列表。
- 开头即结论：执行摘要 3–6 句，第一句就是最重要的判断。
- 业务线"时间线 + 思维链"：涉及既有项目的，写从基线到本期的里程碑链，以及"本期决策为什么是这一步"的因果推理。
- 状态转折写"由 X 转为 Y"，不只写当前状态。
- 禁元话语（"本节将介绍"）；禁对冲结论（"可能/或许"作主语）；数字只在改变读者决定时出现并附出处。

## 6. 长度基准

以逐字稿规模定下限，不以页数封顶：

| 逐字稿 | 纪要正文下限 | 原话引用下限 |
|---|---|---|
| < 8k 字 | 1500 字 | 3 |
| 8k–30k 字 | 4000 字 | 6 |
| 30k–80k 字 | 8000 字 | 10 |
| > 80k 字 | 12000 字 | 15 |

范例：知识库《商务拓展纪要_医疗健康服务商推介会_20260110_完整版》（922 行）是 3 小时推介会的合格长度。
