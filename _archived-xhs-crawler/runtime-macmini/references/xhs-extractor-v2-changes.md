# xhs_extractor_v2.py 修复说明

> 创建时间：2026-05-14
> 对应问题：OPTIMIZATION.md 中的 4 个主要问题

---

## 修复的问题

### 1. 图片数量读取不完整 ⭐⭐⭐

**根因**：小红书使用懒加载 + 轮播图结构复杂

**解决方案**（4 种检测方法）：
1. **指示器检测**：`.swiper-pagination-bullet` 等指示器元素
2. **Slide 检测**：`.swiper-slide` 元素计数
3. **图片预加载**：强制加载 `data-src` 后检测 `img` 标签
4. **页码文本检测**：检测 "1/14" 格式的页码指示器

**代码**：`detect_carousel_slides()` 函数

### 2. App 限制检测 ⭐⭐

**根因**：小红书服务端检测到非 App 请求，返回占位页面

**解决方案**：
- JS 提取器检测页面文本中的 "请打开小红书App"、"扫码查看" 等关键词
- 检测到限制时，立即返回已有数据 + 警告提示
- 建议用户手动在 App 中复制内容

### 3. 降级处理 ⭐⭐

**根因**：任何步骤失败导致整个提取中断

**解决方案**：
- 所有关键步骤包裹 try/catch
- 部分失败时继续处理其余步骤
- 最后返回已有数据 + errors/warnings 数组
- 不中断流程，最大化数据获取

### 4. 增强错误处理

**新增**：
- `errors` 数组：记录所有技术错误
- `warnings` 数组：记录数据完整性警告
- App 限制检测标志
- 正文完整性检查（< 50 字符警告）

---

## 与原版 xhs_extractor.py 的差异

| 特性 | 原版 | v2 修复版 |
|------|------|-----------|
| 轮播图检测 | 单一方法（指示器） | 4 种方法级联 |
| App 限制 | 无检测 | 自动检测 + 提示 |
| 图片预加载 | 无 | 强制加载 data-src |
| 降级处理 | 失败即中断 | 返回已有数据 |
| 错误信息 | 简单打印 | 结构化 errors/warnings |
| 正文兜底 | 基本 | 增强选择器 + 最长文本块 |

## 使用建议

**默认使用 v2**：
```bash
python3 scripts/xhs_extractor_v2.py "<小红书链接>"
```

**v2 失败时回退到 full_extractor**：
```bash
python3 scripts/xhs_full_extractor.py "<小红书链接>"
```
