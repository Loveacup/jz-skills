# 早新闻默认交付形态修正（2026-05-26）

## 背景

当前父皇偏好：日常触发词“早新闻”默认要 Telegram 直接文字版，不能只给文件路径，也不应默认走 PDF。PDF / 手机 PDF / 美化版仅在父皇明确点名时启用。

## 执行规则

1. 父皇只说“早新闻” → 建常规文字链：plan-preview（可简化）→ 门下封驳 → 尚书协调 → 三路检索 → fan-in + 分析总结 → 御史稽核 → 终审交付。
2. 终审卡必须输出可直接发送的完整 Markdown 正文；监国复命时可直接呈正文，不能只报 artifact path。
3. 父皇说“PDF / 手机 PDF / 美化版 / 重新排版” → 才启用 mobile PDF-first 工作流。
4. 若父皇后续在同一日要求 PDF，可基于已批准文字 artifact 建窄范围渲染链，不重跑检索。

## 防错

- 不要把“早新闻”自动解释为“手机版 PDF”。
- 不要先交路径再等父皇催正文。
- 文字版仍必须保留分析、今日总结、来源清单和 URL 可验证性。
