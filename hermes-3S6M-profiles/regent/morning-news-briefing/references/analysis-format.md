# 分析格式规范 v1.0

早新闻每篇 🔍 分析必须严格遵循此格式。任何偏离 → 驳回返工。

---

## 核心三段式 (Non-Negotiable)

```
🔍 分析：{标题 — ≤15字，must be a claim, not a topic}

前提：{1-2句事实陈述，引用具体数据/事件来源，标注来源 ID}
推理：{1-2句因果链，不含"可能/或许/似乎/一方面/另一方面"}
结论：{1句明确判断 — 不能是 "有待观察" "尚不确定"}
趋势：📈 上涨 / 📉 下跌 / ⚠️ 风险 / ➡️ 横盘 / 🔥 升级 / 🟢 缓和
为什么重要：{1句 impact statement — 对读者意味着什么}
```

---

## 反骑墙硬检查 (Mechanical, Auto-Reject on Hit)

以下词汇在任何分析中出现 → **整篇分析驳回**：

| 禁用词 | 为何是骑墙 |
|--------|-----------|
| 一方面……另一方面 | 典型骑墙，回避判断 |
| 可能 | 推测而非判断 |
| 或许 | 同可能 |
| 似乎 | 不确定 |
| 有待观察 | 推给未来 |
| 尚不确定 | 回避 |
| 既有……也有 | 和稀泥 |
| 需要进一步 | 拖延 |
| 取决于 | 条件式骑墙（除非明确列出条件+各路径结论） |

**例外规则**：如果"取决于"后面跟了明确列举的条件+每条路径的结论（如"取决于 X：若 X>10 则 A，否则 B"），则不算骑墙——但这种情况更适合直接写成结论。

## 完整示例

### ✅ 合格

```
🔍 分析：美债收益率见顶信号明确

前提：美国 10 年期国债收益率已从 4.7% 高位回落至 4.35%（WSJ），
5 月 CPI 数据降至 3.3% 低于预期（BLS），联储 6 月会议纪要偏鸽派。

推理：通胀下行 + 联储鸽派转向 → 市场price-in降息预期 → 
长端收益率承压下行。油价回落进一步缓解通胀担忧。

结论：美债收益率已见顶，下半年大概率进入下行通道。

趋势：📉 下行
为什么重要：全球资产定价锚转向，A 股成长板块、港股科技将受益于流动性改善。
```

### ❌ 不合格 (反骑墙检查驳回)

```
🔍 分析：台海局势

前提：一方面赖清德就职演说维持现状基调，另一方面解放军军演持续。

推理：短期可能不会直接冲突，但长期似乎存在不确定性。

结论：有待观察。
趋势：⚠️
为什么重要：台海局势影响区域稳定。
```

驳回原因：
1. 标题是 topic 不是 claim（"台海局势" → 应改为 "赖清德就职后台海短期无冲突风险"）
2. "一方面……另一方面" → 禁用词
3. "可能""似乎" → 禁用词
4. "有待观察" → 禁用词
5. "为什么重要" 太泛，未量化 impact

## 格式检查清单 (渲染前)


- [ ] 每个 🔍 分析含 前提：/推理：/结论：/趋势：/为什么重要： 五要素？
- [ ] 趋势 emoji 是标准集中的？(📈📉⚠️➡️🔥🟢)
- [ ] 前提是否引用了具体来源？（格式：来源 ID 或 outlet 名 + 数字）
- [ ] 推理链是单线程因果，不是分叉/罗列？
- [ ] 结论是明确判断句（非疑问/条件/推诿）？
- [ ] grep "一方面|另一方面|可能|或许|似乎|有待观察|尚不确定" 无命中？

## 数量与分布

| 板块 | 最少分析数 | 类型偏好 |
|------|-----------|---------|
| 🔥 头条/中东 | 2 | 地缘政治/安全 |
| 🇺🇸 美国 | 1 | 经济/政治 |
| 🇨🇳 中国 | 1 | 经济/政策 |
| 🌍 国际 | 1 | 地缘/区域 |
| 📊 市场 | 1 | 金融/商品 |

**总计 ≥6 篇分析**。每篇分析对应一条正文新闻（不能凭空分析）。

## 与每日简报 (DailyBrief) 项目的对比吸收

| DailyBrief 做法 | 我们的调整 |
|----------------|-----------|
| 按 locale 分源 → en/zh 两路 | 我们三路：zh/en/市场 |
| 单源容错 → 源挂了跳过不阻塞 | 同样，但必须 ≥15/18 源成功 |
| 模板化章节 | 固化 5 个固定板块 |
| 无分析层 | 我们增加 🔍 分析层（核心差异） |
