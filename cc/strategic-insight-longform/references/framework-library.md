# 分析框架模型库

> framework-builder 的参考文件。根据 `analysis_type` 选择 **3 个必选 + 3-5 个推荐补充** 框架，组合使用。
>
> v5.0 新增：**双轴分析法（dual-axis）** 作为一级框架引入；新增 analysis_type 路由表显式映射。

## analysis_type 框架推荐路由表

> framework-builder 第一层选择依据。先查 analysis_type，再按下表组合必选 + 补充。

| analysis_type | 必选框架（3 项）                         | 推荐补充（3-5 项）                       |
| ------------- | ------------------------------------- | --------------------------------------- |
| 战略级全息    | S-T-D 立方体 + 5W2H + PESTLE          | 波特五力 / Cynefin / 蓝海战略           |
| **现象解构**  | **dual-axis（双轴）** + 5W2H + 因果链 | S-T-D / 利益相关者矩阵                  |
| **趋势研判**  | **dual-axis** + S 曲线 + 技术成熟度   | PESTLE / scenario planning              |
| **企业战略**  | **dual-axis** + 波特五力 + 价值链     | 资源基础观（VRIO）/ 商业模式画布        |
| 政策分析      | PESTLE + 利益相关者 + S-T-D           | 因果链 / 政策周期                       |
| 行业研究      | 波特五力 + S-T-D + 价值链             | dual-axis / SCP 范式                    |

**使用说明**：
- 必选框架由 framework-builder 自动注入，不可裁切
- 推荐补充由 framework-builder 按主题 + 素材丰度二次评估，选 3-5 个
- 双轴（dual-axis）详见 [`dual-axis-methodology.md`](dual-axis-methodology.md)，对应分类详见下文 §K
- 若 GoT controller 评分判定双轴 ROI > S-T-D，可在 analysis_type = "战略级全息" 时动态切换主框架

## A. 战略规划

### SWOT 分析 (Strengths, Weaknesses, Opportunities, Threats)

- **别名**: 态势分析法
- **类别**: A.战略规划
- **适用类型**: enterprise, industry, comparison
- **核心用途**: 识别内部优劣势与外部机会威胁，制定战略匹配方案（SO/WO/ST/WT 四象限策略）
- **关键维度**: 内部能力 × 外部环境
- **输出**: SWOT 矩阵 + 四象限战略建议
- **与S-T-D关联**: 空间轴（内外部环境扫描）+ 时间轴（机会与威胁的时效性）

### BCG 矩阵 (Boston Consulting Group Matrix)

- **别名**: 波士顿矩阵、增长-份额矩阵、四象限矩阵
- **类别**: A.战略规划
- **适用类型**: enterprise, industry
- **核心用途**: 根据市场增长率和相对市场份额将业务/产品分为明星、金牛、问题、瘦狗四象限，指导资源配置
- **关键维度**: 市场增长率 × 相对市场份额
- **输出**: 四象限定位图 + 资源配置建议
- **与S-T-D关联**: 空间轴（市场份额对标）+ 时间轴（增长率趋势）

### 安索夫矩阵 (Ansoff Matrix)

- **别名**: 产品-市场扩展矩阵
- **类别**: A.战略规划
- **适用类型**: enterprise, trend
- **核心用途**: 通过现有/新产品 × 现有/新市场四象限，规划增长路径（市场渗透、产品开发、市场开发、多元化）
- **关键维度**: 产品新旧 × 市场新旧
- **输出**: 增长路径选择 + 风险评估
- **与S-T-D关联**: 空间轴（市场地理扩展）+ 领域轴（产品多元化）

### GE 矩阵 (GE-McKinsey Matrix)

- **别名**: 通用电气矩阵、行业吸引力-竞争力矩阵
- **类别**: A.战略规划
- **适用类型**: enterprise, industry
- **核心用途**: 以行业吸引力和业务竞争力两维度评估业务组合，指导投资/维持/退出决策
- **关键维度**: 行业吸引力（高/中/低）× 竞争实力（强/中/弱）
- **输出**: 九宫格定位 + 投资优先级
- **与S-T-D关联**: 空间轴（行业定位）+ 领域轴（竞争力评估）

### VRIO 分析

- **别名**: 资源基础观分析
- **类别**: A.战略规划
- **适用类型**: enterprise
- **核心用途**: 评估企业资源和能力是否具有价值(V)、稀缺性(R)、难以模仿(I)、组织支撑(O)，判断可持续竞争优势
- **关键维度**: 价值性 → 稀缺性 → 不可模仿性 → 组织性（逐层筛选）
- **输出**: 资源竞争优势等级（暂时/可持续/竞争均势/劣势）
- **与S-T-D关联**: 领域轴（核心能力识别）+ 时间轴（优势持续性）

### 三层面理论 (Three Horizons)

- **别名**: 麦肯锡三层面增长理论
- **类别**: A.战略规划
- **适用类型**: enterprise, trend
- **核心用途**: 将业务分为 H1（核心业务维护）、H2（新兴业务培育）、H3（未来业务探索），平衡短中长期增长
- **关键维度**: 时间跨度 × 业务成熟度
- **输出**: 三层面业务组合 + 资源分配比例
- **与S-T-D关联**: 时间轴（短中长期规划）+ 领域轴（业务多元化）

### 战略钟 (Strategy Clock)

- **别名**: Bowman 战略钟
- **类别**: A.战略规划
- **适用类型**: enterprise, industry
- **核心用途**: 以价格和感知价值两维度，展示 8 种竞争策略定位（低价低值、低价、混合、差异化等）
- **关键维度**: 价格 × 感知附加值
- **输出**: 竞争策略定位 + 战略转移路径
- **与S-T-D关联**: 空间轴（竞争定位）+ 领域轴（价值主张）

### 核心竞争力分析 (Core Competence)

- **别名**: Prahalad & Hamel 核心能力
- **类别**: A.战略规划
- **适用类型**: enterprise
- **核心用途**: 识别企业难以被竞争对手复制的核心能力（通过客户价值、竞争差异化、延展性三重检验）
- **关键维度**: 客户价值贡献 × 竞争独特性 × 业务延展性
- **输出**: 核心能力识别 + 能力杠杆战略
- **与S-T-D关联**: 领域轴（能力边界）+ 时间轴（能力演进）

### 平衡计分卡 / 战略地图 (BSC / Strategy Map)

- **别名**: BSC、KPI 体系
- **类别**: A.战略规划
- **适用类型**: enterprise
- **核心用途**: 从财务、客户、内部流程、学习与成长四维度建立战略执行体系，将战略转化为可量化指标
- **关键维度**: 财务 × 客户 × 内部流程 × 学习成长
- **输出**: 战略地图 + KPI 指标体系 + 行动计划
- **与S-T-D关联**: 领域轴（多维度绩效）+ 时间轴（目标分解）

### 情景规划 (Scenario Planning)

- **别名**: 情景分析法、Shell 情景法
- **类别**: A.战略规划
- **适用类型**: trend, industry
- **核心用途**: 构建 2-4 个未来可能情景（通常为 2×2 矩阵），为不同情景制定应对战略
- **关键维度**: 两个关键不确定性因素交叉
- **输出**: 情景矩阵 + 各情景下的战略响应
- **与S-T-D关联**: 时间轴（T+5 终局预判）+ 领域轴（不确定性因素）

### 战略意图分析 (Strategic Intent)

- **别名**: Hamel & Prahalad 战略意图
- **类别**: A.战略规划
- **适用类型**: enterprise
- **核心用途**: 分析企业超越现有资源的远大目标及实现路径，评估"以小搏大"的战略张力
- **关键维度**: 愿景野心 × 资源约束 × 杠杆策略
- **输出**: 战略意图声明 + 能力差距 + 杠杆路径
- **与S-T-D关联**: 时间轴（长期愿景）+ 空间轴（竞争格局）

## B. 竞争分析

### 价值链分析 (Value Chain Analysis)

- **别名**: Porter 价值链
- **类别**: B.竞争分析
- **适用类型**: enterprise, industry
- **核心用途**: 分解企业活动为主要活动和支持活动，识别价值创造环节和成本驱动因素
- **关键维度**: 主要活动（进货→生产→出货→营销→服务）× 支持活动（基础设施/人力/技术/采购）
- **输出**: 价值链活动分解 + 成本/价值分析 + 优化建议
- **与S-T-D关联**: 领域轴（产业链定位）+ 空间轴（全球价值链分工）

### 竞争战略三角 (Competitive Strategy Triangle)

- **别名**: 大前研一 3C 模型
- **类别**: B.竞争分析
- **适用类型**: enterprise, industry
- **核心用途**: 从公司(Company)、客户(Customer)、竞争者(Competitor)三角关系分析竞争态势
- **关键维度**: 公司能力 × 客户需求 × 竞争者行为
- **输出**: 三角关系图 + 差异化策略
- **与S-T-D关联**: 空间轴（市场竞争格局）+ 领域轴（多方利益）

### 战略群组分析 (Strategic Group Analysis)

- **别名**: 竞争集群图
- **类别**: B.竞争分析
- **适用类型**: industry, comparison
- **核心用途**: 将行业内企业按战略特征分组，识别竞争强度和移动壁垒
- **关键维度**: 任意两个战略维度（如价格×专业化程度、规模×地理覆盖）
- **输出**: 战略群组地图 + 群组间竞争分析
- **与S-T-D关联**: 空间轴（行业内定位）+ 领域轴（战略差异）

### 基准化分析 (Benchmarking)

- **别名**: 标杆管理、对标分析
- **类别**: B.竞争分析
- **适用类型**: enterprise, industry, comparison
- **核心用途**: 与行业标杆或最佳实践进行系统性对比，识别绩效差距和改进方向
- **关键维度**: 绩效指标 × 对标对象（内部/竞争/功能/通用）
- **输出**: 差距分析表 + 改进优先级 + 行动计划
- **与S-T-D关联**: 空间轴（全球对标）+ 时间轴（绩效趋势）

### 蓝海战略 (Blue Ocean Strategy)

- **别名**: 价值创新、四动作框架
- **类别**: B.竞争分析
- **适用类型**: enterprise, trend
- **核心用途**: 通过"消除-减少-增加-创造"四动作框架，开辟无竞争的新市场空间
- **关键维度**: 行业竞争要素（消除 / 减少 / 增加 / 创造）
- **输出**: 战略画布 + 四动作框架 + 新价值曲线
- **与S-T-D关联**: 领域轴（市场边界重构）+ 时间轴（新市场演进）

### 竞争态势矩阵 (CPM)

- **别名**: Competitive Profile Matrix
- **类别**: B.竞争分析
- **适用类型**: enterprise, industry, comparison
- **核心用途**: 对关键成功因素进行加权评分，量化比较竞争对手的相对竞争地位
- **关键维度**: 关键成功因素 × 权重 × 评分
- **输出**: 竞争对手加权评分表 + 排名
- **与S-T-D关联**: 空间轴（竞争格局量化）+ 领域轴（多维度评估）

## C. 营销增长

### STP 分析 (Segmentation-Targeting-Positioning)

- **别名**: 市场细分-目标-定位
- **类别**: C.营销增长
- **适用类型**: enterprise, trend
- **核心用途**: 市场细分、目标市场选择、品牌定位三步法，制定精准营销策略
- **关键维度**: 细分变量 → 目标评估 → 定位声明
- **输出**: 细分市场地图 + 目标市场选择 + 定位声明
- **与S-T-D关联**: 空间轴（市场地理细分）+ 领域轴（需求细分）

### 营销组合模型族 (4P / 4C / 4R)

- **别名**: Marketing Mix
- **类别**: C.营销增长
- **适用类型**: enterprise
- **核心用途**: 4P（产品/价格/渠道/促销）从企业视角、4C（客户/成本/便利/沟通）从客户视角、4R（关联/反应/关系/报酬）从关系视角构建营销策略组合
- **关键维度**: 4P（Product/Price/Place/Promotion）或 4C/4R 对应维度
- **输出**: 营销策略组合方案
- **与S-T-D关联**: 空间轴（渠道/地理覆盖）+ 领域轴（产品/市场策略）

### AARRR 漏斗 (Pirate Metrics)

- **别名**: 海盗指标、增长漏斗
- **类别**: C.营销增长
- **适用类型**: enterprise, trend
- **核心用途**: 按获客(Acquisition)→激活(Activation)→留存(Retention)→收入(Revenue)→推荐(Referral)五阶段分析用户增长
- **关键维度**: 五阶段转化率 + 各阶段关键指标
- **输出**: 增长漏斗分析 + 各阶段优化策略
- **与S-T-D关联**: 时间轴（用户生命周期）+ 领域轴（增长引擎）

### KANO 模型

- **别名**: 卡诺模型、需求分类模型
- **类别**: C.营销增长
- **适用类型**: enterprise, trend
- **核心用途**: 将产品功能分为基本型、期望型、兴奋型、无差异型、反向型五类，指导产品功能优先级
- **关键维度**: 功能充足度 × 用户满意度
- **输出**: 需求分类矩阵 + 功能优先级排序
- **与S-T-D关联**: 领域轴（用户需求层次）+ 时间轴（需求演变）

### RFM 模型

- **别名**: 客户价值分析
- **类别**: C.营销增长
- **适用类型**: enterprise
- **核心用途**: 按最近购买时间(Recency)、购买频率(Frequency)、消费金额(Monetary)三维度细分客户价值
- **关键维度**: R × F × M 三维评分
- **输出**: 客户分群（8 类）+ 差异化运营策略
- **与S-T-D关联**: 时间轴（购买行为周期）+ 空间轴（客户地理分布）

### 消费者决策路径模型族 (AIDMA / AISAS)

- **别名**: 注意-兴趣-欲望-记忆-行动、注意-兴趣-搜索-行动-分享
- **类别**: C.营销增长
- **适用类型**: enterprise, trend, phenomenon
- **核心用途**: AIDMA（传统媒体时代）和 AISAS（互联网时代）描述消费者从认知到购买的决策路径
- **关键维度**: 认知阶段链路 + 各阶段触点
- **输出**: 消费者旅程图 + 各阶段营销策略
- **与S-T-D关联**: 时间轴（决策周期）+ 领域轴（媒体渠道演变）

### HOOK 模型

- **别名**: 上瘾模型
- **类别**: C.营销增长
- **适用类型**: enterprise, trend, phenomenon
- **核心用途**: 通过触发(Trigger)→行动(Action)→多变酬赏(Variable Reward)→投入(Investment)四步循环，构建用户习惯
- **关键维度**: 四步循环 × 内外触发机制
- **输出**: 习惯形成循环图 + 各步骤设计方案
- **与S-T-D关联**: 领域轴（产品机制）+ 时间轴（习惯养成周期）

### 用户旅程地图 (Customer Journey Map)

- **别名**: 用户体验地图、触点地图
- **类别**: C.营销增长
- **适用类型**: enterprise
- **核心用途**: 可视化用户从认知到忠诚的全流程体验，识别痛点和优化机会
- **关键维度**: 用户阶段 × 行为 × 情感 × 触点 × 痛点/机会
- **输出**: 旅程地图可视化 + 体验优化优先级
- **与S-T-D关联**: 时间轴（用户生命周期）+ 领域轴（多触点体验）

### 增长飞轮 (Growth Flywheel)

- **别名**: Amazon 飞轮、正反馈循环
- **类别**: C.营销增长
- **适用类型**: enterprise, trend
- **核心用途**: 识别业务增长中的正反馈循环要素，构建自我强化的增长引擎
- **关键维度**: 循环要素 × 因果关系 × 摩擦力
- **输出**: 飞轮循环图 + 关键驱动力 + 减摩策略
- **与S-T-D关联**: 领域轴（业务系统）+ 时间轴（循环加速度）

### 定价策略矩阵

- **别名**: 价格-质量矩阵
- **类别**: C.营销增长
- **适用类型**: enterprise
- **核心用途**: 根据产品质量和价格水平的组合，选择溢价、渗透、撇脂、经济等定价策略
- **关键维度**: 价格水平 × 感知质量
- **输出**: 定价策略选择 + 竞争价格对标
- **与S-T-D关联**: 空间轴（区域定价差异）+ 时间轴（价格生命周期）

## D. 商业模式

### 商业模式画布 (Business Model Canvas)

- **别名**: BMC、Osterwalder 九模块
- **类别**: D.商业模式
- **适用类型**: enterprise, trend
- **核心用途**: 通过 9 个模块（客户细分、价值主张、渠道、客户关系、收入流、核心资源、关键活动、关键伙伴、成本结构）系统描述商业模式
- **关键维度**: 价值创造 × 价值传递 × 价值获取
- **输出**: 商业模式画布图 + 模块间关联分析
- **与S-T-D关联**: 领域轴（商业系统完整描述）+ 空间轴（市场覆盖）

### 精益画布 (Lean Canvas)

- **别名**: Ash Maurya 精益画布
- **类别**: D.商业模式
- **适用类型**: enterprise, trend
- **核心用途**: 面向创业场景的商业模式工具，聚焦问题、解决方案、关键指标、独特优势、渠道等 9 要素
- **关键维度**: 问题-解决方案匹配 × 市场-产品匹配
- **输出**: 精益画布图 + 关键假设清单
- **与S-T-D关联**: 领域轴（产品市场匹配）+ 时间轴（验证迭代）

### 平台战略 / 双边市场 (Platform Strategy)

- **别名**: 多边平台、平台经济
- **类别**: D.商业模式
- **适用类型**: enterprise, trend, phenomenon

- **适用类型**: 所有
- **核心用途**: 通过情境→冲突→问题→答案的叙事结构，构建有说服力的分析框架
- **关键维度**: 背景设定 → 矛盾揭示 → 核心问题 → 解决方案
- **输出**: SCQA 叙事框架

- **输出**: 失败模式清单 + 防护措施
- **与S-T-D关联**: 通用工具，特别适用于时间轴（风险预判）

- **与S-T-D关联**: 领域轴（Composite 复合生态）+ 时间轴（动态演化）

- **关键维度**: 目标 × 结果 × 差距原因 × 规律提取
- **输出**: 复盘报告 + 经验教训 + 行动改进
- **与S-T-D关联**: 时间轴（历史回顾）+ 领域轴（跨域经验迁移）

### 问题树分析 (Issue Tree)

- **别名**: 逻辑树、假设树
- **类别**: G.思维工具
- **适用类型**: 所有
- **核心用途**: 将复杂问题层层分解为可解决的子问题，遵循 MECE 原则
- **关键维度**: 核心问题 → 子问题 → 子子问题（树形展开）

- **与S-T-D关联**: 通用工具，用于框架构建阶段的问题拆解

- **别名**: 连锁效应分析、Howard Marks 二阶思维
- **类别**: G.思维工具
- **适用类型**: 所有

- **关键维度**: 偏差类型 × 触发场景 × 影响程度
- **输出**: 相关偏差识别 + 去偏策略
- **与S-T-D关联**: 领域轴（行为机制）+ 时间轴（决策过程）

### 乔哈里窗口 (Johari Window)

- **别名**: 自我意识模型
- **类别**: I.心理行为
- **适用类型**: enterprise, phenomenon
- **核心用途**: 通过公开区/盲区/隐藏区/未知区四象限，分析信息不对称和沟通障碍
- **关键维度**: 自己知道/不知道 × 他人知道/不知道
- **输出**: 四象限分析 + 沟通改进策略
- **与S-T-D关联**: 领域轴（信息不对称分析）

### 福格行为模型 (Fogg Behavior Model)

- **别名**: B=MAT 模型
- **类别**: I.心理行为
- **适用类型**: trend, phenomenon, enterprise
- **核心用途**: 行为 = 动机(Motivation) × 能力(Ability) × 触发(Trigger)，三要素同时满足才产生行为
- **关键维度**: 动机强度 × 能力/难度 × 触发时机
- **输出**: 行为设计方案 + 干预策略
- **与S-T-D关联**: 领域轴（行为机制设计）+ 时间轴（行为养成）

### 损失厌恶 / 前景理论 (Prospect Theory)

- **别名**: Kahneman & Tversky 前景理论
- **类别**: I.心理行为
- **适用类型**: phenomenon, trend
- **核心用途**: 人们对损失的敏感度约为收益的 2 倍，决策依赖参照点而非绝对值
- **关键维度**: 参照点 × 收益/损失不对称 × 确定性效应
- **输出**: 决策偏差分析 + 框架效应应用
- **与S-T-D关联**: 领域轴（决策心理）+ 时间轴（预期管理）

### 社会认同理论 (Social Identity Theory)

- **别名**: Tajfel 社会认同、群体认同
- **类别**: I.心理行为
- **适用类型**: phenomenon, trend
- **核心用途**: 人们通过所属群体获得自我认同，解释群体偏见、品牌忠诚、文化认同等现象
- **关键维度**: 内群体/外群体 × 认同强度 × 群体行为
- **输出**: 群体认同分析 + 行为解释
- **与S-T-D关联**: 空间轴（群体分布）+ 领域轴（社会心理）

## J. 财务估值

### 杜邦分析 (DuPont Analysis)

- **别名**: ROE 分解
- **类别**: J.财务估值
- **适用类型**: enterprise
- **核心用途**: 将 ROE 分解为利润率 × 资产周转率 × 权益乘数，诊断盈利能力、运营效率、财务杠杆
- **关键维度**: 净利润率 × 总资产周转率 × 权益乘数
- **输出**: ROE 分解树 + 驱动因素诊断
- **与S-T-D关联**: 领域轴（财务健康度）+ 时间轴（趋势对比）

### DCF 估值 (Discounted Cash Flow)

- **别名**: 现金流折现法
- **类别**: J.财务估值
- **适用类型**: enterprise
- **核心用途**: 将未来预期自由现金流折现到当前，评估企业内在价值
- **关键维度**: 自由现金流预测 × 折现率(WACC) × 终值
- **输出**: 企业估值 + 敏感性分析
- **与S-T-D关联**: 时间轴（现金流预测）+ 领域轴（估值方法论）

### EVA 经济增加值 (Economic Value Added)

- **别名**: 经济利润
- **类别**: J.财务估值
- **适用类型**: enterprise
- **核心用途**: 衡量企业是否创造了超过资本成本的真实经济利润（EVA = NOPAT - 资本成本）
- **关键维度**: 税后经营利润 × 投入资本 × 加权资本成本
- **输出**: EVA 计算 + 价值创造/毁灭判断
- **与S-T-D关联**: 领域轴（价值创造评估）+ 时间轴（趋势追踪）

### 本量利分析 (CVP Analysis)

- **别名**: 成本-产量-利润分析、盈亏平衡分析
- **类别**: J.财务估值
- **适用类型**: enterprise
- **核心用途**: 分析成本、销量、利润三者关系，计算盈亏平衡点
- **关键维度**: 固定成本 × 变动成本 × 单价 × 销量
- **输出**: 盈亏平衡点 + 安全边际 + 利润敏感性
- **与S-T-D关联**: 时间轴（盈利时间线）+ 领域轴（成本结构）

### 财务比率分析族

- **别名**: 流动比率、速动比率、资产负债率、利息保障倍数等
- **类别**: J.财务估值
- **适用类型**: enterprise, comparison
- **核心用途**: 通过偿债能力、营运能力、盈利能力、成长能力四类财务比率，综合评估企业财务状况
- **关键维度**: 偿债能力 × 营运能力 × 盈利能力 × 成长能力
- **输出**: 财务比率仪表板 + 行业对标 + 健康度评估
- **与S-T-D关联**: 空间轴（行业对标）+ 时间轴（趋势分析）

## K. 双轴框架（v5.0 新增类别）

### 双轴分析法 (hv-analysis / Dual-Axis Methodology) ⭐

- **别名**: 纵横轴分析法、hv-analysis
- **类别**: K.双轴框架
- **适用类型**: phenomenon, trend, enterprise（**现象解构 / 趋势研判 / 企业战略 三大场景必选**）
- **核心用途**: 把 S-T-D 三维空间中的「时间维度」与「对比维度」显式化为可直接调用的执行模板，避免分析陷入隐式路径或单点深挖
- **关键维度**:
  - 纵轴（历时 / temporal）：起源追溯 → 诞生节点 → 演进历程 → 决策逻辑 → 阶段划分（5 步硬模板）
  - 横轴（共时 / spatial）：A/B/C 决策树（A 无竞品讲生态位 / B 1-2 竞品深度对比 / C 3+ 竞品矩阵化）
  - 交汇：5 个核心问题 + 三剧本未来推演（最可能 / 最危险 / 最乐观）
- **输出**:
  - `temporal-axis.md`（纵轴 5 步硬字数区间）
  - `spatial-axis.md`（横轴 A/B/C 分支输出）
  - `cross-insight.md`（横纵交汇 5 问 + 三剧本）
- **与 S-T-D 关系**:
  - S-T-D 是三维全息空间（Subject / Time / Dimension）
  - 双轴 = S-T-D 的「时间维度」+「对比维度」的可调用模板
  - 二者不互斥：战略级全息时 S-T-D 主导；现象/趋势/企业战略时双轴优先；GoT 阶段会评分自动切换
- **与 GoT / CoV 关系**:
  - 双轴启用后 GoT 评估"双轴 vs S-T-D 哪个 ROI 更高"，可动态切换
  - CoV 与双轴正交，双轴启用时 CoV 仍按原流程跑
- **完整模板与执行细节**: 见 [`dual-axis-methodology.md`](dual-axis-methodology.md)
- **agent 分工**:
  - `framework-builder` 选定 dual-axis 时，把横纵轴模板注入 prompt
  - `temporal-researcher` 执行纵轴 5 步
  - `spatial-researcher` 执行横轴 A/B/C 决策树
  - `domain-researcher` 补充维度交叉点
  - `insight-synthesizer` 产出"横纵交汇洞察"固定输出块

**典型使用示例**：
- 现象解构："为什么瑞幸能反超星巴克"→ 纵轴讲瑞幸 2017-2026 演进 + 横轴对比星巴克/Manner/Mstand + 交汇洞察"中国咖啡赛道的供给侧革命"
- 趋势研判："DeepSeek-R1 对全球 AI 格局的影响"→ 纵轴讲开源 LLM 2020-2026 演进 + 横轴对比 OpenAI/Anthropic/Meta + 交汇三剧本
