# hv-analysis 双轴方法论详解

## 方法论起源

双轴方法论（Horizontal-Vertical Axis Analysis，简称 hv-analysis）是 SIL v5.0 显式引入的核心分析框架，与 [std-cube-methodology.md](std-cube-methodology.md) 并列。它将「时间演化」（纵轴）与「空间对比」（横轴）这两条最高频的分析路径模板化，避免分析师每次都从零拼骨架。

> 不再把"对比"和"演化"当作隐式直觉，而是把它们升格为强制执行的两条轴。

## 适用场景

| analysis_type | 是否首选双轴 | 理由 |
|---|---|---|
| 现象解构 | ⭐ 首选 | 现象一定发生在某段时间、并与某些对照物形成反差 |
| 趋势研判 | ⭐ 首选 | 趋势 = 历史曲线 + 横向异变检测 |
| 企业战略 | ⭐ 首选 | 企业 = 时间叙事 + 竞争格局 |
| 战略级全息 | 与 S-T-D 并用 | S-T-D 主导，双轴作为时间维和领域维的具体执行模板 |
| 政策分析 | 备选 | PESTLE 优先；双轴可作演化轴补充 |
| 行业研究 | 备选 | 波特五力优先；双轴用于补全行业演化与标杆对比 |

## 纵轴 5 步执行模板（历时维度）

> 由 **temporal-researcher** 主导，硬字数区间 6000-15000 字（不区分模式，所有模式同标准）。

### 步骤 1：起源追溯

**核心问题**：今天我们看到的东西，30 年前长什么样？甚至更早？

**数据点要求**：
- 至少 2 个跨越 5 年以上的历史节点
- 至少 1 个跨界类比（例如分析咖啡赛道时类比茶饮、便利店）
- 引用年代必须精确到年份，不接受"上世纪""很多年前"等模糊表述

**执行要点**：
- 起源不只是"创立时间"，而是「形成这个赛道的更深层底层条件何时出现」
- 必须问"如果某条件不在，今天这个赛道会不会存在"

### 步骤 2：诞生节点

**核心问题**：哪一个具体事件、哪一年、哪一家公司，标记了这个东西「真正诞生」？

**数据点要求**：
- 必须给出精确的年份 + 关键人物 + 事件描述（不少于 200 字）
- 引用至少 2 个独立来源（财报、新闻、行业白皮书）
- 区分「技术诞生」「商业诞生」「文化诞生」（可能是 3 个不同节点）

**执行要点**：
- 警惕"事后追认"——很多创业者宣称的诞生时间是包装出来的
- 必须找到一个第三方可验证的拐点

### 步骤 3：演进历程

**核心问题**：从诞生到今天，经历了哪几个阶段？每个阶段的标志事件是什么？

**数据点要求**：
- 至少切分 3 个阶段（建议 3-5 个）
- 每个阶段配 1 张时间轴图（Mermaid timeline 或 ASCII）
- 每个阶段标注：标志事件 / 关键玩家 / 用户规模 / 政策环境

**执行要点**：
- 阶段切分不能凭感觉，必须有「质变信号」（市场规模翻倍、政策突变、技术代际跃迁）
- 使用「S 曲线」「Gartner 技术成熟度曲线」校准每个阶段在曲线上的位置

### 步骤 4：决策逻辑

**核心问题**：每个阶段的关键玩家做了什么决策？为什么是那个决策、不是另一个？

**数据点要求**：
- 至少分析 3 个关键决策（成功 + 失败各举例）
- 每个决策必须重建当时的信息环境（不能用今天的认知去判断当年的人）
- 引用 1 次以上当事人原话或决策时刻的内部备忘录

**执行要点**：
- 拒绝事后诸葛——一定要还原决策时的不确定性
- 找出「关键岔路口」：如果当时选了另一条路，今天会怎样

### 步骤 5：阶段划分总结

**核心问题**：把上述时间叙事浓缩为「我们今天处在哪一个阶段、下一个拐点何时来」？

**数据点要求**：
- 一句话标注当前位置（S 曲线上的爆发期？过热期？出清期？）
- 给出下一个拐点的 3 个领先指标（leading indicators）

**执行要点**：
- 必须输出一个可证伪的预判（例如「如果 18 个月内 X 指标不达到 Y，则进入出清期」）
- 模糊的"未来可期"不算

## 横轴三分支决策树（共时维度）

> 由 **spatial-researcher** 主导。**先识别竞品数量**，再选分支。

```
横轴入口：识别竞品数量
   │
   ├─ 0 个竞品（无直接对手）─────────→ A 场景
   ├─ 1-2 个竞品（核心对手清晰）─────→ B 场景
   └─ 3+ 个竞品（红海格局）───────────→ C 场景
```

### A 场景：无竞品 → 讲生态位 + 替代品分析

**何时落入此分支**：分析对象处于全新赛道、或主动构建了独占细分（例如「特斯拉 2010 年的纯电豪华车」）

**执行模板**：
1. **生态位定义**：用 3 句话回答「它占了哪个空白格」
2. **替代品矩阵**：列出 5-10 个替代品（不是直接竞品，是用户在它出现前用什么）
3. **替代成本结构**：从替代品迁移过来的用户付出了什么代价
4. **生态位天花板**：这个空白格本身有多大、能撑多久

**字数要求**：A 场景 2000-4000 字（替代品分析占比 60%）

### B 场景：1-2 个竞品 → 双向深度对比

**何时落入此分支**：分析对象有 1-2 个公认的核心对手（例如「瑞幸 vs 星巴克」「DeepSeek vs OpenAI」）

**执行模板**：
- 对每个竞品做 1500-3000 字的深度对比
- 强制使用「四维交叉对比矩阵」：
  - 维度 1：产品策略（定位 / 定价 / SKU 宽度）
  - 维度 2：组织能力（团队基因 / 决策速度 / 执行密度）
  - 维度 3：资本运作（融资节奏 / 估值逻辑 / 上市路径）
  - 维度 4：用户心智（品牌联想 / NPS / 替换成本）
- 每个维度必须给出「对手赢在哪、自己赢在哪」的双向判断

**字数要求**：B 场景 1500-3000 字 × 竞品数

### C 场景：3+ 个竞品 → 矩阵化 + 标杆筛选

**何时落入此分支**：红海赛道（例如「2024 年的新茶饮」「中国电动车」）

**执行模板**：
1. **第一轮：全量矩阵**——把所有竞品按 5-7 个维度铺成大表，做粗筛
2. **第二轮：标杆筛选**——从矩阵中识别 2-3 个「真正威胁」（市占率前三、增速前三、估值前三的并集）
3. **第三轮：标杆深度对比**——对筛出的 2-3 个标杆，回到 B 场景的四维交叉
4. **第四轮：长尾分析**——剩余玩家用 1-2 段话概括「为什么活着但没威胁」

**字数要求**：C 场景 4000-8000 字（矩阵 + 标杆深度 + 长尾概括）

## 横纵交汇洞察输出模板

> 由 **insight-synthesizer** 在 Stage 4 强制产出此模板（不是可选项）。

```markdown
## 横纵交汇洞察

### 5 个核心问题

1. **为什么是现在？**（纵轴决定 × 横轴催化）
2. **为什么是它，不是别人？**（纵轴积累 × 横轴差异）
3. **它的不可替代性来自哪里？**（纵轴沉淀 × 横轴稀缺）
4. **它最大的风险来自哪里？**（横轴新对手 × 纵轴节奏失控）
5. **18 个月后这张牌桌长什么样？**（横轴洗牌 × 纵轴拐点）

### 三剧本未来推演

🎯 **最可能剧本**（概率 50-60%）
- 触发条件：[2-3 个高概率事件]
- 演化路径：[6 个月 / 12 个月 / 18 个月节点]
- 终局形态：[一句话]

⚠️ **最危险剧本**（概率 15-25%）
- 触发条件：[2-3 个黑天鹅]
- 演化路径：[关键拐点 + 多米诺骨牌]
- 终局形态：[一句话]
- 防御信号：[3 个领先指标]

🚀 **最乐观剧本**（概率 15-25%）
- 触发条件：[2-3 个突破口]
- 演化路径：[杠杆 + 加速器]
- 终局形态：[一句话]
- 跟踪信号：[3 个领先指标]
```

每个剧本必须给出概率估计（三者之和 = 100%）和可观测信号，禁止「未来充满不确定性」的废话收尾。

## 与 S-T-D 立方体的关系

| 维度 | S-T-D | 双轴 |
|---|---|---|
| 空间 | Space 轴（Point/Region/Nation/World 四层） | 横轴（竞品对比） |
| 时间 | Time 轴（T-5/T0/T+5 三段） | 纵轴（5 步演进） |
| 领域 | Domain 轴（Single/Multi/Composite 三层） | 不显式覆盖（由 domain-researcher 单独承担） |

**判断准则**：
- `analysis_type = "战略级全息"` → **S-T-D 主导**，双轴作为时间维与对比维的执行模板
- `analysis_type ∈ {"现象解构", "趋势研判", "企业战略"}` → **双轴优先**
- 二者**不互斥**，可以同时启用（GoT 阶段会自动评估 ROI）

详见 [std-cube-methodology.md](std-cube-methodology.md) 文末「与双轴的关系」段。

## 与 GoT / CoV 的关系

| 子系统 | 与双轴的关系 |
|---|---|
| **GoT 自适应** | got-controller 评估「双轴 vs S-T-D 哪个 ROI 更高」，可动态切换或并用。若 GoT 评分判定「时间维信息密度 > 空间维」，则纵轴权重上调。 |
| **CoV 反幻觉** | 与双轴**完全正交**。双轴启用时 CoV 三层验证（覆盖率 / 可达率 / 交叉验证）按原流程独立运行，不受影响。 |
| **L1-L4 质量门** | 与双轴正交。L3 内容终审会校验「横纵交汇洞察」是否齐全，缺失即回炉 insight-synthesizer。 |

## 何时启动 / 何时不用

### 启动条件（满足任一）
- framework-builder 路由判定 analysis_type ∈ {现象解构, 趋势研判, 企业战略}
- 用户在 prompt 中明确提到「演化」「历史」「对比」「竞争」等关键词
- got-controller 评估时间维或对比维 ROI 排前二

### 不启动条件
- 分析对象是**纯概念**（例如「什么是 RAG」），没有时间演化也没有竞品
- 分析对象是**静态截面**（例如「某国 GDP 构成」），时间和对比都不是核心
- 用户已明确要求纯 S-T-D 全息分析

## Worked Example：瑞幸反超星巴克

> 这是一个 B 场景双轴分析的完整骨架示意，不是范文。

### 纵轴 5 步
1. **起源追溯**：1971 年星巴克在西雅图诞生；2017 年瑞幸创立；底层条件是「中国移动支付 + LBS 配送基础设施」在 2014-2016 成熟
2. **诞生节点**：星巴克 1999 年进中国（北京国贸首店）；瑞幸 2018 年 1 月银河 SOHO 首店
3. **演进历程**：星巴克阶段切分（1999-2010 教育期 / 2010-2017 黄金期 / 2017-2023 守势期）；瑞幸阶段切分（2018-2019 闪电扩张 / 2019-2021 财务造假与重生 / 2021-2024 反超）
4. **决策逻辑**：星巴克坚持第三空间 vs 瑞幸 ALL-IN 数字化外带；星巴克 2018 年的「数字化转型」太晚
5. **阶段划分总结**：当前处于「外带咖啡渗透率拐点」，下一个拐点信号 = 县级城市渗透率 > 30%

### 横轴 B 场景（双向对比）
- 瑞幸 vs 星巴克 四维交叉对比
- 每方写 2000 字深度对比

### 横纵交汇 5 问 + 三剧本
- 5 问聚焦「为什么瑞幸赢、为什么是 2023 年赢、星巴克还能赢回吗」
- 三剧本：最可能（瑞幸稳坐 + 星巴克守住高端）/ 最危险（瑞幸再次造假）/ 最乐观（瑞幸出海复刻成功）

## 核心信条

1. **横纵必须交汇**：分别跑完不算完成，必须输出「横纵交汇 5 问 + 三剧本」
2. **演化必须给拐点**：不能只描述发生了什么，必须判断当前处于哪个拐点附近
3. **对比必须双向**：B/C 场景下不能只夸自己赢，必须诚实写出对手赢在哪
4. **数字必须精确**：年份、市占率、营收增速必须精确到年/月或个位数百分比
5. **预判必须可证伪**：三剧本的概率与领先指标都要可观测、可回顾
