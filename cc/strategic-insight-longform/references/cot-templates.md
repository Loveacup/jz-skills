# 详尽思维链模板库 (Comprehensive Chain-of-Thought Templates)

> 本文档提供每个分析阶段的**极其详细**的思维链模板，确保推理过程透明、可追溯、可验证。

---

## 一、元认知思维链框架 (Meta-Cognitive CoT Framework)

### 1.1 思维链的三层结构

```
┌─────────────────────────────────────────────────────────────────────┐
│                     思维链三层结构                                  │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  【第一层：认知层 - What I See】                                    │
│  ├─ 观察 (Observation): 我看到了什么？                             │
│  ├─ 识别 (Recognition): 这是什么类型的信息？                       │
│  └─ 分类 (Classification): 如何对这些信息分类？                    │
│                                                                     │
│  【第二层：推理层 - What I Think】                                  │
│  ├─ 关联 (Association): 这些信息之间有什么联系？                   │
│  ├─ 推断 (Inference): 从这些联系可以推断出什么？                   │
│  ├─ 假设 (Hypothesis): 我的初步判断是什么？                        │
│  └─ 验证 (Validation): 如何验证这个判断？                          │
│                                                                     │
│  【第三层：元认知层 - What I Know About My Thinking】               │
│  ├─ 置信度 (Confidence): 我对这个判断有多确定？                    │
│  ├─ 局限性 (Limitation): 我的分析有什么局限？                      │
│  ├─ 盲点 (Blind Spot): 我可能遗漏了什么？                          │
│  └─ 反思 (Reflection): 如果我错了，最可能错在哪里？                │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 1.2 思维链质量标准

| 维度 | 标准 | 检查点 |
|------|------|--------|
| **完整性** | 推理步骤无跳跃 | 每个结论都能追溯到前一步 |
| **透明性** | 推理过程可见 | 读者能理解"为什么这样想" |
| **可验证性** | 结论可被验证或反驳 | 提供了验证方法 |
| **自省性** | 承认不确定性 | 明确标注置信度和局限 |
| **可追溯性** | 来源清晰 | 每个信息点都有出处 |

## 四、思维链撰写最佳实践

### 4.1 DO（应该做的）

- ✅ 每个步骤都用"因为...所以..."结构
- ✅ 所有数字都标注来源
- ✅ 对不确定的判断标注置信度
- ✅ 主动提出可能的反驳
- ✅ 区分"事实"和"推测"
- ✅ 记录所有搜索和筛选过程
- ✅ 说明为什么选择这个而不是那个

### 4.2 DON'T（不应该做的）

- ❌ 直接给出结论不说推理过程
- ❌ 使用"显然"、"众所周知"等跳过论证
- ❌ 把假设当作事实
- ❌ 只列举支持证据忽略反面
- ❌ 使用模糊的程度词如"很多"、"大量"
- ❌ 遗漏来源标注
- ❌ 忽略置信度和不确定性

### 4.3 思维链模板句式

**观察阶段**：
- "我观察到..."
- "数据显示..."
- "在[来源]中，我发现..."

**推理阶段**：
- "因为[A]，所以[B]"
- "考虑到[A]和[B]，可以推断..."
- "这让我联想到..."
- "根据[理论/经验]，这意味着..."

**假设阶段**：
- "我的初步假设是..."
- "基于以上分析，我推测..."
- "我有[X%]的置信度认为..."

**验证阶段**：
- "支持这个判断的证据有..."
- "反对或存疑的证据有..."
- "如果这个判断正确，我们应该看到..."

**元认知阶段**：
- "我的分析可能存在的局限是..."
- "我可能遗漏了..."
- "如果我错了，最可能错在..."
- "需要进一步验证的是..."
