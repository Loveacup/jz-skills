# S-T-D 立方体方法论详解

## 方法论起源

S-T-D 立方体（Space-Time-Domain Holo-Cube）是一种战略洞察分析框架，由 Alex Cai 基于多年跨领域战略研究经验提炼而成。核心理念是：**拒绝静止、孤立的观点，通过三轴变焦形成全息洞察**。

## 核心理念

> 你不仅是一个分析师，更是一个"变焦者"。

传统分析往往陷入两个极端：
1. **只见树木不见森林**：只关注具体现象，缺乏系统视角
2. **只见森林不见树木**：只谈宏观趋势，缺乏具体支撑

S-T-D方法论通过三轴变焦，实现**既见树木又见森林**：
- 在**空间**上层层缩放
- 在**时间**上前后溯源
- 在**领域**上跨界融合

## 三轴详解

### X轴：空间变焦 (Spatial Zoom)

**核心问题**：这个现象的地域特殊性与普世性分别是什么？

**四层结构**：

| 层级 | 定义 | 典型问题 |
|------|------|---------|
| Point (点) | 具体的案例、场景、门店 | 这个具体案例有什么特点？ |
| Region (线) | 区域、产业集群、供应链 | 这个区域有什么独特性？ |
| Nation (面) | 全国趋势、政策、市场 | 在全国层面呈现什么规律？ |
| World (体) | 全球对标、普世规律 | 放到全球视野下如何理解？ |

**应用示例**：

分析"杭州咖啡创业热潮"：
- **Point**：Manner在杭州银泰的门店
- **Region**：长三角城市群的咖啡消费特征
- **Nation**：中国咖啡市场整体格局
- **World**：与日本便利店咖啡革命的对比

### Y轴：时间延展 (Temporal Stretch)

**核心问题**：为什么是现在？将来会怎样？

**三层结构**：

| 层级 | 定义 | 典型问题 |
|------|------|---------|
| T-5 (基因) | 历史溯源 | 它以前是什么？为什么现在爆发？ |
| T0 (周期) | 当前定位 | 处于S曲线的哪个位置？ |
| T+5 (终局) | 未来预判 | 未来会演化成什么？ |

**S曲线定位标准**：

```
         爆发期    过热期
              ╱ ╲
            ╱     ╲
          ╱         ╲ 出清期
        ╱             ╲
      ╱                 ╲ 成熟期
    ╱                     ╲
萌芽期
```

| 阶段 | 特征 | 关键指标 |
|------|------|---------|
| 萌芽期 | 少数玩家试错 | 渗透率<5% |
| 爆发期 | 快速增长，资本涌入 | 增速>30% |
| 过热期 | 泡沫形成，非理性竞争 | 估值泡沫 |
| 出清期 | 洗牌整合，弱者出局 | 融资困难 |
| 成熟期 | 格局稳定 | 增速<15% |

### Z轴：领域复合 (Domain Complexity)

**核心问题**：表面现象背后的真正本质是什么？

**三层结构**：

| 层级 | 定义 | 视角 |
|------|------|------|
| Single | 就事论事 | 只看本行业 |
| Multi | 寻找交叉 | 邻近领域互动 |
| Composite | 系统论视角 | 社会功能重定义 |

**复合生态分析公式**：

> **商业现象 = 经济行为 + 社会心理补偿 + 制度空间缝隙**

**社会心理维度**：

| 需求类型 | 问题 | 示例 |
|---------|------|------|
| 身份认同 | 满足什么身份表达？ | 咖啡=都市精英 |
| 社交货币 | 如何成为社交资本？ | 打卡=朋友圈内容 |
| 情感补偿 | 补偿什么缺失？ | 宠物=陪伴需求 |
| 意义感 | 如何提供意义？ | 公益=价值实现 |

**制度空间维度**：

| 维度 | 问题 |
|------|------|
| 政策红利 | 受益于什么政策？ |
| 监管套利 | 是否规避某种监管？ |
| 制度缝隙 | 填补什么制度空白？ |
| 基础设施 | 依赖什么基础设施成熟？ |

## 使用流程

### Phase 0: 三轴坐标校准

在深入细节前，先拉开分析的"景深"：

1. 确定空间变焦范围（需要分析到哪个层级）
2. 确定时间延展范围（回溯多远，预判多远）
3. 确定领域复合深度（单一还是复合）

### Phase 1: 六维填充

在确定的坐标系中，填充以下六个维度的信息：

| 维度 | 内容 |
|------|------|
| D1 消费者心理 | 需求、动机、行为 |
| D2 供给侧人力 | 人才、能力、供给 |
| D3 政策生态 | 政策、监管、趋势 |
| D4 市场成熟度 | 规模、增速、格局 |
| D5 文化认同 | 文化、价值观、符号 |
| D6 社会功能 | 社会角色、系统功能 |

### Phase 2: 联网补全

识别信息缺口，针对性搜索补充：

- 空间-世界维度缺乏对标 → 搜索 "global benchmark for [topic]"
- 时间-T-5维度缺乏历史 → 搜索 "[topic] history evolution"
- 领域-Composite缺乏分析 → 搜索 "[topic] social psychology"

### Phase 3: 洞察提炼

从填充的信息中提炼：

1. **全息摘要**：融合三轴的一句话核心判断
2. **核心洞察**：3-5个关键发现
3. **金句锚点**：可传播的记忆点
4. **战略启示**：可执行的建议

## 输出规范

### 全息摘要写作公式

> 这看似是 [表面现象]，实则是 [更深层的系统原因] 在 [特定时间周期] 于 [特定空间范围] 的 [必然/偶然] 产物。

### 核心洞察写作公式

> **洞察 = 观点 + 支撑逻辑 + 意外性**

### 本质重定义写作公式

> 它不是 [表面定义]，它是 [深层功能]。

## 应用场景

| 场景 | 空间侧重 | 时间侧重 | 领域侧重 |
|------|---------|---------|---------|
| 现象解构 | Point深挖 | T-5溯源 | Composite深度 |
| 行业分析 | Nation/World对标 | T0数据 | Multi交叉 |
| 趋势预判 | World对标 | T+5推演 | Single聚焦 |
| 战略规划 | 全层级覆盖 | 全周期覆盖 | 全深度覆盖 |

## 常见误区

1. **只有广度没有深度**：三轴都浅尝辄止
2. **只有深度没有广度**：只在某一轴深挖
3. **机械套用**：不根据主题调整三轴侧重
4. **数据堆砌**：有数据无洞察
5. **观点先行**：先有结论再找数据

## 核心信条

1. **变焦者思维**：在微观与宏观之间自由切换
2. **时间感知**：理解历史才能预判未来
3. **跨界融合**：打破领域边界才能看到本质
4. **数据驱动**：观点必须有事实支撑
5. **洞察为王**：不是堆砌信息，而是提炼洞见

## 与双轴方法论（dual-axis）的关系（v5.0 新增）

- **S-T-D** = 三维全息空间（Subject / Time / Dimension），强调"变焦者"自由切换
- **双轴**（dual-axis）= S-T-D 的「时间维度 + 对比维度」的**显式可调用模板**（纵轴 5 步 + 横轴 A/B/C）
- **何时用 S-T-D**：`analysis_type = "战略级全息"` 时主导，追求三维全景覆盖
- **何时用 双轴**：`analysis_type ∈ {"现象解构", "趋势研判", "企业战略"}` 时优先，追求纵横交汇的可执行模板
- **二者不互斥**：GoT controller 阶段会评分两条路径的 ROI，可在主框架中段自动切换
- **agent 分工差异**：S-T-D 主导时 spatial/temporal/domain 三 researcher 平行覆盖；双轴主导时 temporal 跑纵轴 5 步、spatial 跑横轴 A/B/C 决策树
- 详见 [`dual-axis-methodology.md`](dual-axis-methodology.md)
