# 焊接策略决策树 + 文档类型适配表

## 1. 三策略定位

| 策略 | 极性 | Faigley-Witte 落点 | 本质动作 | 典型触发软处 |
|---|---|---|---|---|
| **整章注入** Chapter-Injection | additive（主线） | 意义层 × 宏观论旨 | 增补承重论证骨架/新分析章节，洞察熔为承重结构 | 论证断层 / 证据缺位 / **backing缺失**（桥墩悬空，建背书层） |
| **措辞纠偏** Phrasing-Correction | corrective | 表层×微观 或 意义×微观 | 改写局部命题/修事实瑕疵/补单句证据/补出隐含推理许可 | 措辞含糊 / 措辞失准 / **warrant缺失(微观)** |
| **口径降格** Stance-Downgrade | corrective(防御) | 意义层 × 微观/宏观 | 把过强断言降为有限断言(hedge)，加真值限定符防反例 | 口径过强 / 反例未防御 |

## 2. 决策树（对每个软处 SS-i，读 softness_type + fw_* + claimcheck_status）

```
┌─ claimcheck_status == hallucinated ?
│   └─YES → 【不焊接】剔除，记入幻觉日志（CLAIMCHECK 红线）
│   └─NO ↓
├─ softness_type == backing缺失（warrant 已述，但本身无机制/先例/理论背书，桥墩悬空）?
│   └─YES → 【整章注入】(additive·意义×宏观) ← 成段成章建「背书层」（贵）
│   └─NO ↓
├─ softness_type == warrant缺失（数据与结论俱在，独缺「凭什么由此及彼」的隐含推理许可）?
│   └─YES → fw_micro_macro == 宏观 ?
│            └─YES → 【整章注入·缩微版】显式写出推理许可 + 1-2 段支撑
│            └─NO  → 【措辞纠偏】补出隐含许可单句即可（便宜）
│   └─NO ↓
├─ softness_type ∈ {论证断层, 证据缺位, 反例未防御} ?
│   └─YES ↓
│       ├─ fw_micro_macro == 宏观（动摇全文论旨 / 需成段成章论证）?
│       │     └─YES → 【整章注入】(additive·意义×宏观) ← 主力
│       │     └─NO  → fw_surface_meaning == 意义 ?
│       │              └─YES → 【整章注入·缩微版】注入 1-2 段承重论证
│       │              └─NO  → 【措辞纠偏】补单句证据即可
│   └─NO ↓
├─ softness_type == 口径过强（断言强度超出证据支撑）?
│   └─YES → 【口径降格】(corrective 防御·意义层) ← CLAIMCHECK 驱动
│   └─NO ↓
└─ softness_type ∈ {结构错位, 措辞含糊} ?
    └─结构错位(宏观) → 【整章注入】的「重排」子动作（移动/合并段落）
    └─措辞含糊(表层微观) → 【措辞纠偏】(corrective·表层×微观) 收尾批处理
```

> ⚠️ **判定优先级铁律(additive 优先)**：同一轮焊接，**先做完所有【整章注入】(additive)，再做【口径降格】，最后批处理【措辞纠偏】**。additive 是默认主线；纯表层措辞润色降级为收尾，不得占用主力预算。

## 3. 按文档类型的焊接策略适配表（P3 选策略前先查此表定基调，再逐点跑决策树微调）

| 基底 → 产物 | 整章注入 | 措辞纠偏 | 口径降格 | 质量门侧重 | 适配理由 |
|---|:--:|:--:|:--:|---|---|
| **分析稿 → 深度研究/方案稿** | 高 | 低 | 中 | **G3 宏观一致性**（新承重墙不能与原叙事冲突） | 软处集中在证据缺位+口径过强 |
| **CQI 清单 → SKILL.md/强化方案** | 高 | 中 | 低 | **G2 逐条落地**（每条问题/改进都落成一条可执行规则） | 软处是 warrant/backing 缺失，须补「现象→根因→规则」推理桥与背书 |
| **文献综述 → 方法论/设计稿** | 中 | 中 | 中 | **G1 反幻觉**（命名查证、引用可达性最易翻车） | 软处在缝合处与命名，引文密集易幻觉 |
| **规范文档 → 强化规范/SKILL.md** | 低 | 高 | 高 | **G4 反「只换措辞」**（须真堵反例，不是改说法） | 软处是反例未防御+措辞含糊，重在收紧边界 |
