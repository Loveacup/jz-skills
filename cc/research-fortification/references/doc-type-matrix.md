# 基底文档类型矩阵 + 洞察源矩阵 + IC 契约

> P0/P1 开工前先把基底对号入座，拿到「该重点找哪种软处」的先验；再按基底类型选对透镜源。先验错配会让 P1 漏掉主力软处。

## 1. 基底文档类型矩阵（血肉的形态决定软处分布）

| 基底类型 | 血肉特征 | 承重论点常见形态 | 典型软处分布 | 主导焊接策略 | 焊接产物形态 |
|---|---|---|---|---|---|
| **技术/战略分析稿** | 架构图、伪代码、接口、路线图齐全 | 「形态联想」「自我宣称」式判断 | **证据缺位 + 口径过强** | 整章注入 ＋ 口径降格 | 深度研究/方案终稿 |
| **CQI 改进清单/问题日志** | 真实问题现象、复跑记录、任务 ID 翔实 | 「根因诊断」「改进方向」凭直觉 | **warrant/backing 缺失 + 论证断层** | 整章注入(补根因论证) ＋ 措辞纠偏 | 强化 CQI 方案 / **SKILL.md 规则** |
| **方法论/文献综述稿** | 框架完整、引文密集、范式齐备 | 多范式「缝合处」、命名、理论→落地路径 | **结构错位 + 反例未防御** | 整章注入(补缝合论证) ＋ 措辞纠偏 | 方法论方案/设计规格 |
| **流程/规范文档(SKILL.md类)** | 步骤、约束、模板、门禁齐备 | 「规则有效性」「边界完整性」「门禁可执行性」 | **反例未防御 + 措辞含糊** | 口径降格 ＋ 措辞纠偏 | 强化版规范/SKILL.md |

## 2. 洞察源矩阵（钢筋的来源可插拔）

洞察稿真正不可让渡的是**「透镜外置 + 承重论点批判 + 证据锚」三条契约**，而非由哪个 skill / 谁来产。

| 洞察源 | 形态 | 最适配基底类型 | 透镜外置保证 |
|---|---|---|---|
| **本 skill 多透镜自产**（默认） | RUN-1 的 lens-diagnostician×N 互盲并行 | 通用 | fresh-context subagent + 基底为外部输入（没写过它）|
| **A. strategic-insight 长文** | SI skill 结构化洞察长文（独立 run）| 技术/战略分析稿、需竞品/趋势对标 | SI 独立 run + 内部多 agent 多视角 |
| **B. 人工专家评审稿** | 领域专家手写批判 | 强领域门槛、合规/法务/医疗 | 专家≠基底作者，天然外部视角 |
| **C. 另一独立 CC 深研稿** | 第二 CC 会话独立自采自证 | 怀疑基底信源偏窄、需独立复核 | 全新 session + 不投喂基底 |
| **D. 对抗视角 red-team 稿** | 以「证伪者」立场专找反例 | 高风险结论、发布前压测 | 独立会话 + 角色设为对立面 |
| **E. 运行实证/CQI 诊断稿** | 从真实运行日志/问题复跑/用户反馈反推根因 | CQI 清单、规范/SKILL.md 文档 | **运行实证 ≠ 设计自述**：日志是跑出来的事实，对设计稿天然外置 |

> **CQI 日志的双重身份**：同一份 CQI 日志既可作**基底**（被加固成 SKILL.md），也可作**洞察源 E**（运行实证当透镜照「设计自述」类规范）。判定看它本轮充当血肉还是钢筋——充当钢筋时必须过 IC-1..5 契约关。
>
> **基底内夹带实证段的处理**：当基底（作血肉）内部含「已采取的改进/已复跑/运行结果」这类实证自述段，**仍按承重论点处理**——它宣称的「已闭环/已生效」是可被审视的承重断言（改了 ≠ 根因消除，CQI 闭环需复测证据）。不要把它当「已落地的钢筋」豁免批判；若其真伪须基底外信息，标 `claimcheck=needs-external` 上报。

## 3. 洞察源接口契约（任何源都必须满足的最低规格）

```
[IC-1] 独立上下文产出（透镜外置）：洞察在与「基底生成」隔离的上下文/视角产出。
        默认 = RUN-1 的 fresh-context subagent（基底是外部输入，subagent 没写过它，互盲并行）；
        外部 CC 源 = 独立 run/session 不投喂基底作者上下文；人工源 = 作者≠基底作者；
        运行实证源 = 日志/反馈本身即外部事实。违反 = 自审，作废。
[IC-2] 含可定位的承重论点批判：逐条点名基底承重论点，给 [成立/存疑/证伪/需补证] + 可定位锚(章节/行号)。
[IC-3] 每条批判带证据锚：≥1 个(URL/qmd hit/可复核数据/运行日志条目/具名反例)。无锚剔除(对齐 CoV L1)。
[IC-4] 结构化、机器可焊：每条洞察 = {锚点, 判定, 批判正文, 证据锚, 焊接建议} 五元组，使 RUN-2 welder 可逐条映射 W 清单。
[IC-5] 覆盖率自证：文末附「承重论点覆盖清单」，给定候选承重点逐条被处理(可增不可漏)。
```
