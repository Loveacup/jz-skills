## Read 查询流程

```
用户输入："这周的安排"
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  解析意图                                                        │
│  • 查询类型：本周日程                                             │
│  • 时间范围：本周一至本周日                                        │
└─────────────────────────────┬───────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  执行查询                                                        │
│                                                                 │
│  osascript -e '                                                  │
│    tell application "Calendar"                                   │
│      -- 获取所有日历的本周事件                                     │
│      tell calendar "个人"                                         │
│        events whose (start date ≥ 本周一 AND start date ≤ 本周日) │
│      end tell                                                    │
│      tell calendar "工作"                                         │
│        events whose (start date ≥ 本周一 AND start date ≤ 本周日) │
│      end tell                                                    │

## Update 修改流程

```
用户输入："把明天的网球课改到 4 点"
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  解析意图                                                        │
│  • 操作：Update                                                  │
│  • 修改内容：时间 / 日期                                         │
│  • 新值：16:00 或 新日期                                         │
└─────────────────────────────┬───────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  判断修改类型                                                     │
│                                                                 │
│  ┌─────────────────────┐    ┌──────────────────────────────┐   │
│  │   仅改时间           │    │   改日期（移动事件）          │   │
│  │   (同一天)          │    │   (跨天)                     │   │
│  │                     │    │                              │   │
│  │  可以只改 hours/     │    │  ⚠️ 不要直接改 start/end     │   │
│  │   minutes           │    │  date — 会报 -10025 错误     │   │
│  │                     │    │                              │   │
│  │                     │    │  ✅ 用 delete + recreate     │   │
│  │                     │    │  (见 applescript-operations  │   │
│  │                     │    │   的「移动事件」章节)          │   │
│  └─────────────────────┘    └──────────────────────────────┘   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  查找事件                                                        │
│  • 关键词：网球课                                                │
│  • 时间：明天                                                    │
│  • 查询所有日历                                                   │
└─────────────────────────────┬───────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  匹配结果                                                        │
│                                                                 │
│  找到 2 个匹配事件：                                              │
│  1. 2月6日 17:00 网球课-Naomi（Naomi 日历）                       │
│  2. 2月6日 17:00 网球课-Zelda（Zelda 日历）                       │
│                                                                 │
└─────────────────────────────┬───────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  询问用户选择                                                     │
│                                                                 │
│  ❓ 找到多个"明天的网球课"，请选择：                              │
│                                                                 │
│  [ ] 1. 2月6日 17:00 网球课-Naomi（Naomi 日历）                  │
│  [ ] 2. 2月6日 17:00 网球课-Zelda（Zelda 日历）                   │
│                                                                 │
└─────────────────────────────┬───────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  用户选择：1（Naomi）                                             │
└─────────────────────────────┬───────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  执行修改                                                        │
│                                                                 │
│  osascript -e '                                                  │
│    tell application "Calendar"                                    │
│      tell calendar "Naomi"                                        │
│        set start date of (first event whose summary contains "网球课") ││          to date "Friday, February 6, 2026 at 4:00 PM"                 │
│      end tell                                                     │
│    end tell'                                                      │
│                                                                 │
└─────────────────────────────┬───────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  返回确认                                                        │
│                                                                 │
│  ✅ 已将 2 月 6 日 17:00 的网球课改为 16:00                       │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 信息合并 vs 拆分流程（2026-02-05 新增）

```
用户输入：新事件
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  检测到目标日期已有事件                                           │
│  • 查询目标日历当日所有事件                                       │
│  • 比对标题、时间、备注                                          │
└─────────────────────────────┬───────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  判断：同一活动还是不同活动？                                      │
│                                                                 │
│  ┌───────────────────────────────────────────────────────────┐  │
│  │  同一活动                                                    │  │
│  │  • 标题相同（如都是"休业式"）                               │  │
│  │  • 标题相似（如"休业式"+"休业式+烘焙"）                     │  │
│  │  • 同一活动的细节补充                                        │  │
│  └────────────────────────────────────────┬────────────────────┘  │

## AppleScript 命令速查

### Calendar.app

```applescript
-- 获取所有日历
tell application "Calendar"
    get name of every calendar
end tell

-- 获取指定日历的事件
tell application "Calendar"
    tell calendar "Naomi"
        events
    end tell
end tell

-- 创建事件
tell application "Calendar"
    tell calendar "个人"
        make new event with properties {summary:"🏥 医院复诊", start date:date "...", end date:date "..."}
    end tell
end tell

-- 删除事件
tell application "Calendar"
    tell calendar "工作"
        delete (first event whose summary contains "会议")
    end tell
end tell

-- 修改事件
tell application "Calendar"
    tell calendar "Naomi"
        set summary of (first event whose summary contains "网球课") to "🏃 网球课-乐不思"
    end tell
end tell
```

### Reminders

```applescript
-- 获取所有列表
tell application "Reminders"
    get name of every list
end tell

-- 获取列表中的提醒
tell application "Reminders"
    tell list "家庭"
        get every reminder
    end tell
end tell

-- 创建提醒
tell application "Reminders"
    tell list "家庭"
        make new reminder with properties {name:"买牛奶", due date:date "..."}
    end tell
end tell

-- 删除提醒
tell application "Reminders"
    tell list "家庭"
        delete (first reminder whose name contains "牛奶")
    end tell
end tell
```
