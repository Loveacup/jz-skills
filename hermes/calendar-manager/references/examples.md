# 示例场景

## 创建日程示例

### 示例 1：添加网球课

**用户输入：**
```
下周三下午 3 点网球课
```

**处理过程：**
1. 解析意图：标题"网球课"，时间"下周三 15:00"
2. 类型判断：日历事件
3. 日历归属：询问用户（无孩子关键词）
4. 用户确认：Naomi
5. 重复检测：无重复
6. 智能增强：匹配默认地点（冠享网球俱乐部），添加 emoji
7. 格式化输出

**创建结果：**
```
🏃 网球课-Naomi
时间：2026-02-12（周三）15:00
地点：冠享网球俱乐部（滨江区信诚路 99 号西门一百米）
提醒：提前 1 小时
```
