# 部门盘点与吏部专家分际

## 规则（父皇亲定，2026-05-19）

- **部门 agent / 三省六部职能名册**：由三省/尚书调度体系（dispatcher）盘点。问"有哪些可用部门/谁管什么事"→找 dispatcher。
- **专家/人才库**：才归吏部（registry）。问"有哪些外部专家/哪个专家适合此任务"→找吏部。
- **监国太子**：不得亲自跑 `hermes profile list`。只承旨、定级、派工、把关。

## 反例

- ❌ 吏部盘点部门 — 越界
- ❌ 太子亲跑 profile list — 越界
- ✅ dispatcher 盘点部门 agent
- ✅ 吏部盘点 agency-agents-zh 精选 28 位专家

## 来源

用户纠正：原话 "不应该吏部盘点部门，这应该是三省的活，吏部要盘点专家才是"
