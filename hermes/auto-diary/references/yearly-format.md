# 年报格式规范

本文档定义年报 markdown 的完整输出格式。生成年报时读取此文件获取格式要求。

## 数据源

🔴 **年报聚合自当年月报（周←日 · 月←日 · 年←月）**：直接 `Read` `50-Self/06_月报/` 下当年所有 `YYYY-MM月报.md`。
月报缺失的月份 → 降级直接读该月日记补充，并在脉络表标注 `(无月报，据日记)`。

## YAML Frontmatter

```yaml
---
status: 常青
type: 年报
priority: 重要
aliases: [YYYY年度总结, YYYY年复盘, Yearly-YYYY]
tags: [年报, 总结, 复盘, 年度]
created: YYYY-MM-DD
modified: YYYY-MM-DD
---
```

> 遵循库 CLAUDE.md：所属区域由路径决定，**不写 class 字段**。

## 文件命名

`YYYY年报.md`（如 `2026年报.md`）

## 输出路径

`~/Documents/Obsidian/AlexCai/50-Self/07_年报/`

## 段落结构（按此顺序）

### 1. 标题 + 速览

```markdown
# 年报：YYYY 年

> [!abstract] 📋 年度速览
> - 📅 覆盖 N 月（有月报 M 月）
> - 🎯 年度主线：主线1 · 主线2 · 主线3
> - 🏆 年度高光：最重要的 1-2 件事
> - 📚 知识库年度新增 N 篇
```

### 2. 🎯 年度主线（倒金字塔顶层）

```markdown
## 🎯 年度主线

> 用 3-6 条叙事概括全年最重要的脉络，每条跨多个月。

1. **主线名**：全年演进叙事（关联 [[相关月报]]）
2. ...
```

- 从 12 篇月报的「🎯 本月主线」中提炼贯穿全年的大主题
- 🔴 年报是"主线的主线"，不复述月度细节

### 3. 📈 年度脉络（按月）

```markdown
## 📈 年度脉络

| 月份 | 关键词 | 高光 | 月报 |
|------|--------|------|------|
| 1月 | 关键词 | 高光事件 | [[2026-01月报]] |
| ... | | | |
```

- 12 行，每月一行，链接对应月报
- 月报缺失标 `(无月报，据日记)`

### 4. 🏆 年度高光与转折

```markdown
## 🏆 年度高光与转折

### 高光时刻
- 事件 + 时间 + 意义

### 关键转折
- 改变方向的决策/事件
```

### 5. 🔍 年度主题与洞察

```markdown
## 🔍 年度主题与洞察

### 贯穿全年的主题
1. **主题**：全年视角的提炼

### 年度洞察
- 一年沉淀下来的高层模式、成长、教训
```

### 6. 📊 年度数据

```markdown
## 📊 年度数据

- **覆盖月份**：N 月（有月报 M 月）
- **AI 会话年度累计**：🐴 Hermes N · 💻 CC N
- **知识库年度新增**：N 篇
- **主要关注领域演进**：上半年 X → 下半年 Y
- **核心人物**：人物1、人物2
```

### 7. 💡 来年展望

```markdown
## 💡 来年展望

1. **方向**：年度级目标
```

### 8. 🔗 相关链接

```markdown
## 🔗 相关链接

### 月报
- [[2026-01月报]] · [[2026-02月报]] ...

### 里程碑
- [[关键项目/文档]]
```

### 9. 页脚

```markdown
---

> [!tip] 💡 提示
> 年报由 auto-diary skill 自动生成 — YYYY-MM-DD HH:MM · 请补充年度复盘后删除此 callout
```

## 校验

生成后运行 `python3 {baseDir}/scripts/verify_report.py <年报文件>`，FAIL 则对照本 spec 重写直到 PASS。
