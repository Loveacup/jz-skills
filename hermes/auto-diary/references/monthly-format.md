# 月报格式规范

本文档定义月报 markdown 的完整输出格式。生成月报时读取此文件获取格式要求。

## 数据源

🔴 **月报聚合自当月日记（周←日 · 月←日 · 年←月）**：直接 `Read` `50-Self/01_日记/` 下当月所有 `YYYY-MM-*.md`（含已归档到 `归档/YYYY-MM/` 的）。
不要依赖 `collect_data.py weekly`（未实现）。也可参考当月已生成的周报作为骨架补充，但**事实以日记为准**。

## YAML Frontmatter

```yaml
---
status: 常青
type: 月报
priority: 正常
aliases: [YYYY年M月总结, MM月复盘, Monthly-YYYY-MM]
tags: [月报, 总结, 复盘]
created: YYYY-MM-DD
modified: YYYY-MM-DD
---
```

> 遵循库 CLAUDE.md：所属区域由路径决定，**不写 class 字段**。

## 文件命名

`YYYY-MM月报.md`（如 `2026-05月报.md`）

## 输出路径

`~/Documents/Obsidian/AlexCai/50-Self/06_月报/`

⚠️ 与周报目录（`02_周报/`）**平级**。

## 段落结构（按此顺序）

### 1. 标题 + 时间范围

```markdown
# 月报：YYYY年M月

> [!abstract] 📋 本月速览
> - 📅 覆盖 N 天日记（有实质内容 M 天）
> - 🎯 核心主线：主线1 · 主线2 · 主线3
> - 🐴 Hermes 累计 N 会话 · 💻 CC 累计 N 会话
> - 📚 知识库新增/修改 N 篇
```

### 2. 🎯 本月主线（倒金字塔顶层）

```markdown
## 🎯 本月主线

> 用 3-5 条叙事概括本月最重要的进展，每条点出"做了什么 + 推动了什么"。

1. **主线名**：跨多天的叙事概括（关联 [[相关周报]] / [[关键日记]]）
2. ...
```

- 从当月所有日记的「🎯 每日总结」三问中提炼跨日主题
- 🔴 严禁罗列每日流水账；要聚合成主线

### 3. 📈 月度脉络（按周）

```markdown
## 📈 月度脉络

| 周次 | 时间范围 | 关键词 | 周报 |
|------|----------|--------|------|
| W18 | 5/?-5/? | 关键词 | [[2026-W18周报]] |
```

- 每个 ISO 周一行，链接到对应周报（若该周报存在）
- 周报不存在则备注 `(无周报)`

### 4. ✅ 行动项滚存

```markdown
## ✅ 行动项滚存

### 本月完成
- [x] 事项（来自 M/D）

### 滚入下月
- [ ] 事项（来自 M/D 提及，仍未完成）
```

- 收集当月所有日记 `- [ ]` 未完成项，去重，标来源日期

### 5. 🔍 主题与洞察

```markdown
## 🔍 主题与洞察

### 核心主题
1. **主题**：简述 + 关联 [[wikilink]]

### 关键洞察
- 跨周/跨项目的高层模式、决策、教训
```

### 6. 📊 数据统计

```markdown
## 📊 数据统计

- **日记天数**：N 天（有实质内容 M 天）
- **AI 会话**：🐴 Hermes N · 💻 CC N
- **知识库**：新增 N · 修改 N
- **主要关注领域**：领域1、领域2、领域3
- **主要人物提及**：人物1（N 次）、人物2（N 次）
```

### 7. 💡 下月重点

```markdown
## 💡 下月重点

1. **方向**：具体计划
```

### 8. 🔗 相关链接

```markdown
## 🔗 相关链接

### 周报
- [[2026-W18周报]] · [[2026-W19周报]] ...

### 重要日记
- [[50-Self/01_日记/归档/YYYY-MM/YYYY-MM-DD|YYYY-MM-DD]]

### 项目与人物
- [[项目/人物]]
```

- 归档日记用归档路径 wikilink

### 9. 页脚

```markdown
---

> [!tip] 💡 提示
> 月报由 auto-diary skill 自动生成 — YYYY-MM-DD HH:MM · 请补充个人复盘后删除此 callout
```

## 校验

生成后运行 `python3 {baseDir}/scripts/verify_report.py <月报文件>`，FAIL 则对照本 spec 重写直到 PASS。
