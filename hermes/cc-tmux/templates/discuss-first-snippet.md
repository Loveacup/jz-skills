# discuss-first-snippet — Pre-Send 理解对齐片段

> **用途**：in-turn wait 三段协议「节点① 发任务前讨论」的可复用 context 片段。
> **怎么用**：把下面 `>>> 粘贴起 <<<` 区块**追加到任务 context 文件末尾**，再 `cc-send.sh` 发送。
> **为什么需要**：`cc-send.sh` 只传文件路径、不加工内容，CC 读完 context 默认直接开干、不会自停。
> 没有这段，节点① 的「等 CC 读完 → 看理解 → 讨论」就没有可插入的停顿。
> **何时跳过**：决策树判定无需 Pre-Send 讨论的简单/机械任务。这是 convention，非脚本强制。

## ⏸️ 先停下，别直接执行

在动手之前，请先做并**只做**这一步，然后停下等我确认：

1. **复述理解**：用 2-4 句话说明你对本任务的理解——目标、产物、关键约束。
2. **列关键决策点**：你打算怎么做？有哪些地方你不确定、或有多个走法需要我拍板？
3. **停**：复述完就停，**不要开始写代码/跑命令/改文件**。等我回复「确认」或「按 X 调整」后再开干。

> 如果任务里有「保存到文件」「测试覆盖」等硬性要求，复述时一并确认你接收到了。

>>> 粘贴止 <<<
