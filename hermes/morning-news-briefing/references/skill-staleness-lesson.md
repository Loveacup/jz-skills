# 技能腐化与实战优先原则 (2026-05-27)

## 触发事件

父皇在跑早新闻时两次纠正：
1. "skill 的规定老旧了啊，你要按你的来"
2. "skill 里的所有链路都老旧了，你按你的来"

## 根因

`morning-news-briefing` skill 在多次修补中积累了自相矛盾的规则：
- 一处说"默认手机 PDF"（2026-05-26 纠正）
- 另一处说"默认文字版"（同一天的另一纠正）
- plan-preview 分"文字版可选 / PDF版强制"两档，但实际已统一为全 PDF 交付

这些矛盾导致 agent 读取 skill 后选了错误的默认值。

## 原则

1. **Skill 文本可能滞后于实战**：skill 是知识快照，父皇的口头纠正、实战中的流程演进可能未及时回写
2. **优先实战记忆**：当 skill 文本与近期实战模式冲突时，以近期实战为准
3. **父皇的原话 > skill 文本**：父皇说"按你的来"意味着信任实战积累的模式，而非照搬陈旧 skill
4. **及时回写**：发现冲突后立即 patch skill，不积累技术债

## 本 session 修复

- 删除冲突的"文字版默认"规则
- 简化 plan-preview 为统一强制
- 默认交付形态统一为手机版 PDF
