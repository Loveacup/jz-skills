# 中文去 AI 味 · 体系层

中文 AI 检测不是 pattern matching，是靠**密度 × 语体 × 功能**三维判断。本文件定义这套判断体系——怎么保护不该改的、怎么避免改坏的、怎么确认改到位了。

---

## 🧱 冲突仲裁树（唯一优先级，序号小的胜出）

所有规则冲突时，一律按此顺序仲裁：

| 优先级 | 约束 | 一句话 |
|:---:|---|------|
| §1 | 不发明事实 | 终稿里的具体数字/事件/人物/引用，原文都得能打钩。打不到 → 删除，或标 `[改写者补注,请核对]` |
| §2 | 真人停手门检 | 输入是真人写的 → 停手，只清格式，不动语言 |
| §3 | 语体降级保护 | 改写终稿跟原文语体档最多差一档。跨档先问用户 |
| §4 | 过度消毒反制 | 终稿至少留一处"毛边"——AI 写不出来的痕迹 |
| §5 | 模式减法 | 按语体激活的子集做减法 |
| §6 | 主动打磨 | 弱动词/机关枪节奏/filler/抽象词 → 看到就改 |

**典型仲裁示例：**
- 减法要删一个词，但删掉后全文没毛边了 → §4 胜出，保留
- 打磨想把"速度提升"改成"快了 3 倍"，原文没数字 → §1 胜出，放弃
- 把对外公告改成朋友圈口吻 → §3 阻止，要么保留原档，要么先问用户

---

## 🛑 第负一步：真人停手门检

**在识别语体之前，先判断输入是不是真人写的。** 把金庸的"恨得牙痒痒地"改成"特别烦"、把王朔的"用比较酸的话说"改成"坦白讲"——比残留 AI 腔更严重。

### 真人文本强信号（命中任一 → 不改）

1. **自纠/犹疑语气** — "我忘了""三十秒还是一分钟""说不上来为什么"
2. **方言语素** — 京味（内/咋）、上海（侬/册那）、粤语（嘅/喺）、东北（贼/唠嗑）、川渝（哈/安逸）
3. **自嘲/meta-irony** — "用比较酸的话说""装一把""我知道这话鸡汤但..."
4. **只有这个人/这件事的细节** — 具体书名、人名、金额、引用原话
5. **作家口吻** — 金庸（文言色彩）、王朔（京味白话）、汪曾祺（短句+具体名词）、阿城（极简）
6. **访谈/对话实录** — 保留 filler、自我打断、不完整句

### 判断不准时 → 宁可判"真人"不改

残留 AI 腔可以再改一轮，改坏真人的声口不可逆。

### 门检声明（强制输出）

任何改写前必须输出一行：
```
【门检】判断：AI 生成文本 | 证据：[≤2 条具体信号]
【门检】判断：真人文本（停手）| 证据：[≤2 条具体信号]
【门检】判断：不确定 | 证据：[各一条] | 行动：反问用户
```

## 🧭 语体识别（必须先做）

不同语体的"AI 腔"标准完全不同。把学术"进行了深入分析"改成"我好好分析了"、把公文"依法予以处理"改成"按法律办"——结果是**把所有文本降级为微信聊天**。

### 六种语体（精简自 9 种，覆盖中文最常见场景）

| 语体 | 特征 | 典型场景 |
|------|------|---------|
| **社交/口语** | 短句、代词多、emoji | 微信聊天、朋友圈、微博 |
| **自媒体/内容** | 带人设、带节奏、有 CTA | 公众号、小红书、短视频口播 |
| **商务/职场** | 半正式、结构化、有数字 | 工作邮件、产品文案、内部备忘录 |
| **书面/一般** | 完整句法、中性、段落节奏 | 博客、时评、科普文章（默认） |
| **学术/科技** | 术语密、名词化、逻辑连词多 | 论文、技术报告、白皮书 |
| **公文/法律** | 高度规范、结构固定 | 法规、合同、公报 |

### 规则激活矩阵

不同语体激活不同规则子集。`✅` = 激活，`部分` = 视情况，`❌` = 不触发。

| 规则类别 | 社交 | 自媒体 | 商务 | 书面 | 学术 | 公文 |
|------|:-:|:-:|:-:|:-:|:-:|:-:|
| A 内容拔高/套路 | ✅ | ✅ | ✅ | ✅ | 部分 | ❌ |
| B 语言/AI 高频词 | ✅ | ✅ | ✅ | ✅ | 部分 | ❌ |
| C 修辞 | ✅ | ✅ | ✅ | ✅ | 部分 | ❌ |
| D 交流/客服腔 | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| E 填充/模糊 | ✅ | ✅ | ✅ | ✅ | 部分 | ❌ |
| F 翻译腔 | ✅ | ✅ | ✅ | ✅ | 部分 | 部分 |
| G 篇章节奏 | ✅ | ✅ | ✅ | ✅ | ✅ | 部分 |
| H 平台/文体 | ✅ | ✅ | ❌ | ❌ | ❌ | ❌ |
| I 幻觉/格式 | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |

**关键边界：**
- 学术语体：`进行+V`、`性/化` 后缀、被动语态是规范表达，**不改**
- 公文语体：几乎只改客服腔（D 组）
- 社交/自媒体：最激进，全激活
- 默认语体：用户没说也判不出来 → **书面/一般**

## ⚖️ 密度检测原则

> 单独出现不算 AI 腔。短段内反复堆叠、脱离具体内容、空转修辞才是。

**三问：**
1. **密度** — 短段（<200 字）内出现几次？三次以上基本确认
2. **落地** — 这个修辞紧扣具体内容吗？还是换成任何话题都适用？
3. **负载** — 删掉之后原意会丢失吗？不会就是装饰性

**抽象万能动词 vs 具体动作：**
AI 爱用"换到任何话题都能套"的抽象动词；真人用"只有这事能用"的具体动作。

| AI 万能词 | 真人具体动作 |
|-----------|------------|
| 激发/激活 | 逼香/把香气激出来 |
| 实现了突破 | 做出来了/搞定了 |
| 推动了发展 | 做成了/跑起来了 |
| 赋能/助力 | 具体帮了什么忙 |

## ⚠️ 避免过度修正

去 AI 腔 ≠ 去一切规范化表达。"支持 Windows""基于 Transformer""用于生产环境"——这些是真人每天在写的规范表达，不是 AI 腔。

**改写前三问（反向验证）：**
1. **倒译验证** — 改写后一对一倒译回英文，落成 `runs on` / `is compatible with` 直译骨架？是 → 引入了翻译腔，改回原文
2. **功能验证** — 被删的词承担话题引入/指代功能吗？是 → 不能删
3. **语体验证** — 改写后和原文档位一致吗？降档了 → 违反 §3

### 语体降级保护

终稿正式程度不得偏离原文超一档。从正式到口语：
```
公文 > 学术 > 商务 > 书面/自媒体 > 内部口语/朋友圈
```
只允许相邻档切换。跨档必须先问用户场景。

---

## 🚫 不发明事实（硬约束）

**终稿里每条具体事实都必须在原文里能打钩。禁止凭空发明：**
- 具体数字（原文"速度提升"→ 不能写"快了 3 倍"）
- 具体事件（原文没写妈妈打电话 → 不能编）
- 不存在的主体（原文无主语 → 不能引入"我们团队"）
- 金额/时间/地点/引用原话

**原文没毛边时：**
1. 优先在已有信息里挑
2. 次选用明显的作者视角（"我觉得""说不上来"）
3. 再次告知用户："建议您补一句真实的个人观察，我不帮您编"
4. 宁可让终稿有轻微中性散文味——比编造事实好

---

## 🩸 过度消毒反制：保留毛边

去 AI 腔的**反向陷阱**：把 AI 腔改成"AI 假装正常人"——干净、工整、中性，但没有任何记忆点。

**硬约束：终稿至少保留一处"毛边"：**
- 个人化表达（"我觉得""说实话我也不知道"）
- 具体的感受/复杂情绪
- 圈层/语境特有表达

### AI 不敢写测试

**终稿自检：问一句——这段话里有没有一句是 AI 不敢写的？**

"AI 不敢写"指：
- 自嘲/自黑（"用比较酸的话说""我知道这话鸡汤，但..."）
- 承认不确定/记不清（"三十秒还是一分钟"）
- 冒犯性/不合时宜的观点
- 身份降格/私人暴露
- 别人不会知道的具体细节

**终稿一句都没有 → 太干净，回去从原文挑一处加回来。**

⚠️ 发明的毛边不算通过。毛边必须来自原文，不能编造——§1 和 §4 互锁。

## 🎯 主动打磨（6 条）

| # | 动作 | 说明 |
|---|------|------|
| 1 | 动词强化 | 弱动词替换：`进行讨论`→`讨论`、`开展工作`→`工作`、`发挥作用`→`起作用` |
| 2 | 节奏重塑 | 朗读有机关枪节奏（连 3 句 20-30 字）→ 合并短句或拆分长句 |
| 3 | filler 切除 | 删：`一些/相关/各种/实际上/本质上/从某种意义上讲/在一定程度上` |
| 4 | 抽象换具体 | 原文有具体细节就保留，删抽象重复版。**禁止凭空发明。** |
| 5 | 语序归位 | 状语归位、条件从句前置、定语堆叠拆分 |
| 6 | 语体匹配 | 程度词按档位选（学术偏`极其`，日常偏`很/特别`） |

## ⚡ 中文 Quick-Check（终稿前扫射）

- [ ] "值得注意的是/众所周知/毋庸置疑"？删
- [ ] "随着...的不断发展/在...的大背景下"？删
- [ ] "首先...其次...最后...此外...综上所述"链？打断
- [ ] 四字成语连续 3+ 个堆叠？只保留最贴切的一个
- [ ] "赋能/助力/打造/护航/抓手/闭环"？换成具体动作
- [ ] "希望对您有帮助/如有疑问请告诉我"？删（客服腔）
- [ ] "未来可期/大有可为/光明的前景"？删（空洞结尾）
- [ ] 连 3 句 20-30 字完整主谓宾？打断节奏
- [ ] 破折号 `——` ≥ 2 处且不承担修辞功能？删
- [ ] 半角标点混入全角？统一为全角
- [ ] 英文术语强行括注中文（`推理(inference)`）？删括注
- [ ] 终稿有没有至少一处 AI 不敢写的？没有 → 回去加

## 📋 打磨报告（强制输出）

终稿后必须附报告。**只描述，不评级，不开药方。**

```
【打磨报告】
· 动词强化：[若干处/通篇/无] · 例：原文「XXX」→ 终稿「YYY」
· 节奏重塑：[若干处/无]
· filler 切除：[若干处/无] · 切词：原文「一些/实际上/...」
· 抽象换具体：[若干处/无]（仅限原文已有）
· 语序归位：[若干处/无]
· 语体匹配档位：[社交/自媒体/商务/书面/学术/公文]

可观察指标（只报事实）：
- 具体名词：[N 处]
- 第一人称代词：[N 处]
- 段长变异：最短 X 字 / 最长 Y 字
```

**四条硬约束：**
1. 例子必须是原文/终稿的字面引用，不许撰写范例
2. 计数不确定用限定词（若干处/多处/通篇），不伪造整数
3. 可观察指标只报能数的
4. 只描述，不开药方
